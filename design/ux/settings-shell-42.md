## 1. 类型声明与闭集边界

本 spec 是 `AC-42-F1` 七员闭集**第四员**「**④ 设置界面壳(42)**」(`skeuomorphic-ui.md:1480`)的
per-screen UX spec;模态身份 = `ModalId.SettingsShell`(`adr-013:355`)。

**⚠️ 本员与其余六员的根本差异:它是「壳」,不是「一页内容」。**
规则八(`:233-240`)钉死分权 —— **42 拥有框架与元件**(哪些页签、翻页方式、焦点顺序、样式);
**条目语义归各自系统**(音量/mono ⇒ 44 · 文本缩放 ⇒ 49 · 键位(P1a)⇒ 3)。
本 spec 因此**只规格化壳本身 + P0 在架条目(44)的承载位**,不代 44/49/3 写任何条目语义。
全案**无独立设置系统且不新立**(规则八登记说明,与「不加 #54」取向一致)。

- **`AC-42-G2`(BLOCKING 装配断言)是本壳的宪法**:断言**不存在「42 内缓存一份音量/mono 值」的路径**
  (缓存 = 第二份真相,破规则六)。壳对条目**只转发、不中转存储**。
- **`OQ-42-6` 的两半,本 spec 处置不同**(勿混读):
  ① **壳形态(「一本簿子」还是「一个列表」)** —— 规则八把「框架与元件」判给 **42 拥有**,
  而本 spec 即 42 的屏规格 ⇒ **本节行使该归属权裁定:簿子**(§5.2);`OQ-42-6` 之形态半随之结清,
  回写归 42 GDD 修订轮(**未回写前 GDD 该行不得读成已裁**)。
  ② **条目进壳时间表(键位 3 / textScale 49 何时进壳)** —— 归 42+44/3/49、期限 P1a 前,**仍 open**;
  本 spec 只保证壳的**加页机制不需要结构改造**(§5.2 页签 = 可插拔)。
- **P0 在架条目 = 仅 44**(规则八:「44 的总线音量与 mono 开关 —— 这是 P0 唯一的设置项」;
  44 侧同口径:`audio-system.md:765`「唯一交互面 = 设置菜单里的总线音量滑块 / mono 开关」)。
  ⚠️ 该「唯一」与无障碍档位承诺之间的张力 → ✅ **2026-09-22 `OQ-SS-2` 已裁 = 甲「验收随 49(P2),P0 不早进」**(张力消解:档位验收随 49,P0 维持「唯一设置项 = 44」不变;见 §14 OQ-SS-2 结案行)。

## 2. Purpose & Player Need

玩家把医馆案头的**调治簿**翻开:它不诊疗、不记账 —— 它**校准器具**(耳畔的声响、此刻的纸页、
手上的键)。壳的存在让全部「端侧适配」有唯一去处,从而**其余六屏零内嵌设置**(设置混进器物
= 器物不再诚实,P-06 的版面侧同族)。

**这个屏存在的理由**:
- 44 无任何玩家可见 UI(AC-44 侧明令,音量面板「不属 44」)⇒ 承诺(总线音量 / mono)必须有宿主;
- L-1(改键 UI 推 P1a)= 有意的欠账登记处 —— 壳的页签结构让「欠页」与「无结构」可区分;
- 无障碍承诺若日后落 49,P-10(端本地、不进流)要求宿主与流世界物理隔离 —— 壳天然如此。

**什么会变糟**(若壳被越权实现):
- 42 缓存值 = 第二份真相(AC-42-G2 抓的正是这条):44 快照恢复与壳显值分叉,静默。
- 条目各自开弹窗 = 壳失格:设置散落成六屏的私搭控件,拟物纪律全线渗漏。

## 3. Player Context on Arrival

- **两个入口**:① 主菜单「调治」项;② 游戏内暂停壳内项。二者皆**导航层级目的地**(非上下文模态)。
- **进入前一刻**:① 态无世界;② 态在世界/模态嵌套之上(暂停壳 = 表现层壳,主机 tick 不停 ——
  真源 = `accessibility-requirements.md:128`「随处可暂停」行承 ADR-005,2026-09-22 补点名;
  无障碍认知表「随处可暂停」行的项目化口径,须向玩家显式说明的文案**归 narrative**,此处只留位)。
- **情绪**:低唤醒、事务性;条目改动**即时生效**(音量滑一条,耳中立刻变),无「应用」按钮 ——
  纸器没有「提交」。

## 4. Navigation Position

```
MainMenu / Pause
  └─ 选择「调治」──▶ ModalId.SettingsShell(本屏)
                        ├─ 页签(簿口系绳牌)→ 音频页(P0 唯一页)
                        ├─ 条目焦点 + 调整(§7)
                        └─ 同一入口 toggle(关闭)──▶ 回进入前状态栈
```

- **嵌套合法,双栈非法**:本壳内不叠 `ModalId`(单值约束,规则十四);条目浮出的取词/说明
  一律**页内展开**(纸背注),不开新模态。
- 加页(49/3)在页签机制内完成,**不改本层级**(§5.2)。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **当前页的条目行**(P0 = 音频页诸行) | 行 = 题签(名)+ 控件(值);一屏一页,页不滚动 |
| 2 | **页签(簿口系绳牌)** | 「有哪些类可调」的目录;P0 仅一牌,但牌的**存在位**恒定(加页不改版) |
| 3 | **页背注**(行聚焦后纸背可翻出的一行小注) | 条目的一句话解释;文案归各属主系统(44 给语义,narrative 给字)|
| 4(环境) | 簿外一圈(案面 / 簿脊)| 唤起「簿摊在案上」;零数据 |

层级原则:**行 = 控件,牌 = 目录,注 = 解释** —— 三者各位不重叠;`textScale` 类条目**未来进架时**
同样只落行位(结构零改)。

### 5.2 Layout Zones

裁定(§1 之①):**一本簿子** —— 「调治簿」,非列表、非现代分组面板。等比纸本族的
**「纸页 + 黄铜件」混材变体**(族默认承 `paper-closeup-48.md` §1;本屏特殊性 = 规则五双材质语言的
**首个混材屏**):

1. **页签带**(簿口右缘,纵向系绳牌):P0 = 单牌「声」(音频);预留「形」(49)「手」(3,P1a)
   两牌位 —— **占位牌不渲染**,加页 = 数据驱动显牌(壳零硬编码页集)。
2. **条目页**(右页摊开):每行 = 左半**纸侧**(题签,墨迹元件)+ 右半**黄铜侧**(控件)。
   **材质分界铁律**(规则五 `:1119-1129`):水墨侧**禁**刻度条/进度;黄铜侧**允许錾刻刻度**
   —— 故音量滑块 = **黄铜滑杆**(錾刻刻度 on 铜条,指尖为压花钮),mono = **黄铜拨栓**(二档,
   錾「独听 / 双听」两字于栓位)。**禁**把滑杆画成纸上一条墨杠(= 水墨侧偷用进度形态,元件语言破)。
3. **页背注位**(行下方 ≤1 行,翻纸背显):聚焦行时纸背小注可翻出(焦点意图 + Select,再按收回)。
4. **P0 条目集**(= 44 在架项,语义全归 44,本表只登记承载):
   | 行 | 控件(黄铜侧) | 语义源 |
   |---|---|---|
   | 总听(Master)/ 乐 / 景 / 语 / 效 / 脉(听诊器)/ 牌(UI cue)× 七总线 | 滑杆 + 錾刻刻度 | 44 `AudioMixer` exposed params;总线名 = ADR-018 拓扑的**世界内译名**(译名词表归 narrative+49 轮) |
   | 独听(mono 开关) | 二档拨栓 | **AC-44-13** `[A]` |

   ⚠️ 七总线全开还是只开部分 = 条目密度问题(44 的参数量纲),登记 OQ-SS-3,不代拍。

**加页契约**(壳为 49/3 预留,兑现「时间表仍 open」期间的结构承诺):
新页 = 新牌 + 新页纸,行元件/焦点序/注位全部复用;**壳的代码与布局零改**。
任何「新条目要求壳改结构」= 本契约破,评审时 BLOCKING。
⚠️ **页集是数据驱动的,「一屏一页」不是恒等式**(2026-09-22 /ux-review 轮登记):150% 缩放下
音频页压页拆「器 / 栓」两页 = 本契约的**首批同批先例** —— 拆页走的是**同一注册表目录**(页集条目增减),
非布局改造,契约不破;此读法随本件生效,49/3 进架时沿用。

## 6. States & Variants

| 状态 | 触发 | 表现 |
|------|------|------|
| **未绑定** | 44 参数快照未到达 | 题签全显,控件停于**上次已知位**(读自 44,非缓存);快照缺位 = 控件居中 + 纸背注「器具未校」 |
| **可调**(默认) | 绑定完成 | 调整即时生效(§3),控件位 = 44 当前值的纯投影 |
| **单项失效** | 某 exposed param 在 mixer 中丢失(理论不可达,ADR-014 启动硬失败之外)| 该行题签仍在、控件**卸为平整铜片**(无形态即无权限),页背注一行;整簿不崩 |
| **空页** | 未来某页的条目集为空 | 摊开白纸 + 页脚「此页未设」小注;牌不隐(隐牌 = 目录撒谎)|
| **设备切换**(手柄断开 / 换用键鼠)| 活动输入设备变更 | 本壳**不切布局、不换标签**(规则三:无「模式」痕迹);唯一变化 = P-05 的**设备图标**随活动输入换形 —— 该呈现**归 3 的提示层,壳零自绘**;故本壳**无「设备未接」状态行**:条目失效已由「未绑定 / 单项失效」两通道穷尽(值来自 44,与设备在场无关)|
| **平台变体** | 平面 P0 | 全部如上;**VR 不做**(P1a 重议) |

**无「保存中/已保存」态**:条目即时生效 ⇒ 无提交动作 ⇒ 无任何「成功」呈现
(AC-42-F1 闭集内零 toast 的同族纪律;存档时机归 7a 与设置无关 —— 设置持久走 sidecar
✅ **2026-09-25 OQ-SS-5 = 甲 已裁**,见 §14)。

## 7. Interaction Map

| 动作 | 输入(键鼠) | 输入(手柄) | 即时反馈 | 结果 |
|---|---|---|---|---|
| 开 / 关簿 | 菜单项 / toggle | 同一 action 资产(换绑不换语义 —— P-05 的**意图**侧;其**图标随设备换形**侧本壳无按键提示,不适用)| 摊簿 ≤200ms | 切 `ModalId.SettingsShell`;P-01 门归 UI Toolkit 栈 |
| 移焦(牌 / 行 / 控件)| 指针 = 快捷方式(**点击 / 移入,非悬停判据** —— 本表无鼠标精度纪律)| 官方桥 `NavigationMoveEvent`(P-01,禁自实现)| 焦点墨框压签脚 | 序 = 牌 → 行(自上而下)→ 行内控件 |
| 换页 | 点牌 | 焦点上牌 + Submit | 翻页 | 页集 = 数据驱动(§5.2)|
| 音量调整 | 拖动铜钮 / 滚轮于钮上 | 行聚焦后**左右向 = 定档增减**(錾位逐格;无长按依赖)| 钮随指,耳中即变 | 写 44 exposed param(直写,零缓存)|
| mono 切换 | 点拨栓 | Submit 于栓上 | 栓咔位 | 写 44 |
| 纸背注 | 指针移入行(键鼠)/ 焦点落于行(手柄,零 Submit)| 同 | 纸背翻出/收回 | 纯呈现 |

**双导航等价注**(P-04):手柄下滑杆**不用拖动、不用长按** —— 定档增减把「连续拖动」换成
「逐格拨动」,等价且更快(錾刻度 = 档位可见);键鼠滚轮路径与指针拖拽路径并存。
L-2 的「长按不承诺 toggle 替代」判据:此处**无长按交互被承诺**,故不产生豁免空洞。

**零按键提示**(AC-42-F1 本员判据):全屏零提示浮层;拨栓/滑杆的用法由 48 教(P0 设置面最小,
教学义务登记为对 48 的引用,不在此自教)。

## 9. Transitions & Animations

| 转场 | 规格 | 减动效钩子 |
|---|---|---|
| 开簿 / 关簿 | 摊开 / 合上 ≤200ms | 直接切 |
| 换页 | 翻页(物理纸) | 直接到位移终态 |
| 拨栓 / 滑杆 | 咔位 / 随指(无缓动弹跳 —— 器具没有橡皮筋)| **不挂**(机械位移非动效)|

## 10. Data Requirements

| 数据 | 来源 | 读/写 | 说明 |
|---|---|---|---|
| 七总线音量值 + mono 态 | **44**(`AudioMixer` exposed params 读侧)| **读写直穿** | 壳**零缓存**(AC-42-G2 [L] · 引用集+类型树断言);呈现 = 44 当前值纯函数 |
| 页集 / 行集目录 | 各属主系统的**注册表条目**(44 现架;49/3 未来)| 读 | 「加页契约」的数据面:壳只消费 `{page, row, owner-api-ref}` 目录,不解释语义 |
