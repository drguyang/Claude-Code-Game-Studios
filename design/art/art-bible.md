## 1. 视觉身份声明 (Visual Identity Statement)

### 1.1 一句话视觉规则(锚点原文 · 不得改写)

**「整体用水墨,还原用黄铜。」**
- 凡是表达**「身体作为一个整体」**(经络、气血、证候、情绪)的画面 —— 用**水墨**:晕染、留白、笔触。
- 凡是表达**「身体作为一台机器」**(解剖、器械、缝合、细菌)的画面 —— 用**黄铜工业质感**:金属、齿轮、錾刻刻度、冷光。

**材质归属判据 【本稿扩展 · 提案】**:墨/铜按**画面在这一刻向玩家提出的问题**选边,不按物件身份。
同一把戥子:画面问「这个人的分量配到哪一档」(整体·判断)时属墨侧;问「这台机器哪里坏了」(还原)时属铜侧。
**当材质归属有歧义时,本判据说选:看谁在提问,不看物件是什么。**(服务支柱三)

> **与 `diagnosis-system.md:1474` V-8.0 的一致性**:该件总纪律写「**水墨 = 看(整体、活的、会散)。
> 黄铜与纸 = 记(还原、定格的、算数)**」—— 与本判据同刀。**「看 vs 记」即「谁在提问」的机制侧措辞。**

### 1.2 支撑原则(锚点已定三条 P1–P3 + 本稿新增一条 P4)

**P1 · 两种材质同框**(锚点 · 服务支柱三)
同一画面里墨与铜并存:手术场景 —— 手是黄铜的(器械、精准),胸口呼吸的起伏是水墨的(整体、生命)。
**同框配额 【扩展 · 提案】**:对侧材质须占 ≥5% 画面面积、且至少一个可独立辨认的形属对侧。
**当「要不要同框」有歧义时,本原则说选:减内容,不减材质** —— 装不下两种材质,是因为你想同时讲两个命题。
**反支柱读法**:一框只剩一种材质时,支柱三的「还原 × 整体」退化为「两张皮」。

**P2 · UI 必须可被主角拿在手里**(锚点 · 服务支柱一)
原文测试:这个信息怎么显示?—— 如果它不能画在一本《脉案》、一张纸质地图或一个出诊箱上,就重新设计。
**材质封闭性推论 【扩展 · 提案】**:界面只许使用世界材质表里有的材质。发光进度条、半透明毛玻璃面板
—— 一切需要「世界里不存在的材质」的界面效果都禁止。
**当「这信息很重要但画不到纸上」有歧义时,本原则说选:删信息或改判断结构,不造新载体。**
**反支柱读法**:每一个新增 HUD 元素都是对支柱一的一次投票反对 —— 判断开始替屏幕记住,而不是玩家记住。

**P3 · 唯一例外 = 敌人的黄铜读数条**(锚点 · 服务支柱二、三)
原文:命中或瞄准时出现,脱离战斗数秒后淡出,挂在敌人身上;**主角自己永远没有血条**。
测试:**这个状态该给谁看?—— 敌人可以被仪器读,你自己不能。**
**挂对象封闭名单 【扩展 · 提案】**:读数条只挂敌对实体,永不挂病人、同伴、动物。
「病人状态条」类需求出现时,走 13 的行为反馈语汇(姿态/呼吸/目光),不走 UI。
**当「不给读数条玩家会误判致死」有歧义时,本原则说选:那是关卡信息问题,不是 UI 问题。**

**P4 · 黄铜必须有来历 【本稿新增 · 提案】**(服务支柱四 ∩ 支柱五)
黄铜是这个时代随炮舰入境的外来物:画面里每一处黄铜元素都必须能回答「谁把它带来的、它为什么在这里」。
深山没有商路,就没有手术灯。
**当「画面需要视觉焦点」有歧义时,本原则说选:添一盏灯或一片留白,不添一件器械。**
**反支柱读法**:黄铜一旦沦为蒸汽朋克装饰,支柱四的「时代即关卡」就变成「时代即皮肤」。
> ⚠️ **本条是史实断言**(商路 / 器物分布),状态 = **待 40 考据复核**(见前置声明)。
> **编号说明**:原稿把本条编作「P4」,与锚点给定的 **P1/P2/P3** 顺承,故本件的支撑原则序
> = 锚点三条 + 本稿新增一条 = **P1…P4**,**与支柱编号(一~五)无关,不可混读** ——
> 下文 §2–§4 与 §4.1/§4.2 引用的「P4」一律指**本节的「黄铜必须有来历」**。

## 2. 氛围与状态 (Mood & Atmosphere)

> **主导比记法**:「墨 7 : 铜 3」指画面信息重量 70% 由墨侧语言(晕染/留白/笔触)承担、
> 30% 由铜侧(金属/刻度/冷光)承担。**区分各状态的是这个比值与下面的光参数,不是形容词。**
> **可区分性判据 【本稿提案】**:任意两个状态必须在 {色温、墨↔铜主导比、对比度} 中至少 **2 项**上不同。
> 照明美术觉得两个状态"长得像"时,来查这张表。

| 游戏状态 | 情绪目标 | 光特征 | 墨↔铜 | 形容词 | 能量 | 承载情绪的元素 |
|---|---|---|---|---|---|---|
| **出诊探索** | 警觉的平静 ——「我穿过世界,世界也在生病」 | 5600K 日光中性暖滤(经旧纸米黄),低角度长影;对比低-中 | 墨 7 : 铜 3 | 疏朗 · 干暖 · 静观 · 绵长 | 低-中 | **道路的留白**:前景不渲染透的空带 |
| **诊断与把脉** | 屏息 —— 判断落笔的瞬间 | 2800K 单侧暖光(油灯)照亮纸面圆斑,环境 6500K 冷侧回填;高对比但只作用于小块面积 | 墨 6 : 铜 4(器械入框) | 静 · 细 · 冷中有暖 · 纸感 | 低 | **纸上的灯斑**(其余一切沉入淡墨) |
| **急救操作**(含 VR) | 手稳心切 | 7000K 顶光硬光(手术灯),深阴影压缩至视野边缘成**水墨渗边**;全作最高对比 | 墨 2 : 铜 8 | 精确 · 冷 · 窄 · 金属 | 高 | **器械盘錾刻刻度上的反光** |

## 3. 形状语言 (Shape Language)

### 3.1 角色剪影哲学

**三层可读判据**(由远及近):32px 缩略辨**职能**(体态)→ 中景辨**装备**(背负方式)→
近景辨**状态**(衣物破度)。剪影预算:职能区分层中**体态占可辨识度 ≥60%**,服装饰件只做补充。

| 角色 | 剪影公式 | 一眼可读点 |
|---|---|---|
| **医者(玩家)** | 竖直稳定线 + 一手恒可见(拎着出诊箱提梁) | **提梁手** = 全作主角符号;医者剪影**无锐角**(剪影不得读成武器) |
| **同伴(1-4 人)** | 与医者同底盘,差异落在**背负方式**(肩背/手提/斜挎)与挂件数量 | 靠背负剪影差异辨识;**禁止以颜色或头顶标记区分玩家** |
| **病人** | 塌陷曲线,重心低于站姿,双手护一处或垂空 | **从不负器械**;身体蜷缩方向提示病位(= 诊断线索,不是装饰) |
| **敌人 —— 人(兵痞 / 匪)** | 前倾楔形 + 锐角衣物破度,但与病人共用「**人形底盘**」 | 可读成「**同一种人的两种处境**」;威胁感来自**失序**(抽动节奏/窃步/褴褛),**不来自巨物化或怪物化** |
| **敌人 —— 兽** | **不套用上行的「人形底盘」与「失序」立法**(见下方 ⚠️ 张力) | 可读 = **动物性的饥饿与领地**;P0 可猎杀取材(`game-concept.md:212`)⇒ 其剪影**允许被读成威胁**,与匪徒不同判 |

> ⚠️ **「失序非可憎 / 禁巨物化」的适用范围 = 人,不含兽 —— 本稿先前把两者塞进同一格,是错刀。**
> 依据:支柱二原文即「土匪会杀你,**野兽会吃你**」(`game-concept.md:205`),
> 且「**不杀」只约束人,不约束野兽**;动物可猎杀取材、可驱赶(P0)(`:212-213`)。
> **但本件不改写支柱二**:下行立法**按字面只作用于人**;兽的形状语言是否另立一行、
> 或连「不巨物化」一并放开给巨兽类敌人 —— **归用户裁(AB-9)**。
>
> **✅ 2026-09-21 AB-9 已裁 —— 兽另立立法,「巨物化」门对兽不设禁**:§3.1 兽行自此
> **不受**人形敌人「禁巨物化」门约束 —— 「巨物化」的归属判据对兽**不适用**(巨化崩坏的场景保留给
> 危难本身 = 支柱四建筑尺度形;**兽类可巨化,巨化的那个「灾」仍归危难**),「失序非可憎」
> 语序对兽**不同判**(兽可读成威胁、可读成可憎 —— 它不是人,不承担「手软」义务)。
> 两种读法**只作用于兽;人形敌人四行一律不动**(文字仍按 §3.1 原样)。
> **实现落点**:25 / 27 的敌人资产规格(先于资产制作)按此读;后续敌人 GDD 与 art §5–9
> 写作时**承此已裁方向,不再复判**。

**支柱二的形状立法 【本稿提案】**(作用域 = **人形敌人**):
**玩家出手前应当手软**。禁止把**人**设计成「可憎」,设计成「失序」;
巨兽化形态保留给危难本身,不给人形敌人。
> **与反支柱的一致性**:「NOT 火器 / NOT 致命终结…永远以制服收场」
> (`game-concept.md:282`)⇒ 剪影上的锐角属于**失序**而非**武装**;此判**只作用于「医者 / 同伴 / 病人 /
> 人形敌人」四行**,**不**自动作用于「兽」行(承上方 ⚠️,AB-9)。
> ⚠️ 行号引用自此**改为行名引用** —— 原写「第二行与第四行」在本节加行后已漂移,即是一处
> 「按号不按名」的失效样本。

**危难的形状**:疫情爆发没有巨型怪物。它的形状语言 = **尺度与空无** ——
烟柱、石灰线、空街、封了纸的一整片窗。**Boss 是建筑尺度的形,不是生物尺度的形。**(支柱四)
> ⚠️ 防误读:「建筑尺度」指**弥漫性的形**(一片被封锁的街口),**不是**「一个楼一样大的遭遇对象」。
> 瘟疫不站在你面前 —— 若实现期出现「巨兽型 Boss」需求,即与本行冲突,须回裁支柱四。

### 3.2 环境几何(按生态区)

| 生态区 | 主导几何 | 为什么(支柱归属) |
|---|---|---|
| **租界城镇** | 几何直线;柱廊/铁艺/铆钉的重复节奏 | 铜侧形状语法 = 重复、精密、模块化 = 租界的「外来秩序」;支柱四·三 |
| **贫民窟** | 曲线 + 有机 + 补丁叠补,形状密度高 | 「整体」侧的环境;密度本身是流行病信息(拥挤/潮湿),供 8/52 作环境线索读;支柱三 |
| **战乱前线** | 断裂直线 + 对角:被推倒的直线 | **秩序的残骸** —— 与租界同一套语法,只是完整 vs 破碎;支柱四 |
| **深山疫区** | 大曲线山形 + 皴法(斧劈/披麻)转译为 3D 岩面语言 | 墨侧环境之最;山形直接引用画论 = 「整体观」的视觉母语;支柱三 |

> ⚠️ 四区名(租界城镇 / 贫民窟 / 战乱前线 / 深山疫区)本身在 **`O-6-13` 待史实核验**队列,
> 本表**继承其待定态**,不新立主张。

**一笔原则 【本稿提案】**:每个画面**恰好一个**「主笔」级形 ——
一个不对称的大形锚点(大树/墙段/山脊/烟囱)。
**当画面「缺东西」有歧义时,本原则说:添一根主笔或添留白,永不添装饰碎形。**
主笔形跟随该生态区主导材质(租界 = 铜侧硬边,深山 = 墨侧笔意形)。

**建造模块形状语法**(承 23 模块化建造 · 与地形共用格,ADR-015 §五):
建造基础件必须全部读成「同一套零件」—— 统一的接缝语言(榫卯/铆接二选一,每生态区材质包一套)。
**逻辑网格不得外显为网格感**:直角由生态区包浆柔化(补丁/氧化/苔痕)。

### 3.3 UI 形状语法

**核心问题回答:UI 不另立语言,UI = 世界物件的放大特写。**(锚点原则二已强制 UI 是手持实物)
**比例语法差 【本稿提案】**:纸纤维、笔锋磨损、铆钉、印泥纹在 UI 比例下渲染到
**世界比例不可见的细节级**;反向约束同样成立 —— **世界比例物件不得出现「特写细节」**,
否则手持物失去比例感。

- **元件库(已定事实 · 42)**:纸面 / 卷轴 / 墨迹 / 印章四种(`skeuomorphic-ui.md:43` 规则五);
  新界面需要**第五种元件时,先改元件库**。
- **焦点呈现(已定事实 · 42)**:`skeuomorphic-ui.md:255` + V-1 明写「拟物风格的焦点高亮
  **不得是纯色** —— 墨色加深 / 纸面压痕」,**禁纯色高亮块 / 描边**。
  本稿扩展其形状义务:压痕须含**明暗双 1px 边对**(不是单色描边),
  且在 1280×720 手柄档最小缩放下仍可辨。
  > ⚠️ 另有一条**更硬的既有判据**须并入:`skeuomorphic-ui.md:1104` 要求
  > 「焦点态前后的最小 luminance Δ 在**灰阶渲染**下 ≥ 阈值,以**黑白截图夹具**断言」
  > —— 即焦点可读性的验收轴是**明度**,不是本节的边对形状。两者不冲突,但**实现期须先满足明度 Δ**。
- **敌人读数条形状**(承锚点原则三):**錾刻弧 + 指针**(机械表式),**禁止填充条** ——
  填充条是纸/墨侧语法;两栈材质不得互渗。
- **命中区形状底线(2026-09-21 已裁 AB-3 —— 由「待采建议」升为无障碍承诺)**:手柄焦点可落点
  (纸面字段/线格/留白栏)≥ 720p 等效 **44×44 逻辑像素**;「字段」由**线格划出**,
  不画成按钮 —— **纸上没有按钮,只有栏。**
  > ✅ **44×44 已进无障碍承诺面**(2026-09-21 AB-3):`accessibility-requirements.md` §Motor
  > 新增「**手柄焦点目标尺寸**」行(Standard,≥44×44 @720p 等效,高于 WCAG 2.2 AA 的 24×24)
  > + 测试判据(焦点盒测量夹具)。原「待采建议,须进承诺表后才生效」注解除;
  > 本行与 a11y 该行 = **同一对象、同一判据**,验收归一。

## 4. 色彩系统 (Color System)

> 本节全部 hex 为 **sRGB · 【本稿提案值】**,须由 technical-artist 在 **URP linear 工作流**
> 导入配置定稿后校准替换(⚠️ sRGB 值进 linear 空间须经 gamma 解码 —— 未经校准的 hex 直接抄进
> 代码常量会产生系统性偏色)。

> (承 `accessibility-requirements.md:98`「色盲模式」行既有口径「**不引入后处理全屏滤镜**」
> 与 ADR-020 §六)。⚠️ **P0 侧另有更硬的一道闸**:ADR-023 ⑧ —— **P0 零 custom Renderer Feature**
> (`ScriptableRenderPass` / RenderGraph 定制面零使用,引入须**另开 ADR**)⇒ 本节的
> 「换表 + 禁滤镜」**不是**「后处理之外的滤镜效果已获准」的许可。

### 4.1 主调色板

|---|---|---|
| **旧纸米黄** | `#E4D5B7` | 世界底衬 —— 时代发黄的一页;一切日光都「透过一页纸」;UI 纸面之源 |
| **浓墨** | `#26241F` | 笔迹与界线 —— 玩家判断本身;**永不用纯黑**(纯黑是印刷品,不是手书) |

### 4.2 语义色规约

- **红**只出现在活体与其流体上。UI chrome(按钮/边框/焦点)**禁用红**;
  唯一合法 chrome 红 = **印泥色** —— 它是权力之红非血之红,故必须同时是纸面唯一红元素,
  并以形状(方印直边)与血(流体漫边)彻底区分。
- **两种「青」以材质载体分离**:环境青绿 = 金属氧化(干、哑光、粗糙);
  面色青 = 肤色基底向灰蓝的低饱和偏移(湿、只出现在诊断态光下)。
  **皮肤永不发铜绿,铜锈永不成肤色。** 此条是 §4.6 色觉安全的第一道防线。
- **金/铜**:从 §1 P4 来历判据;无商路的深山没有黄铜 —— **缺席本身是深山疫区的色温语言**。
- **白/留白**:**留白是墨侧信息** —— 脉案空白栏 = 未查项,不是装饰性空域。
  纸白 vs 冷白:凡居住空间的白必须偏黄,「无菌主张」场景才有冷光白资格。
- **墨**:墨色只落纸/木/布;**环境阴影是灰褐不是墨黑**(墨是写字的颜色,不是投影的颜色)。

### 4.3 生态区色温规约

| 生态区 | 主色温 | 滤色 | 饱和度策略 | 铜↔墨 |
|---|---|---|---|---|
| 租界城镇 | 5600–6500K 中性 | 微蓝灰 | 基线(已整体压低) | 铜 6 : 墨 4 —— 全作唯一「冷日光」区 |
| 贫民窟 | 2700–3200K 灯油 | 浊橙 | 基线 −20% | 铜 3 : 墨 7 —— 锈重于铜(器械多而皆旧) |
| 战乱前线 | 4200–4800K 尘掩 | 灰黄 | 基线 −40%,火是唯一满饱和源 | 铜 5 : 墨 5 |
| 深山疫区 | ≥7000K 但低亮雾 | 青灰 | 基线 −30%,**血红为此区唯一暖色** | 铜 1 : 墨 9 —— 全作最水墨的一区 |

**跨区规则(支柱四)**:「翻过这道坎,**颜色不再同理**」—— 同一种药材在不同区光照下呈色不同。
这合法且刻意,因为药材辨识的第一通道已钉死为**形态**(§4.6),色只是辅助通道;
若某辨识确需靠色,改为**脉案文字的性状描述**(8 的既有通道),不改世界光。

### 4.4 高饱和例外规则 【本稿提案 · 量化】

锚点原文(`game-concept.md:543-544`):饱和度整体压低,**只在「生命体征变化」时允许一次高饱和**
(血色回涌、瞳孔收缩)。机械化预算:

- **触发白名单**:血色回涌 / 瞳孔收缩 / 正确施治后的关键体征改善 / 疫情爆发的火与血源。
  **名单外永远不解锁**(建造、采集、拾取、升级均无资格
  —— 此为 **ADR-018 §六 无提示音铁律的视觉侧**,同一铁律,与 ADR-020 §六 镜头效果禁令同源)。
- **预算旋钮**(范围为提案,**定值归数值轮由用户手调**):
  - `SAT_BLOOM_MULT` 饱和度倍率:建议 **1.6–2.4×**
  - `SAT_BLOOM_AREA` 最大同屏高饱和面积:建议 **≤ 画面 4%**
  - `SAT_BLOOM_HOLD` 峰值保持后衰减:建议 **≤ 1.5–2.0 秒**,衰减曲线用墨晕缓动(**禁线性**)
  - `SAT_BLOOM_COOLDOWN` 冷却:建议 **≥ 8 秒(= 160 ticks @ 20 Hz** —— tick 频率已由 OQ-25-8 裁定**)
- **并发规则**:同屏任意时刻**至多一处**高饱和;两事件同时请求时,
  优先给**与玩家当前判断直接构成反馈**的那个。
- **独占组合**:「全画面去饱和 + 单点高饱和」为**疫情爆发专属**(§2 附注),
  任何状态复用即违可区分性判据。

### 4.5 UI 调色板(与世界色的分歧)

- **纸面基色 `#EAE0C8`**,比世界旧纸米黄亮约一档。分歧理由:UI 纸面是**自发光阅读面**,
  世界里的纸是被照物体 —— 同值会让手持物「没被点亮」。**两值禁止合并。**
- **正文对比底线**:浓墨 `#26241F` 于纸面 `#EAE0C8` ≈ **11.8:1**(WCAG AAA 之上)。
  此数为底线:**任何调色板变体(含色盲模式)不得低于 7:1。**
  > 现承诺对照(2026-09-21 AB-4 已提档):`accessibility-requirements.md` 正文对比承诺
  > 已从 **≥4.5:1 → ≥7:1**(该件 :84 / :181 已改);本件的 7:1 = **承诺底线**而非自我约束。
  > ⚠️ 验收口径不变:该件自带的「拟物纸纹是**纹理**不是纯色底」警告仍有效 ——
  > 真实对比须按「**USS 主题色值 × 烘焙纹理最亮像素**」跑对比器,不是两色对比。
- **焦点态**:墨色加深至 `#17150F` + §3.3 的压痕边对,**不用色相**。
- **禁用**:铜锈青绿不得作主操作色(「氧化残迹」语义与「可操作」冲突);
  血迹红不得进 UI chrome(唯一 chrome 红 = 印泥)。
- **墨龄**:`skeuomorphic-ui.md:295` 规则十三 + V-4 **已定事实** ——
  湿墨(边缘洇开)→ 干墨(边缘收干、**色沉**),**只走明度轴、不色相漂移**
  —— 墨龄因此天然色盲安全。⚠️ 具体两值 hex 系本稿提案。

### 4.6 色觉安全 (Colorblind Safety)

**总则 【本稿提案】**:色在本作可以承担**强化**,**不得承担唯一判定** ——
每个需判定的语义对必须另有 形状 / 运动 / 明度 / 位置 / 音频 中**至少一条**备份通道。

| 语义配对 | deutan / protan | tritan | 必备备份通道 |
|---|---|---|---|
| 血暗红 ↔ 铜锈青绿 | ❌ 失效(红绿轴) | ⚠️ 部分 | **光泽差**:血 = 湿反光 + 流动运动;锈 = 干哑光 + 粗糙纹理。位置规则兜底:红只在活体,青绿只在金属木石 |
| 印泥红 ↔ 血污红 | ❌ 两红相混 | ✅ | **形状为主通道**:方印直边 vs 流体漫边;印泥恒干 |
| 黄铜 ↔ 铜锈(「新器械 vs 用过」) | ⚠️ 不保证 | ⚠️ | 移入**明度轴纪律**:两值相对亮度差 ≥12%;锈侧纹理噪声备份 |
| 冷光白 ↔ 纸面米黄(无菌 ↔ 生活) | ✅ | ❌ 失效(低饱和冷暖白相混) | **光源形状**:冷光出硬边高光 / specular 边缘,纸光恒软边;42 纸面元件两态走明度不走色相 |
| **面色五色(赤/青/黄/白/晦暗)** —— 全作色依赖峰值 | ❌ 赤↔青 | ⚠️ 赤↔黄 | ① **已定事实**(`accessibility-requirements.md:98`):姿态 + 呼吸通道恒在、脉案文字读数(「Reading」事件流)复述已读出的面色词;② **本稿提案**:五色按**单调明度阶梯**排布 晦暗 < 青 < 赤 < 黄 < 白,色盲换表时**保明度序、不保色相距**;终裁归 **`OQ-A1`**(该条已在 accessibility 登记,与 ADR-014 调色板评审并批) |
| 敌人 ↔ 病人 | ✅(形状已是主通道:楔形 vs 塌曲线,§3.1) | ✅ | 体态 + 运动节奏;**禁止引入任何敌我色区分**(该命题本身违支柱二) |
| 同伴 ↔ 玩家 | ✅ | ✅ | 背负方式 + 挂件形(§3.1),无色标 |
| 药材辨识 | ⚠️ 同色异种风险 | ⚠️ | **形态优先铁律**:任意两味药材不得仅靠色相区分;脉案侧已有铅笔小勾(靠形状 · 42) |
| 急救节奏提示(CPR 频率 / 缝合路径) | —— | —— | 已由运动 + 音频承担;**禁在表盘画红绿安全区**(工业表惯例,本作禁用)——「超频」以指针撞击**机械限位**(视觉抖动 + 限位声)表达 |

- **色盲模式实现约束(已定事实 · accessibility)**:UI 调色板变体 = **烘焙数据换表**(ADR-014),
  **不引入后处理滤镜**。本节 §4.1 / §4.5 表即**基线表**;色盲变体须作为另一张登记
  `ConfigVersion` 的表另行评审。
- **AD 侧走查动作 【本稿提案】**:每次调色板换表,固定三场景 × Coblis 三型走查 ——
  **脉案五通道区 / 急救呈现面 / 生态区地物识别**。

### 8.1 文件格式与单位坐标系

> 单位 / 坐标系 = **引擎事实重申**(Unity 左手系 · +Y 上 · 1 unit = 1 m,不构成新主张);
> 压缩方向与其余 = **本稿提案**;压缩**定值**归构建面,本件不代拍(承 Draw Calls / Memory
> Ceiling 待定口径)。

| 资产类别 | 首选交接格式 | 原因 / 约束 |
|---|---|---|
| 纹理源文件 | `.tga`(32bit 带 alpha)或 `.png`(无损) | 按「带 alpha 能力」等价;**禁 `.psd` 直挂 Unity**(须先导出);源文件与导入压缩**分离** —— 源永不进构建,构建吃压缩后导入产物 |
| 模型 | `.fbx`(嵌骨架 / 动画 / 法线) | DCC 源不作交接物;`.blend` / `.ma` 不进资产库 |

### 8.6 材质槽位与 shader 分配

> P0 零 custom Renderer Feature(ADR-023 ⑧)、禁全屏滤镜 = **既有裁定**;皮肤永不铜绿 / 红禁 /
> 灰褐阴影 = **既有**(§4.2);敌人读数条 = **既有**(§3.3 錾刻弧 + 指针、禁填充条,挂对象封闭
> 名单 §1 P3);槽位上限与墨↔铜通道表达 = **本稿提案(裁向,待用户认可)**。

**shader 选用规则(合稿双方一致)**:

| 场景 | 选用 | 理由 |
|---|---|---|
| 受光实体(角色 / 病人 / 建筑 / 道具 / 植被) | **URP Lit(默认)** | 全项目唯一主 shader,压缩变体面 |
| 不受光 / 背景层 / 远景卡片 / 标线 | **URP Unlit** | 免光照实例 |
| **禁用** | URP Simple Lit / 自定义 Shader / Shader Graph 资产 / 自写后处理 | Simple Lit = 第二 Lit 族,扩散变体;自定义 shader 与 ⑧ 同闸(8.0 硬闸一) |

**SRP Batcher 兼容(硬规则)**:禁按实例 `new Material`(实例化材质);视觉变体一律走**烘焙纹理换表**
(承 ADR-014),不用实时参数改写;同类型材质槽位保持同属性表 ⇒ 合批对齐。材质差异优先
`MaterialPropertyBlock` 参数实例化,**禁为一小块差异复制材质变体**。

**光照预算(P0 提案)**:全局单直射光 + 烘焙环境(IBL / 静态反射);动态光不进 P0;VR = **只强化
不放松** —— 单硬光是上限(ADR-020 §六)。

**墨 ↔ 铜如何落在材质图上(裁向提案,合稿双方一致)**:

- **铜侧** = PBR 金属工作流:`_mask`(R=金属度, G=粗糙度, B=AO);金属度高 + 粗糙度低(抛光 → 器械
  冷光高光);锈蚀**不在色板做** —— 金属度局部降 + 粗糙度局部升(干 · 哑光 · 粗糙),磨亮边缘金属度
  回升 = 「用过」的证据(§4.2 铜锈语义)。
- **墨侧** = **不脱离 PBR,统一「非金属 + 高粗糙」**:金属度恒 0(提案机械化 —— 墨槽 mask 金属度
  通道恒 0,断言防锈斑进墨 / 皮肤侧同断言);纸 / 木 / 布差异**住在 albedo**(晕染 / 留白 / 笔触)
  与 normal 微扰;粗糙度区间 纸 0.8–0.95 / 木 0.6 / 布 0.9(提案区间,定值归数值轮)。
  **不引入任何特殊着色器**(P0 零 custom RF 的唯一相容裁向)。
- **皮肤** = 恒非金属(金属度 0 断言,承皮肤永不铜绿);血 / 汗 = roughness 局部降 + albedo 血迹,
  **禁 emissive 血**。
- **红禁**:环境 / 道具 / 模块 albedo 禁纯红;唯一例外 = **活体与其流体 + 印泥**(方印直边,§4.2)
  —— 此条进美术验收拒收表。
- **阴影**:环境阴影走灰褐非墨黑(§4.2)⇒ 世界资产 albedo 暗端与光照共同承诺,不做墨黑投影。

**材质槽位上限(提案/待定;SRP Batcher 合批直接乘数)**:

| 类别 | 槽位上限(提案) | 理由 |
|---|---|---|
| 角色(玩家 / 同伴 / 敌人) | ≤3(皮肤 / 衣料 / 器械) | 医者 = 衣料(墨)+ 皮肤 + 器械(铜),同框配额 P1 的两材质下限恰为此数 |
| 病人 | ≤2(皮肤 / 衣料) | 病人永不负器械(§3.1) |
| 建造模块 | ≤2(本体 / 装饰缀) | 模块量大,槽位是合批大头 |
| 环境建筑 / 地物 | ≤2 | |
| 环境道具 / 小物件 | 1 | |
| 植被 | 1(单材质) | |
| UI-纸纹 | 1(纸纹单材质) | 变体全走烘焙换表 |

**合稿注记(生产侧 ↔ 引擎侧槽位差异就地吸收)**:生产侧原稿对角色上限写「≤4(皮肤 / 衣料 /
金属件 / 饰品)、病人 ≤2(病服 / 床品 / 器械件)」,引擎侧写「角色 4、病人 3」且含床品 ——

「金属件 / 饰品」并入器械槽;床品槽取消(归环境道具)。**此为一处两稿冲突,合稿决定已就地吸收**,

### 8.7 灰盒政策(承 AB-10)

> **既有裁定**(2026-09-21 AB-10):§8 前置补写 · slice 用灰盒豁免**不再隐式宽限**;
> 下列定义与判断点 = **本稿提案(待用户认可)**。

**定义**:灰盒 = 以素模 / 白模(无材质语汇、无形状语言、无贴图、无 §8 规格)代替正式资产的
中间态。它**只许服务「判定 / 手感 / 布局 / 协议」验证,不许服务「视觉验收」**。

**判断点(可勾选)**:

1. **本帧是否以视觉验收为目的**(截图 / 门判 / 给外部评审)?是 → 灰盒不得出镜;否 → 允许。
2. **灰盒是否有登记可追溯的正式替换关系**(替换后原灰盒删除,不留 ghost)?是 → 允许并登记
   slot;否 → 禁入。
3. **本验证是否依赖 §3.1 形状判据**(32px / ≥60% 剪影)?是 → **灰盒测不了**,必须等正式资产;
   否 → 允许。
4. **灰盒是否进入交给外包团队的参考包?**是 → 禁(灰盒体态会被误读为「形状已达标」);否 → 允许。
5. **是否确需灰盒出镜进入验收面?**是 → **显式豁免一次**(范围 / 期限 / 验收降级写入
   session-state);**「默认允许」不存在** —— 此即 AB-10「不再隐式宽限」的落地。

**判定者**:视觉验收场景 = **art-director**;玩法 / 手感场景 = 玩法侧判。灰盒**不豁免**
§8 任何规格 —— 灰盒 ≠ 免检。

**§8 如何算「照做」**:交付物按 8.1–8.6 的拒收表逐条查(命名 / 分辨率 / 槽位 / LOD / 导出 /
接缝);凡不符合 §8 而交付的资产,**自动落入灰盒类别**,按本政策申报,而非静默放行。

### 8.8 灰度替换验收清单

> **既有裁定依赖**:AB-10(灰盒可用性判定归属 §8 批次);本节 = 技术侧下限的展开
> (**本稿提案**)。

**技术侧下限 —— 灰盒可用时「可省」vs「不可省」**:

- **可以省**:材质集(统一灰盒材质,≤2 槽)· 纹理(纯色 G 卡,可零纹理)·
  面数(建议 ≥ 提案档 1/4,能承载碰撞与交互即可)。
- **不能省**:
  - 碰撞体 —— 与格对齐一致,承 ADR-015 整数格;
  - 交互槽位 —— 拾取 / 建造 / 诊断 / 急救的判定点固定到位,与正式资产同坐标;
  - 格对齐 —— 建造位 / 门洞 / 病床摆位逐条过格对齐检测;
  - 命名合规 —— 灰盒名 = 正式名的占位,直接可迁移,不建第二命名体系;
  - 可跑性 —— 灰盒必须可跑完整游戏循环(建造 / 拾取 / 诊断 / 急救),可听可见均可测。

**灰盒 → 正式资产替换验收(三查)**:

1. **替换后对比**:同机位采图,灰盒 vs 正式,轮廓 / 交互区 / 尺寸范围必须不变(截图对比存档)。
2. **性能**:正式资产替换后同场景实测帧时间,对灰盒基线不得劣化超提案容忍带(带值 = 提案/待定,
   挂最低目标硬件判据一同定稿);表里资产过 8.4 清单勾选留痕。
3. **命名 / 残留**:新资产命名校验通过;被替换的灰盒资产按仓库清理规则移除,不留双份。

**交付顺序**:灰盒先行不阻塞玩法测试;正式替换逐簇推进,每簇独立过三查,禁止整表批量替换不验证。
