# 竞品对标:英灵神殿 × 我的世界 × 本作

*创建日期: 2026-09-13 · 状态: Draft*
*上游文档: `design/gdd/game-concept.md`*

---

## 1. 概述 (Overview)

本作在产品定位上明确对标《英灵神殿》(Valheim)的**框架**与《我的世界》(Minecraft)的
**创造思维**,但在**核心动词**上刻意做了一个反转:把「杀」换成「判」。

本文档逐项对照三者的异同,目的是:
**① 标出我们直接复用的已验证结构(低风险)**
**② 标出我们刻意背离的地方(高风险,但也是差异化的全部来源)**

---

## 2. 玩家幻想 (Player Fantasy)

对标分析本身不交付玩家体验,但它保护一件事:
**当我们说「像英灵神殿」时,我们要的是它的什么?**

答案是:**它的节奏、它的世界感、它的投入产出结构** ——
而不是它的战斗。《英灵神殿》的战斗是「你变强所以你能杀更狠的东西」;
本作要反过来:**「你懂得更多所以你能救更难的人」**。

---

## 3. 详细规则 (Detailed Rules)

### 3.1 与《英灵神殿》的对照

| 维度 | 《英灵神殿》 | 本作 | 判定 |
| ---- | ---- | ---- | ---- |
| **核心动词** | 杀(战斗) | **判(诊断)** | ⚠️ **背离** —— 差异化来源,也是最大风险 |
| **世界结构** | 生态区推进,每区一个 Boss | 生态区推进(租界城镇 → 贫民窟 → 战乱前线 → 深山疫区) | ✅ **沿用** |
| **推进门槛** | 打 Boss 解锁下一区 | **解决公共卫生危难 / 权贵疑难**解锁下一区 | ✅ 沿用结构,⚠️ 换掉内容 |
| **Boss 奖励** | 物理能力(新矿、新工艺) | **制度性权限**(防疫督办权、黑市通行证) | ⚠️ **背离** —— 支柱四的核心 |
| **建造** | 模块化建造 + 结构完整性 | 模块化建造 + **位置即逻辑 + 快 vs 好双评分** | ✅ 沿用并加深 |
| **技能** | 21 项,使用即成长,上限 100,死亡掉 ~5% | **19 项**,使用即成长,上限 **60**,死亡掉 5% | ✅ 沿用模型,⚠️ 换成**医术线 + 格斗线** |
| **食物/药物** | 3 个食物槽,各给不同属性曲线 | **3-4 个药物槽**,各给带**半衰期**的曲线 + 过量毒性 | ✅ 沿用结构,➕ **加深**(半衰期是本作新增) |
| **联机** | 1-10 人 | 1-4 人,非对称分工(主刀/主诊/后勤) | ✅ 沿用,⚠️ 缩规模 + 加分工 |
| **死亡代价** | 掉落物 + 掉技能(跑尸) | 掉落物 + **掉技能(框定为「手生」)** + 精神压力 | ✅ 沿用并**叙事化** |
| **NPC** | 极少(Haldor、Hugin) | 少量,但病患与村落是核心 | ⚠️ **偏离** —— 我们需要更多「人」 |
| **世界事件** | 「被袭击」等随机事件 | 时代事件(辛亥革命、1918 大流感、废止中医案) | ✅ 沿用结构,⚠️ 换内容 |

> ### ⚠️ 两处「沿用」实为断裂(2026-09-14 对标复核)
>
> **① Boss 的形态换了,但「站在你面前」的强度没接上。**
> 英灵神殿的「杀 Boss → 解锁」有一条**正反馈闭环**:战斗 → 胜利 → 奖励 → 下一区,
> 而且 Boss **摆在你面前**。本作换成「公共卫生危难」方向是对的,
> **但「危难」不站在你面前** —— 一个瘟疫不像一个巨魔。
>
> **解法已写进支柱四的补注**:**Boss = 一个你「拼」出来的图样**,不是实体。
> 认得散落病例之间的模式,就是 Boss 战。
>
> **② 空间难度轴被弃用后,没有替代品。**
> 「离世界中心越远越强」是英灵神殿里**玩家能自己感觉到**的自动难度曲线。
> 本作是**固定世界**,弃用它是对的;**但改成的「随玩家状态缩放」是隐性的 —— 玩家感受不到**。
> → **P0 必须给一条看得见的「深水线」**(见 `systems-index.md` §5 #52 注:采集衰减 + 季节修正,
> 让「更远 = 更稀有的药 = 更危险的路」成为玩家自选的难度滑杆)。
>
> **③ 一处文档缺失(非功能问题)**:§3.1 建造行声称「快 vs 好双评分」,
> **但文档从未给出一个证明「两轴能产生多种合法布局」的例子** ——
> 若最优解显而易见,Expression 就退化成抄作业。**例证已补入 §5 边界情况表末行。**


**结论**:我们从英灵神殿拿走的是**「一套已经被验证过的开放世界生存建造骨架」**;
我们换掉的是**骨架上的肉** —— 动词、奖励、技能线、事件内容。

### 3.2 与《我的世界》的对照

| 维度 | 《我的世界》 | 本作 | 判定 |
| ---- | ---- | ---- | ---- |
| **建造粒度** | 体素,逐块自由 | **模块化房间 + 家具位**,不逐块 | ⚠️ **背离** —— 见下 |
| **「机器」思维** | 红石:摆对零件 → 自动运转 | **医馆**:摆对房间 → 自动降低感染率 / 提高成药率 | ✅ **借用思维**,⚠️ 换掉实现 |
| **资源循环** | 采 → 合成 → 建 → 探索更深 | 采药 → 炮制 → 医馆 → 出诊更远 | ✅ 沿用 |
| **配方空间** | 极大,可自由组合 | **明确不做** —— 无组方/配伍 | ⚠️ **刻意收窄** |
| **无限世界** | 程序生成,无限 | 4 个手工生态区,**有限** | ⚠️ **背离** —— 内容全部手制 |
| **种子/重开** | 种子随机,重开即新世界 | 固定世界,重开 = 新角色在同一世界 | ⚠️ 背离 |
| **UGC** | 模组生态是生命力来源 | P2 考虑「异步医案传承」(受限) | ⚠️ 暂缓且**受限** |

**结论**:我们从《我的世界》拿的**不是它的体素世界**,而是它最核心的那句话 ——
**「玩家摆零件,世界就会运转」**。

### 3.3 三者核心定位的一句话说清

| | 一句话 |
| ---- | ---- |
| **英灵神殿** | 「你变强,所以你能杀更狠的东西。」 |
| **我的世界** | 「你想造什么,就能造什么。」 |
| **本作** | 「你懂得更多,所以你能救更难的人;你怎么建医馆,就暴露了你怎么理解医学。」 |

## 4. 公式 (Formulas)

对标分析不适用公式章节。此处代以**复用度评分**,用于决定「哪些系统可以低成本照搬」:

```
ReuseScore = W_structure × 结构相似度 + W_content × 内容相似度
```

| 变量 | 含义 | 取值 |
| ---- | ---- | ---- |
| `结构相似度` | 骨架能否直接复用 | 0.0 ~ 1.0 |
| `内容相似度` | 内容是否可直接复用 | 0.0 ~ 1.0 |
| `W_structure` | 结构权重 | **0.7**(结构复用省的是工程) |
| `W_content` | 内容权重 | **0.3**(内容复用省的是设计) |

**示例:联机系统**

```
ReuseScore = 0.7 × 0.9 + 0.3 × 0.6 = 0.81  → 高复用,直接采用标准方案
```

**示例:建造系统**

```
ReuseScore = 0.7 × 0.7 + 0.3 × 0.2 = 0.55  → 中复用,骨架照搬,语义重写
```

**示例:战斗系统**

```
ReuseScore = 0.7 × 0.1 + 0.3 × 0.0 = 0.07  → 不复用,必须从零设计
```

## 5. 边界情况 (Edge Cases)

| 情况 | 处理 |
| ---- | ---- |
| **玩家期待「像英灵神殿一样打 Boss」** | 我们的 Boss 战是**公共卫生危机**,不是战斗。首个生态区的教学必须明确建立这个预期,否则玩家会持续等一场不会来的 Boss 战。 |
| **玩家期待「像我的世界一样自由建造」** | P0/P1a 的建造是**模块化 + 家具位**,不是体素。宣传物料不得使用「自由建造」一词,避免预期错位。 |
| **玩家抱怨没有配方/合成深度** | 这是**刻意的收窄**(见反支柱)。补偿手段是医馆的布局深度,而非配方数量。 |
| **对标作品的玩家觉得节奏太慢** | 英灵神殿的节奏来自「跑路 + 采集」;本作多了「判断」这一层。P0 必须验证判断层不拖慢节奏。 |
| **玩家找不到「变强」的感觉** | 技能成长必须以**行为变化**呈现(能认出的药材变多),而非数值面板。这是拟物 UI 的硬约束。 |
| **「快 vs 好双评分」的两轴退化成抄作业**(2026-09-14 补) | **A3 例证**:同一间药庐,两轴各给一个**合法最优**——<br>**布局甲(偏「好」)**:病房贴南窗采光、灶房隔离在下风处 → 治愈率高、但取药动线长,**单位时间接诊少**。<br>**布局乙(偏「快」)**:病房紧邻药房与灶房、动线最短 → 周转快,但油烟串味、采光差,**重症治愈率低**。<br>**两轴都可高分,取舍不同 → Expression 成立**(最优解不唯一)。<br>⚠️ 这是**例证不是规格** —— 正式数值与约束由 **24 医馆即机器**的 GDD 定义;此处只证明「两轴确有多种合法布局」。 |

## 7. 调参旋钮 (Tuning Knobs)

| 旋钮 | 默认 | 作用 |
| ---- | ---- | ---- |
| `W_structure` | 0.7 | 结构复用权重。调高 = 更保守,更贴近英灵神殿 |
| `W_content` | 0.3 | 内容复用权重。调高 = 更愿意照搬内容 |
| 复用阈值 - 高 | ≥ 0.7 | 可直接照搬标准方案 |
| 复用阈值 - 中 | 0.4 ~ 0.7 | 骨架照搬,语义重写 |
| 复用阈值 - 低 | < 0.4 | 必须从零设计 |
