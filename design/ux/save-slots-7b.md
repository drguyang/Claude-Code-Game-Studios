## 1. 类型声明与闭集边界

per-screen UX spec —— 该员的 NOT-RUN 阻塞自此**解除一半**:判据存在、可实测,执行归实现轮(**禁借绿**)。

- **模态身份**:本屏 = `ModalId.SaveSlots`(枚举权威 `adr-013:353` 「SaveSlots, // ② 存档位 7b」);
  开/关 = 模态开合,**不落为进流的边沿**(ADR-013 §十 ~~③~~ **②** 豁免 —— ③ 是单值约束,项号 off-by-one,2026-09-22 /ux-review 轮订正;⑦ 件 `paper-closeup-48.md` 同型引法待 42 侧核对轮统一,族内 Draft 本批逐件改),与教学纸近景同构)。

- **所有权三层分离**(承 7b GDD 规则一 `:93-102`):**7a = 逻辑**(能不能写/读,全部判定在此)·

## 2. Purpose & Player Need

玩家翻开医馆案头的**登记簿**:`继续诊治`(从册载入)/ `留档`(手动落一行)。
它是全案唯一「时间分叉点」界面 —— 载入即锁(7b 规则三),所以这册子同时承担**保护玩家进度**
的功能与**「纸簿不能改写」的世界内解释**。

**这个屏存在的理由**:
- 拟物铁律下无任何 HUD 弹窗、无系统级 toast —— 存/载的全部可达路径必须长在一件世界器物上;
  登记簿 = 医馆账房的既有器物语义(登册、画押、翻页),不引入任何「游戏菜单」外来形态。
- 「不能覆盖旧档」若只表现为「按钮灰了」= 无声拒绝(反 scumming 的可理解性破)——
  须由**纸面自身的物理语言**(灰墨/折角/笔迹消失)讲通(AC-7b-08 幻想层判据)。

**什么会变糟**(若本屏不存在或难用):
- 手柄玩家断头(P-04)= 不可玩:载入路径 = 继续游戏的唯一门。
- 灰置只靠变暗 = 色-only 违反(AC-7b-12);「整册不可读」与「单页不可写」混同 = 玩家
  以为存档坏了(实为安全上下文门,7b 规则三)。

## 3. Player Context on Arrival

- **两个入口**:① 主菜单「继续诊治」(尚未入世界,册 = 首屏);② 游戏内暂停开册
  (存/载钩子承 7b 规则四:**须在落笔 / 病例结案 / 出诊启动之后**,落点缝隙外不可写也不可读取)。
- **进入前一刻**:① 态 = 无世界态(从容);② 态 = 世界内自由态或**暂停壳之上**。
  ⚠️ **暂停壳不是 `ModalId` 成员**(闭集七员无 Pause;`adr-013:352-358` 逐字核过)⇒ 「册开在暂停壳上」**不构成 §约束 3 意义上的叠模态** ——
  暂停 = 42 侧**本地呈现门态**(承 `accessibility-requirements.md:128`:本地暂停 UI + 主机 tick 不停),
  不占 `Modal` 单值槽。若未来裁「暂停须具模态身份」⇒ 那是**第八员**,须另判(本件不代裁,按现读法书写)。
- **情绪**:低唤醒、事务性 —— 与教学纸同族;任何急促转场与「账房翻册」冲突。
- **空册**:首次游戏 = **空白册**允许打开,零「无存档」弹窗(7b `:239-240`)。

## 4. Navigation Position

```
World / MainMenu
  └─ 暂停壳 toggle 或主菜单选择 ──▶ ModalId.SaveSlots(本屏 · 世界栈输入冻结 · 移动仍可,7b :50)
                                        ├─ South=Submit → 槽位动作(载入 / 落笔存盘)
                                        ├─ 翻页(§7)→ 册内页 N+1 / N-1
                                        └─ 同一 toggle(关闭)──▶ 回进入前状态栈
```

- 本屏是**导航层级中的目的地**(主菜单可达、暂停可达),与 P-02 的上下文模态不同类
  —— 但它**仍是 ModalId 员**(冻结世界交互意图,不冻结移动)。
- **册内无子屏**:载入即执行(单次 Submit,§7 理据);**无二级确认弹窗** ——
  AC-7b-07 点名闭集内零弹窗/toast,且 7b GDD 无确认流程;防误触由**落笔缝隙门**(规则四)
  + **读档即锁**(规则三)双保护承担,不靠纸外 UI。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **册页上的槽位列表**(逐行「登记」) | 每行 = 一条 `SaveSlotInfo` 投影;行动 = 焦点落点 |
| 2 | **页级因由标记**(折角 / 笔迹消失 / 灰墨) | 「整册此刻不可读」vs「这页不能改写」的区分载体(三义三通道,§5.2) |
| 3 | **页角一行小字**(拒绝/回退解释) | OQ-7b-2 / OQ-7b-4 的**承载**;**文案本体归 narrative**(UI-7b.1 `:341`) |
| 4 | **册页序号 + 翻页提示物**(纸边厚度感) | 「还有下一页」由物理形态传达,不由图标传达 |
| 5(环境) | 册外一圈(封面压边 / 案面木纹) | 只唤起「册摊在案上」;无数据 |

层级原则:**行 = 数据,页 = 因由,角 = 解释** —— 三级各占一个物理位,互不冒充。

### 5.2 Layout Zones

裁定:**等比纸本族的「册中册」变体**(族默认承 `paper-closeup-48.md` §1 用户裁定;本屏布局语义
归 7b,42 只渲染)—— 摊开的线装登记簿,**左页 = 册面(封面信息)/ 右页 = 当前登记页**。

三区:
1. **封面区**(左页):册名(主题变量最大字号档)+ 墨龄(规则十三)+ 当前页码(页脚鱼尾压印)。
   不承载判定信息。
2. **登记页区**(右页 · 主交互区):**每页 6 行**(OQ-7b-1 由本 spec 裁,见 §14 OQ-SB-2 注);
   行 = 纸线格上的一「笔登记」;页容量是**呈现常数**,槽位总数无上限(超出即续页,
   与 7a `OQ-7a-8` 的裁剪语义解耦 —— 被裁 = 7a 不再投影该行,本屏**不画**「已裁剪」行)。
   6 的理据:1080p 下纸线格行距 ≥ 24px 字号 + 行高呼吸 ≈ 每页 6 行为不滚动的最大可读密度;
   超过即转「册后另起一册」。**册间导航 = P1a**(登记,见 §14)。
3. **页角注区**(右页右下 · ≤1 行小字):因由文案位。三种文案场景共用此位,永不叠加
   (叠加 = 二义):**拒绝覆盖** / **册当前不可读**(安全上下文门)/ **损坏回退痕迹**(AC-7b-13)。

**灰置四通道**(承 7b `:345` 附近「页级因由三义分通道」口径 + 本 spec 补第四义 `Locked`,本 spec 物化到行/页两级;
⚠️ 三→四的差 = `Locked=true` 的槽位级呈现此前**无处落**,正撞 GDD 首轮评审 BL-4 修过的「`¬Locked` 死项」失败模式):

| 因由(全由 7a 返回值决定,AC-7b-02) | 呈现 | 聚焦性 |
|---|---|---|
| 该行 `Writable=false`(不可写:槽位只进不退,覆盖=拒,7a 规则 `persistence-service.md:205` —— ⚠️ 原引 `:196-198` 指向规则十三「退出保存重试」,行号漂移,2026-09-22 订正;7b GDD 自引「规则十四 `:187-202`」同型漂移,归 GDD 修订轮)| **灰墨**(新行字色降档)+ **页边折角** | **仍可聚焦**,Submit 给拒绝反馈(§7) |
| 整册 `Loadable=false`(安全上下文门 / 未决医疗动作中) | 右页**笔迹消失**(行字退为纸底压痕)+ 页角注「此刻不可读」文案 | 册页仍可聚焦、Submit 给拒绝反馈 |
| 损坏回退痕迹(7a 自动读 `bak` 后的一次性标记) | 页角注**一行小字**(文案归 narrative)+ 该行墨色**深浅不匀**(物理=回退的纸) | 正常 |
| 该行 `Locked=true`(读档即锁 —— 同会话再载同槽 = 7a 拒,7b 规则三 `save-slot-ui.md:116-122`)| **合上之形**:该行墨字退为压痕 + 页边**折角双叠**(与「不可写」单折角形状可分);呈现 = 7a `Locked(slot)` 返回值的**纯函数**,本屏不实现锁、只画锁 | **仍可聚焦**,Submit 给拒绝反馈(§7)|

**非颜色冗余**(AC-7b-12 BLOCKING):四通道 = 折角(形状)/ 笔迹消失(有vs无)/ 墨色深浅 / **单折 vs 双叠折**;
「不能改写」与「不能读取」与「已合上(Locked)」在形状通道上**两两可区分**(单折角在页边 vs 整页笔迹消失 vs 双叠折角)。

### 5.3 Component Inventory

| 组件 | 类型 | 内容 | 可交互 | 元件库来源 |

| 册面元件 | 容器(封面纸纹 + 线装压线 + 鱼尾页码) | 册名 / 页码 | 否 | 规则五「纸面」+ 九宫格 `-unity-slice-*` |

## 7. Interaction Map

**映射基础**:键盘/鼠标(主)+ Gamepad(partial——完整可用)+ 无触摸、无 VR。

| 动作 | 输入(键鼠) | 输入(手柄) | 即时反馈 | 结果 |
|------|-----------|-----------|---------|------|
| 打开册 | 暂停壳入口 / 主菜单「继续诊治」(action 资产,3 绑重) | 同一 action 资产 | 开册 ≤200ms(§9) | 切 `ModalId.SaveSlots`;世界意图冻结、移动不冻 |
| 关闭册 | 同一 toggle | 同一 toggle | 合册 | 回进入前状态栈;焦点回载体(P-02 · §7.1) |
| 移焦(行/页缘) | 指针 hover = 快捷;方向键 | 左摇杆 / D-pad 经官方桥(P-01,禁自实现) | 焦点墨框 | 依 `slot_seq` 升序遍历 |
| 载入 | 点行(South=Submit) | 行上 South=Submit | 笔迹「画押」动效(§9)→ 执行 | `ISaveService.Load(SaveSlot)`;随后拆册(§9) |
| 存盘(落笔) | 空行 / 末行后 Submit(缝允许时) | 同一 Submit | 新行墨迹由淡入浓 | `Checkpoint(SaveSlot)`;**不跳页**,新行即第 1 焦点 |
| 前页 / 后页 | 点页缘 / 滚轮 | L/R 肩 → 页缘行(焦点可落,无独占按钮) | 翻页 | 页内焦点重置为该页首行(**本 spec 的 ux-design 外推**,同 OQ-SB-2 的合法外推口径;⚠️ 原括注「或末,见 OQ-SB-1」系引据漂移 —— `OQ-SB-1` 问的是跨开合持久,与本行的**页内**落点不同题,已于 2026-09-22 单独结案;若「回翻是否落末行」日后果需独立裁决,另立条目) |

**手柄路径无「按钮形态」**:翻页走「焦点移到页缘行再 Submit」或肩键意图(两者都在 action 资产内,
换绑不换语义 P-05);**South = Submit 归 7b**(规则七 `:180`),Interact 被模态冻结,零双触发。

**灰置行仍可聚焦且有反馈**(AC-7b-06,其 GDD 侧标 **[L]**;GDD 未标 BLOCKING 级 —— 本件引为走查执行体,措辞 2026-09-22 订正防漂移):「不能做」必须被**问得出**才讲得通 ——
灰置不可聚焦 = 玩家找不到问的地方 = 无声拒绝。
