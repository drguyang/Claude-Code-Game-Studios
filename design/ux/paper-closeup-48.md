## 2. Purpose & Player Need

玩家走近世界中的一张教学纸,「把纸拿到眼前读」。这张纸承担**一种媒体**:「纸上的图」
(承三媒体规则 —— 口述/示范/纸上的图,`tutorial-and-onboarding.md` 三媒体表)—— 它不教动作,
只给**可读的静态信息**:图示、标注、一句话结论。

**这个屏存在的理由**:
- 世界中的纸(美术布置的道具)只能「感知存在」,不可读(texel 密度不足,贴纸不可读);读 = 切近景。
- 教学纸的内容是**主动去读**的(拟物铁律:无 HUD、无弹出、无任务条);近景 = 「纸拿起来了」。
- 它是 P0 六步引导中「诊断/判断」第一步的主要书面载体(与口述并行;两媒体同源同时)。

**什么会变糟**(若本屏不存在或难用):
- 「纸上的图」媒体悬空(OQ-48-4 原三 BLOCKING 同根因)—— 教学纸退化为不可读的装饰。
- 手柄玩家无法关闭(断头)= P-04 破 = 不可玩级故障。

## 3. Player Context on Arrival

- **首次遭遇**:P0 教学清单第一幕(医馆初始房间),玩家跟随口述/示范流程,走近布置在案上的教学纸。
- **进入性质**:自愿(走近步进;纸非唯一路径,AC-48-07 玩家可完全不读)。
- **进入前一刻**:玩家在世界中自由移动(键鼠移动/手柄左摇杆);无时间压力(读纸无时限)。
- **情绪状态**:好奇、从容(引导期;非战斗非急救)。纸近景是**低唤醒**状态 —— 任何急促转场
  (快速推镜/缩放弹跳)都与此情绪冲突。
- **载体状态**:玩家站在纸旁(纸道具锚点格邻域),面对纸面;纸在其前。

## 4. Navigation Position

本屏是 **模态**(`ModalId` 面无表情切换),住在世界之上:

```
World(玩家自由移动 · 世界栈输入)
  └─ toggle(打开) ──▶ ModalId.PaperCloseup48(本屏 · 世界栈冻结 · 纸面近景)
                        └─ 同一 toggle(关闭) ──▶ World(焦点回进入前载体)
```

- **不是**导航层级中的目的地(不常驻可达);是上下文相关的模态(纸存在 → 可开)。
- **无二级入口**:仅「走近纸道具 + toggle」唯一路径(无菜单入口、无快捷键以外的入口)。
- **本屏内无子屏**:纸无内部交互(AC-48-16),无翻页/缩放/链接。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **纸上之图**(示意插图) | 教学纸的第一视觉承担 —— 「图」先于「文」(识字负担最低的障碍通道) |
| 2 | **墨色正文**(一句话说明) | 图的注解/结论;短句,≤170 字符(内容侧约束,防滚动) |
| 3 | **墨色标题**(纸张名/图题) | 纸的「身份」;教学纸为命题卡片式(如「望诊四要」) |
| 4(环境) | 纸外一圈世界环境 | 只唤起「纸在手上、世界还在」,不承载信息(无数据) |
| 5(环境) | 口述字幕(若口述在播) | AC-44-15 管线;与纸正文**可并存**但视觉上独立(字幕 = 随时换行,不看纸不看) |

层级原则:纸近景 = 「图 → 文 → 标题」的阅读序,不是「标题 → 正文 → 插图」的文档序。
纸上之图必须**接近视觉上部**(眼睛先落图,再落字)—— 承「图先于文」。

### 5.2 Layout Zones

裁定:**等比纸本**(2026-09-21 用户裁定,本页 §1 族默认)。

三区:
1. **环境区**(全屏背景,UI Toolkit 面板背景**透明**,露出下方相机渲染的世界)——
   世界**原样呈现**(P-02 反例铁律:**禁**加暗角/模糊/滤镜表达「进入模态」,破 ADR-020 §六)。
   近景时**主相机不动**(教学纸特例登记:纸 = 静态只读,推镜无增益,且引入晕动 + 报状态风险;
   详见 §9)。
2. **纸面区**(居中 · 等比)· 承纸面元件(纸纹底/边角压痕/九宫格切片)+ 墨迹元件;
   纸的长宽比 = 世界内纸道具的**出版纵横比**(作者态数据声明,见 §12)。
3. **字幕条**(屏底 · 横贯)· 口述字幕(AC-44-15,42 呈现、44 供语义;说话人前置 — 承 :92)。

**纸的尺寸规则**(1080p 基准 · 逻辑像素):
- 纸面区最长边 ≤ `min(72% 视口宽, 64% 视口高)`(留纸外环境 + 底字幕条)。
- 纸内容区宽 ≤ **720px**(正文 ≥24px × 每行 ~28 字中文的阅读舒适带)。
- 纸**等比缩放到上述两条约束的交集内**;长纸被「面积」而非「高度」约束。

### 5.3 Component Inventory

| 组件 | 类型 | 内容 | 可交互 | 元件库来源 |
|------|------|------|--------|-----------|
| 纸面元件 | 容器(纸纹底 + 边角压痕 + 九宫格切片) | 整张纸的外形 | 否 | 规则五「纸面」+ `-unity-slice-*` |
| 墨迹标题 | 文本(主题变量字号) | 纸名/图题 | 否 | 规则五「墨迹」 |
| 纸上之图 | 贴图载体(插图图集) | 示意插图(art 素材,AB §8.3 UI-纸 1K 档) | 否 | 42 素材装载(AC-48-02:素材归 42;48 只给内容语义) |
| 墨迹正文 | 文本(主题变量字号) | 一句话说明 | 否 | 规则五「墨迹」 |
| 字幕条 | 文本容器 | 口述字幕(44 供语义) | 否 | 42「语声字幕呈现」(AC-44-15 回刷落点) |

**零新增交互组件**(零按钮/零热区/零嵌套焦点);全屏无可交互元素 —— 这是本屏与
其他纸面屏(脉案/出诊箱)的关键差异:**读纸 = 纯呈现**。唯一动作(开/关)= 全局 toggle(§7)。

## 7. Interaction Map

**映射基础**:键盘/鼠标(主) + Gamepad(partial—— 完整可用) + 无触摸、无 VR
(承 `technical-preferences.md` Input & Platform)。

| 动作 | 输入(键鼠) | 输入(手柄) | 即时反馈 | 结果 |
|------|-----------|-----------|---------|------|
| 打开近景 | 互动 toggle(与拾取/互动同 action 资产,`EMPTY` 泛化 —— 见下) | 同一 action 资产(换绑不换语义,P-05) | 纸淡入(≤200ms,见 §8) | 切 `ModalId.PaperCloseup48`;世界栈输入冻结;相机不动 |
| 关闭近景 | **同一 toggle**(`EMPTY` 泛化) | **同一** toggle | 纸淡出(≤200ms) | 切回 `ModalId.None`;世界栈输入恢复;焦点回进入前载体(§7.1) |

**打开的交互判定归属**:走近判定 = **近近似 + 面向**的意图事件(承 4 交互系统;
纸近景的「读」触发 = `interaction-patterns.md` P-02 的「读纸 = 切 ModalId」)—— 具体判距/半径
属 4 的 GDD(本 spec 只承诺「走近可开」,不代拍值;数值域归数值轮)。

**关键形态:P-02 键鼠路径的「指针在纸面内直接取物」在此屏不适用** —— 教学纸无可取
(AC-48-16 纯装饰);故**唯一交互动作 = toggle**(开 + 关共用;**点纸外环境 ≠ 关闭**,不承诺
指针快捷关闭 —— 保持「双导航等价」齐平:两侧都只有 toggle,无任何一侧特权)。

**无自动消失 / 无超时关闭**(承 `accessibility-requirements.md:132`「含可操作信息的纸面提示禁止
自动消失」—— ⚠️ 原引 `:129` 为**行号漂移**:「UI 阅读时间」行实在 `:132`,`:129` 是「教学持久性」行,
2026-09-22 /ux-review 轮注式订正,同修见 save-slots-7b / casebook-39 / clinic-panel-24;引文逐字未动):纸近景唯一关闭路径 = toggle;口述播完**不**关纸,纸**不**随玩家走远自动收起
(玩家关纸后才恢复世界移动 —— 承 §7.1 载体回归)。

### 7.1 焦点(本屏 = 零焦点元素)

- **开**:纸无内部焦点元素(全屏无可交互),**不产生焦点移动、不施加焦点高亮**
  (承 :255「门关时不施加」);世界栈冻结(`IModalState.Modal` 只读,hide — 4 交互系统的第二门)。
- **关**:焦点**必须回到进入前的载体**(P-02 手柄路径铁律)—— 在教学纸语境 = 玩家控制的
  角色(世界侧输入恢复,toggle 后立即恢复移动)。这不是「焦点漂移」:纸近景没有格子/标记
  可回,载体 = 玩家的世界控制权本身;**载体回归义务 = 关后玩家可立刻继续移动,无任何
  焦点残留/丢失**。

### 7.2 零提示

- 全屏**零**按键提示/浮层/箭头(AC-48-01;`AC-3-F1a` ①② —— 关 = 由口述媒体教学「再按一次」)。
- 零教学设计音(AC-48-12 / AC-44-09:无 jingle、无叮声)。

## 8. Events Fired

| 玩家动作 | 事件 | 载荷 | 说明 |

OQ-42-5(42 只渲染的一次具体执行)的检验点。

## 9. Transitions & Animations

| 转场 | 规格 | 减动效(49 钩子) |
|------|------|-----------------|
| 纸进入 | 淡入 + 轻微纸上扬(动效缩放挂点 · 第四钩子,`:256`)—— **不**推镜(主相机**不动**,教学纸特例:纸 = 静态只读,推镜无增益 + 晕动/报状态风险) | 直接切(零动画) |
| 纸退出 | 淡出(同挂点) | 直接切 |
| 状态内切换 | 无(本屏无内部状态动画 —— 未绑定→可读 = 内容就位,纸本身无动效;口述字幕出现 = 字幕条自身管线) | 字幕无动效 |

**禁入**:任何相机运动(推/拉/摇)、任何镜头滤镜(暗角/模糊)在进入/退出纸近景时出现
= 均破 P-02 反例 + ADR-020 §六。纸近景的「近」来自**纸的尺寸**(纸拿近了),不来自镜头。
