## 1. 类型声明与所有权边界

本 spec 是 `AC-42-F1` 七员闭集**第一员**「**① 脉案页(39,⭑ 含方笺同页)**」
(`skeuomorphic-ui.md:1480`)的 per-screen UX spec;模态身份 = `ModalId.Casebook`(`adr-013:352`)。

- **39 = 独立系统,层籍 = 分册态层**(用户裁定 C 路,`OQ-39-1`/`OQ-42-5` 已于 2026-09-19 闭合):
  39 **与 42/44 不同构** —— 它是唯一「带持久化的呈现系统」,**`ADR-013 §9 C3` 对 39 不适用**
  (`casebook.md:341`)。⇒ 本屏不是「纯渲染」:它的布局语义归 39,但**分册键、两个 tick、页码/折叠状态**
  是 39 持有的真数据。
  ⚠️ 措辞纪律:全仓 `Loadable` 一词在 39/42/7a 三件**零命中** —— 本 spec 用「**分册态段** / `VolumeKey`」,
  不用「Loadable」(防造词)。
- **三方分权**(本屏最容易越权处,逐条钉死):
  | 方 | 拥有 | 不拥有 |
  |---|---|---|
  | **8** | 焦点顺序(`UI-8.2`)· 四态的**形态规则**(`V-8.2`)· 病名栏/置信度形态规则 · 「把握不足」的传达方式(`V-8.3`) | 纸的布局位、翻页组织 |
  | **39** | 纸面布局(五通道区 + 病名/置信度栏的**位置**)· 翻页与折叠组织 · 分册态段 · 相机档位的**唯一请求方** | 任何判定 · 任何词表内容 · 痕的独立存储 |
  | **42** | 渲染 · 元件库 · 焦点单栈门持有(不持游戏状态) | 布局语义(承 `skeuomorphic-ui.md:358` 39 先例) |
  | **11** | 方笺页的**数据语义**(药名/剂量/用法) | 相机档位意图(裁定「同一本书」⇒ 11 不发新意图) |
- **判据**:若本 spec 出现「按病情严重程度排序」「未查通道自动置顶」「已查计数」中任一 = 破 8 的
  焦点顺序铁律 + 39 三条「绝不」(§6 表)。
- **分册键 = `player_id`**(走 `IIdAuthority` 铸造,**非常量 0**;第二十七批订正 `casebook.md:117-121`)·
  `F-39.2 VolumeKey(p) = p.player_id` · 哨兵 `PatientId.None = -1` **不**用于分册。
- **痕(改写史)= 病例流读时投影,零独立存储**(`casebook.md` 规则二 · `OQ-39-3` 已闭合)——
  分册态段只存**两个 tick + 页码 / 折叠状态**等纯呈现量,**不存痕**。

## 2. Purpose & Player Need

脉案是**玩家判断的外化纸张**:五通道读数落笔其上、病名与置信度写在另一栏、方笺续在同一本书后头。
它是全案唯一「把隐性思考变成可复盘笔迹」的界面 —— 也是支柱一(判断为先)的物证。

**这个屏存在的理由**:
- 无血条 / 无 HUD(P-07):读数**必须主动去读、落笔即成事件** —— 脉案是唯一的落点。
- 医学顺序即输入顺序(`S-8.4` 路线甲):望闻问切**先于**处方,世界空间一个键装不下这个顺序,
  模态内行级动作天然表达「对这一通道做这件事」。
- 「方笺 = 同一本书」(`ADR-013 §十-B`):诊 → 脉案 → 方笺同册连写,施治笔本身即目标绑定。

**什么会变糟**(若本屏形态不对):
- 五行按「哪些已查」重排 ⇒ 肌肉记忆失效(8 的 `UI-8.2` 原话)= 手柄玩家的查体效率归零。
- 病名栏做成下拉列表 ⇒ 退化为图鉴,**击穿反幻想二**(8 侧 `AC-8-43/8-44` BLOCKING 守门)。
- 任何「把握不足」的文字标签 ⇒ 违反 `V-8.3` 且击穿规则五(§6)。

## 3. Player Context on Arrival

- **入口**:世界空间对病人裸 `Interact` = **就诊/立案**(单义,路由 37,`S-8.4` 表)→ 立案即开册;
  或已立案病例再次打开脉案(焦点自载体回归)。
- **进入前一刻**:世界内站定于病人旁(查体需近身;判距归 4,数值域归数值轮)。
- **情绪**:高压或从容皆可能(急救态下开册 = `Armed` 期被 10 压制 `InteractIntent`,本屏不与之争,
  见 `S-8.4` 路由表末行)。
- **档位耦合**:`OpenCasebook() ⇒ ICameraRig.SetMode(Casebook)`;`Close ⇒ Explore`(规则五)。
  **39 是全案唯一档位请求方**(用户裁定 2026-09-19;2 侧已按此修订)⇒ 本屏的开合是**唯一**
  会改机位的 UI 动作,转场次数受 `AC-39-07` 约束(恰 2 次 · `SetMode` 幂等)。
- **联机**:档位 = 本机表现态,不上行(规则五)。「结束」判据归 39。

## 4. Navigation Position

```
World(自由态)
  └─ Interact(病人) ──▶ ModalId.Casebook(本屏 · 档位 Casebook · 世界意图冻结 · 移动不抑制,OQ-39-4 已裁)
                          ├─ 行级 Submit ×5 → 查体(路由 8)
                          ├─ 病名栏 Submit → 病名册(§5.2 右页内嵌,非新模态)
                          ├─ 续页 → 方笺页(同模态内的一页,11 语义)
                          └─ toggle/离开判据(「结束」归 39)──▶ World(档位 Explore · 载体回归)
```

- 本屏是**导航层级的主目的地**(可反复回),不同于上下文模态;但**病名册 / 方笺页不新增 `ModalId` 员**
  —— 二者皆「同一本书里的另一页/另一处」(`ADR-013 §十-B` 对 ① 的语义扩充)。
- **零嵌套模态**:任何「在脉案上再开一个窗」= 破 `IModalState` 单值非集合约束(规则十四)。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **五通道体征区**(面色 → 语声 → 姿态 → 呼吸 → 触感) | 固定自上而下 = 焦点顺序 = 视觉顺序(同一个序,不两套) |
| 2 | **病名栏**(与体征区**物理分离**) | 8 的 UI-8.1 铁律③ —— 分离是「判断不是读数」的空间表达 |
| 3 | **置信度**(笔迹笃定度 + 墨色深浅 + 「?」) | 「?」**只许出现在此栏**,溢入体征栏 = 变相数值 |
| 4 | **方笺续页**(同一本书的下一页) | 施治落笔位;药签式古籍功效词呈现(11 规则八) |
| 5 | **页边铅笔小勾**(「旧读数」附加标记) | 临床病历物理做法,**不靠颜色**(8 的 UI-8.2 末行) |
| 6(环境) | 纸外一圈世界(案面 / 病人轮廓在景深外) | 唤起「我在床边摊开了册子」;零数据 |

**层级原则**:体征区读「**一个人**」,病名栏读「**我的判断**」—— 两者永不并排成表格
(并排 = 诱发「对着填」= 归纳泄漏路径)。

### 5.2 Layout Zones

裁定:**等比纸本族的「册页摊开」变体**(族默认承 `paper-closeup-48.md` §1 用户裁定;本屏布局语义归 39)。

两栏(承 `skeuomorphic-ui.md` 对 39 的「五通道区 + 两栏」既有描述,布局语义已随 `OQ-42-5` 闭合归 39):

1. **体征区**(左页 · 满版纸线格):
   - **恰五行**,序 = `channel` 枚举逐字:**面色 / 语声 / 姿态 / 呼吸 / 触感**
     (`diagnosis-system.md:390`;面色正式口径含「一般检查·头面」)。
   - **永不留空隐藏**(UI-8.1 铁律①):未查 = **空行 = 有格线无字**,非徽章、非灰字、非占位符文本。
   - 每行右侧 = 该通道的**落字词位**(三档词表槽位由 8 的 R-8.2 决定写哪个词;「纸上有字 ≠ 证据」——
     `slot` 决定写哪个词,`tier_named` 决定算不算证据,二者分工见 `:406-412`)。
   - **纸外无数据**:通道行不显示任何手段标签计数(`reveal_by` = 视/触/叩/听/问诊 是**机制侧**字段,
     不进呈现 —— 呈现的是笔迹本身)。
2. **判断区**(右页 · 上半 = 病名栏 · 下半 = 置信度栏):
   - 病名栏与体征区**跨页物理分离**(不同一页 = 最强的分离保证)。
   - 病名栏下方 = 置信度栏(笔迹形态三件:笃定 vs 迟疑 · 墨色深浅 · 「?」)。**零第三档控件**
     (`S-8.3` 三态:空 / 疑似 / 确定;UI-8.4 禁第四档)。
     **⭑ 输入侧形状 = 甲「循环落笔」(✅ 2026-09-22 用户裁 `OQ-CB-5`)**:置信度**无独立焦点位** ——
     档位由**病名栏的重复落笔**循环填入 `judgment.confidence: u8`:
     **指认落笔 = 疑似 → 同栏再 `Submit` = 确定 → 第三落 = 擦除回空**(恰三态 = `S-8.3`)。
     **零新焦点位 / 零新动作 / 零新机制** —— 置信度栏因此是**纯呈现区**(不进焦点遍历):
     空 = 无字 · 疑似 = 迟疑笔迹 + 淡墨 + 「?」 · 确定 = 笃定浓墨收锋。
     ⚠️ **本裁暴露 8 / 42 的陈旧面(登记残留,见 §14 OQ-CB-5 结案行)**:`diagnosis-system.md`
     规则六(「勾一档置信度」)· UI-8.2 / `AC-8-23` / `AC-8-44`(焦点序含「置信度」)· 与
     `skeuomorphic-ui.md` F3 算例(「一屏 7 个元素」K = 7)均仍把**置信度当作第 7 个可聚焦元素**;
     甲裁定后脉案的可聚焦元素 = **五通道 + 病名栏(K = 6)**,置信度**不是焦点位**。
     8 的焦点序**语义**权威须就本点改写 —— **归 8 回写轮;本裁只登记冲突,不代改 8 正文**。
3. **方笺续页**(本书翻页后的下一张):方笺是一个**书写面**,不是勾选框(出处 = `prescription-and-medication.md:771` §Visual —— ⚠️ 原稿注「11 规则七」为**出处漂移**:11 的规则七 = 剂量「资源刻度」收窄(`:80` 指针),不是书写面句,2026-09-22 /ux-review 轮订正);
   其上剂量读数元件 = **黄铜侧**(戥子档位读数,第二十八批认领;禁降级数字角标,两栈皆禁)。

**纸页容量与翻页组织**(`OQ-39-2` —— 39 侧已明载「表现层组织合法外推 /ux-design,机制契约零外推」,
故本节由本 spec 行使裁定权):

| 项 | 裁定 | 理据 |
|---|---|---|
| 一案的纸面 = | **一开册页摊**(左页五通道 + 右页判断区)+ **方笺续页 1..n**;**150% 缩放溢出时同此组织** —— 续页摊开,**零滚动**(✅ 2026-09-22 `OQ-CB-3` = 甲) | 判断链的单元是「一次面对一个人」;分页 = 把判断切成两半。溢出吸收走**翻页组织**(纸不滑动),行高恒定判据**不变** |
| 翻页序 = | **遇见顺序**(病例流的 `CaseOpened` 序),**不可按任何状态重排** | 任何「未结案排前面」= 隐性计数/引导 = 破三条绝不① |
| 册内检索 = | **无**(无索引、无标签、无分类、无搜索) | 破绝不②(分组的结果就是归纳) |
| 折叠 = | 右页可**向左折回**盖住判断区(纸背朝上);折/展 = 焦点到折边 + Submit | 分册态段**已存**「折叠状态」(`casebook.md:296`)⇒ 该呈现量必须有语义,否则字段悬空 |
| 折叠的机制影响 = | **零**(不进流 · 不参与判定 · 不入痕) | 纯呈现量;守卫见 AC-CB-07 |

**墨龄**(规则十三):`当前 tick − 落笔 tick` → 旧字**洇散 + 氧化黄**,**新读数压印在旧字之上**
(`V-8.2`「旧」态);时钟源 = `ITickProvider` 只读视图(**非墙钟**,`OQ-42-14` 同族纪律)。

## 6. States & Variants

**每通道行的四态**(形态规则权威 = 8 的 `V-8.2`,本表只落呈现位):

| 态 | 触发(来自 8 的 `S-8.2` 状态机,经 `VitalsDto` 只读) | 呈现 |
|----|---|---|
| **待查** | 未落笔 | **空行:有格线无字**,纸面平整无压痕(零提示文案,`AC-39-09` 空置零提示) |
| **阳性(已落笔)** | 落笔事件投影 | **浓墨收锋**,玩家笔迹,行内左对齐题签后落字 |
