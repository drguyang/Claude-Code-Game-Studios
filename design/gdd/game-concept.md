## 电梯陈述 (Elevator Pitch)

> 一款以清末民初为背景的开放世界生存建造游戏:你是一个只懂西医的孤身游医,
> 在战乱与瘟疫的乱世里采药、炮制、开方、救治、建造医馆 ——
> 并以医术与格斗在这片土地上活下来。**西医给你还原(微观精准),中医给你整体(宏观平衡);
> 而在这乱世,你必须两样都会 —— 还得先活着走到下一个病人面前。**

10 秒测试:「医学版的《英灵神殿》,但你治的不是怪,是病人;你的武功一半是医术、一半是格斗,
而**你永远不杀生**。」→ 通过。

## 核心幻想 (Core Fantasy)

> **「在这片谁都在死的土地上,我是那个把人拉回来的人。」**

玩家获得的力量不是数值成长,而是三种能力的叠加:

1. **认得出来** —— 从只会清创缝合的普通西医,到能一眼看出病人是什么证候。
2. **亲手救回** —— 一次真实的急救:按压、包扎、开方。有手感,有节奏,有紧张的几秒。
3. **留下东西** —— 一间从茅草屋长起来的医馆,一本自己写的《脉案》,一个被改变的村子。

这个世界里没人能靠刀剑活下去,但**医者可以**。

## 独有钩子 (Unique Hook)

> **它像《英灵神殿》的生存建造探索,AND ALSO 你的核心能力是「判断 + 医术 × 格斗」——
> 诊断决定你用哪种手段,手段决定你活不活得下来,而你永远不杀生。**

四条支撑这个钩子的设计:

1. **判断为骨,手感为肉** —— 治疗的主体是「观察 → 判断 → 选手段」这个判断链;
   对应的急救动作做成手感小游戏,**可跳过**。跳过时用「判断 + 熟练度」结算 ——
   判断对了就成,手技只是加分。同时服务两类玩家:想「想」的,和想「做」的。
2. **全非致命(双向)** —— **人不杀**:敌人的生命值**照常可以打到归零,但归零是昏迷不是死亡**;
   他躺下之后你选:救治、审讯、捆绑。**但这个世界不回报这份仁慈 —— 别人会杀你。**
   **「不杀」只约束人。** 出诊途中撞上的危险动物(蛇 / 熊 / 狼 / 野狗)**可猎杀取材、可驱赶**;
   驯化与招为护卫 = P1a(并入 `systems-index.md` #28)。
3. **格斗 × 医术耦合** —— 战斗是一条**真实的独立技能线**(徒手·短兵·钝器·长兵·暗器,
   见 `skill-system.md` §3.4),但它和医学**共用同一套身体知识**:短兵对解剖(哪里会流血)、
   暗器对经络(哪里会麻痹)、徒手对正骨(关节怎么卸、怎么锁)。**会打的打得过,
   懂行的打得更狠** —— 医术最多把战斗效能抬高 20%,永远替代不了格斗。
   他不只是个游医,他是个**带着一箱子器械、知道该往哪儿下手**的人。
4. **医馆即机器** —— 医馆不是一栋房子,是一台**你摆零件就会运转的机器**。
   房间的位置决定感染率、药材产量、病人恢复速度。**你怎么建医馆,就暴露了你怎么理解医学。**

## 玩家体验分析 (MDA Framework)

### 目标审美 (玩家感受到什么)

| 审美 | 优先级 | 如何交付 |
| ---- | ---- | ---- |
| **Expression**(表达、创造) | **1** | **① 医馆即机器** —— 你的布局 = 你的医学观的实物版<br>**② 治疗风格与名声** —— 你救过谁、你怎么救、人家怎么记得你 |
| **Discovery**(探索、秘密) | **2** | 生态区推进、失传古方、时代事件背后的真相 |
| **Challenge**(挑战、精通) | **3** | 判断难度(表现相似、信息不全)、急救小游戏的手感上限 |
| **Fantasy**(代入、角色扮演) | **4** | 「游医」身份、清末民初的时代质感 |
| **Narrative**(戏剧、故事弧) | **5** | 时代篇章、病患的个体故事 |
| **Fellowship**(社交、连接) | **6** | 1-4 人非对称协作(主刀/主诊/后勤) |
| **Sensation**(感官愉悦) | **7** | 水墨 × 黄铜工业的双美术、拟物 UI、京戏与药香 |
| **Submission**(放松、舒适区) | N/A | 非本作目标 —— 死亡与压力是设计的一部分 |

### 关键动力学 (期望涌现的玩家行为)

- 玩家会开始**先观察再动手**:因为判断错了,后面全白做。
- 玩家会**为布局纠结**:「手术室挪过来感染率降,但床位就少了。」
- 玩家会**主动去找没见过的病**:因为新颖度加权,重复病例几乎不涨熟练度。
- 玩家会**为一个救不回的病人的死而难过**,然后回去翻自己的脉案。

### 核心机制 (我们要造的系统)

1. **判断链** —— 观察(西医查体 / 后期的望闻问切)收集信息 → 判断 → 从手段池选治疗方式
2. **急救动作模块** —— 每个动作一套手感小游戏(第三人称;VR 可选),可跳过
3. **技能与熟练度** —— 19 项技能,行为决定成长,新颖度加权防刷(见 `skill-system.md`)
4. **格斗与医术耦合** —— 五条武器线(徒手/短兵/钝器/长兵/暗器),格斗主导战斗效能,
   医术给 ≤+20% 修正;**制服而非杀戮**
5. **医馆即机器** —— 房间位置约束 + 「快 vs 好」两套冲突评分
6. **药物槽** —— 药物 = 带半衰期的状态槽;时机与过量都有意义
7. **采集 · 炮制** —— 采集(识别品级/单次采量)、炮制(药效强度/转化率)

   > ⚠️ **口径裁决(2026-09-13)**:**P0 的「炮制」= 提取 / 干燥 / 标准化**(植物化学流程),
   > 采的是**药用植物原料**(柳树皮、毛地黄、金鸡纳树皮),产出**西药成品**
   > (水杨酸类、洋地黄酊、奎宁)。**「炮制」要到 P1a 才取得它的中医含义**(蜜炙、清炒)。
   > 采药对象与加工法的 P0/P1a 分档见 `skill-system.md` §3.2。
   > **理由**:P0 是纯西医切片,但采集/炮制是 P0 熟练度七项之二 ——
   > 它们必须有产出归宿,否则是两个练不动的技能。详见 `item-database.md` §命名铁律。

## 玩家动机画像 (Player Motivation Profile)

### 核心心理需求 (SDT)

| 需求 | 本作如何满足 | 强度 |
| ---- | ---- | ---- |
| **Autonomy**(自主、有意义的选择) | 去哪、救谁、怎么建医馆、在「快」和「好」之间选哪个 —— 全部开放;**没有预设职业** | **Core** |
| **Competence**(精通、技能成长) | 技能是「行为决定」而非「点天赋」;你会真的**认得出来** | **Core** |
| **Relatedness**(连接、归属) | 联机非对称分工;NPC 病患与村落的羁绊 | Supporting |

### 玩家类型 (Bartle)

- [x] **Explorers**(探索者) —— 生态区推进、失传古方、时代事件的真相。**主要受众。**
- [x] **Achievers**(成就者) —— 19 项技能的成长、医馆升级、公共卫生危难的攻克。**主要受众。**
- [x] **Socializers**(社交者) —— 1-4 人协作急救。次要受众。
- [ ] **Killers/Competitors** —— **非本作受众。**无 PvP,战斗以制服为终点。

### 心流设计 (Flow State)

- **上手曲线**:P0 从「止血包扎」教起(最直观)→「心肺复苏」(引入节奏与时间压力)
  →「处方用药」(引入判断与取舍)。
- **难度爬升**:判断难度来自**信息不全**(查体只能拿到部分信息)与**表现相似**;
  手感难度来自**环境 debuff** 与**精神压力**。
- **反馈清晰度**:拟物 UI,但状态必须可读 —— 呼吸声、屏幕边缘微红、把脉音效的变化频率。
  **无血条不等于无反馈。**
- **失败恢复**:救人失败 = 病患死亡,不可撤销。但你的《脉案》会记下这一例,
  失败是**叙事与学习的材料**,不是读档点。

## 核心循环 (Core Loop)

### 瞬时循环 (30 秒)

**判断链**(永远在做):
观察(查体 / 望闻问切)→ 判断(这是什么?)→ 选手段(该用哪一项?)

**操作层**(可选,可跳过):
所选手段对应的动作 —— 跟着节拍按压 / 按顺序清创包扎 / 斟酌开方。
跳过 = 用「判断 + 熟练度」结算。

> 内在满足感:①判断对了的「我懂了」②小游戏最后几秒的时间压力
> ③病患状态从危到稳的可见变化。

### 短期循环 (5-15 分钟) —— 「出诊」

接获急症 → 前往事发地(途中可能遇敌/遇险) → 现场判断 → 施治 →
收获病历与材料 → 回医馆整理脉案、**调整医馆布局**、炮制药材

**「再来一次」的心理落在哪里**:「这个病人我没看懂,下一个呢」/「医馆这么摆到底行不行」。

### 单次会话 (30-120 分钟) —— 「一个案子」

一次完整出诊 + 一趟采集 + 医馆事务 → 天然停止点 = 把脉案写完、把布局改完。
回访钩子:城里还躺着一个你没救回来的病人;山里那一味药还没找到。

### 长期成长 (天/周) —— 「一个时代」

**技能(19 项,行为决定)** × **地理(4 生态区)** × **医馆(逐步扩建)**
× **时代篇章(辛亥革命 / 1918 大流感 / 废止中医案)**

**奖励逻辑**:解决重大公共卫生危难**不掉神装,掉「权限」**——
控制贫民窟霍乱 → 解锁「市政防疫督办」权(可强制隔离、调动城防军);
治愈军阀头目 → 解锁「租界黑市通行证」(可买稀缺血清)。
**医者的力量是制度性权限,不是数值。**

### 留存钩子 (Retention Hooks)

- **好奇**:生态区那头的疫源地是什么?药农手里的古方从哪来?
- **投入**:你的医馆、你的脉案、你救过和没救回的人。
- **社交**:联机时队友在你手上活过来;分工失误导致病人死在台上。
- **精通**:19 项技能的成长曲线、格斗手感、判断准确率。

## 游戏支柱 (Game Pillars)

### 支柱一:判断为骨,手感为肉

治疗的主体是判断,不是操作。每个动作都**必须有跳过路径**,跳过时以
「判断正确 + 熟练度足够」结算。手感小游戏是给愿意亲手做的玩家的加分,不是门槛。

*设计测试*:如果我们在争论「这个动作要不要做成强制小游戏」,这条支柱说:
**不做成强制。永远给一条判断结算的路。**

### 支柱二:医者不杀

玩家永不杀生 —— 包括被逼到绝境时。但**这个世界没有这份仁慈**:土匪会杀你,
野兽会吃你。你的克制是一种**选择**,不是这个世界的规则。

*设计测试*:如果我们在争论「能不能给玩家一个真正致命的攻击」,这条支柱说:
**不能。恰恰因为别人可以,而你不可以,这个选择才有分量。**

> 注:敌人**永不因你的攻击而死** —— 生命归零结算为**昏迷**(脑震荡 / 失血性晕厥),
> 之后你可**救治 / 审讯 / 捆绑**。伤害全程有效,不存在「打到某个百分比就停手」的魔法阈值。
> **「不杀」只约束人,不约束野兽** —— 动物可猎杀取材、可驱赶(P0),可驯化、可招为护卫(P1a)。
> 这不是支柱的例外 —— 支柱二原文写的就是「土匪会杀你,**野兽会吃你**」:
> 野兽**从一开始就不在那份仁慈的范围内**。2026-09-13 裁决收回的只是此前对这条的过度延伸。
> 昏迷后**晾着也不会死**(D1=甲)—— 你**连见死不救都杀不掉人**。
> 「医者不杀」因此没有机制牙齿,它纯粹是表达;而这正合支柱二原文:
> **你的克制是选择,不是世界的规则。**

### 支柱三:还原 × 整体(两种看法,一次长出来的转变)

**P0 只有「还原」**:诊断技能回答的是「**这是什么病**」——
看清楚、看准确。它给你细节,不给你全局。

中医不是一套独立玩法,而是在 **P1a** 逐步打开的两处门:
- **辨证**(P1a) —— 你开始问「**这个人整体是什么样的**」(情志、体质、时序),
  并因此获得**有条件的被动加成**。这是「整体」这一半
- **处方用药里的中药**(P1a) —— 中药进入你的处方(**用药选项的扩展**,不做组方系统)

> **两种能力,一个转变**:诊断让你把身体当成一台可以逐个零件检查的机器;
> 辨证让你开始把身体当成一个相互关联的整体。**它们不是同一个技能的两个等级,
> 而是两种不同的看法。**
>
> **接续关系**:诊断练到一定火候(P1a 门槛)才能开辨证 ——
> 先把细节看清,才谈得上看出整体。

*设计测试*:如果我们在争论「要不要给中医做一套独立操作/组方系统」,这条支柱说:
**不做。整体观是「换一种看法」,不是「多一套工具」。**

### 支柱四:时代即关卡,危难即 Boss

清末民初的动荡与瘟疫是世界的驱动力。「Boss」= 重大公共卫生危机或权贵疑难杂症,
通关奖励是**改变世界规则的权限**,不是装备。

*设计测试*:如果我们在争论「这次通关给什么奖励」,这条支柱说:
**给权限,不给数值。让玩家改变世界的规则,而不是变强。**

> **⚠️ Boss 的形态:不是一个你打的实体,是一个你「拼」出来的图样。**
> *(2026-09-14 补注,据英灵神殿/我的世界对标复核)*
>
> 本作**固定世界**(弃用「离中心越远越强」的空间轴)+ **医者不杀**(没有可击杀的 Boss)——
> 这两条合起来会掏空「Boss」这个词。**支柱四因此必须回答:Boss 长什么样?**
>
> **答案:瘟疫不会站在你面前。** 它表现为**散落的病例** —— 一个病人、又一个病人,
> 分散在不同街区、不同时间。**认出「这些是同一个东西」这件事本身,就是 Boss 战。**
> 玩家在脉案上把它们钉在一起、看出模式的那一刻 = 通关。
>
> **为什么这忠于本作而不是硬凑**:
> - **支柱一(判断为骨)** 被**放大** —— 判断从「一个病人」抬到「一群人」
> - **支柱二(医者不杀)** 无冲突 —— 你**遏制**的是模式,不是杀生
> - **支柱三(还原 × 整体)** 装得下 —— 跨病例归纳是**流行病学**,属西医还原论传统,
>   正是 P0 的「还原」半边;**还顺手为 P1a 的「整体」埋了伏笔**
> - **奖励天然闭合** —— 认出疫情 → 处置 → 拿到**防疫督办权** → 下一生态区开门
>
> **⚠️ P0 的断口(已记账,见 `systems-index.md` §5 #52 注 + §11)**:支柱四是对的,
> **但 P0 唯一的事件池是「兵痞 + 野兽」—— 打兵痞不算行医**。P0 必须补
> **医疗事件模板 + 一条手工编写的病例链**,否则「往哪走」在 P0 是断的。
> 完整的公卫系统(#34)仍留 P1a。
>
> **⚠️ 一条不可动摇的规则**:进度解锁**挂「处置结果」,不挂「诊断正确」**。
> 否则**误诊会软锁进度,而玩家不自知** —— 那会**同时违背 8 的全部哲学**
> (误诊不报错 · 空是合法终态)。**例例要有交代,判断对错不是门槛。**

### 支柱五:史实为骨,架空为肉

真实的医学史作骨架(1910 东北鼠疫 / 1918 大流感 / 1929 废止中医案),
真人只作**原型**,永不作为可交互角色。断代必须经得起考据。

*设计测试*:如果我们在争论「能不能让史实人物出场并与之对话」,这条支柱说:
**不能。原型可以借,人不能上台。**

### 反支柱 (本作明确不做的事)

- **NOT 火器 / NOT 致命终结** —— 战斗是一条真实的技能线(见钩子 #3),但它**永远以制服收场**,且**不引入火器**(枪没有非致命终点)。
- **NOT 中药组方/配伍系统** —— 中药是处方里的选项,不是一套合成玩法。
- **NOT 硬核生存折磨** —— 饥饿与温度服务于「行医」,不是目的。
  **P0 不设饥饿 / 体温系统**;**玩家自己的身体不产生持续生存压力**;
  **药物槽是唯一的身体反馈层**,P0 的「生存」= **补给管理**(带药量 / 时段)。
  *(理由:把压力让给「判断」,而不是「续命」。2026-09-14 裁决)*
  > ⚠️ **这条与「主角也有身体」的张力**:下面《玩家死亡与代价》写着
  > 「这个游戏的主角**也有身体**,他会受伤,会手生」。**P0 用「死亡代价三件套」兑现它,
  > 不用「饥饿/体温」兑现** —— 身体在**被打倒时**说话,不在**吃饭时**说话。
  > 后果与责任落在 **#53 医疗后果与责任**(P0);长期名声落在 31(P1a)。
- **NOT 十卷线性剧情** —— 世界是沙盒,故事从探索与时代事件里长出来。
- **NOT 玩家自制内容影响真实医学认知** —— 医案 UGC 必须设内容边界(见《风险》)。

## 玩家死亡与代价

**玩家会死**(英灵神殿式),三样代价:

| 掉什么 | 为什么 |
| ---- | ---- |
| **掉落物**(药物、材料、器械) | 需要回去捡 —— 制造一次「狼狈的回程」 |
| **技能熟练度**(-5%) | 框定为「**手生**」而非「遗忘」:你被打倒、卧床养伤,伤好了手却生了 |
| **精神压力**上升 | 这才是你真正的损失 |

**不掉**:已解锁的动作、已学的知识、已写的脉案。

> **这条规则强化主题**:这个游戏的主角**也有身体**。他会受伤,会手生。
> 「医者也是人」不是设定文案,是数值规则。

## 药物槽 (Drug Slots)

替代英灵神殿的「食物槽」,但**比食物槽更有医学道理**:

- **3-4 个槽**,每个槽装一味药
- 每味药给一组**曲线**:生命恢复 / 体力上限 / 判定精度 / 抗感染
- 带**半衰期** —— 药效随时间衰减,不是常驻 buff
- **过量有毒性** —— 同一个槽反复灌同类药会中毒
- **时机有意义**:术前吃抗凝要算凝血时间;战前吃提神要算峰值;补药不能当饭吃

> 这既是「专家不出戏」的必要条件,也是**几乎白送**的一套深度 ——
> 它复用英灵神殿已验证的机制结构,只把「食物」换成「药物」,主题立刻变厚。

## 技能与熟练度系统

> 完整设计见 `design/gdd/skill-system.md`。此处仅列清单。

参考英灵神殿的模型(21 项技能 / 使用即成长 / 上限 / 死亡扣减),本作 **19 项,6 类**:

| 类别 | 技能 |
| ---- | ---- |
| **医术 (6)** | 诊断 · 辨证 *(P1a)* · 急救(止血/包扎/正骨/复苏)· 手术 · 处方用药 · 针灸 |
| **生产 (3)** | 采集 · 炮制 · 装备(器械与设备生产) |
| **社会 (3)** | 沟通 · 公卫 · 商业 |
| **生存 (2)** | 奔跑 · 潜行 |
| **格斗 (5)** | 徒手 · 短兵 · 钝器 · 长兵 · 暗器 —— **战斗效能的来源;与医术耦合(≤+20%)** |

> **P0 只有「诊断」这一项医术判断技能** —— P0 是纯西医切片:主角做**西医诊断**
> (**有技能,可成长**),全程不使用任何中医词汇。**「辨证」是 P1a 的技能** ——
> 那才是「看出整体」成为可成长能力的时刻(见《支柱三》)。
>
> **诊断 vs 辨证的分工**(本作「还原 × 整体」的两种能力):
> - **诊断**(P0)= 回答「**这是什么病**」—— 病名层面,看清细节,判断更准(还原)
> - **辨证**(P1a)= 回答「**这个人的整体状态如何**」—— 个体层面,情志/体质/时序,给治疗加成(整体)

**三条成长规则**:
1. **使用即成长,行为决定** —— 没有天赋树,没有职业
2. **新颖度加权** —— 首次处理某证候/病种/药材 → ×3.0;立即重复 → ×0.2(防刷)
3. **上限 60**,前段快、中段稳、后段慢

**格斗 × 医术耦合**(完整规则见 `skill-system.md` §3.4):

```
战斗效能 = (格斗技能等级 × 武器系数) × (1 + 医术修正)
医术修正 = 0.20 × (关联医术等级 / 60)      ← 上限 +20%
```

| 武器线 | 关联医术 | 耦合的道理 |
| ---- | ---- | ---- |
| **徒手** | 急救(正骨)| 你知道关节怎么卸、怎么锁 |
| **短兵** | 手术 *(P1a)* | 你知道哪里会流血、哪里脆弱 |
| **钝器** | *(无)* | —— |
| **长兵** | *(无)* | —— |
| **暗器** | 针灸 *(P1a)* | 你知道哪里会麻痹 |

> **医术最多把战斗效能抬高五分之一** —— 会打的人(格斗高)打得过,懂行的人(医术高)
> 打得更狠,但**医术一个人撑不起战斗**。一个手术 60、短兵 5 的医生,打不过短兵 40 的人。
> **P0 里只有 `徒手 ← 急救` 这一条耦合是活的**(手术/针灸是 P1a)。

## 医馆即机器 (The Clinic as a Machine)

> **一句话**:你的医馆不是一栋房子,是一台**你摆零件就会运转的机器**。
> 用《我的世界》打比方:红石摆对了自动开门;这里是把「红石逻辑」换成了「医学逻辑」。

### ① 位置即逻辑(不是「有没有」,是「在哪」)

| 摆放 | 后果 |
| ---- | ---- |
| 病房紧挨手术室 | **术后感染率上升**(脏病人污染手术区) |
| 药圃背阴却种喜阳的药 | **减产或枯死** |
| 丹房离水井太远 | **炮制火候难控,成药率下降** |
| 传染病区与普通病房相邻 | **交叉感染,可能死一片** |

这是**空间解谜**:在有限地块里满足一堆互相冲突的邻近约束。

### ② 两套评分,互相抢(「快」vs「好」)

| | **效率(快)** | **疗愈(好)** |
| ---- | ---- | ---- |
| 供给 | 更多床位、更短动线 | 更多阳光/通风/安静/宽敞 |
| 得益 | 能同时接更多病人 | 病人恢复更快、复发更少 |
| 代价 | 舒适度↓、感染风险↑ | 占地大、吞吐低 |

两条路都对,但你**只能选一个偏**。

### ③ 所以 —— 这就是 Expression

> **你怎么建医馆,就暴露了你怎么理解医学。**
>
> 只懂西医的玩家会建:诊室 → 药房 → 手术室,一条干净的流水线(**把身体当机器修**)。
> 开始有整体观的玩家会想:病人住的地方会不会影响他好起来?(**把身体当整体养**)
>
> 你造出来的不是「一栋好看的房子」,是**你对医学的理解的实物版**。

随着 **辨证** 熟练度上升(P1a 起),「疗愈」侧的价值会被你自己的眼睛重新定价 ——
**医馆的演变 = 你的整体观的演变**。

## P0 的叙事钩子:《他回来了》

> 支柱三说「还原 × 整体是两种看法」。但 **P0 只有还原**。
> 那么 P0 的钩子不能是「还有另一种看法」(那是 P1a),
> 只能是它的反面:**「这一种看法有尽头。」**

这不是另起炉灶 —— 是**把原钩子倒过来**。原「穴位针扎 = 中医解锁时刻」让玩家
第一次发现「还有别的看身体的方式」;它随针灸推至 P1a 后,P0 承担的是**同一个主题的另一半**:
玩家必须先**撞上墙**,P1a 的那扇门才有意义。

### 两幕结构

| | 内容 | 玩家得到 |
| ---- | ---- | ---- |
| **第一幕** | 一次外科急症 / 战伤。**你的西医手段漂亮地救回来了。** | 「**我行了**」—— 一次毫不含糊的胜利 |
| **第二幕** | 同一个病人**回来了**。这次是失眠、心悸、乏力、说不出的疼。查体**全部正常**,西药**全部无效**。 | 「**我全都做对了,那我错在哪?**」 |

**切片结束时:他还在病着,脉案上那一栏病名是空的。**

### 为什么是「神经衰弱」

第二幕的病选 **神经衰弱(neurasthenia)** —— 这是**西医自己承认的盲区**,不是游戏强加的失败:

- Beard 于 1869 年提出,19 世纪末 20 世纪初在欧美极流行;
  **1920–1930 年代在中国城市高度流行**,集中在通商口岸,时人称之为「**文明病**」
- 它是一个**兜底诊断** —— 症状是疲劳、失眠、焦虑、头痛、抑郁,
  药厂专门为它打补药广告。**它的定义就是「没有可证实病变的功能障碍」**
- 这意味着:**还原论在概念上就处理不了它**。这不是「西医不行」,是「**还原论有尽头**」
- **DSM-III(1980) 正式删除该诊断**;DSM-IV 仅作为文化相关综合征保留于附录,
  并专项点名中国的 shenjing shuairuo —— 它从来不是「治好了」的,是「换了个名字」

**两个额外的好处**:

1. **自带的时代质感** —— 当时的病人典型是**受过新式教育的城市男性**。
   这个病例于是自动接上《新青年》的德赛之争:一个信科学的人来看一个科学解决不了的病。
2. **天然的 P1a 桥梁** —— 时人把神经衰弱与**肾虚、遗精**做了混合理解。
   于是 P1a 里中医会对这张**同样的脸**给出一个名字。玩家第一次亲眼看到:
   **另一种看法在白纸上说出了东西。**

### 红线(不可违反)

⚠️ **第一幕必须是一次毫不含糊的西医胜利。**

处理不好,这个钩子会读成「**西医不行,中医才行**」—— 那会毁掉整个概念。
本作是 **还原 × 整体**,不是 整体 > 还原。顺序不能反:
**玩家必须先赢一次**,第二幕的失败才读作「这条路有尽头」,而不是「这条路是错的」。
对医学从业者受众尤其致命 —— 那是他们第一眼会盯的地方。

### 载体:脉案里空着的那一格

**几乎零成本的交付方式。** 《脉案》是 P0 已有的拟物 UI 系统(MVP 第 6 项)。
每个病例记「病名 / 体征 / 处方 / 结果」。切片结束时,满本已结案 ——
**只有一格,病名那栏是空的。**

不需要旁白说「你还不会治这种病」。**空着的那一格自己会说。**

### 对 P0 范围的增项

| 增项 | 说明 | 性质 |
| ---- | ---- | ---- |
| **复诊** | 同一病人二次到访。复用现有病例系统,加一条时间触发 | 小 |
| **「查体全正常」的诊断变体** | 玩家真的做检查,结果是一排「正常」。这是**诊断系统的扩展,不是新系统** | 中 |
| **两套状态曲线** | 第一幕急性(数小时),第二幕慢性(数日~数周) | 中 |
| **结尾呈现** | 脉案的空栏 + 病人仍在医馆(或反复来) | 小 |

> **不新增**:新场景、新手术、新道具、新 UI 系统。全部在「一间医馆、一个场景」内完成。

### 史料出处(待病例落笔时逐条复核)

已核实的部分:

| 断言 | 出处 |
| ---- | ---- |
| Beard 1869 年提出 neurasthenia;19 世纪末 20 世纪初欧美流行 | Beard, *Neurasthenia* (1869);*American Nervousness* (1881) |

## 视觉身份锚点 (Visual Identity Anchor)

> 本锚点由用户直接给出,作为美术圣经的种子。

- **选定视觉方向**:《双材》。中医水墨写意 × 西医黄铜工业写实。
- **一句话视觉规则**:**「整体用水墨,还原用黄铜。」**
  凡是表达「身体作为一个整体」的画面(经络、气血、证候、情绪),用**水墨**:晕染、留白、笔触;
  凡是表达「身体作为一台机器」的画面(解剖、器械、缝合、细菌),用**黄铜工业质感**:
  金属、齿轮、刻度、冷光。
- **支撑原则一:同一画面里两种材质并存。** 设计测试:一个手术场景该用什么?
  —— 手是黄铜的(器械、精准),胸口呼吸的起伏是水墨的(整体、生命)。**两者同框。**
- **支撑原则二:UI 必须可被主角拿在手里。** 设计测试:这个信息怎么显示?
  —— 如果它不能画在一本《脉案》、一张纸质地图或一个出诊箱上,就重新设计。
- **支撑原则三:唯一的例外是「敌人的状态」。** 遭遇时敌人身上会出现一条**黄铜质读数条**——
  命中或瞄准时出现,脱离战斗数秒后淡出,挂在敌人身上(**英灵神殿的做法**)。
  这是全作**唯一**允许贴出来的数值反馈,而它之所以成立是因为
  **它读的是「身体作为一台机器」**(与支撑原则一同一条规则:还原用黄铜)。
  **主角自己永远没有血条** —— 他的状态只能靠呼吸、视野边缘、把脉音去读。
  设计测试:这个状态该给谁看?—— **敌人可以被仪器读,你自己不能。**
- **色彩哲学**:基调 = **旧纸的米黄 + 铜锈的青绿 + 血迹的暗红**。饱和度整体压低,
  只在「生命体征变化」时允许一次高饱和(血色回涌、瞳孔收缩)。

## 风险与待解决问题 (Risks and Open Questions)

### 设计风险

- **判断层可能不好玩** —— 如果「观察 → 判断 → 选手段」退化成查表,游戏就死了。
  **全案最大的未知,且无法靠加人解决 → P0 必须首先验证。**
- **医馆即机器可能变成「抄作业」** —— 如果存在唯一最优布局,Expression 就废了。
  需要用**两套冲突评分**保证没有唯一解。
- **急救动作小游戏可能沦为一次性内容** —— 玩家玩过三遍后开始全部跳过。
- **主题可能压垮乐趣** —— 清末民初 + 瘟疫 + 死亡率,情绪基调沉重。

### 技术风险

- **联机 + 精密操作** —— 急救动作的输入精度在网络上难同步。
  **架构预留必须在 P0 做对,否则 P1b 重写。**
- **VR 范围** —— 已定「只做急救动作」。风险:每个动作要做两遍(平面 + VR)。
- **拟物 UI 的信息可读性** —— 无血条 + 无小地图是强声明,需要成体系的替代反馈方案。

### 市场风险

- **医学题材受众窄** —— 但「医学 × 生存建造」是空白,差异化强于受众窄的损失。
- **历史题材的本地化天花板** —— 清末民初题材对海外市场是认知门槛。

### 范围风险

- **完整愿景是 3-5 人年** —— 单人 1-2 年现实可达 = P0 + P1a。必须以 EA 分阶段上线。
- **P0 已包含格斗线**(2026-09-13 追加) —— **两条武器线(徒手/短兵)** + 敌人 AI
  进入垂直切片,**P0 的工期与美术量都需要重估**。规模控制手段已内建:
  **钝器 / 长兵 / 暗器不在 P0**,P1a 再开。
  ✅ **重估已完成(2026-09-13,`/map-systems` 拆解后)**:P0 = **26 个系统**,
  工期由 `3-6 个月` 改为 **`6-9 个月`**。原估计从没把战斗系统算进去 ——
  这正是"先拆系统再估工期"的价值。
  ⚠️ **后又追加裁决**:+5 时间天气 · +48 教学 · +51 遥测 · **#52 随机事件导演** ·
  **#53 医疗后果与责任**,

## MVP 定义 (MVP Definition)

**核心假设**:玩家会认为「判断 → 施治」这个医疗循环**本身**就好玩,
且「亲手做小游戏」与「跳过用判断结算」两种路径都能带来满足感。

**MVP(P0 垂直切片)**:

1. **判断链(西医诊断)** —— 观察、查体、问诊收集信息 → 判断 → 选手段。
   **P0 的技能叫「诊断」**(见《技能与熟练度系统》):等级越高,查体读出的体征越多、判断越准
2. **两个急救动作** —— 心肺复苏(节奏)/ 止血包扎(顺序与力道)
3. **处方用药** —— 基本的开药决策(纯西医)
4. **一间固定医馆 + 小改造** —— 允许更换家具/设施位置(验证「位置即逻辑」的雏形),不允许新建
5. **极简采集 + 极简炮制** —— 手采几味**药用植物原料**,一步简单加工(= 提取 / 干燥)
   → 产出**西药成品**。**P0 不出现任何中药饮片**(口径见《核心机制》第 7 条注)
6. **极简脉案日记** —— 验证拟物 UI 是否可读
7. **格斗线(两条武器线)** —— 出诊途中遭遇的人与兽,由 **52 随机事件导演**触发
   (时机随机、强度随玩家当前状态,内容池 = 兵痞 + 随机危险动物**+ 医疗事件模板 ×3,待补**)。**P0 只开徒手与短兵**;
   战斗效能**由格斗技能主导**,医术给 **≤+20%** 修正。**对人永远以制服收场;对兽可杀、可驱赶。**
   P0 里只有 `徒手 ← 急救` 一条耦合是活的(短兵的 `← 手术` 要等 P1a 手术上线)
8. **P0 熟练度**:**七项技能**(诊断、急救、处方用药、采集、炮制 + **徒手、短兵**)
   按新颖度加权成长

**P0 明确不做**:联机、VR、开放世界、自由建造、时代事件、精神压力、
**辨证与一切中医内容**、中药与针灸、**钝器/长兵/暗器**、装备/商业/沟通/公卫、
异步医案 UGC、主机、**火器**。

> **P0 是纯西医切片** —— P0 有「**诊断**」(西医,看得清),没有「**辨证**」(中医,看得全)。
> 玩家不使用任何中医词汇。这条是有意的 —— 先在**完全没有中医**的情况下证明核心循环成立。
> 「中医解锁」的完整弧(**辨证 + 中药 + 针灸**,P1a)才有地方可落。

### 范围阶梯 (Scope Tiers)

| 档位 | 内容 | 系统 | 工期(单人) |
| ---- | ---- | ---- | ---- |
| **P0 垂直切片** | 一间医馆 + 一个小场景 + 2 个急救动作 + 处方 + **两条武器线(徒手/短兵)** | 诊断、急救、处方、采集、炮制、**格斗 ×2**、小改造、7 项熟练度 —— 原列 **26 个系统**;**按 `systems-index.md` 实为 31 个**(含 7 拆为 7a/7b、新立 #52/#53) | **6-9 个月**(2026-09-13 按 26 项重估;原 3-6 个月未计入格斗线。⚠️ P0 已增至 **31 项** + **≈2.5 M 内容债**;**2026-09-14 用户裁:不重算,此即基线**) |
| **P1a 可玩成品** | 2 个生态区 + 中医解锁(**辨证** + 中药 + 针灸)+ 6-8 个动作 + 自由建造 + **其余三条武器线** | + 全部 19 项技能、医馆即机器完整版、NPC、药物槽、装备 | +6-9 个月(**EA 首发点**) |
| **P1b 完整成品** | 4 个生态区 | + 1-4 人联机、VR 急救动作、精神压力、动态事件 | +6-9 个月 |
| **P2 完整愿景** | 全部内容 + 时代篇章 | + 异步医案 UGC(云端医阁)、终局(医学教育/公卫/研究)、主机 | 3-5 年总计 |

### 优先级排序原则

1. **先切承重的未知** —— 判断层(观察 → 判断 → 选手段)是全案唯一「不知道好不好玩」的东西,
   加人解决不了。P0 必须证它 —— 且要用**纯西医**去证,不借中医的复杂度遮掩。
2. **放大器后置** —— 开放世界、联机、VR 是「放大已有玩法」的系统。核心没验证时做它们,
   是在没打地基的地上盖楼。
3. **内容黑洞后置** —— 生态区、建造件、药材库是无底洞,必须等玩法定了才知道要做多少。
