## 1. 类型声明与所有权边界

本 spec 是 `AC-42-F1` 闭集**第九员**「⑨ 炮制屏(18)」的 per-screen UX spec;
模态身份 = `ModalId.Processing`(`adr-013:792` §十-E)。**它是本屏的唯一定义面** ——
在此之前的实现(`Screens/Processing18Screen.cs`)自陈为「最小可操作壳,排版 / 文案 / 焦点序均未经 UX 评审」。

**四方分权**:

| 方 | 拥有 | 不拥有 |
|---|---|---|
| **18** | 准入判定(`IsAdmissible` 单函数)· 时序(`Craft` 落流 / `CompleteTick`)· 单炉判据 | 任何渲染 · 任何文案 |
| **21a** | `Recipe` 数据(输入 / 输出 / `duration_ticks`)· 显示名 · 品级质地 | 候选过滤 · 排版 |
| **20** | 库存与**选中态**(被点名的实例集) | 配方候选 · 点火 |
| **42** | 渲染 · 焦点桥 · 布局参数 | 候选集 · 准入真值 |
| **本 spec** | 版面形态 · 三种空态的措辞 · **二段确认的形态与撤销路径** · 焦点序与焦点保持 | 任何机制量 · 任何准入判据 |

- **本屏不持游戏状态**(ADR-013 §9 C3):候选集、选中、炉忙全部**开屏时喂入**,屏内只发**意图**。
- **本屏不是第二求解器**:过滤只问 `IProcessingAdmissionQuery.IsAdmissible`(**单函数**,`AC-18-20`);
  「等级 / 品质 / 炉忙」的合取**不在屏内**。
- **档位零耦合**:开/关本屏**不发相机意图** —— 39 是全案唯一档位请求方(用户裁定 2026-09-19)。
- **进度不归本屏**(`skeuomorphic-ui.md:1259` 已裁):等待期进度住**世界器物状态**,
  本屏**零进度条 / 零倒计时 / 零百分比**。

## 2. Purpose & Player Need

炮制是**时间换品质**的交易:玩家站到灶前,面对的是「以手上的料,我能起哪一炉」。
这一屏要回答的只有一句 —— **能做什么**;以及一个不可撤销的动作 —— **落火**。

**这个屏存在的理由**:
- 准入是**机制**上的过滤(`AC-18-10`),但没有屏,玩家就无从知道「手上这味料作不作得了」;
- 点火**不可取消、料在点火 tick 即真实消耗**(`OQ-18-3` 已裁)⇒ 需要一个**看得见、退得回**的落火动作;
- 手柄没有指针(`TR-concept-008`),焦点序是唯一导航路径 ⇒ 必须是一件**有确定的序**的器物。

**什么会变糟**(若本屏形态不对):
- 把「不可发起的配方」灰置出来 ⇒ 直撞 `AC-18-10b` 与规则十(灰置 = 隐形提示,反幻想);
- 加进度条 / 倒计时 / 完成提示音 ⇒ 撞 `UI-18.2` 零数字、`AC-44-09` 状态播报禁令;
- 单次 Submit 即落火 ⇒ 误触一次 = 一批料永久损失,而「慢」本就是本系统的手感(支柱五);
- 空态写成一句「请先在出诊箱选料」 ⇒ 按键提示 + 说明系统,两条都禁(`AC-3-F1a` / 反幻想)。

## 3. Player Context on Arrival

- **入口**:站在灶(`Utensil`)的宽容半径内按交互键(`E`);由 4 的选靶给出目标
  (`r_interact = 3`,Chebyshev;灶 = `KindPriority 2`)。
- **进入前一刻**:玩家**已在出诊箱里选中了料**(屏的候选集由那批料的品级集决定)——
  这是本屏的**硬前提**,见 §6 空态「案上无料」。
- **情绪**:事务性、偏慢;站在火上,不赶时间 —— 本屏**不催促**(零倒计时即不催促的机制化)。
- **世界状态**:开屏即挡路模态 ⇒ **真停 sim tick**(ADR-013 §十-C Amendment D)⇒
  开屏期间炉子也不推进;关屏后世界继续。
- **出口**:`Escape` / 手柄返回;焦点回进入前的载体(P-02)。

## 4. Navigation Position

```
World(自由态 · 站在灶旁)
  └─ E(4 的选靶 = Utensil)──▶ ModalId.Processing(本屏 · 挡路模态 · 世界 tick 暂停)
                                 ├─ 行焦点 + Submit(第一次)→ 行内「落火」二段态
                                 │     └─ Submit(第二次)→ 意图上行 · 落火 · **留在本屏**
                                 ├─ 方向键移动 → 撤销二段态(安全侧)
                                 └─ Escape / 返回 ──▶ World(焦点回进入前载体)
```

- **零嵌套模态**:本屏内不开任何第二层(无配方详情窗 —— 说明走**页侧注**,见 §5.3)。
- **上游是容器屏但不是「上一级」**:选料发生在**世界内的另一个模态**(20 容器屏),
  两者**不是父子关系** —— 玩家可以在任何时刻重开出诊箱改选,再回来开本屏。
  ⇒ 本屏的候选集**每次开屏重算**,不缓存。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **可发起的方子**(一行一方) | 「我能做什么」;不可发起的不出现 |
| 2 | **二段态**(行内) | 「这一步要落火了」—— 不可撤销动作的唯一缓冲 |
| 3 | **状态注**(一行,不可聚焦) | 只在无候选时出现;说明**当前状态**,不说明系统 |
| 4(环境) | 灶 / 火 / 烟(世界) | 屏外一圈;`OQ-18-9` 已裁的器物状态归 42 器具档 |

**层级原则**:删掉纸上任何一行字,信息仍完备 = 本屏的验收直觉 ——
因为屏回答的只有「能做什么」,而**做什么**由玩家按下决定。

### 5.2 Layout Zones

1. **纸面**(窄列居中,与族内件同形):`.paper` 底纹 + `.pause-column` 定宽 ——
   **零新增布局参数**;行高 `.ruled`(≥44px 焦点落点下限,AB-3)。
2. **行区**:一行一方,**行内只有配方显示名**(见 §5.3);**不做网格、不做图标、不做分类**。
3. **状态注区**(仅空态):行区位置的一行小字(字号走 `--skeuo-font-size-paper`,
   与暂停壳副标题同级);**不可聚焦**、无边框、无背景。
4. **无标题、无页脚、无按键提示** —— 纸面即屏;屏的身份由「站在灶前」这一世界事实承担。

### 5.3 Component Inventory

| 组件 | 类型 | 可交互 | 来源 |
|------|------|--------|------|
| 纸面 | 纸纹容器 | 否 | 42 元件库(`.paper` / `.pause-column`) |
| 方子行 ×n | 有字行(`.ruled`)| **是**(焦点 + Submit)| 42;文案 = 21a 显示名 |
| 二段态行 | 同一行的**态**,不是新组件 | **是** | 本 spec(§7) |
| 状态注 | 小字行 | **否** | 42 注排版(不新增 USS 类) |

**文案来源铁律**:行文字 = **21a 的配方显示名**,本屏**不翻译、不改写、不拼接**。
⚠️ **粗糙边(如实登记)**:21a 的 `Recipe` 目前**无 `DisplayName` 字段**,屏上显示的是
`RecipeId`(如 `herb_soup`)。显示名回写 `Recipe` schema = **本件涟漪义务**(§15 之 1),回写前
本屏交付的是**键名**,不是「麻黄汤」。

## 6. States & Variants

### 6.1 空态(三种成因,一行状态注,**不可聚焦**)

> 用户裁定 2026-11-06:**空纸 + 一行状态注**。注只陈述**当前状态**,不陈述系统、不给操作指引。
> **禁**:「请先在出诊箱选料」类操作提示 · 任何数字 / 件数 / 「还剩几种」 · 未解锁提示。

| 成因 | 判据(屏侧只读) | 状态注 |
|---|---|---|
| **案上无料** | 选中集为空(`consumedQualities.Count == 0`) | `案上无料` |
| **无方可起** | 有料,但无一行可发起 | `无方可起` |
| **炉上有药** | 本玩家已有一炉在烧(`ISingleFurnaceQuery`)| `炉上有药,火未熄` |

- ⚠️ **「无方可起」不得写成「未解锁 / 还差 X 种 / 成功率」** —— 规则十:面板侧**无灰置网格、
  无未解锁列表、无缺口量提示、无成功率**。一句「无方可起」只陈述**此刻没有能起手的方子**,
  不陈述「存在但不可用」的方子(那属世界侧线索:出诊所见 / 医馆旧档 / 病家口述)。
- ⚠️ **三种成因互斥且全覆盖**:炉忙优先于另两者(炉忙时即便有料也不可发起);
  无料优先于无方(没有料时「无方」是必然结果,不报两行)。

### 6.2 屏级状态

| 状态 | 触发 | 呈现 |
|---|---|---|
| 候选(常态) | ≥1 行可发起 | 纸面 + n 行;焦点在第一行 |
| **二段态** | 某行第一次 `Submit` | **该行**进入落火态(行内文案 + 可辨的形态变化);焦点**留在该行** |
| 已落火(留在屏内) | 点火意图被主机接受 | 候选清零 ⇒ 空态「炉上有药,火未熄」;**屏不关**。⚠️ 开屏即挡路模态 ⇒ **世界 tick 停**:留在屏内不烧掉任何等待时间,`duration_ticks` 从玩家关屏后继续走 —— 「留在屏内」与「守炉」不冲突 |
| 空态 | §6.1 三成因 | 纸面 + 一行状态注;无焦点落点(不悬空 `Focus()`)|
| 被拒 | 点火意图被主机拒(`AC-18-12` / `AC-18-23`) | **屏上零变化**(不弹窗、不变色、不播报);玩家可再来一次 |
| 屏内选中态失效 | 屏开着时被点名料的实例集被清空(理论不可达:选中面在另一模态,且本屏开着时世界 tick 停) | 点火被拒、**屏上零变化**;屏内**不得**伪造新选中集或自行改候选 |
| 未绑定 | 数据面未到达 | 空纸,零行零注(不崩、不弹窗) |

⚠️ **「被拒 ⇒ 屏上零变化」是裁定,不是遗漏**:拒绝的可感面在**世界侧**
(`UI-18.2` 的「料被搬回、火折子划不着」),归 1 / 23 / 44 的物理与音频反馈;
42 侧**不得**用文字、音效、颜色报拒绝(`AC-44-09` / P-06)。

## 7. Interaction Map

| 动作 | 键鼠 | 手柄 | 即时反馈 | 路由 |
|---|---|---|---|---|
| 开屏 | `E`(4 的选靶命中灶)| 同一 action | 纸面摊开 ≤200ms(减动效:直接显)| 无流事件 |
| 移焦 | 指针 hover = 快捷方式 | 官方桥 `NavigationMoveEvent` + `FocusController`(P-01,禁自实现)| 焦点铜环压行 | —— |
| **第一次 Submit** | `Return` / 点击行 | A / 确认 | **本行进入落火态**;焦点不动 | **零意图**(屏内状态) |
| **第二次 Submit** | `Return` / 点击「落火」 | A / 确认 | 行态落定(不播报) | **18 意图事件 → 主机裁决 → 世界流 `Craft`** |
| 撤销二段 | 方向键移动 / 点别处 | 同 | 该行回落火前形态 | 零意图 |
| 关屏 | `Escape` | B / 返回 | 纸面收 | 无流事件(顺带撤销未落定的二段态)|

**二段确认的判据(本 spec 的核心裁定,用户 2026-11-06)**:

1. **第一次 `Submit` 绝不落火** —— 它只把该行推进落火态(`Ignite` 调用数 = **0**);
2. **任何离开该行的动作即撤销** —— 方向键 / 指针移开 / `Escape`;
3. **只有第二次 `Submit` 才产生意图**,且**恰一次**;
4. 落火态**必须可辨**:行内文案由「方名」变为「方名 ── 落火」,并有形态变化
   (纸面压痕 / 笔锋加粗 —— 不靠颜色,`UI-18.2` 与 P-06)。

**焦点序铁律**:行序 = **`Recipe.Ordinal` 升序**(21a 表的稳定序);
准入变化**只增删行、不重排** —— 重排会让手柄焦点在两次开屏之间跳位。
⚠️ 与 20 容器屏同一条纪律(`instance_id` 升序),两屏各自稳定、互不借用。

**零按键提示**:全屏零浮层;「怎么选料 / 怎么落火」由 48 教(`AC-3-F1a` ②)。

**开屏落焦**:有行 ⇒ 焦点落第一行;空态 ⇒ **无落点且不得悬空 `Focus()`**
(悬空 `Focus()` 会把焦点扔到看不见的元素上)。

**重绑保持焦点**:候选因料位变化重建时,按 **`Recipe.Ordinal`** 还原焦点
(不按元素引用 —— 重建会重造行)。这是 `TD-skeuo-20` 的同一条教训。

## 9. Transitions & Animations

| 转场 | 规格 | 减动效钩子 |
|---|---|---|
| 纸面摊开 / 收起 | ≤200ms | 直接切 |
| 二段态推进 | 行内压痕 / 笔锋变化,≤150ms | 直接到终态(态本身不删)|
| 落火后候选清零 | 行淡出 ≤200ms | 直接清空 |

完成 jingle / 成功提示音(`AC-44-09`)· 任何「就绪」呼吸光效(状态播报的视觉变体)。

## 12. Localization Considerations

| 项 | 约束 |
|---|---|
