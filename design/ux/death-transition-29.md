## 1. 类型声明与闭集边界(不宣称改闭集)

- **本页 = 全屏过渡(非界面)**:`death-and-respawn.md:503`「倒下 / 醒来 = 全屏过渡(非界面)」。
  它**不是模态**:零焦点元素、零交互件、不可操作 ⇒ **不进 `ModalId` 闭集**(ADR-013 Amendment A/B/C 的
  八员闭集不动)——规则七的模态门(`Modal ≠ None`)不因本页翻转,过渡期间的输入抑制走
  **1 的移动禁用**(1 读 `PlayerDied`,story-001 接线),**不是**本页的职责(呈现层不自持状态)。
- **本页是「呈现三件套同构纪律」的第四员**:只渲染 / 只触发,**永不持有游戏状态**
  (承 ADR-013 §9 C3 的 42、ADR-018 §一的 44、ADR-020 §五的相机)。
- **白名单边界(story-006 AC-29-06 的设计面)**:本页全部呈现产物 ∈
  **{过渡动画 · 环境音 · 42 拟物元件}**。以下产物**不在白名单 = 出现即红**:
  「你死了」文字化弹窗 / 大标题 · 「重试」按钮 · 死亡统计面板(掉落/掉级/死亡次数,
  **哪怕只显一项**) · 失败 sting / jingle / ducking 报状态。
  **代价要玩家自己发现**(`death-and-respawn.md:258`)—— 这是幻想的主通道,不是信息屏。

## 2. Purpose & Player Need

**玩家 arriving 时想要的是:被这个世界诚实地接住「倒下」这件事,而不是被一个系统宣判。**

- 死亡在本作里是**叙事事件**而非失败结算:「我倒下了 —— 而世界没有停」(`:54`)。
  玩家需要的是一个**安静的时刻**让「失去控制权」落地,然后**狼狈地走回医馆**取回自己的东西 ——
  这段回程是 29 交付的核心体验(`:60-61`)。
- 若没有本页(或做成 Game Over 屏):倒下变成系统的判词,幻想断裂(支柱一「这个游戏的主角
  也有身体」被弹窗否认),且代价发现(回程捡回)的动机会被「重来一局」的暗示替代。
- 完成句:**玩家在倒下的那一刻想要的是「世界继续,我需要爬起来回去」**。

## 3. Player Context on Arrival

| 维度 | 状态 |
|---|---|
| 到达方式 | **被动**(sim 判死 ⇒ `PlayerDied` 落流)—— 玩家不能主动进入本页 |
| 到达前刚发生 | 交手/病程走到终局;屏幕上最后一刻是黄铜侧的交手或病程体征 |
| 情绪设定 | 挫败但不羞辱 —— 设计任务是**降噪**而非**刺激**(无提示音铁律的视觉侧同源:ADR-020 §六「不得用于报状态」) |
| 控制权 | **已失去**(sim 侧已判死;1 已抑制移动/交互)—— 本页零操作 |
| 联机队友 | 看到的是**远端变体**(局部水墨,见 §6),不是全屏过渡 |

## 4. Navigation Position

**非导航屏** —— 本页不在菜单层级内,是游戏世界视口上的**全屏表现态叠层**:

```
游戏世界(World) ── [PlayerDied 事件(表现态投影)] ──▶ 死亡/复活过渡(全屏叠层)
        ▲                                                    │
        └──────────── 醒来相位结束,叠层消散,回到世界视口 ──────────┘
```

- 入口唯一(sim 判死);出口唯一(醒来相位完成)。**无任何菜单可达性**、不可暂停进入、
  不与 42 模态并存(倒下时若恰有模态开着:模态先被 sim 判死路径的世界事实覆盖 ——
  过渡叠层在其上;模态自身保持打开,醒来后玩家回到同一模态。**呈现层不关闭任何模态** —— 不持状态)。

## 6. States & Variants

| 状态 / 变体 | 触发 | 变化 |
|---|---|---|
| **Φ0 未激活** | 默认 | 叠层不存在(零开销) |
| **Φ1 倒下·失支撑** | `PlayerDied` 落流(表现态投影) | 水墨自四边渐入;相机开始**两段式第一段**(失支撑,ADR-020 自建机位) |
| **Φ2 倒下·躺定** | Φ1 时长尽(表现态动画时长) | 墨色满屏前的**静默段**;仅环境音衰减(`death-and-respawn.md:492`「失去控制权的静默」) |
| **Φ3 醒来** | 复活命令落地(落点 = 医馆床格,story-005) | 相机第二段(床格视角);**环境音渐入**(呼吸/纸页/远处人声 —— F-44.7 世界语境呼吸路径) |
| **Φ4 消散** | Φ3 稳定 | 水墨渐散,回世界视口;玩家恢复控制权(1 侧解除移动禁用) |
| **远端变体** | 任一**其他**玩家 `IsDowned`(第二 QoS) | **局部**水墨标识于其世界位置;**不**全屏、**不**有相位序列 |
| **模态并存变体** | 倒下时 42 模态开着 | 过渡叠层在最上;模态保持打开不动(呈现不关模态);醒来后回到该模态 |
| **VR 变体** | (P1a) | **全禁镜头效果**(ADR-020 §六 硬禁);平面两段式相机运动不得平移到 VR —— 登记为 P1a 设计债 |
| **ΦE 降级/错误态** | 水墨素材未就绪(加载失败)或 `DeathTransitionDto` 查无 | **纯黑 opacity 淡入淡出兜底**(零水墨、零文字、零结算),四段节奏不变;不得裸崩、不得跳过过渡直接复活。**null 处理**:DTO 查无相位 ⇒ 视为 Φ0 未激活(零叠层);激活中出现查无 ⇒ 走 ΦE。呈现降级**不构成任何 sim 状态**(零写路径不变) |

> **相位是表现态**:Φ0–Φ4 只存在于呈现层,由 sim 事件(`PlayerDied` / 复活)**投影**驱动,
> **不落流、不存档、不构成第二状态机**(`:448`「倒下/醒来的过渡呈现 = 表现层」)。呈现层
> **不自持死亡计时器**(story-006 Forbidden)—— 相位时长 = 动画自身的 duration(表现资产参数),
> 不是游戏状态;**死亡过渡时长**作为手感旋钮归用户数值轮(`:466`)。

## 7. Interaction Map

**本页零交互** —— 这是设计立场,不是遗漏:

| 输入 | 键鼠 | 手柄 | 过渡期间行为 | 依据 |
|---|---|---|---|---|
| 移动 / 视角 | WASD / 鼠标 | 左摇杆 / 右摇杆 | **无效**(1 读 `PlayerDied` 抑制移动,MotorSuppressed 面) | story-001 接线;ADR-011 |
| 交互 E / 急救 F | E / F | 对应键 | **无效**(同上抑制链) | 同上 |
| 暂停 Esc | Esc | Start | **照常可用**(42 的 `PauseTogglePressed` 独立于本页;暂停壳不感知过渡) | 42 既有面;本页零交互 ⇒ 不新增抑制 |
| 跳过 | —— | —— | **无跳过**(过渡时长短且受调参;跳过键 = 给「失败」一个可按掉的确认,反幻想) | 设计裁定,登记 Open Questions 供主创复核 |

> 覆盖口径:键鼠为主、手柄 partial —— 本页零交互 ⇒ **双导航等价(P-04)平凡满足**
> (没有可导航元素,两输入法的过渡体验完全一致)。

### 7.1 焦点(本页 = 零焦点元素)

过渡期间无任何可聚焦元素 ⇒ **焦点单栈门(P-01)无新增栈**;暂停壳若被打开,
焦点归暂停壳(其自有焦点序),过渡叠层继续其表现态推进(两者互不感知)。

### 7.2 零提示

本页**零提示音 / 零提示色 / 零提示文本** —— P-06(无提示音报状态)的**视觉侧同源**
(ADR-020 §六「不得用于报状态」):倒下动作音 / 醒来环境音 ∈ 行为反馈白名单,
任何「你失败了」语义的 sting/jingle/ducking ∉ 白名单(AC-29-12 与 AC-44-09 联合)。

## 9. Transitions & Animations

| 转场 | 规格 | 出处 |
|---|---|---|
| 进入(Φ1) | 水墨自四边向中央渐入(**晕染感**,非线性 easing;禁瞬间黑屏) | `:472` 水墨侧 + 42 水墨元件族 |
| 相机(Φ1→Φ2) | **两段式**:先失去支撑(下沉 + 微倾)→ 再躺定(**禁甩镜**) | `:491` 承 25 `:1639` 规格;ADR-020 自建机位(`ICameraRig`) |
| 静默段(Φ2) | 画面近满墨,环境音衰减至近零(**最短的一段**) | `:492` Impact Moment ① |
| 醒来(Φ3) | 相机在床格视角睁眼(第二段);环境音渐入(呼吸/纸页/人声) | `:476`;Impact Moment ② |
| 退出(Φ4) | 水墨自中央向四边消散(与进入**非对称** —— 消散快于渐入,不拖节奏) | 设计裁定(登记 §14) |
| 状态变化动画 | 远端标识的出现/消失 = 局部墨晕淡入淡出 | P-09 |

- **晕动评估**:两段式为**小幅度机位运动 + 全屏 2D 叠层**,非视场旋转;VR 面全禁(上表)。
  平面侧不触发 L-1 运动敏感承诺的强规避项;若用户后续开启任何减动效设置,晕染渐入以
  **纯 opacity 衰减**替代(无位移)—— 登记为 L-1 联动项。
- 禁用清单(与白名单同源):**禁**镜头闪红/震动报失败、**禁**文字淡入、**禁**数字滚动。

## 11. Accessibility

承诺档 = **Standard + L-1/L-2**(`design/accessibility-requirements.md`):

- **零文本 ⇒ 无对比度/字号/读屏文本面**(但零文本本身 = 对色盲/低视力玩家**无信息损失** ——
  本页不承载任何必知信息,代价发现走世界交互,不走路障屏)。
- **色独立**:水墨为亮度渐变,非色彩编码信息(无「红色 = 死亡」类映射)。
- **运动(§9)**:两段式小幅机位运动;减动效设置 ⇒ 纯 opacity 替代(L-1 联动,登记)。
- **音频**:环境音为世界语境氛围,非状态信息 ⇒ 无字幕义务面;**零状态播报音**同时是
  无障碍友好项(无突发惊吓音)。
- **键盘/手柄**:零交互 ⇒ 零焦点序义务;暂停路径保持可达(§7)。
- **设置持久化**:本页不新增任何设置项(L-2:无障碍设置本地化 —— 沿用既有面)。

  总时长 ≤ 调参上限(数值归用户数值轮);**无跳过键**。
- [ ] **AC-UX-04(远端变体)**:远端玩家倒下仅显示局部水墨标识,本地视口不被全屏遮蔽;
  远端无相位序列。
- [ ] **AC-UX-05(零状态播报)**:全程零 sting/jingle/ducking;醒来只有环境音渐入
  (与 AC-44-09 联合)。
- [ ] **AC-UX-06(零文字)**:全流程零文字、零数字、零图标、零进度指示(截屏走查)。
- [ ] **AC-UX-07(呈现不持状态)**:重开呈现层(重建/重连)不改变任何 sim 事实
  (负断言:呈现侧零写路径、零三流写入)。
- [ ] **AC-UX-08(导航/暂停)**:过渡期间暂停壳仍可开合;模态并存变体下模态保持原状,
  醒来后回到该模态。
- [ ] **AC-UX-09(降级态)**:水墨素材缺失或相位 DTO 查无时走纯黑兜底过渡 —— 四段节奏
  与总时长不变,零文字零结算;**不**裸崩、**不**跳过过渡直接复活;查无相位且未激活 ⇒
  零叠层(Φ0)。
