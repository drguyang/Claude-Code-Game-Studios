# 技能系统 (Skill System)

*创建日期: 2026-09-13 · 状态: Draft*
*上游文档: `design/gdd/game-concept.md`*

---

## 1. 概述 (Overview)

本作没有天赋树、没有职业、没有等级。玩家的一切能力由 **19 项技能** 表示,
每项技能按 **「做了就涨」** 的方式成长,成长速度受 **新颖度** 调节 ——
反复处理同样的病人几乎不涨熟练度,第一次遇到新东西才大涨。

技能上限为 **60**。玩家死亡时每一项技能损失 **5%**(向下取整),
叙事上框定为 **「手生」** 而非「遗忘」。

**本系统的核心作用是:让「见识」成为一种真实的游戏资源。**
在其它生存建造游戏里,变强靠刷;在本作里,变强靠**遇到没见过的病、药、人**。
这直接把「探索」和「成长」缝在了一起。

---

## 2. 玩家幻想 (Player Fantasy)

> **「我不是变强了,我是见过得多了。」**

玩家应该感受到的成长,不是「我的攻击力从 12 变成 15」,
而是**有一天突然发现自己一眼就看出了三个月前看不懂的东西**。

四个必须被玩家体验到的时刻:

1. **第一次看穿**(诊断,P0):同样的面色、同样的脉,去年只能给一个笼统的印象,
   今年是「**苍白、发绀、浅快、湿冷**」四个词,**而且这四个词算数了**
   —— 不是你更聪明了,是你**见过**。*(⚠️ 2026-09-14 口径校正:这一档买的是
   「**分得开**」,不只是「看得见」—— 低档本来就看得见人病了,见 8 诊断 §Player Fantasy 锚点一。)*
2. **第一次看全**(辨证,P1a):同一个病人,你开始注意到他不是「一个肺炎」,
   而是一个**困在这个季节、这个处境、这个身体里的人**。
3. **第一次贯通**:扎针的时候,手比脑子先到 —— 你知道该往哪儿下,因为你做过一百次。
4. **第一次手生**:你被打倒、躺了半个月,再拿起手术刀,
   发现那个曾经闭着眼都能做的动作,现在需要想一想。**这是本系统最独特的一刻。**

## 3. 详细规则 (Detailed Rules)

### 3.1 技能清单 (19 项 / 6 类)

| 类别 | 技能 | 成长触发 | 作用 |
| ---- | ---- | ---- | ---- |
| **医术** | **诊断** | 完成一次查体 / 问诊并作出诊断(不论对错,错也涨) | 查体读出的体征更多、判断更准、误诊率下降。**回答「这是什么病」** |
| | **辨证** *(P1a)* | 完成一次望闻问切并作出整体判断(不论对错,错也涨) | 看得更全(情志/体质/时序);正确时给治疗被动加成。**回答「这个人整体如何」** |
| | **急救** | 执行止血 / 包扎 / 正骨 / 复苏 | 动作容忍度、结算成功率;对**徒手**线给少量修正(§3.4) |
| | **手术** | 执行手术 | 手术成功率、失血量;对**短兵**线给少量修正(§3.4) |
| | **处方用药** | 开出一张处方并被执行 | 药效、副作用、用药选项解锁(含后期中药) |
| | **针灸** | 施针 | 施针精度;对**暗器**线给少量修正(§3.4) |
| **生产** | **采集** | 采到一味药材 | 可识别更高品级;单次采集药量随技能提升 |
| | **炮制** | 完成一次炮制 | 药效强度、药材转化率 |
| | **装备** | 制作器械 / 设备 | 可制作的器械档位与品质 |
| **社会** | **沟通** | 完成一次交涉 / 问诊对话 | 病人配合度、问诊可得信息量 |
| | **公卫** | 处理一次防疫 / 检疫 / 群体救治 | 群体事件的处理规模与效率 |
| | **商业** | 完成一次买卖 / 定价 | 进价、售价、可触达的供应商 |
| **生存** | **奔跑** | 奔跑 | 移动速度、体力消耗 |
| | **潜行** | 潜行 | 被发现阈值、移动噪音 |
| **格斗** | **徒手** | 徒手命中 / 制服 | 拳脚、擒拿、锁关节、摔法 |
| | **短兵** | 短兵器命中 | 手术刀、短刀、匕首 |
| | **钝器** *(P1a)* | 钝器命中 | 木棍、铁尺、手杖、药箱 |
| | **长兵** *(P1a)* | 长兵器命中 | 长棍、扁担、杆棒 |
| | **暗器** *(P1a)* | 投掷命中 | 银针投掷、飞石 |

> **格斗线是独立技能,但「医术 × 格斗」的耦合仍然存在** —— 见 §3.4。
> 医术给每条武器线一个**上限修正**(最多 +20%),不替代、不主导。
>
> **P0 只开两条线:徒手 + 短兵**(见 §3.4)。钝器 / 长兵 / 暗器是 **P1a 技能**。
> 原因:徒手承担非致命基底与「擒拿 = 正骨」的耦合,短兵是「手术刀」这个身份道具的自然延伸;
> 这两条**足以验证格斗线成立**,其余三条等 P1a 内容铺开时再开。
>
> **火器不在任何一条线里**。理由:火器会让战斗变成「谁先开枪」,
> 且在断代上,一个游医背着枪会把「医者」这个身份彻底压掉。

> **「诊断」在 P0,「辨证」在 P1a** —— 这两个技能是本作「还原 × 整体」的两种看法,
> 不是同一个技能的两个等级:
> - **诊断(P0,西医)** —— 回答「**这是什么病**」。看得清、看得准。P0 全程只用它,
>   不使用任何中医词汇。
> - **辨证(P1a,中医)** —— 回答「**这个人整体是什么样的**」。看得全,给条件治疗加成。
>
> P0 的熟练度因此是 **7 项**:诊断、急救、处方用药、采集、炮制 + **徒手、短兵**(见 §3.4)。
> **接续关系**:诊断练到 P1a 门槛后才开辨证 —— 先把细节看清,才谈得上看出整体。

### 3.2 成长规则

**规则一:使用即成长,行为决定。** 每次成功触发成长条件,获得经验。没有分配点,没有天赋。

**规则二:新颖度加权。** 每次成长事件都携带一个 `(技能, 对象)` 对,
系统记录该对是否被见过。

| 情况 | 新颖度系数 |
| ---- | ---- |
| 首次遇到该对象 | **×3.0** |
| 冷却期内再次遇到(默认 20 分钟) | **×0.2** |
| 其它 | ×1.0 |

对象的粒度按技能而定:

| 技能 | 对象是什么 | 例子 |
| ---- | ---- | ---- |
| 诊断 | 病名 / 伤情类型 | 「大叶性肺炎」「失血性休克」「股骨骨折」各不相同 |
| 辨证 | 证候 | 「太阳伤寒」「湿热下注」各不相同 |
| 采集 | 药用植物品种 | **P0**:柳树皮、毛地黄各算一个对象 · **P1a**:甘草、黄芪 |
| 炮制 | (品种 × 加工法) | **P0**:柳树皮·生 ≠ 柳树皮·提取渣(提取 / 干燥) · **P1a**:甘草·蜜炙 ≠ 甘草·清炒 |
| 急救 / 手术 | 伤情类型 | 动脉出血 ≠ 骨折 |
| 沟通 | 人群类型 | 士绅、兵痞、妇孺 |
| 奔跑 / 潜行 | 地形类型 | 泥地、山地、城镇 |

> **P0 的采集对象不是中药** —— P0 采的是**药用植物原料**(柳树皮、毛地黄、金鸡纳树皮),
> 「炮制」在 P0 = **提取 / 干燥 / 标准化**;`甘草 / 黄芪 / 蜜炙 / 清炒` 是 **P1a 示例**。
> 口径裁决见 `game-concept.md`《核心机制》第 7 条注与 `item-database.md` §命名铁律。

> **这条规则同时解决三个问题**:①防刷(重复不涨)②奖励探索(必须去找没见过的)
> ③叙事一致性(医生就是「见识多了」才厉害)。

**规则三:上限 60。** 达到 60 后本技能锁定,不再获得经验。曲线前段快、中段稳、后段慢。

### 3.3 死亡掉熟练度

玩家死亡时:

1. 每项技能 **当前等级 × 0.95,向下取整**(至少损失 0 点,不设下限保护)
2. 掉落物散落原地
3. 精神压力上升(见 `game-concept.md`)

**不掉的**:已解锁的动作、已记录的《脉案》、已见过的新颖度对象。

> **为什么框定为「手生」而不是「遗忘」**:遗忘意味着知识没了,
> 但你没忘 —— 你只是**手上没感觉了**。这个区分对本作的主题很重要:
> 主角是一个**有身体的人**,身体会受伤,受伤会影响手艺。

### 3.4 格斗线与医术耦合

**格斗是独立的技能线**(5 项),战斗效能**主要由格斗决定**;
医术在它之上给一个**上限修正**。

> **📌 外部提案裁定(2026-09-15)** —— 一份《奇遇与成长路径扩展》提案提议为 30
> **新增「战斗技能线」**(其 §11#10,含 8 个「战斗解锁」)。裁定:**伪需求,否**。
> 本系统**已含格斗线**(§3.1:徒手 / 短兵 P0;钝器 / 长兵 / 暗器 P1a)+ 奔跑 / 潜行;
> 那 8 个「解锁」是对**已有技能**的叙事包装,非新机制。**给技能加门亦违法** ——
> 本作无天赋树 / 职业 / 等级(§1 开篇)。目录 §2(`design/gdd/content/adventure-catalog.md`)已记录。
> **本节未改。**

```
战斗效能 = (格斗技能等级 × 武器系数) × (1 + 医术修正)
```

| 格斗技能 | 上线档位 | 覆盖武器 | 与哪项医术耦合 |
| ---- | ---- | ---- | ---- |
| **徒手** | **P0** | 拳脚、擒拿、锁关节、摔 | **急救**(正骨) —— 你知道关节怎么卸、怎么锁 |
| **短兵** | **P0** | 手术刀、短刀、匕首 | **手术** —— 你知道哪里会流血、哪里脆弱 |
| **钝器** | P1a | 木棍、铁尺、手杖、药箱 | *(无耦合)* |
| **长兵** | P1a | 长棍、扁担、杆棒 | *(无耦合)* |
| **暗器** | P1a | 银针投掷、飞石 | **针灸** —— 你知道哪里会麻痹 |

**医术修正的效果**:

| 医术技能 | 修正对象 | 修正上限 |
| ---- | ---- | ---- |
| 手术 | 短兵 | **+20%**(命中要害时的出血与效果) |
| 针灸 | 暗器 | **+20%**(银针的麻痹时长) |
| 急救 | 徒手 | **+20%**(锁技与制服的成功率) |

```
医术修正 =  0.20 × (关联医术等级 / 60)
```

**这意味着**:
- **会打的人**(格斗高)打得过,
- **懂行的人**(医术高)打得更狠 —— 但**医术一个人撑不起战斗**。
- 一个手术 60 级、短兵 5 级的医生,**打不过**一个短兵 40 级的人。
  他**知道**该往哪儿切,但这不等于他切得到。

**制服机制**:敌人的生命值**照样可以打到归零** —— 归零**不是死亡,是昏迷**。
生命归零后进入「可处置」状态,玩家可执行:救治 / 审讯 / 捆绑。
**敌人永不因你的攻击而死 —— 每条已上线的武器线都有非致命终点。**

| 武器线 | 上线档位 | 打出「昏迷」的方式 |
| ---- | ---- | ---- |
| 徒手 | **P0** | 锁关节、压制、击晕 |
| 短兵 | **P0** | **刃背**击打、割断装备带(不失血) |
| 钝器 | P1a | 击晕 |
| 长兵 | P1a | 绊倒、压制 |
| 暗器 | P1a | 麻痹(银针)、打落武器 |

> **为什么不是「30% 就停手」**:那个阈值是一堵**魔法墙** ——
> 打到 30% 伤害就没意义了,玩家会立刻出戏。
> 改成「血条可以清空 → 清空 = 昏迷」之后:
> ①**伤害全程有意义**;②昏迷是**真实的医学状态**(脑震荡 / 失血性晕厥),
> 医学从业者一眼认得;③「现在他躺下了,你打算怎么办」这个抉择**更有分量**。

> **火器已砍**。理由:火器会让战斗变成「谁先开枪」,与「医者不杀」直接冲突 ——
> 枪没有非致命终点。

### 3.5 诊断:看得清 (P0)

诊断是 P0 唯一的判断技能。它**不直接提升疗效**,它提升的是
**你能拿到多少信息、以及判断有多准**。

| 诊断等级 | **读得多细**(精度档) | 判断能力 |
| ---- | ---- | ---- |
| 1-9 | **粗档** —— 面色 / 语声 / 姿态 / 呼吸的印象:「面色不好」「喘得急」 | 证据不全时**无法**判断,只能冒险 |
| 10-19 | **中档** —— 「面色发白」「呼吸浅快」;问诊可得**病史** | 证据不全时允许**一次低置信度判断** |
| 20-49 | **细档** —— 「面色苍白、口唇发绀」「双肺底细湿啰音」;**阴性读数第一次构成排除** | 可**排除**相近病名(**鉴别诊断**) |
| 35 | *(检验 —— **P1a**)* —— 显微镜 / 化验,须先由 9 增列通道;P0 无此设备 | 同上(检验只是给鉴别再加一档) |
| 50 | **满档** —— 全通道满精度 | 误诊几乎不再发生;可指认**罕见病** |

> **⚠️ 2026-09-14 口径修正:视触叩听 + 问诊 = 出生自带,不随等级解锁。**
> 原文把「呼吸音」「瞳孔反应、腹部触诊」「化验 / 显微镜」写成**逐级解锁的手段** ——
> **那是错的**。依据本文件 §3.2 的成长触发源原文(「完成一次**查体 / 问诊**并作出诊断」——
> **是「用」驱动,不是「等级解锁工具」驱动**)与 8 诊断的 Player Fantasy 锚点一
> (「技能改变的是**你的眼睛**,不是你的**工具箱**」)。
> **等级买到的不是新工具,是熟练度** —— 逐级变化的是**读得多细**,不是**能不能查**。
> **层义(每一档读到什么 / 走哪个通道 / 阈值在哪)归 8 诊断**
> (`diagnosis-system.md` 规则三 + R-8.1 / R-8.2);**本文只保留等级数值**(2026-09-14 裁定②)。

**关键设计**:诊断**不**给治疗效果加成 —— 那是辨证的事。
诊断给的是**信息量与准确率**。这保证:
- **P0 的成长是「我看得更准了」**
- **P1a 的成长是「我想得更全了」**

### 3.6 辨证的被动加成 (P1a)

辨证不只是一个「看得更多」的技能,它是**唯一提供治疗增益的技能**,
以此体现「中医给你的是整体观」。

证候判断正确时,依据辨证等级与「该证候是否曾被洞察」给予治疗加成:

| 辨证等级 | 解锁 | 条件加成 |
| ---- | ---- | ---- |
| 1-9 | —— | 无 |
| 10 | **一层洞察** | 诊断正确时,疗效 **+5%** |
| 20 | **二层洞察** | 若该证候**曾被治成功过**,额外 **+5%**(共 +10%) |
| 35 | **三层洞察** | 若病人的**情志 / 体质 / 时序**与你诊断时的考量一致,再 **+10%**(共 +20%) |
| 50 | **四层洞察** | 上述全部满足时,疗效 **+30%**,且失误不造成额外伤害 |

> **「有条件的被动」是本设计的要点**:加成不是白送的,
> 它奖励「你观察得越多、考虑得越全」,而不是「你等级高」。

**三层洞察的判定输入** —— 望闻问切获得的额外信息维度:
- **情志**(病人这三个月在想什么)
- **体质**(这个人天生偏寒 / 偏热 / 虚实)
- **时序**(现在是什么季节、这个病在什么时候会重)

这三样在辨证等级低时**不可见**;等级上来后,它们才进入你的观察面板。
**这不是解锁新工具,这是你的眼睛变了。**

## 4. 公式 (Formulas)

### 4.1 单次经验

```
XP_gain = BASE × K_difficulty × K_novelty
```

| 变量 | 含义 | 取值 |
| ---- | ---- | ---- |
| `BASE` | 动作基础经验值 | 见下表 |
| `K_difficulty` | 难度系数 | 1.0 ~ 3.0,由系统按该次事件的实际难度给出 |
| `K_novelty` | 新颖度系数 | 3.0 / 1.0 / 0.2(见 §3.2) |

**`BASE` 默认值**(Tuning Knob):

| 技能 | BASE | 说明 |
| ---- | ---- | ---- |
| 诊断 | 8 | P0 的主体技能,给得最多 |
| 辨证 | 8 | P1a 的主体技能,给得最多 |
| 急救 | 6 | |
| 手术 | 10 | 高风险、低频 |
| 处方用药 | 6 | |
| 针灸 | 6 | |
| 采集 | 1 | 高频,刻意给得低 |
| 炮制 | 3 | |
| 装备 | 5 | |
| 沟通 | 2 | |
| 公卫 | 8 | 低频、群体 |
| 商业 | 2 | |
| 奔跑 | 0.2 | 极高频,给得极低 |
| 潜行 | 0.5 | |
| 徒手 | 2 | 高频;给得低以防「打拳升级」 |
| 短兵 | 4 | |
| 钝器 | 4 | *(P1a)* |
| 长兵 | 4 | *(P1a)* |
| 暗器 | 5 | *(P1a)* 命中判定更难 |

### 4.2 升级曲线

```
XP_to_next(n) = C × n^P
```

| 变量 | 默认 | 说明 |
| ---- | ---- | ---- |
| `n` | 当前等级(1~59) | |
| `C` | 40 | 曲线系数 |
| `P` | 1.4 | 曲线指数。**`P` 越大后段越慢**;1.0 = 线性,2.0 = 平方 |

**默认曲线的含义**(C=40, P=1.4):

| 从 | 到 | 所需经验 | 累计 |
| ---- | ---- | ---- | ---- |
| 1 | 10 | ~1,160 | 1,160 |
| 10 | 20 | ~3,320 | 4,480 |
| 20 | 35 | ~12,600 | ~17,000 |
| 35 | 50 | ~31,000 | ~48,000 |
| 50 | 60 | ~29,000 | ~77,000 |

> **校验**:假设诊断 `BASE=8`、平均 `K_difficulty=1.5`。
> 每个**新**病名给 36 经验,每个**重复**病名给 2.4 经验。
> 若要从 1 级练到 60 级(~77,000 经验)全靠重复病例,
> 需要 **32,000 次**;靠新病例则需要约 **2,100 个不同的病名**。
> **结论:靠刷不可能到 60。这符合设计意图 —— 60 级应该属于「走遍这片土地的人」。**

### 4.3 死亡惩罚

```
new_level = floor(current_level × 0.95)
```

| 当前等级 | 掉到 | 损失 |
| ---- | ---- | ---- |
| 10 | 9 | 1 |
| 20 | 19 | 1 |
| 40 | 38 | 2 |
| 60 | 57 | 3 |

> 惩罚刻意做得**不痛但讨厌**:高等级玩家每次死亡损失 2-3 点,
> 需要面对几个新病例才能补回来。**它不制造挫败,它制造「我不想再死一次」。**

### 4.4 战斗效能

```
CombatPower = (CombatSkillLevel × WeaponMultiplier) × (1 + 医术修正)
医术修正     = 0.20 × (关联医术等级 / 60)
```

| 武器线 | `CombatSkill` | `WeaponMultiplier` 默认 | 关联医术 | 上线档位 | 备注 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 徒手 | 徒手 | 0.9 | 急救 | **P0** | 制服效率最高 |
| 短兵 | 短兵 | 1.0 | 手术 | **P0** | 出血与要害效果 |
| 钝器 | 钝器 | 1.0 | *(无)* | P1a | 击晕 |
| 长兵 | 长兵 | 1.1 | *(无)* | P1a | 距离,出手慢 |
| 暗器 | 暗器 | 0.8 | 针灸 | P1a | 远程,附带麻痹 |

**医术修正上限 +20%** —— 即 `关联医术 = 60` 时满值。
这意味着:**医术最高只能把战斗效能抬高五分之一**,战斗仍然由格斗技能主导。

> **P0 里只有一条耦合是活的**:`徒手 ← 急救`(急救是 P0 技能)。
> `短兵 ← 手术` 在 P0 **不生效** —— 手术是 P1a 的技能。
> 也就是说,**P0 的战斗里只有徒手能吃到医术加成**;P0 的短兵是纯格斗,
> 它的医学耦合(「你知道哪里会流血」)要等 P1a 手术上线才亮。

**昏迷阈值**恒为**生命归零**,不受任何技能影响 ——
技能影响的是**打出伤害的速度**,不是**能否制服**。

> **D1 已裁决(2026-09-13):采 (甲) 永久昏迷。**
> 昏迷的敌人**不会因为被晾着而死** —— 他只是一直躺着。
> 这意味着**你永远不可能杀掉任何人,连见死不救也杀不掉**。
> 代价明说:「医者不杀」因此**没有机制上的牙齿**,它纯粹是一种表达。
> 而这**忠于支柱二原文** —— 支柱二自己写的是「你的克制是一种**选择**,
> 不是这个世界的规则」。世界不奖励它,也不惩罚它的缺席。
> **不对称才是核心**:你杀不了任何人;**别人可以杀你。**

> **「途中遇敌」的触发源(2026-09-13 定)**:出诊途中遭遇的**触发时机与强度**
> 由 **52 随机事件导演**拥有(P0 新立系统;初判并入 27,因 P1a 起还要调度疫情/篇章/求诊,
> 超出敌人 AI 范畴而独立)。27 只管**行为**(追击 / 包抄 / 逃跑),52 只管**要不要来、来多少、来多强**。
> 格斗线的 P0 两项技能(徒手 / 短兵)因此有了可成长的对象池。
> **若这两者不拆开**,格斗线会在 P0 失去触发源 —— 两个练不动的技能。
> 见 `systems-index.md` §5(四个随机轴的取舍表)与 §9。
>
> ⚠️ **「不杀」的边界(同日裁决)**:非致命约束的对象是**人**,不是**兽**。
> 这是 §5 边界表里「危险动物生命归零」一行的由来。

## 5. 边界情况 (Edge Cases)

| 情况 | 处理 |
| ---- | ---- |
| **诊断错误** | 诊断**仍然涨经验**(×0.5 `K_difficulty`)。理由:错诊也是见识。但治疗会失败。 |
| **辨证错误** | 同上(×0.5)。辨证错不直接导致治疗失败,只是**拿不到那层条件加成**。 |
| **诊断与辨证结论冲突**(P1a) | 两者独立结算。**冲突本身不给提示** —— 玩家要在「机器视角」与「整体视角」之间自己取舍。 |
| **技能到 60 后继续使用** | 获得经验但被丢弃,UI 显示「已臻化境」。不惩罚,不溢出到别的技能。 |
| **联机中队友重复处理同一病例** | 新颖度按**玩家个人**追踪,不共享。每人各自第一次。 |
| **同一病例由多名玩家接力处理** | 各自按自己参与的部分得经验(主诊得诊断/辨证,主刀得手术)。 |
| **玩家从未见过的药材被队友采走** | 玩家本人**不得**新颖度加成 —— 必须亲手采过。 |
| **死亡时技能已为 1 级** | `floor(1 × 0.95) = 0`。**允许掉到 0** —— 但 0 级技能仍可执行,只是无加成。 |
| **反复在同一病人身上练同一个动作** | 冷却期(20 分钟)内 ×0.2;超出冷却后仍按已见过处理(×1.0)。**没有无限刷的路径。** |
| **VR 模式下的小游戏失败** | 与平面模式同样结算:VR 失败 = 小游戏失败,可重试或用判断结算。 |
| **跳过小游戏** | 用「判断正确 + 技能等级」结算,**同等获得经验**。跳过不是惩罚路径。 |
| **格斗技能刷级** | 新颖度对象是**对手类型**(兵痞、地痞、野兽、山匪),不是单次命中。同一类型反复打 → ×0.2。**打木桩不涨。** |
| **医术高但格斗低**(P1a) | **不允许**用医术绕过格斗。短兵 5 级的医生即使手术 60,战斗效能 ≈ 5 × 1.0 × 1.2 = **6**。他打不过短兵 40 的人。 |
| **格斗高但医术低** | 完全可行,而且**这是合法打法**。只是拿不到那至多 +20%,且治疗能力弱 —— 他要为自己的伤买单。 |
| **人形敌人生命归零** | **昏迷,不是死亡**。生命清零后进入可处置状态(救治 / 审讯 / 捆绑)。伤害**全程有意义**,不存在「打到某个百分比就不能再打」的魔法阈值。 |
| **人形敌人被误杀** | **不可能发生**。你的攻击不产生死亡状态,生命归零一律结算为昏迷;昏迷后**晾着也不会死**(D1=甲)。 |
| **危险动物生命归零** | **可以死** —— 「不杀」只约束人(2026-09-13 裁决)。动物**可猎杀取材 / 可驱赶**(P0);**驯化与招为护卫是 P1a**(`systems-index.md` #28)。依据:支柱二原文即「土匪会杀你,**野兽会吃你**」,野兽从来不在那份仁慈的范围内。 |

## 8. 验收标准 (Acceptance Criteria)

### 功能验收

- [ ] 19 项技能全部可成长,每项都有明确的成长触发条件
- [ ] 新颖度系统能区分「首次 / 冷却内 / 正常」三种情况并施加正确倍率
- [ ] 新颖度的追踪粒度为 `(技能, 对象)` 对,且**按玩家独立**(联机验证)
- [ ] 技能到达 60 后停止累积,UI 有明确反馈
- [ ] 死亡后每项技能按 `floor(level × 0.95)` 结算
- [ ] 战斗效能由**格斗技能主导**,医术修正**不超过 +20%**(硬上限,可验证)
- [ ] **医术等级不能替代格斗等级** —— 短兵 5 + 手术 60 的效能 < 短兵 40 + 手术 0
- [ ] **P0 已上线的两条武器线**(徒手、短兵)**全部**有可用的非致命终结手段
- [ ] 敌人生命归零时进入**昏迷**(可处置:救治/审讯/捆绑),**不进入死亡状态**
- [ ] 伤害结算**全程有效**,不存在「生命低于某百分比后伤害失效」的阈值
- [ ] 格斗技能的新颖度对象是**对手类型**;打木桩 / 无对手不获得经验
- [ ] 火器不产生任何技能经验,也不出现在武器线里
- [ ] **P0 中格斗线两项技能(徒手、短兵)全部可成长**,且与「出诊途中遇敌」的循环接通
- [ ] 钝器 / 长兵 / 暗器在 P1a 之前不可用(不显示、不累积经验)
- [ ] 诊断在 10 / 20 / 35 / 50 级**提高精度档**(**不是解锁体征层 / 手段** —— 四法出生自带),**且不提供任何治疗效果加成**
- [ ] 辨证在 10 / 20 / 35 / 50 级解锁洞察层,且加成**仅在有条件满足时生效**
- [ ] 诊断错误 / 辨证错误时仍获得经验(×0.5 难度系数)
- [ ] **P0 可玩版本中不出现「辨证」「证候」等任何中医词汇**
- [ ] P1a 之前,辨证技能不可用(未到门槛时不显示、不累积经验)
- [ ] 跳过小游戏与手动完成获得**同等经验**

### 平衡验收

- [ ] 从 1 级到 60 级不能靠重复同一病例达成(需 > 20,000 次重复才可能)
- [ ] 死亡惩罚在 60 级时损失 3 点(不多于 3 点,不少于 2 点)
- [ ] 单次游戏会话(90 分钟)内,主力技能应能上升 1-3 级
- [ ] 采集、奔跑、徒手的 BASE 足够低,不至于在前期因高频动作而爆涨
- [ ] 战斗不是最优成长路径 —— 一场战斗的收益应低于同时长的出诊

### 体验验收

- [ ] 玩家在不看数值的情况下,能通过**行为变化**感知技能成长(可识别的药材变多、动作更稳)
- [ ] 玩家能说出「我最近在治什么类型的病」而不是「我升了几级」
- [ ] 「手生」被玩家理解为叙事事件,而不是纯粹的数值惩罚
