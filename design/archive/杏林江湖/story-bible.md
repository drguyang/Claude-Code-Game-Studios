## 二、故事愿景与主题

### 2.1 一句话的野心

**这是一个关于"看法"的故事，不是关于"疗法"的故事。**

在医学的世界里，争论从来不只是"用什么药"，而是"用什么眼光看人"。中医看的是关系、是气机、是整体；西医看的是结构、是病灶、是证据；术数看的是推演、是概率、是可计算；心身看的是情绪、是执念、是病人这个人本身。

每一种眼光都是真的，每一种眼光也都只看见了病人的一半。

《杏林江湖》要讲的，是一个年轻人如何把这些互相敌视的眼光，一块一块拼成**一副完整的眼镜**——而这副拼起来的眼镜，就是钱学森晚年念念不忘的、"把一颗思想的种子种下去"的**新医学**。

### 2.2 新医学：不是加法，是眼睛

本故事最核心、最不可动摇的命题是：

> **新医学不是"一半中医加一半西医"，而是一种新的眼光。**

如果我们把新医学写成"中西医结合"= 中医的方子加西医的药片，那它就死了。那只是拼盘，不是融合。真正的融合发生在**看问题的方式**上：当一个西医能够看见中医所说的"证"背后的关系网络，当一个中医能够读懂显微镜下的因果链，他们都变成了新人——不是因为他们多学了一门技术，而是因为他们**多长了一只眼睛**。

这就是为什么主角的成长被设计成"逐步理解新医学的过程"，而不是"逐步学会更多方剂的过程"。他的每一次顿悟，都是一副新的眼镜落到鼻梁上。

### 2.3 种子：为什么要"种下去"

结局那一句——"把一颗思想的种子种下去"——不是煽情，是**结构的必然**。

新医学在这个时代做不成，也做不完。霍崇光可以被打倒，废止中医案可以被驳回，但中西医的裂痕不会因为一个人的牺牲就弥合。主角能做的，不是给出答案，而是**留下问题**。他著书、收徒，把那副拼起来的眼镜交给下一代人去戴。故事的终点不是胜利，而是**传递**。

这也是"杏林"二字的重量：中医传统里，杏林是医者的代名词。一片杏林，不是一棵树。种子落下去，要几十年才成林。主角这一代人，种树；下一代人，成林。

### 2.4 外行即内行：为什么人人都能玩

支撑整个"双主并重"受众策略的，是一个医学从业者自己给出的洞察，也是本作的灵魂：

> **目前的西医普遍专科化。一个心脏科医生，在面对一个神经系统疾病时，和一个从没学过医的普通人，是同样的外行。**

这句话的价值在于——它**消灭了"医生"和"玩家"之间的墙**。

医生玩这个游戏时，他不是专家，他是主角：在中医的气机面前、在术数的推演面前、在心身的执念面前，他和他自己的病人一样茫然。这种"原来我也什么都不知道"的体验，是给医生的礼物。

而普通人玩这个游戏时，他也不是学生，他是主角：中医、西医、术数、心身四门学问，在他面前是**平起平坐的四门外语**，没有谁先谁后、谁高谁低。这种"我也能看懂一点"的体验，是给大众的礼物。

"外行 → 内行"的旅程之所以动人，是因为**它属于每一个人**。医学生的成长、非医学者的理解、主角的顿悟，本质上是同一件事的三个刻度。

### 2.5 三层受众的同一颗心

- **给医生**：一个"重新做回外行"的机会，让被专科化切碎的整体感重新长回来。
- **给医学生**：一条看得见的成长路——原来"想通一件事"比"背下一个答案"重要得多。
- **给普通人**：一扇窗，让他们在故事里遇见自己身体里那些从未被好好解释过的道理。

三层受众，一颗心：**理解，从承认自己不懂开始。**

## 三、世界观设定

### 3.1 时代与地理：一个正在碎裂又正在缝合的民国

故事发生在 **1905 年至 1929 年**，清帝国最后六年到南京国民政府初立。这不是一个浪漫的抒情年代，而是一个**一切都必须被重新回答**的年代：

- 科举废了，读了半辈子"之乎者也"的读书人一夜之间不知何去何从；
- 西医随传教士、海关、庚款和洛克菲勒的钱涌进通商口岸，协和、广济、湘雅相继立起来；
- 中医从"唯一的医"变成了"待审视的旧物"，第一次需要向另一个体系证明自己的合法性；
- 军阀在打，瘟疫在跑，铁路在修，报纸在骂——**医学的论争，其实是整个民族"如何活下去、如何重新认识自己"的缩影。**

**地理骨架**（一条自东向西、自南向北的求索之路）：

| 区域 | 象征 | 主要登场卷 |
|---|---|---|
| 东海港口 · 江南故乡 | 起点与归处，旧学与新学的交界 | 卷一、二、十 |
| 关东北地 | 现代公共卫生第一次闯入中国，极寒与死亡 | 卷三 |
| 杏林世家 · 江南医门 | 师承血脉的堡垒与牢笼 | 卷四 |
| 京师 | 论战中心，学院、报馆、衙门 | 卷五、八 |
| 隐世秘宗 · 山中道场 | "气"可被亲眼看见的地方 | 卷六 |
| 南疆乱世 · 战地 | 秩序崩坏处，医学的极限 | 卷七、九 |

### 3.2 "气"：这个世界的显性规则

《杏林江湖》是一部"仙侠为壳、医学为核"的作品，因此必须严肃地回答一个问题：**"气"在这个世界里，到底是什么？它是真的吗？谁看得见？**

统一规则如下——**写得像物理定律，不留模糊**：

**第一定律：气是真的。**
气不是比喻，不是心理暗示，是一种可被感官直接经验到的实在。修炼内观者能在入静时"看见"人体内气机的升降浮沉，如同常人看见水流与风。气动，则病生；气滞，则痛作；气复，则人安。

**第二定律：气不与解剖矛盾，气是"动态的关系"。**
这是让本作在智识上站得住的关键。显微镜看见的是**结构**——细胞、组织、器官，是"是什么"。气看见的是**动态**——流动、制约、生克、升降，是"正在发生什么"。二者不冲突：解剖是一张静态的地图，气是地图上流动的河流。西医没有看见河流，不是因为河流不存在，而是因为它没有**看河流的眼睛**。

**第三定律：看见气，需要一堵墙被推倒。**
- **天生的**：极少数人（如苏晚棠）自幼便能模糊感知气，但这感知是零碎的、无法言说的，如同能听见声音却不懂乐理。
- **修炼的**：中医、禅医、术数世家通过内观、静定、推演训练，能系统性地"看见"气。陆九针、清和、陈九章属于此类。
- **顿悟的**：一个从未修炼的人，可以在极致的专注、极致的痛、或极致的爱之中，第一次"看见"气。**沈砚之就是这样看见的**——在他最笃信"只有显微镜下可见的才是真实"的那一年，他第一次看见了不可被显微镜看见的东西。这是全篇最重要的个人转折。
- **看不见的**：绝大多数普通人、绝大多数西医，终其一生看不见气。这不是愚昧，是**未开之眼**。

**第四定律（边界定律）：气有极限，不可越界。**
- 气**不能**起死回生，不能无中生有，不能治愈一切。
- 气**能**调和、引导、疏通、固本，能改变人**自身的走向**——但它只加速或延缓，不能凭空创造。
- 越界用气者，反受其害。这正是反派霍崇光指控中医"巫术骗人"时，最能命中痛处的软肋；也是主角一方必须始终自我约束的地方。**设定一个不能越界的规则，故事才有真正的紧张。**

### 3.3 志怪元素的边界：一条铁律

本作带志怪色彩——民间传说里的鬼、祟、精、怪、邪疫、附体，都会出现。但为了不让世界观陷入混乱，设定一条**贯穿全篇的铁律**：

> **气是真的；鬼神是气的误读。**

意思是：所有看似"鬼神"的现象，都可以被**两条解释同时容纳**——
- **民间解释**：这是鬼，是祟，是怨气，是报应；
- **气的解释**：这是气机的紊乱、心神的失衡、环境的疫疠、群体心理的共振。

故事**从不明确判定哪一种解释为真**，但两条线始终并存。一个村民的女儿夜里惊啼、日渐消瘦，神婆说是"丢了魂"，清和说她是"心气浮越、神不守舍"，陆九针说她是"惊则气乱"。**三个人说的是同一件事，用的是三种语言。**

这条铁律带来两个好处：
1. **氛围**：志怪的恐怖与神秘被保留，仙侠的浪漫不被牺牲。
2. **主题**：它本身就是"新医学"的预演——**面对同一个病人，不同的眼睛看见不同的真相，而真相是它们的总和。** 玩家在游戏里一次次经历的"多镜看人"，在叙事层面被这条铁律反复排练。

唯一例外的是**反派霍崇光**的邪术路线：他走的是"否认一切不可见之物，却为了消灭它而使用更不可见的力量"的悖论之路。他的"纯医学"，最终变成了一种真正的、被他自己否认的邪祟——这是对他的证据至上主义最锋利的讽刺。

### 3.4 杏林江湖：隐喻体系

"江湖"在本作中有三层含义，层层递进：

1. **武侠的江湖**：一个医者也要行走江湖的民国——匪、军、商、帮、教会、衙门，医者不再是坐堂的先生，而是背包走天涯的行者。这是最表层的"仙侠"外衣。
2. **学派的江湖**：中医内部有经方派、时方派、温病派、汇通派；中西医之间有新旧之争；门派与门派之间，恩怨、师承、秘方、门户之见，构成一个真实的、残酷的"武学体系"。卷四"杏林血"、卷八"国医之殇"，都是这个江湖的正面战场。
3. **人心的江湖**：每个人心里都有一个走不出的江湖——苏晚棠走不出仇恨，柳希白走不出冷漠，沈砚之走不出傲慢，霍崇光走不出他的"真理"。**故事的真正战场，从来是人心。**

三义合一：主角行走的是地理的江湖，卷入的是学派的江湖，修炼的是人心的江湖。

### 3.5 "医道图谱"的世界观化身

玩家在游戏里逐步点亮的"医道图谱"，在世界观内部有一个名字——**《杏林汇通录》**。

这是主角一路上记下的、由无数"点拨"碎片拼成的手稿：
- 每一片碎片，是某个人在某个地方教给他的**一个看问题的角度**；
- 当来自不同学科的碎片被连成一片，就诞生一条**"通"**——一条属于他自己的、从未有人走过的看法。

《杏林汇通录》就是故事内部的游戏存档：主角走了多远，不是看他杀了多少病邪，而是看他的图谱上，有多少条线**终于连了起来**。

## 四、主题回响：我们向《仙剑奇侠传》借什么

《杏林江湖》在结构上是对《仙剑奇侠传》的一次**郑重致意**。但必须说清楚：**我们借的是结构，不是内容。**

仙剑的动人，不在于它的仙、它的妖、它的锁妖塔，而在于几条**古老而有效的叙事律**。我们把这些律拿过来，换上医学的肉身：

| 仙剑的结构律 | 它为什么有效 | 《杏林江湖》的用法 |
|---|---|---|
| 平凡少年 + 亲人怪病触发启程 | 用最私人的危机，把主角推入宏大的命运 | 沈砚之为救母，被迫走进他毕生否定的中医世界 |
| 命运之人携身世之谜登场 | 主线引擎与情感锚点合一 | 苏晚棠 = 身世之谜的持有者，全篇脊柱 |
| 对手 → 同伴的欢喜冤家 | 队伍化学反应，冲突即成长 | 门户之争 → 并肩（沈砚之 × 苏晚棠） |
| 导师授艺、不说道理 | 给技能，也给世界观，且留着悬念 | 陆九针以点拨代替训诫，像酒剑仙以醉代替说 |
| 队伍裂痕：离队 / 反目 | 中期至暗，让"聚"显得珍贵 | 卷六苏晚棠因理念分歧离队 |
| **同伴牺牲（"月如那一刀"）** | 全篇情绪重写点，主角性格永久改变 | 卷九苏晚棠归来后殉职 |
| 反派怀极端信念 | 主题的对立面，而非扁平的恶 | 霍崇光的"纯医学"= 科学至上主义的极端化身 |
| 结局：牺牲 + 传承 + 留白 | 不是胜利，是传递；玩家带着余味离开 | 著书、收徒，"把一颗思想的种子种下去" |

### 4.1 牺牲与传承

仙剑的结局之所以成为一代人的记忆，是因为它**没有给圆满**。灵儿化入封印，月如死在塔中，逍遥抱着婴儿回到余杭——活下来的人背负着死去的人的重量，把故事继续活下去。

《杏林江湖》继承这种"不圆满的重量"。苏晚棠会死，而且是在她终于放下私仇、重新成为医者之后，死在她最该活着的时刻。她的死不是惩罚，是**一种职业的宿命被写到了极致**：一个医者，最终是死在救人里的。而主角活下来，背负着这份重量著书收徒——他的余生,就是她的墓志铭。

### 4.2 聚散

仙剑的队伍在聚散之间推进，聚时温暖，散时刺骨。《杏林江湖》把"聚散"提升为一条**核心玩法主题**——队伍的每一次加入与离去，都对应一个成员"局限之墙"的破与立。人不是因为有敌人而强大，是因为有同伴而完整；而当同伴离开，你才第一次看清他曾经替你挡下了什么。

### 4.3 医者仁心

这是本作与仙剑气质最贴、也最不该被口号化的一条。**仁心不是"好人做善事"，而是"无论对方是谁，都把他当作一个完整的人来看"。**

这正是"四镜看人"的意义：把病人变成病例，是医学的进步；但把病例重新变成一个完整的人，是医学的良心。故事的每一个顿悟，最终都指向同一个方向——**看见人**。

| 1918 | **张锡纯《医学衷中参西录》首期刊行**（此后分六期陆续出齐），汇通派崛起 | 卷五 论战 | 中西药并用之辩白热化 |
| 1918 | **西班牙大流感蔓延**（在华南北多地亦暴发重症，民间称"骨痛病""五日瘟"） | 卷六 气海 | 沈砚之第一次"看见气" |
| 1919 | 1 月陈独秀《〈新青年〉罪案之答辩书》喊出"德先生""赛先生"；**五四运动**（科学主义高峰） | 卷六 气海 | 清和加入；**苏晚棠离队** |
| 1920–1924 | **军阀混战、战地医疗、霍乱与天花流行**（直皖 1920、两次直奉 1922/1924；1920 华北霍乱） | 卷七 邪疫 | 霍崇光崛起；苏晚棠放下私仇归来 |
| 1929 | **2 月余云岫《废止旧医案》获中央卫生委员会通过**；3 月 17 日全国医药团体代表大会于上海请愿（后定"国医节"） | 卷八 废止 | 论战白热化，父辈血仇与时局对撞 |
| 1929（同年稍后） | 废止案余波；大疫暴发（**以 1929–1930 华北/江南霍乱、伤寒为原型整合，详见卷九**） | 卷九 汇通 | 众所学汇成新医学雏形；**苏晚棠殉职** |
| 1929 之后 | 国医存续，中西医渐趋并存 | 卷十 种子 | 著书、收徒；队伍各归其所 |

**时间骨架的设计意图**：每一条史实不仅是背景，更是**下一卷剧情压力的成因**。
- 科举废了 → 旧学生存危机 → 卷二的师承之争；
- 教育规程漏列中医 → 官方对中医的第一次制度化否定 → 卷四的门户血战；
- 协和与汇通派同时崛起 → 科学主义与国医正面相撞 → 卷五的论战；
- 五四把"赛先生"推上神坛 → 主角在最信仰科学的那一年看见气 → 卷六的信仰崩塌；
- 军阀乱世 + 废止案 → 霍崇光需要的时代土壤成熟 → 卷七、八的连环危机。

故事因此**不需要靠巧合推动**：时代本身就是那个不断收紧的、巨大的命运。

### 6.1 主角与反派（故事的两极）

> **本节定位**：故事的两极。沈砚之与霍崇光是"同一种病的两种极端"，必须放在一起阅读才能看见对照关系。

#### 沈砚之 —— 主角 · 留洋西医

**身份：** 江南中医世家"沈氏医庐"第四代孙；祖父沈济时是当地名医，父亲沈伯渊早逝。他自幼被寄予继承家学的厚望，却因父亲的固执与失败、家道的衰落，对中医生出深切的怀疑，远赴海外学医，立志"用真正科学的方法救人"。学成归国时，他西装革履、言语锋利、满腹新学。

**学科 / 医道：** 西医（病理学、细菌学、靶向、实证方法）。

**局限之墙：** 科学傲慢。他相信"只有显微镜下可见、可重复、可被数字证明的，才是真实"。这面墙的底色其实是恐惧——他否认中医，是因为他无法承受"父亲坚持了一辈子的东西可能也有价值"这个念头。

**人物弧：**
- **引入：** 归国时视中医为"待淘汰的旧物"；
- **发展：** 救母失败于西医、成功于中医（卷二）；在疫城学会敬畏死亡（卷三）；在杏林血中被门户之见刺痛（卷四）；
- **转折：** 卷六，在西班牙大流感与五四科学主义最盛的年份，他第一次亲手"看见"了气——那一刻不是胜利，是他毕生信仰的地基裂开；
- **成熟：** 卷七至卷九，他不再问"哪种医学对"，而问"这个病人需要哪一双眼睛"；
- **结局：** 卷十，著《杏林汇通录》、收徒、把种子种下去。

**关系：** 陆九针是"另一个父亲"（他真正不肯和解的是自己死去的父亲）；苏晚棠是镜像与挚友（两人都是"被家学困住的人"，一个逃离一个背负）；柳希白是他科学信仰的同道与拷问者；陈九章让他第一次意识到"数学也是一种医学语言"。

**标志性台词：**
- 出场时："我看过一千个病例的解剖报告，中医连一张化验单都没有。"
- 卷六顿悟时："原来我一直只戴了半副眼镜——不是它没有度数，是我这只眼睛，从来没有睁开过。"
- 卷十结尾："我不是医生。我只是一个终于学会了怎么做外行的人。"

**加入 / 离场：** 卷一登场，贯穿全篇。

**成长机制钩子：** 主角的成长不体现在"数值变强"，而体现在《杏林汇通录》图谱上的连线数量。玩家的每一次跨学科顿悟，都直接增强他在战斗中的"合方"能力。

#### 霍崇光 —— 反派 · 科学至上者

**身份：** 新医学体制内的权威人物——卫生行政要员、新式医学院的院长、科学派的执牛耳者。他留洋多年，是那个时代最主流、最正确、最无法反驳的一种声音的化身：中国要强盛，就必须用科学驱逐一切迷信，而中医，在这场"祛魅"的战争里，是头号障碍。

**学科 / 信念：** 实证科学、公共卫生、制度化医学。他主张"废止旧医"（对应真实的废止中医之争）。

**局限之墙（也是他的心魔）：** 不信"人"，只信"理"。他曾经是苏晚棠祖父苏问岐最得意的弟子——一个真正相信"医不一家"的年轻人。二十年前，在一次关乎人命的重大决断中，他照着"最科学"的方案行事，却眼睁睁看着最该活下来的人死掉，而苏问岐用"不科学"的方法救了另一批人。在巨大的羞耻与痛苦中，他没有承认师父对，反而认定"如果不彻底消灭这种'不科学'的医术，还会有更多人像那天一样，死在不可控的偶然里"。从此他把自己钉在了"正确"的十字架上——他要用绝对的、不容置疑的科学，消灭一切"说不清"的东西。

**与苏晚棠的血仇：** 他构陷苏问岐，是为了"证明中医终将失败"这一信念；苏家的衰落，是他信仰的祭品。当苏晚棠站在他面前时，他看见的不是仇人的后代，而是自己二十年前那个不敢承认错误的、年轻的自己。

**人物弧：**
- **发展：** 卷四至卷八，他一步步登上权力顶峰，借"废止旧医案"达到其理论的最高潮；
- **转折：** 卷九，他鼓吹的"纯医学"在真实的大疫面前暴露出致命的短板——它灭菌，却不医人；它统计，却看不见个体；它清除"迷信"，却在清除的过程中酿成了比迷信更大的灾难（可能是激进的隔离、也可能是被否认的"心身"维度的病人大量死亡）；
- **结局：** 他的崩溃不是被主角击败，而是被现实证伪。他在自己一手建起的、绝对正确的殿堂里，看着它坍塌。他的最后一问，是全篇对"科学主义"最深的扣问："如果我一直是对的……为什么死去的人，一个都不像数据？"

**关系：** 与主角是同一种病的两种极端——主角后期学会承认无知，霍崇光至死不肯承认。他是主角"如果不变"的那个未来。

**标志性台词：**
- "你们管这叫'医道'？我看是骗术。把不可控的东西叫'气'，把不可验证的东西叫'经验'。中国就亡在这种'说不清'里。"
- 卷八："我不是恨中医。我是恨'说不清'。说不清的东西，就该被清除——为了剩下的人。"
- 卷九终局："我算过每一个变量。……我算过每一个人。可人，怎么可以不算进去？"

**加入 / 离场：** 卷四作为阴影浮现，卷五正式登场，卷九崩解，卷十成为后世的一段教训。

**成长机制钩子：** 霍崇光是"科学主义的终极 BOSS"，其战斗机制与"证据 / 数据"高度绑定——玩家需要打破他"可计算、可重复"的战斗节奏，用"个体化、不可量化"的医道才能取胜。他的战斗是主题对立面的玩法化。

### 6.2 队伍成员

> **本节定位**：五位可操作队伍成员的完整角色卡。按加入顺序排列。

#### 陆九针 —— 导师 · 老中医

**身份：** 年逾六旬的民间老中医，祖上与沈砚之的祖父沈济时是数十年同道。他一生颠沛：开过药铺、坐过冷板凳、也曾在京城名动一时。他看起来很"旧"——青布长衫，背一只旧药箱，说话慢，爱在句尾加个"罢了""咯"。但他不迂腐：他订阅报纸，读西医书，对新生事物有着老农般的好奇。

**学科 / 医道：** 经方、针灸、气机。他是"气的眼睛"持有者，能看见气。

**局限之墙：** 轻西医。他嘴上不否定西医，心里却始终觉得"机器看的是死肉，看不出气"。他这面墙，是用一个真理去掩盖另一个真理——直到卷三的疫城，现代防疫第一次让他哑口无言。

**人物弧：**
- **引入：** 卷二以经方救回主角母亲，主角的医学世界观第一次被"证伪"；
- **发展：** 他是主角的老师，但更像一条河的源头——他给的不是答案，是看问题的方式；
- **转折：** 卷三学会用"钟表、隔离、口罩"这些西医手段，第一次亲手推开自己的墙；
- **成熟：** 卷五、卷六，他成为年轻人在乱世中唯一不动的那块石头；
- **结局：** 卷九，他救回了无数人，唯独没能救回苏晚棠。卷十，与主角合著医书，笑言"我这一生的方子，可能就为了配上你这一双眼睛"。

**关系：** 对主角亦师亦父；对苏晚棠有隐秘的歉疚（因为他认得苏家，却沉默了太多年）；与清和是忘年之交。

**标志性台词：**
- "证不是病。病是你从显微镜里看见的那个东西；证是那个人此刻整个的样子。"
- 救回主角母亲后，顿了顿："我救的不是你娘。我救的是你没看明白的那半个世界。"
- 卷九："像她那样死，是医者的一种福气。我们剩下的人，才苦。"

**加入 / 离场：** 卷二加入，至卷十存活。

**成长机制钩子：** 陆九针是队伍中"辨证"能力的主持者——战斗里玩家需要靠他辨识"证候"，才能对症下药。他的成长体现在他愿意使用多少非中医手段（随剧情解锁"防疫""镜检"等跨学科技）。

#### 柳希白 —— 防疫女医 · 公共卫生

**身份：** 新式医学堂毕业的第一代中国女医之一，曾供职于海关检疫与新式防疫处。出身寒微，靠教会医学堂的资助读完书，性格冷静、行动力极强、不擅寒暄。她随身带着显微镜，把一切活人都先看成"潜在的传染源"。

**学科 / 医道：** 公共卫生、细菌学、显微镜检、流行病学雏形。

**局限之墙：** 把病人当数据。她能算出十万人里有几个该死，能为了多数人的安全放弃少数人——这让她在疫城中表现得冷酷而高效，也让她一次次在具体的、有名字的病人面前失语。她的墙，是用理性砌成的自我保护。

**人物弧：**
- **引入：** 卷三，在东北疫城与主角并肩，把现代防疫带进故事；
- **发展：** 她与陆九针的"整体观"反复冲撞——她要隔离，他要温养；她要统计，他要个案；
- **转折：** 卷六至卷七，一个被她"放弃"过的病人成为她午夜梦回时的刺，她第一次问出"如果那个数字里，有我认识的人呢"；
- **结局：** 卷九大疫中，她终于学会在非常时期为每一个"数字"找来名字。生还。

**关系：** 她与主角是"科学信仰的双子星"，彼此照见、彼此拷问；与陆九针是学术上的对手、人格上的敬重；她暗地里把苏晚棠当作"如果当初我选了中医会怎样"的那个自己。

**标志性台词：**
- "数字不会哭。所以我信数字。"
- 卷九，对着病人名册："一百七十三。……不。是一百七十三个人的名字。我得一个一个念出来。"

**加入 / 离场：** 卷三加入，至卷十存活。

**成长机制钩子：** 柳希白主持队伍的"防控"与"诊断"分支——越是疫情类关卡，她的价值越突出。她的成长线解锁"群体防治"与"个体关怀"两类相冲突的技能，玩家需要在两者间选择。

#### 苏晚棠 —— 中医学徒 · 全篇脊柱 · 身世之谜持有者

**身份：** 年轻的中医学徒（女），出身衰败的江南医门苏家。她的祖父苏问岐是一代名医、汇通思想的先驱之一，曾著医书、开馆授徒，却在二十年前被自己最得意的弟子出卖、构陷，郁郁而终，家道中落。苏晚棠自幼由遗老师父抚养，身负两样东西：一部残缺的祖父遗稿，和一段连她自己都未曾完全知晓的家族血仇。

**学科 / 医道：** 针药、医案、经方。她是少数天生便能模糊感知"气"的人——但她自己也说不清那是什么，只当作"直觉"。

**局限之墙：** 门户自卑 → 私仇。前期，她因家道中落而自卑，在留洋西医面前抬不起头，卑怯里藏着极深的骄傲；后期，当她拼出祖父之死的真相，自卑被仇恨取代，她一度只想为死去的人复仇，而不是为活着的人治病。她的墙，是让过去的冤屈劫持了未来的人。

**人物弧（三段最重）：**
- **身世（卷四）：** 登场即与主角针锋相对（门户之争）；随着共同治病，她开始怀疑祖母留下的遗稿另有隐情；卷四末尾，祖父之死的关键一页浮出，指向霍崇光。
- **离队 / 反目（卷六）：** 真相摊开后，她无法接受队伍（尤其是崇尚"程序正义"的主角）不肯用复仇的方式对付霍崇光。她一意孤行，孤身离开。
- **归来（卷七）：** "我必须亲眼看着他倒下，而不是亲手杀了他。"她在战地的死人堆里重新做回了医者，也第一次原谅了那个只想着复仇的自己。
- **殉职（卷九）：** 大疫中，她像祖父一样，把最后一个病人的命放在自己前面。她死在救人里——不是被霍崇光杀死，而是主动选择了那个当年夺走她祖父的、纯粹的职业宿命。她临终的平静，是全篇最重的一刀。

**关系：** 与主角是"被家学困住的双子"——一个逃离、一个背负，互为镜像，也是彼此唯一能听懂对方的人；与陆九针有隐秘的师承线（陆九针曾见过苏问岐）；与霍崇光是不共戴天的私仇。

**标志性台词：**
- 登场时（对主角）："你们西医最会的一招，是把人锯开看看，然后说'你看，这里坏了'。可人不是一头可以拆开的牲口。"
- 卷四揭示身世时："原来我一辈子练的针，是为了有一天能刺进那个人的心口。"
- 卷六离队时："你讲道理，我讲血。我爷爷埋在土里二十年，谁的证据替他说话了？"
- 卷九临终，对着主角："别哭。……我修了一辈子的气，就是为了能这样走。像爷爷一样。"

**加入 / 离场：** 卷四加入 → 卷六离队 → 卷七归队 → 卷九殉职。

**成长机制钩子：** 苏晚棠是队伍的核心输出与"证候识别"的关键节点。她离队期间，玩家的医道图谱会出现一块空白（系统性留白），迫使玩家用不完整的队伍通关——这块空白，就是"失去"在玩法上的具象化。

#### 陈九章 —— 术数传人 · 数理

**身份：** 出身于一个兼通天文、历算、术数的世家，家学既可算天象、又可算人事，表面上像"算命先生"，骨子里是中国式的数学与系统思维。他体弱多病，靠家传养生法勉强活着；他相信"万物可算"，也相信"算不出人心的那一部分，才是人生"。

**学科 / 医道：** 数理、推演、系统、概率雏形。

**局限之墙：** 以图为真。他把万物建构成模型之后，便信模型甚于信眼前的人——当"图"与"病人"冲突时，他下意识信图。他的困境不在"说不清"（那是中医的墙），而在**把系统错当成了世界**：趋势算得极准，却在那些不遵循模型的、具体的病人面前失语。

**人物弧：**
- **引入：** 卷五京城论战，他以一套推算气候与疫病趋势的方法现身，被众人视为骗子，却被陆九针识出其中真意；
- **发展：** 他把"气候—人—疫"看作一个可建模的系统，成为队伍里第一个提出"整体"的科学视角；
- **转折：** 卷七至卷八，当他的推算第一次害了人（算得没错、却用错了地方），他开始懂得"数据背后的责任"；
- **结局：** 卷九、卷十，"汇通"的工程部分由他完成——他把四门语言翻译成同一张图。生还。

**关系：** 与柳希白是"理性同盟"（都被指为"冷血"）；与主角是"两套科学的相遇"——一个西医、一个数学，谁也说服不了谁，却最终合作。

**标志性台词：**
- "我算得出这场疫什么时候来，算不出你为什么会怕它。"
- 卷九："把四门语言画进一张图，需要有人先承认，四种都对，四种都不全。"

**加入 / 离场：** 卷五加入，至卷十存活。

**成长机制钩子：** 陈九章是队伍的"推演 / 预判"角色，带来战斗中的"布局"能力（预判病邪走势、机制推演）。他的成长解锁"系统之眼"——把多个零散信息连成趋势。

#### 清和 —— 禅医 · 心身

**身份：** 一位隐居山寺的医僧（或在隐世秘宗道场修行的医者），年岁不详，性别在不同的旅人记忆里都不相同（志怪式的留白）。他/她奉行"医身先医心"，专治那些"药治不好的病"——因执念而病、因心结而病的人。

**学科 / 医道：** 心身、安神、禅修、气的静定面。

**局限之墙：** 出世疏离。他以为"不动心"就是慈悲。他能安他人的神，却渐渐冷了自己的心；他能看透别人的执念，却回避自己在尘世中的责任。

**人物弧：**
- **引入：** 卷六隐世秘宗，他/她点化主角"看见气"——用的是一个"什么都不说、只是陪你坐三天"的方式；
- **发展：** 他/她给队伍带来"医治人心"的维度：很多病，病人自己不肯好，就永远好不了；
- **转折：** 卷七乱世中，他/她第一次"入世"——为了救人，破了"不动心"的规矩；
- **结局：** 卷九、卷十，他/她终于明白"入世即修行"。生还。

**关系：** 与陆九针是忘年知己；他/她在苏晚棠离队期间，是唯一能看穿她"其实想回来"的人。

**标志性台词：**
- "把气看病了，是治身；把人看执了，是治心。这两件事情，中间隔着一整个人的一生。"
- "不理尘世，不是不染尘埃。是把自己也关进了那间空屋子。"

**加入 / 离场：** 卷六加入，至卷十存活。

**成长机制钩子：** 清和提供"心神 / 纾解"类技能，专治非器质性、心因性的证候（抑郁、惊悸、癔症等），是"双主并重"中针对大众心理、易共鸣的病种关卡的主持者。

## 七、十卷分卷详述

> 每卷记录：时代与史实锚点 · 地理 · 剧情梗概（含场景与对白片段）· 本卷大顿悟 · 队伍变动 · 关卡形式 · 伏笔（埋 / 收）。

### 卷一 · 归舟（1905）

**时代与史实锚点**：清廷废除科举（1905 年 9 月诏令，自丙午科即 1906 年起停乡会试）。全国的书院、私塾、旧学体系在一年之内失去"功名"这个终极目标，无数读书人一夜之间失去出路。与此同时，新式学堂、报馆、留学生、通商口岸的新事物涌现。这是一个**"旧的意义崩塌、新的意义尚未建成"**的真空期——医学的新旧之争，正是这个大崩塌的一个切面。

**地理**：东海港口（主角登岸处）→ 江南水乡故乡。码头、洋行、租界、青石板巷、沈氏医庐的旧宅。

**剧情梗概**：

汽笛长鸣，火轮靠岸。沈砚之站在甲板上，一身剪裁合体的西式西装，怀里揣着一沓在海外写的病理学笔记。他不是衣锦还乡——他是回来"告别"的。他计划在故乡处理完旧宅，接母亲去上海，从此和那个"连一张化验单都拿不出"的中医世家，断得干干净净。

故乡比他记忆里更旧。青石板上的苔痕、药铺里散不去的苦味、堂屋里祖父沈济时的匾额——"杏林春暖"四个字他已经十几年没正眼看过。母亲周慧兰在灶间给他温了一碗他小时候的药茶。他一口没喝，说："娘，这东西没用的。换我给你带的新药。"

母亲只是笑："你祖父喝了一辈子这个。"

他在祖父留下的旧书箱里，翻出一沓手稿——祖父的字迹，密密麻麻，全是关于"中气"与"气血"的推演。他一页页看过去，越看越烦，最后把稿子往箱底一塞。**（埋设伏笔：祖父遗稿 / 陆九针二字在稿末出现过）**

镇上传出消息：科举废了。卖笔墨的老周在巷口哭了一夜，他的儿子从此不知道该念什么书。沈砚之站在人群里，忽然意识到：**他脚下的这个旧世界，正在他眼前坍塌；而他，是回来参加葬礼的。**

母亲端着一碗药茶站在门口。她轻声说了一句：

> "砚之，世界可以推倒重来。可人的身子，倒不下重来的。"

他当时没听懂。

**本卷大顿悟（序章级，微弱）**：
> "旧的不一定是错的，它可能只是——还没被这个时代听懂。"

**队伍变动**：主角登场。年末，母亲周慧兰忽然病倒。

**关键关卡与形式**：
- *序章·归舟*：叙事引入，无可失败；通过"码头—旧宅—母亲"三段场景建立主角的立场与内心的矛盾（**"人间层"教学**：如何看一个人，而不只看他的病）。
- *卷一终·母亲的病*：一个**"你以为你懂医学"的下马威**——主角用自己所学诊断母亲的病，却发现处处对不上。引入"证候"这一未知变量，为卷二做引。

**伏笔**：
- 埋：祖父遗稿（结尾出现"陆九针"三字）；
- 埋：母亲那句"人的身子，倒不下重来的"（卷九、卷十回收）；
- 埋：主角怀中那沓病理学笔记（卷六回收——他会用它烧掉自己旧的世界观）。

### 卷二 · 旧医（1906）

**时代与史实锚点**：新式医学堂与旧式师承医馆并存的过渡期。西方医学堂在口岸城市招生，旧式中医仍凭"师徒、家传、秘方"存续。**"学医"这件事第一次出现两条并行、互相看不起的路**。

**地理**：故乡及周边乡镇。陆九针的旧药铺、山间采药径、病家宅院。

**剧情梗概**：

母亲的病越拖越重。沈砚之试遍了他所知的现代手段：退热、强心、补液——症状压下去，人却越来越虚。西医的教科书在这里失灵了。他第一次感到一种他不愿承认的恐惧：**他脑子里那套"最先进"的知识，救不了自己的母亲。**

有人告诉他，镇外住着一个古怪的老先生，姓陆，人称"陆九针"，据说针下能"看气"。沈砚之嗤之以鼻，但母亲危在旦夕，他还是去了。

陆九针的药铺又暗又乱，老头正打盹。沈砚之把母亲的症状说完，陆九针眼皮都没抬，只问了三句："她何时咳得最凶？是在夜里，还是天明？她怕冷还是怕热？她这些日子，可有放不下的事？"

沈砚之愣住了——**第三个问题，和他的医学训练毫无关系。**

三副药。母亲在第三天睁开了眼。一周后能下床。

沈砚之坐在药铺的门槛上，一夜没睡。天光初白时，陆九针递给他一碗药茶，说了本作最重要的台词之一：

> "证不是病。病是你从显微镜里看见的那个东西；证是那个人此刻整个的样子。"

沈砚之盯着自己那沓笔记，第一次说不出反驳的话。他低下头：

> "……我只戴了半副眼镜。"

陆九针笑了笑，慢悠悠地摆手："不是半副。是从来不知道还有另外半副。小子，要不要跟我走一趟江湖？"

**本卷大顿悟**：
> "'看不见'不等于'不存在'——只是我没有那双眼睛。承认这一点，是学习真正开始的地方。"

**队伍变动**：**陆九针加入。** 他成为主角的导师，也是队伍第一块基石。

**关键关卡与形式**：**病例推理（第一次完整呈现）**——玩家需要像真正的医者一样"问诊"：不是问"你有什么病"，而是问"你什么时候最不舒服、你的饮食起居、你的喜怒哀乐"。**正确的答案，藏在病症之外的人的生活里。** 这是首次确立"看人，而不只看病"的核心玩法。

**伏笔**：
- 埋：陆九针看到主角祖父遗稿时，手指曾微微一顿（卷四回收——他认得苏家，也认得沈济时与苏问岐的交往）；
- 埋：陆九针说"我年轻的时候，也救错过一个人"（卷九回收）；
- 收：卷一"证候"这一未知变量，在本卷被正式引入医学体系。

### 卷三 · 疫城（1910–1911）

**时代与史实锚点**：**东北大鼠疫**（1910 年 10 月满洲里暴发，1911 年 3 月扑灭）。这是中国近代史上第一次以现代科学手段（隔离、检疫、口罩、尸检、交通阻断）成功控制的重大疫情，也是"现代公共卫生"第一次真正闯入中国的视野。它在国际上确立了"中国也能科学防疫"的形象。**史实人物以原型出现，不作为角色出场。**

**地理**：关外苦寒之地。火车站、隔离棚、尸横的街巷、临时防疫处、风雪中的坟场。

**剧情梗概**：

一列从关外来的火车带来了消息：瘟疫。短短数日，一个小镇熄灭了一半灯火。沈砚之与陆九针本要去京城，却被迫留在了这座封锁中的疫城。

在这里，他们遇见了**柳希白**——新式防疫处的女医官。她穿着白大褂，戴着口罩，手持显微镜与消毒水，身后跟着一群穿制服的人。她做的第一件事，是把整条街封了。

冲突爆发。

陆九针要"温养"。柳希白要"隔离"。陆九针说病人是活人，不能像牲口一样圈起来；柳希白说，你圈起一百个人，可能救了一千个人。**两种医学第一次正面相撞。**

沈砚之站在中间——他的科学信仰让他想站到柳希白这边，可他亲眼见过陆九针把母亲从死亡里拉回来。

危机的转折点是一场葬礼。一个死于瘟疫的老妇，尸体要在雪夜里被草草掩埋。陆九针拦下了防疫队，坚持要替死者"送一口气"——他不是在和陈规较劲，他是在告诉周围的人：**如果连死人都不被当作人，那活着的人凭什么相信你们是在救人？**

柳希白站在雪里看了很久。最后，她摘下口罩，说了全篇对她而言最重要的一句话：

> "他救的是人心。我救的是没染病的人。……也许，这两个都得有人做。"

防疫最终成功。城市活下来了。但代价是：死亡名单很长很长，那张名单上，每一个名字都曾是一个人。

**本卷大顿悟**：
> "医学的敌人，是死亡，不是另一种医学。"——中西医第一次停止互相指责，因为它们在同一个死人面前，同时低下了头。

**队伍变动**：**柳希白加入。** 队伍第一次拥有"科学 / 公共卫生"的视角，与陆九针形成张力。

**关键关卡与形式**：**疫情资源博弈 + 推理**——玩家在有限的人力、药品、隔离空间下做取舍：救这一个，可能放弃那一个；封这条街，可能饿死另一条街的人。**没有"全对"的解法，只有"你愿意背负哪一种后果"的选择。** 这一卷是"两难选择"玩法的奠基。

**伏笔**：
- 埋：柳希白对人命"数字"的冷漠（卷九回收——她终于学会了念出每一个名字）；
- 埋：防疫处的一位西式医官顾慎行，在一份文件上拒绝签字（卷八回收——他后来成为队伍在体制内的盟友）；
- 收：陆九针"轻西医"的墙第一次出现裂缝，他开始学着戴上口罩。

### 卷四 · 杏林血（1912）

**时代与史实锚点**：民国肇建，北洋政府教育部颁行《医学专门学校规程》（1912 年 11 月—1913 年初），**漏列中医**（史称"教育系统漏列中医案"）——这是官方制度层面对中医的第一次系统性否定：中医被排除在"正规教育体系"之外，失去合法办学的名分。一纸规程，把"中医该不该存在"从学术问题变成了**生存问题**。

**地理**：江南杏林世家所在的古镇。气派的旧宅、堆满医案的藏书楼、荒败的祠堂、雨中的石桥。

**剧情梗概**：

队伍行至一座以医门著称的古镇。这里有一个没落的大族——**苏家**。苏家的宅子还立着，人却已经散尽，只剩一个年轻的女医**苏晚棠**守着祖宅、替乡邻看些小病。

初见即是火药味。沈砚之在镇上替人看病，开了西药；苏晚棠路过，当场指出他的方子"只见病、不见人"；两人当街争执，苏晚棠留下一句：

> "你们西医最会的一招，是把人锯开看看，然后说'你看，这里坏了'。可人不是一头可以拆开的牲口。"

沈砚之被她戳到痛处——因为她说得对。但他同样戳到了她的痛处：他拿出新公布的《规程》，冷冷地说："现在连国家都不认你们的学堂了。"

苏晚棠脸色煞白，转身就走。陆九针在旁看着，没有说话——他早就认出，这是苏问岐的后人。

一次突发的乡间急症，让两人被迫合作：一个孩子的病，西医的检查查不出、中医的方子也吃了不见效。**只有两人的判断合在一起，才拼出真正的病因。** 那一夜，他们第一次并肩。沈砚之第一次体会到，苏晚棠说的"气""证的层次"不是玄学，而是**另一种精度**。

此后，苏晚棠将他们引入苏家藏书楼——祖父苏问岐的医案与遗稿堆满半间屋子。她要查明，为什么一代名医会被一个"最科学的官"逼到身败名裂、郁郁而终。

**祖父遗稿的最后几页，是一份证词：苏问岐的得意弟子，为了推行"纯粹的科学医学"，构陷了师父。那个人的名字，是霍崇光。**（此谜底为卷一遗稿伏笔的回收。）

苏晚棠握着那几张纸，手在抖。她说：

> "原来我一辈子练的针，是为了有一天能刺进那个人的心口。"

**本卷大顿悟**：
> "门户之争，争的从来不是对错，是两个都不愿承认自己不全的人，各自守着半副眼镜。"

**队伍变动**：**苏晚棠加入。** 身世之谜浮出水面，主线正式挂上钩。

**关键关卡与形式**：**门户论辩 · 回合策略战**——本卷确立"论战即战斗"的玩法：玩家以队伍成员的学科为"招式"，围绕一个疑难病例展开回合制辩论/诊疗对抗。"病灶"是"两套诊断各执一词"的分歧本身，玩家要用证据与医理把它一步步拆解。首次出现"合方 / 合击"（中西搭配的招式）。

**伏笔**：
- 埋：苏问岐遗稿（卷八——成为废止案论战中驳倒霍崇光的铁证）；
- 埋：苏晚棠对霍崇光的仇恨（卷六——成为她离队的引信）；
- 收：卷一遗稿末的"陆九针"三字，在本卷得到解释——陆九针与苏问岐是旧交，却沉默多年；
- 收：卷二陆九针"手指微顿"的伏笔在本卷回收。

### 卷五 · 论战（1915–1918）

**时代与史实锚点**：**洛克菲勒基金会于 1915 年收购原协和医学堂着手筹建、1917 年 9 月奠基北京协和医学院（1921 年正式落成）**，科学医学在中国获得国际资本与顶级教育的加持，声势如日中天；与此同时，中医内部的**汇通派**崛起，其中以**张锡纯《医学衷中参西录》**（1918 年首期刊行，此后分六期陆续出齐至 1931 年）为代表——即"衷中参西"，主张以中医为本、借鉴西医。**这是一个"科学主义的高歌猛进"与"国医的自我革新"同时发生的年代。**

**地理**：京师。医学院的红砖楼、报馆的排字房、茶馆里的论战、衙门的会客厅。

**剧情梗概**：

京城是全中国最"新"的地方。队伍来到这里，正赶上一场持续数年的、公开的论战：新式医学院的教授在报纸上撰文，称中医为"旧医""玄医"，主张"废医存药"；国医界的名宿则在报纸上反唇相讥。论战的文章贴满了茶馆的墙，看客边喝茶边叫好。

沈砚之在这里如鱼得水——这是他最熟悉的战场。他的一篇文章被新派报馆看中，几乎要成为"新医学的旗手"。**也正是在这里，他第一次遇见了陈九章。**

陈九章是个面色苍白的青年，自称能推算"天时、地气、人疾"，被众人当作神棍。他在茶馆里推演一场气候与疫病的关系，被新派学者当场斥为"伪科学"。全场哄笑。只有陆九针走过去，问他："你算的，是不是'六气'？"两人一见如故。

同时，论战中也出现了一个更强大、更不容置疑的声音——霍崇光。他已身居要津，公开主张"废医存药"，言辞漂亮、风度翩翩、字字占理。沈砚之第一次与他正面交手，竟被他说动：**这个人的话，几乎就是沈砚之内心那个"科学至上"的自己。** 这让沈砚之感到不安。

苏晚棠在论战中越来越沉默。她看着霍崇光在报上侃侃而谈，指节攥得发白。她开始反问队伍：

> "我们是在治病，还是在赢一场辩论？救人要紧，还是证明我们'有理'要紧？"

裂痕，从这一刻开始。

**本卷大顿悟**：
> "赢一场论战，救不了任何一个病人。"——医学的对手不是另一个学派，是疾病与死亡；把力气花在争论上，病人只会等死。

**队伍变动**：**陈九章加入**；苏晚棠心中的离心力开始积聚。

**关键关卡与形式**：**论战 · 说服机制**——玩家在一场场公开辩论中，用"证据、逻辑、案例、人心"四类手段说服不同的听众（学者、病人、民众、官员）。系统刻意不给"碾压式胜利"：有时最漂亮的一击，恰恰会激怒立场最顽固的对手。**玩家会亲身体验"赢了道理，输了人心"。**

**伏笔**：
- 埋：霍崇光与沈砚之"理念上的亲近"（卷九——沈砚之将面对"我差点成为他"的自省）；
- 埋：陈九章推算出的一场大疫（卷六、卷九回收）；
- 埋：苏晚棠那句"我们是在治病还是赢辩论"（卷六——她离队时的注脚）。

### 卷六 · 气海（1918–1919）

**时代与史实锚点**：**1918 年西班牙大流感席卷全球**（当时中国南北多地亦暴发重症疫情，民间称"骨痛病""五日瘟"，西医对之同样束手）；1919 年 1 月，陈独秀在《〈新青年〉罪案之答辩书》中高调喊出"拥护德莫克拉西（Democracy）和赛因斯（Science）两位先生"，将科学主义推向近代以来的最高峰，紧接着**五四运动**爆发。**这是本作最富戏剧张力的时间点：主角将在"科学封神"的那一年，亲眼看见"科学无法解释的东西"。**

**地理**：一座隐于山中的"秘宗"道场 / 医僧清和的静修地。云海、古松、废弃的经络石刻、入静的暗室。

**剧情梗概**：

大流感肆虐。这一次，连沈砚之最信任的现代医学也无力回天——病毒不断变异，疫苗来不及做，成批成批的人倒下，死在自家床上。

队伍来到山中避疫，投宿于**清和**的静修地。

清和不说教。他/她只是让沈砚之做一件事：**坐三天，什么都不做。**

沈砚之坐不住。他的脑子里全是统计数字、病变位置、还没弄清的死因。第三天夜里，他终于精神崩溃——他毕生信仰的那套体系，在真实的死亡面前，第一次显得如此吃力。

就在那个极致的疲惫与无力的瞬间，他睁开眼睛——

**他看见了。**

不是幻觉。是母亲身体里那条缓缓流动的、他一辈子只会用"气血"两字轻慢带过的河；是清和身上那一层安定的、像月光的静;是窗外的云气、松风、大地的吐纳。他看见**流动**，看见**关系**，看见他一生的训练刻意忽略掉的那个层面。

他对着虚空，说出全篇最重要的一句台词：

> "原来我一直只戴了半副眼镜——不是它没有度数，是我这只眼睛，从来没有睁开过。"

（同时，他取出了那沓随身多年的病理学笔记，投进了炭盆——**卷一、卷二的伏笔在此回收：他烧掉的不是知识，是那套"只有我看得见的才是真的"的傲慢。**）

清和加入队伍，带来"医心"的维度。也正是在这里，**苏晚棠与队伍决裂。**

她查清了霍崇光的一切，也看透了队伍的立场：他们讲程序、讲证据、讲"绳之以法"，但他们不会为她死去的祖父以牙还牙。她在雨夜收拾行装，对沈砚之说：

> "你讲道理，我讲血。我爷爷埋在土里二十年，谁的证据替他说话了？"

她走了。雨里没有回头。

**本卷大顿悟**：
> "'看见'不是把世界看得更清楚，是承认自己一直看漏了什么。"——顿悟不是获得能力，是砸碎自己。

**队伍变动**：**清和加入；苏晚棠离队。** 队伍出现无法弥补的空缺，医道图谱上留下一块空白。

**关键关卡与形式**：**顿悟谜题 · 心象探索**——本卷关卡不再以"战胜病邪"为目标，而是**让玩家进入一个病者/自身的内在世界**，在破碎的记忆与感知碎片中，把散落的线索重新连成"看见"。系统不给提示、允许失败、鼓励反复——**"想通"本身就是玩法。**

**伏笔**：
- 收：卷一"母亲的药茶"、卷一"世界可以推倒重来，人的身子不行"——在主角看见"气"时得到呼应；
- 收：卷二"我只戴了半副眼镜"——在本卷被改写为"原来连半副都算不上"；
- 埋：苏晚棠离去的方向（卷七——她会出现在最不该出现的地方）；
- 埋：清和的"不动心"（卷七——将被迫破戒）。

### 卷七 · 邪疫（1920–1924）

**时代与史实锚点**：**军阀混战**的年代（直皖战争 1920、两次直奉战争 1922/1924）。战地医疗、难民潮、霍乱与天花的流行、疫病随军队与流民四处流窜（1920 年华北霍乱大流行）。国家分裂成无数块，每一个军阀都自称"为了秩序"。**这是一个"制度失灵"的极致年代——没有任何一套成体系的秩序能够覆盖整个国家，医学只能在废墟里靠人一个一个地救。**

**地理**：南疆 / 中原交界的战地。焦土、难民营、野战医院、被反复易手的城镇。

**剧情梗概**：

队伍在乱世中辗转行医。这一卷的基调是**规模化的苦难**：不是一个人的病，是成百上千人的病；不是一场可以打赢的仗，是永远救不完的人。

**霍崇光在这一卷崛起。** 他凭借多年经营，成为新政权的卫生要员，掌握了全国医疗资源的分配权。他推行的"纯医学"制度，在纸面上完美无缺：标准化、可量化、高效率。但它有一个致命缺陷——**它不认"人"，只认"病例"。** 那些不符合标准、算不进数据、说不清道不明的病人，被系统性地忽略。

队伍在战地遇到了一个熟悉的身影——**苏晚棠。** 她独自复仇了很多年，最终发现自己下不了手：因为她是个医者。她在死人堆里救人的时候，终于明白，祖父当年要的从来不是复仇，是"把病人治好"这五个字。

她回来了。没有道歉，也没有解释。她只是在队伍最缺人的一个清晨，默默出现在救护棚里，接过了一个伤员的纱布。

沈砚之递给她一碗水。她说了离队以来第一句话：

> "……我修的针，还是先拿来救人吧。"

**本卷大顿悟**：
> "复仇解决不了死亡。能对抗死亡的，只有让活着的人继续被救下去。"

**队伍变动**：**苏晚棠归队。** 队伍重新完整——但所有人都知道，这块拼图已经带着裂痕。

**关键关卡与形式**：**战地危机管理 · 大规模救援**——玩家面对的是一场无法"全胜"的战役：有限的医生、有限的药、源源不断的伤员。**系统故意让玩家"救不过来"**，逼迫玩家在"效率"（学霍崇光，救人如数数）和"关怀"（学陆九针，把每一个都当人）之间做出一次次艰难的平衡。卷末，玩家会第一次意识到，霍崇光的"错误"是多么"正确"——这就是他可怕的地方。

**伏笔**：
- 收：卷五陈九章推算的大疫（在本卷的小规模疫病中初见端倪）；
- 埋：霍崇光制度下被"忽略"的那一类病人（卷九——成为大疫时最致命的死因）；
- 埋：苏晚棠在战地救过的一个孩子（卷九——这个孩子会再次出现，成为她殉职的直接情境）；
- 收：卷六清和"不动心"——他/她在战地为了救一个濒死的孩子破了戒，第一次"入世"。

### 卷八 · 废止（1929）

**时代与史实锚点**：**1929 年 2 月，国民政府卫生部第一届中央卫生委员会通过余云岫《废止旧医以扫除医事卫生之障碍案》**，主张以行政手段废除中医。消息一出，举国震动。**同年 3 月 17 日，全国 17 个省市、242 个团体、281 名代表云集上海召开全国医药团体代表大会，组建赴京请愿团**，迫使当局取消议案——这一天后来成为中医界的"国医节"。**这是中西医学之争的最高潮，也是本作主题对立面登场的巅峰时刻。**

**地理**：南京（政府所在）与上海（请愿中心）。报馆、会场、街头、请愿队伍。

**剧情梗概**：

废止案的消息像一记闷雷。一时间，全国的中医馆要挂上"限期取缔"的牌子，成千上万的医者要失去行医的资格。

队伍陷入前所未有的困境。这已经不是一个病人的问题，是**一个体系、无数人的"生死"问题**。

霍崇光走到了他一生信念的最高处。他在公开场合的演讲，句句在理——**他的论调，借的正是当年《废止旧医案》的历史原声**：

> "旧医一日不除，新医事业一日不能向上，卫生行政一日不能进展。"（化用自真实《废止旧医案》的论调，为霍崇光信念的历史注脚）

> "我不是恨中医。我是恨'说不清'。说不清的东西，就该被清除——为了剩下的人。"

而在另一边，队伍要做的，不是简单地"反对废止案"——因为队伍自己也说不清中医的全部。**他们能做的，是把苏问岐的遗稿、把二十年来积累的医案、把"中医究竟看见了什么"用能被这个时代听懂的方式讲出来。**

**关键证物，是苏晚棠祖父苏问岐的遗稿。**（回收卷四伏笔。）那里面有一句话：

> "医者，不分中西，只分能不能看见病人。"

可问题在于——**遗稿的提出者，是霍崇光仇人的后代**。霍崇光抓住这一点，把苏晚棠的证词污蔑为"私仇报复"。父辈的血仇与国家的论战，在会场上正面相撞。

苏晚棠必须做出选择：是摔碎那份遗稿以泄私愤，还是把它交出去，让祖父的话去赢那一场辩论——而那个赢，不包括霍崇光的倒下。

她最终交出了遗稿。她说：

> "我爷爷要的，不是他死。是我爷爷那句话，能被人听见。"

废止案被暂时搁置。但霍崇光没有倒——他只是退到了更深的地方，等待下一次机会。

**本卷大顿悟**：
> "最深的胜利，不是让敌人倒下，是让自己的道理，能被敌人之外的人听懂。"

**队伍变动**：无人员进出，但全员关系达到最紧绷也最深刻的状态。柳希白在请愿队伍中，第一次念出了一长串"被废止案波及的医者"的名字——回收卷三她对数字冷漠的伏笔。

**关键关卡与形式**：**论战白热化 · 无战斗收束**——本卷不设传统战斗，最终关是一场**"说服大会"**：玩家的每一次发言，都会得到不同人群（新派学者、老派医者、普通病人、政府官员）的不同反应。**胜负不由"谁有理"决定，而由"谁被听见"决定。** 这是一场"必须同时照顾医生与大众两个受众"的悖论式关卡——正是"双主并重"在设计层面的化身。

**伏笔**：
- 收：卷四苏问岐遗稿；
- 收：卷三顾慎行拒绝签字（他成为体制内为队伍提供关键支持的人）；
- 埋：霍崇光"退到更深的地方"（卷九——他要以另一种方式证明自己）。
- 埋：请愿中一位病重的年轻代表（卷九——成为大疫的第一个死者之一）。

### 卷九 · 汇通（1929，同年稍后）

> **本卷是全篇的情绪核心，写作强度最高。**

**时代与史实锚点**：**本卷"大疫"以 1929–1930 年间华北、江南频发的霍乱与伤寒疫情为原型，为叙事需要进行了一定程度的集中与架空整合**（历史原型与艺术加工的分界，另见第十一节）。废止案余波未平，上层以最"科学"的方式推行防疫；与此同时，一场大疫在此刻暴发，且有霍崇光激进制度之下防控失当推波助澜的成分。**这是全篇所有线索——医学、人心、制度、私仇——总清算的地方。**

**地理**：一个被疫情与制度双重夹击的城镇。封锁线、空荡的药铺、人满为患的临时病院、被征用的会馆。

**剧情梗概**：

大疫来袭。

霍崇光主导的防疫体系，用最"科学"的方式运转：数据、隔离、限额、优先级。它有严格的算法，明确的取舍。**它在纸面上是完美的。**

然后，那些算法算不进去的人，开始死去。

——不符合"重症标准"的轻症病人，因为得不到床位而恶化；——没有社会关系、无法被登记在册的流民，被排除在救济之外；——报病不及时的穷苦人家，整户被"放弃"；——大量心因性、非器质性的病人（正是在卷六清和所医的那一类），因为"查不出病灶"而被当作"装病"无视。

**霍崇光的"纯医学"，在真实的人命面前溃不成军。** 它计算了每一个变量，唯独算不进"人"。这是他一生信念的**证伪时刻**。

与此同时，苏晚棠冲在了最前线。她是队伍里最能识别"证候"的人，也是最能从死亡边缘把人拉回来的人。她在疫区昼夜不停地救治，透支着自己的气与命。

**她救的，正是那个她在卷七战地里救过的孩子。**（回收卷七伏笔。）孩子病危，需要有人长时间贴身守护，把自己暴露在传染的极限里。

所有人都劝她退。她说了一句平静的话：

> "我修了一辈子的气，就是为了能这样走。像爷爷一样。"

**苏晚棠殉职。**

她不是被谁杀死的。她是在救人里，用一种最像她祖父的方式，把自己交了出去。她临终时握着沈砚之的手，笑了：

> "别哭。……我只是，终于把针用对了地方。"

**这一刀，是全篇的"月如之死"。** 它不制造仇恨，它制造**重量**——从此，队伍的每一个人，都背负着苏晚棠。

也是在这一卷，**众所学汇成新医学的雏形**：陆九针的证、柳希白的防、陈九章的推演、清和的心神、苏晚棠用命换来的"最后一课"，被主角拼成了那副完整的眼镜。主角在苏晚棠的病榻前，完成了《杏林汇通录》最核心的一页。

而霍崇光——他没有被主角"打败"。他站在自己一手建立的、绝对正确的体系中央，看着它坍塌。他问出了全篇最后一个、也是最深的疑问：

> "我算过每一个变量。……我算过每一个人。可人，怎么可以不算进去？"

**本卷大顿悟**：
> "医学的终极，不是算得准、治得快，是把每一个'不算数'的人，都算进去。"

**队伍变动**：**苏晚棠殉职。** 队伍失去脊柱。这是不可逆的损失。

**关键关卡与形式**：**总决战 · 综合玩法**——本卷是全部玩法形式的集成：病例推理、资源博弈、论辩、顿悟谜题、危机管理，全部汇聚到一场"大疫总攻"中。有两场并列的终局：①与**霍崇光**的理念之战（玩法上必须用"不可量化、个体化"的医道打破他的"数据节奏"）；②与**疫病**的生死之战（苏晚棠的殉职即在这场战斗中发生）。**玩家会赢，但赢的方式不是"打倒谁"，而是"救回了谁"。**

**伏笔回收总汇**：卷三数字、卷四遗稿、卷五"差点成为霍崇光"、卷六离队、卷七孩子、卷八遗稿证词——全部在本卷汇合。

### 卷十 · 种子（1929 之后）

**时代与史实锚点**：废止案被搁置，国医得以存续；中西医在现实中渐趋并存、互相借鉴（历史事实：此后二者并未谁消灭谁，而是在漫长岁月里彼此渗透）。**这不是一个"胜利"的结局，而是一个"存续"的结局——新医学仍未建成，但种子已被种下。**

**地理**：回到江南故乡。修补过的沈氏医庐、新开的学堂、暮春的杏花。

**剧情梗概**：

大疫过后，队伍各归其所。

柳希白回到防疫一线，她带去的，不只是一套更完善的防疫制度，还有一份厚厚的名册——上面写满了每一个"曾被当作数字的人"。陈九章把《杏林汇通录》里那四门语言，整理成一张谁都能看懂的图，他要让"说不清"变成"说得清"。清和回到山中，但不再闭门，他/她开始收徒，教"医心"。陆九针老了，他在医庐门前种杏树。

沈砚之回到了起点。

他修缮了祖父的旧宅，把"杏林春暖"的匾额重新擦亮。他不再急着证明什么。他在医庐里开了一间小小的学堂，收了几十个徒弟——有想当中医的，有想当西医的，有只是想弄明白"我这身子到底怎么回事"的普通人。

第一堂课，他在黑板上写了两个字：**"外行。"**

他说："你们都会以为，学医是为了变成内行。但我要教你们的，是永远记得自己是外行。因为一个医者最大的病，是以为自己什么都懂了。"

《杏林汇通录》被刊印出来。它并没有立刻改变什么——书里的每一句话，都等着后来的人去验证、去补充、去推翻。**这才是种子。** 它不是答案，它是一道留给下一代的问题。

结尾的场景，是一个暮春的黄昏。沈砚之站在医庐门口，看几个孩子在杏树下追逐。陆九针坐在门槛上晒太阳，怀里抱着一壶酒。风把新开的杏花吹得满院都是。

沈砚之忽然想起，很多年前，母亲曾对他说的那句话——

> "世界可以推倒重来。可人的身子，倒不下重来的。"（回收卷一伏笔。）

他终于明白了。

他笑了。转身进屋，在《杏林汇通录》的扉页上，写下了全书最后一句话：

> **"我不是医生。我只是一个终于学会了怎么做外行的人。"**

杏花落满肩头。江湖还在，路还很长。种子已经种下去了。

**本卷大顿悟**：
> "传承，不是把答案交给下一代，是把问题郑重地交出去。"

**队伍变动**：各归其所（柳希白、陈九章、清和、陆九针各有所归；苏晚棠以记忆与遗志在场）。

**关键关卡与形式**：**无战斗 · 收束与传薪**——本卷不设战斗，是纯叙事收束。玩法上表现为一次**"图谱封笔"**：玩家回看自己一路点亮的《杏林汇通录》，把最珍视的几条"通"郑重地标注为"传给后人"。**玩家此刻的每一次选择，都对应一个"种子"。**

**伏笔回收**：卷一母亲的药茶、卷一"身子倒不下重来"、卷一病理学笔记（已于卷六烧毁，此处作为记忆回收）、卷二"半副眼镜"——全部在本卷落定。

## 十、叙事调性指南

### 10.1 总体文风

本作文风定位：**"民国传奇的苍凉底色 + 仙侠的浪漫笔触 + 医学的冷静精确"**。三者缺一不可——
- **苍凉**：民国的天总是灰的，时代永远在压迫具体的人；
- **浪漫**：气是真能看见的，少年是真的会为了一句承诺走遍山河；
- **精确**：医学的部分必须准确到能被专业人士认可的程度（至少在"思路"层面）。

参考气质：《仙剑奇侠传》的情感与聚散 + 《大明劫》的历史厚重 + 《觉醒年代》的论辩张力。

### 10.2 对白腔调

- **主角（沈砚之）**：初期用词尖锐、逻辑性强、带着留洋归来的隔膜感（"你们中国人……"是他早期的口癖，后期渐渐消失）；顿悟后变得谦抑，话变少，但每一句更重。
- **陆九针**：民间的、慢的、带方言味的口语；爱在句尾加"罢了""咯""罢了罢了"；不直接讲道理，用比喻和反问。
- **苏晚棠**：前期的口头禅带刺（"你们西医……"），后期沉静；她的语言里有中医式的凝练与意象感。
- **柳希白**：简洁、数据化、少形容词；偶尔冒出的冷幽默。
- **陈九章**：喜欢打比方、引数字、说"如果……那么……"。
- **清和**：极简，语速慢，常说"你且坐下""不必急"。
- **霍崇光**：最漂亮的修辞、最严密的逻辑——**他说的话几乎全是对的。这正是他可怕的地方。**

### 10.3 民国用词与语感注意事项

- 人物称呼、器物、制度要用**当时的词**（如"先生""大夫""郎中""西医院""防疫处""学堂""报馆"），避免现代词汇出戏。
- 但**不要滥用历史名词**堆砌——准确比华丽重要；考据支撑不足处宁可模糊带过。
- 保留适当的**半文半白**的叙述语感，但以现代读者可流畅阅读为准，不做文言模拟。
- 避免"穿越式"现代医学名词直接出现在 1905 年的对白中（角色的"认知"要符合时代，只有"叙事的隐喻"可以超前）。

**民国医学词汇"避坑指南"**（文案写作时逐条比对，防"穿越词"）：

**🚫 绝对禁用词（时代错误）**
- **病毒**：当时多称"微菌""病菌"或"疠气"；1918 大流感时多称"流行性感冒""滤过性病原体"。"病毒"一词在民国中后期才普及。
- **抗生素 / 青霉素 / 盘尼西林**：青霉素 1928 年方被发现、1940 年代才用于临床。**民国初年绝无抗生素**；西医抗感染只能靠血清疗法、砷凡纳明（治梅毒）或磺胺类（1930 年代才问世）。
- **输液**：当时多称"打盐水""注射"。
- **CT / B 超**：不存在。
- **X 光**：当时报界与民间多称**"伦琴射线""爱克斯光"**。

**✅ 推荐使用的时代词汇**
- **称呼**：大夫（北方/民间）、郎中（南方/旧派）、先生（尊称）、西医、旧医、国医（1929 年抗争后中医界自称）。
- **机构**：防疫处、检疫所、卫生局、医学堂、报馆、巡警局。
- **中医术语**：气化、六经、卫气营血、汤头、坐堂、游方、悬壶。
- **西医术语（民国译法）**：解剖、微菌、血清、听诊器、体温表（或"寒暑表"）。

### 10.4 仙侠语感与医学用语如何融合

核心手法：**用医学讲仙侠，用仙侠讲医学**。
- 战斗不叫"打怪"，叫"辨证施治"——"病邪"是敌人，"正气"是血条，"方剂"是技能。
- "气"既是仙侠的灵力，也是中医的生理概念——**一个词，两重意义，正是本作的独门味道**。
- 顿悟、师徒、秘籍、江湖恩怨——全部医学化：秘籍是医案，师徒是医承，恩怨是门户之争。
- 但**医学内核必须始终真实**：玩家可以欣赏"仙侠"，但最终学到的是"看人的道理"。

### 10.5 如何兼顾"医生"与"大众"双受众

采用 **"三层解读"** 的写法（对应项目的关卡框架）：
- **人间层**（大众）：用故事、隐喻、人情理解——"为什么这个人的病治不好，因为他的心不肯好"；
- **临床层**（医学生）：给出真实的症状、鉴别、思路——让专业读者"看得懂门道"；
- **论道层**（资深者）：点出学派的根本分歧与哲学——让内行"会心一笑"。

三层在文本中自然穿插，**不设门槛**：看不懂临床层的读者，仍能被情感层打动；看得懂的人，则多一层乐趣。

### 10.6 情绪的节奏

- **每卷一个高潮**，但高潮不能全是"赢"。仙剑式的节奏是：**赢得越多，失去越重。**
- **聚散是情绪的呼吸**：加入要暖，离队要痛，归来要迟疑，牺牲要静。
- **苏晚棠之死，绝不平铺直叙。** 用最平静的笔触写最重的死——她的死不是惨叫，是"我终于把针用对了地方"。

## 十一、医学内容设计原则

### 11.1 史实考据流程

1. 每一位涉及真实史实的写作者（编剧、系统设计、文案），**必须对照权威史料核查时间、人物、事件**；
2. 凡无法确证者，一律在文档中标注 **"（待核）"**，并记入第十三节清单；
3. 待核条目在正式进入制作前**必须清零**（或改为"架空设定"并声明）。**本文件十三条已于此轮核查中清零，见第十三节。**
4. 推荐考据来源：中国近代医学史、疫情史、教育史、中西医论争史的专业著作与论文（而非百科条目）。

### 11.2 虚构与真实的边界

- **真实事件、真实机构**：可作背景，须准确；
- **真实历史人物**：**只作角色原型，绝不作为角色出场**（伍连德、张锡纯、余云岫、洛克菲勒/协和等均不出现在角色表中）——既避免消费真人，也保留创作自由；
- **医学知识**：可使用、改编，但**不得歪曲核心原理**；
- **"气"**：是本作的**文学设定**，不等于对真实中医的医学断言——须在作品中明确其"世界观设定"的属性。

### 11.3 避免误导真实医学（免责原则）

因本作涉及真实医学主题，须恪守：
- 游戏中的疗效、方剂、诊断，**不得被宣称为对现实疾病的可靠指南**；
- 涉及真实疾病处，措辞避免绝对化；
- 在作品（含载入界面、图鉴、官方渠道）显著位置声明：**"本作为文艺创作，所涉医学内容仅供叙事与文化表达之用，不能替代专业医疗建议。"**
- **不贬低任何真实医学体系**：本作的立场是"多镜看人"，而非"判高下"；对中医与西医都应公正呈现。

### 11.4 "气"的呈现尺度（与世界观规则联动）

- 遵循第三节"气"的四条定律，尤其是**边界定律（不可越界）**——越界必受害；
- 视觉呈现上，气宜"若隐若现"，重氛围而非特效炫技；
- 叙事上，气永远保留"另可解释为心理/自然现象"的余地（志怪铁律：**气是真的，鬼神是气的误读**）。

## 十二、与游戏系统的接口

> 本节定义故事圣经如何驱动玩法设计。详细系统文档另见 `design/gdd/` 下各系统 GDD。

### 12.1 顿悟 → "医道图谱"（元成长）

- 叙事中主角的每一次"大顿悟"，在玩法上表现为《杏林汇通录》中**一条新的"通"被点亮**；
- 每一片"点拨碎片"携带学科标签（中医 / 西医 / 术数 / 心身）；
- **跨学科连线**（如"西医的证据"+"中医的证候"）即"合方"能力——**玩家亲手把四门语言缝成一张图**，这就是玩法化的"理解新医学"。

### 12.2 战斗 = 辨证施治（回合制策略）

- **敌人不是怪物，是"病机"**；战斗目标不是"打倒"，是**"治愈"**；
- **双条机制**：降低"病邪"的同时，保护病人的"正气"——猛药可速胜，但会伤正；这是医学伦理的玩法化；
- **辨证即解谜**：正确的"治法"取决于玩家是否正确辨识"证候"，辨识错误则事倍功半；
- **合方 / 合击**：不同学科技能组合触发跨科招式，呼应"四镜看人"；
- **霍崇光的战斗**：以"可量化、可重复"为机制核心，玩家必须用"个体化、不可量化"的医道破之——**主题对立面的机制化身**。

### 12.3 队伍对话 = "外行问内行"

- 队伍成员互为"外行/内行"：沈砚之在中医面前是外行，陆九针在公卫面前是外行；
- **玩家通过"提问"（对话）让队员互相点拨**，这既是叙事，也是解锁图谱碎片的途径；
- 这一机制直接承载主题："每个人在自己的专科之外都是外行"——**医生与玩家共享同一种体验**。

### 12.4 关卡形式与卷的映射

| 卷 | 关卡形式 | 玩法核心 |
|---|---|---|
| 序 / 一 | 叙事引入 · 病例推理入门 | 建立"看人不看病"的立场 |
| 二 | 完整病例推理 | 问诊即解谜，答案在生活里 |
| 三 | 疫情资源博弈 + 推理 | 两难取舍，无"全对" |
| 四 | 门户论辩 · 回合策略战 | 确立"论战即战斗" |
| 五 | 论战 · 说服机制 | "赢了道理，输了人心" |
| 六 | 顿悟谜题 · 心象探索 | 允许失败的"想通"玩法 |
| 七 | 战地危机管理 · 大规模救援 | 效率 vs 关怀 |
| 八 | 论战白热化 · 无战斗收束 | "谁被听见"决定胜负 |
| 九 | 总决战 · 综合玩法 | 全部形式集成，双终局 |
| 十 | 无战斗 · 收束传薪 | 图谱封笔，选择"种子" |

### 12.5 三层解读与关卡难度分层

- 每个病例关都按 **人间层 / 临床层 / 论道层** 提供不同深度的解法与文本；
- **人间层**不设失败惩罚（大众玩家可无压力体验）；
- **临床层**提供真实推理链（医学生成长）；
- **论道层**触发学派分歧的深度讨论（资深者乐趣）。
