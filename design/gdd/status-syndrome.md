## 1. 概述 Overview

证候 / 状态系统是**全作医学机制的公共数据结构层（Foundation）**。它不面向玩家单独存在，而是为上游系统提供三样东西：其一，**证候向量 Syndrome Vector**——每个病机隐藏的一组「八纲四轴（表里 / 寒热 / 虚实 / 阴阳）× 极 × 强度」坐标，是"辨"的对象；其二，**证候状态 Status（词条）**——挂在病机或病人身上、随时间与传变增删的持续效果，是"证"被读出来后的可见后果；其三，**冻结标签词表 Frozen Tag Vocabulary**——一组受控的**病种标签**与**证候标签**，既是战斗里证候揭示与匹配的索引，也是成长系统里「通」（跨树连线）成立的必要条件。**标签一旦冻结，只增不改**——因为战斗与成长两侧都建立在它之上，任何改名都会同时波及两套系统。本系统的设计原则与全篇一致：**确定性优先**——证候传变、状态叠加、四诊误差全部可预测、可归因，不含"运气惩罚"。

## 2. 玩家幻想 Player Fantasy

**"我不是在猜，我是在读。"**

玩家面对一个病机时，眼前是一团**被黑布盖住的坐标**——他知道有四个轴、六个方向，却一个都看不见。他派陆九针去切脉、派柳希白去检验、让自己的角色去望神色。每读出一轴，黑布就掀开一格，心里那张"证候图"就清晰一分。当四轴尽出、方向对上的那一刻，他感到的不是"数值涨了"，而是**"我看明白这个人了"**。

而在看不见的轴上手贱出牌、让病人白白掉一截正气时，他感到的是**"我还没看清，就动手了"**——这份懊悔正是医者成长的起点。证候系统不给玩家任何运气，只给他**信息**：看不清是信息不足，看错了是无视信息。玩家的进步，就是**从"猜"变成"读"**。

**情绪目标**：洞察的快感（一轴轴揭开）+ 谨慎的重量（未证即动手的代价）+ 系统的可信（结果永远可解释）。

## 3. 详细规则 Detailed Rules

### 3.1 系统定位与数据边界

本系统**不产生**玩家动作、不持牌、不打伤害；它只**定义数据**与**结算规则**，供上游调用：

| 上游系统 | 从本系统取用 | 本系统不负责 |
|---|---|---|
| 战斗系统 `combat-system.md` | 证候向量、四诊揭示逻辑、匹配系数口径、状态效果 | 出牌、伤害结算、胜负判定 |
| 成长系统 `progression-system.md` | 病种/证候标签（连线成立的前提） | IP、连线成本、图谱结构 |
| 队伍/角色系统 | 队员的"识证能力"（气感、检验、心身）挂载点 | 队员属性、牌库 |
| 关卡系统 | 病机的证候预设、传变表、状态组合 | 遭遇编排、胜利条件 |

> **冻结原则（本文件最重要的交付）**：§3.7 的标签词表经用户确认后**冻结**。此后**只允许追加新标签，不允许改名或改义**；弃用标签标记为 `deprecated`，保留其 ID 以避免存档断裂。

### 3.2 证候向量数据模型 Syndrome Vector

每个病机持有一组**隐藏**的证候向量，取自**八纲四轴**（与 `combat-system.md` §3.4 完全一致，不得更改）：

| 轴 | 两极 | 强度 | 含义 |
|---|---|---|---|
| 表里 | 表 / 里 | {1, 2, 3} | 病位浅深 |
| 寒热 | 寒 / 热 | {1, 2, 3} | 病性 |
| 虚实 | 虚 / 实 | {1, 2, 3} | 正邪消长 |
| 阴阳 | 阴 / 阳 | {1, 2, 3} | **总纲**（见下） |

数据结构（伪代码）：

```
Syndrome:
  axes: {
    biaoli:  { polarity: 表|里, strength: 1..3 },                    // 单层
    hanre:   { polarity: 寒|热, strength: 1..3 },                    // 单层
    xushi:   { polarity: 虚|实, strength: 1..3 },                    // 单层
    yinyang: { surface: {polarity, strength},                        // 望可见，对 M 无效
               deep:    {polarity, strength},                        // 切可得，决定 M 与悖证
               innate:  -1..1 }                                      // 器质性 = 0
  }
  revealed: Set<Axis>        // 已揭示的轴；初始为空。阴阳的"已揭示"仅指深层极已由切诊揭示
  tags: Set<TagId>           // 见 3.7，至少含 1 个病种标签
```
> 注：**阴阳的"表层极"不进入 `revealed` 的"已知"判定**——它只是一条线索，不构成可据以出牌的"证"（见 §3.2.2）。

#### 3.2.1 阴阳 = 总纲（表层极 + 深层极）

阴阳不与其他三轴平列。它是全 4 轴里**唯一有"两层"的轴**：一层是前三轴派生出来的**表层**（望而得的神色），一层是加上病机固有倾向后的**深层**（切而得的脉里真情）。两层在**普通病机上完全一致**；只在**心身 / 志怪类病机**上才会分叉——而正是这个分叉，构成单镜型玩法的侦探线索。

```
S_surface = w_derive × D_derived              // 表层：只由前三轴派生
S_deep    = w_derive × D_derived + w_innate × D_innate   // 深层：含病机固有阴阳
            默认 w_derive = 0.6, w_innate = 0.4

D_derived_raw = Σ ( sign(axis) × strength(axis) / 3 )    对 表里/寒热/虚实 求和   ∈ [-3, +3]
                其中 sign: 表=+1, 热=+1, 实=+1；里=-1, 寒=-1, 虚=-1
D_derived     = clamp(D_derived_raw, -1, +1)             先归一，后合成（口径同 §4.2）
```

| 变量 | 类型 | 范围 | 说明 |
|---|---|---|---|
| D_derived | float | [-1, +1]（由 [-3,+3] 截断） | 前三轴加权极性；正偏阳、负偏阴 |
| D_innate | float | [-1, +1] | 病机**固有的**阴阳偏移（心身 / 志怪类病机专用；器质性为 0） |
| S_surface | float | [-1, +1] | 表层阴阳值（望诊可见） |
| S_deep | float | [-1, +1] | 深层阴阳值（切诊方可得；**决定 M 与悖证**） |
| 表层极 / 深层极 | — | 阳 (S>0) / 阴 (S<0) / **平 (S=0 → 默认阴)** | S=0 兜底见 §5 |
| 强度 | int | `clamp(round(|S| × 3), 1, 3)` | 表层、深层各算一次 |

- **普通病机（器质性）**：`D_innate = 0` → `S_surface = S_deep`，阴阳**纯派生**，与前三轴必然自洽（表/热/实 → 阳，里/寒/虚 → 阴）。**两读一致，无破绽。**
- **心身 / 志怪类病机**：`D_innate ≠ 0` → 两层可能分叉。**分叉条件可精确给出**：

  ```
  极性矛盾（表层极 ≠ 深层极）  ⟺  |D_derived| < 0.667 × |D_innate|
  ```
  （即前三轴错杂、未同向饱和、而固有阴阳足够强时，深层的极性才会**翻转**）。
- **两种破绽信号并存**（这是**优点**，不是缺陷）：
  1. **极性矛盾**（明显信号）：表层"阴"、深层"阳"，多见于**三轴错杂型**心因病机；
  2. **强度异常**（隐蔽信号）：两层同极、但深层强度**明显弱于**表层（如示例 B 的阴(1)），多见于**三轴同向饱和**的病机——此时极性翻不过来，只有强度露馅，留给高手察觉。
- **设计意图**：让"阴阳"既守中医"总纲"之义（多数情况下是前三轴的总结），又为"无形之病"留出**独立于形质**的表达空间。考据上正对中医诊断学的真实概念——**"脉症不符，舍症从脉"**：望得的是表层（神色），切得的才是深层（脉里藏的真情）。

#### 3.2.2 两读如何影响四诊与结算

- **望 Observe** 揭示的阴阳是**表层极**（`S_surface`）；在**切诊之前，阴阳轴对牌结算一律按"未证"处理（M = 0.7）**。这不是补丁，而是对本作核心承诺的守护：**玩家永远能事先知道一张牌会不会伤到病人**（`combat-system.md` §3.5 / §4.3）——若表层极就能触发 M 或悖证，玩家"望了一眼"却判错，就成了随机惩罚。
- **切 Palpate** 揭示的是**深层极**（`S_deep`）；此后阴阳轴才进入"已知"态，才参与 M 判定与悖证判定。**切诊因此成为不可替代的诊断**——这是它从"被动技能"升格为"战术决策"的机制理由。
- **悖证只认深层极**：表层极**永不**触发悖证（表层只是直觉，不是证）。
- **与单镜型的自然耦合**：切诊需要「气感」属性。**纯还原阵容没有气感、永远切不到深层阴阳** → 心身病机对它**永久不可见**。单镜型的"缺眼"效果**无需任何特判**，直接从上述规则涌现（见 §3.8 / `combat-system.md` §4.10.4）。
- 前三轴（表里 / 寒热 / 虚实）**只有一层**，望闻问切揭示的即是真值，照常参与 M 与悖证，**不受本节影响**。

### 3.3 病机数据模型 Pathomechanism

病机（Pathomechanism）是战斗中的"敌人"，它**不是**怪物，是一团被命名的病：

```
Pathomechanism:
  evilBar:   { current, max }          // 病邪条，默认 max = 100（基准值见 combat §7）
                                       // 不变式：current ≤ max × 1.5；越界 → 自动进入"病势燎原"stage（见 4.4）
  syndrome:  Syndrome                  // 3.2
  ampPerTurn: int                      // 每回合病邪自增（"病在进展"）
  behavior:  加剧病邪 | 损耗正气 | 混合   // 行动倾向
  stages:    [Syndrome, Syndrome, ...] // 传变序列（确定性，见 4.4）；末段可为"自限"段
  stageIndex: int
  tags:      Set<TagId>                // 至少 1 个病种标签；可含证候标签
  statuses:  Set<StatusId>             // 3.6，挂载于病机自身的状态
```

**行为倾向 Behavior**（决定病机行动时做什么）：

| 倾向 | 行动 | 典型病机 | 对玩家的压力 |
|---|---|---|---|
| **加剧病邪 Aggravate** | `evilBar.current += ampPerTurn`（病情恶化，拖延越久越难治） | 急性实热、暴发疫疠 | 逼玩家**快** |
| **损耗正气 Deplete** | 病人 `vitalQi -= drainPerTurn`（病在啃噬病人，与病邪条无关） | 慢性虚劳、阴虚火旺 | 逼玩家**护** |
| **混合 Mixed** | 交替执行上两者（偶数回合加剧、奇数回合损耗） | 复合病、终盘病机 | 双线压力 |

> `ampPerTurn` 与 `drainPerTurn` 均为**正整数**，随病机难度与卷次配置；`drainPerTurn` 的代价与 `combat-system.md` §4.8 回合 3 的"损耗正气 −10"同源。

**`ampPerTurn` 建议区间（与关卡系统联调前的工作值）**：

| 场景 | ampPerTurn | 有效压力 = `amp × (病机Speed / 医者均速)` | 意图 |
|---|---|---|---|
| 卷一（教学） | **2–3** | ≈ 2–4 | 玩家摆烂 30+ 轮才被拖死——足够宽容，允许试错 |
| 卷二 | **4–6** | ≈ 4–8 | 开始逼玩家"别空过回合" |
| 卷三（急性） | **6–10** | ≈ 7–15 | 病邪条 ×0.5 以下才算过关节奏 |
| 慢性虚劳 | 走 `drainPerTurn`，`amp ≤ 2` | — | 慢性病逼"护"不逼"快" |

> **配平原则——"辨证必须划算"**：花 1 行动诊断（M 0.7→1.5）对后续每张牌约值 +20~30 病邪。若有效压力 **超过 ~15/轮**，诊断的收益将被病势增幅吃掉——玩家会算明白"诊断是亏的"，从而放弃辨证、直接暴力输出，**撞碎"先辨证、再下药"的教学目标**。故**任一卷、任一病机的有效压力不得超过 15**；随难度提升应主要靠**缩短回合数 / 提高病邪条厚度 / 加 `drainPerTurn`**，而非无上限地堆 amp。

**状态机**（与 `combat-system.md` §3.9 一致）：潜伏 Latent → 发难 Active → （传变 Shifting → 新 stage → 发难）→ 势穷 Spent → 已瘥 Resolved。

### 3.4 四诊 → 揭示轴 对应表 Four Diagnostics

**照抄 `combat-system.md` §3.5，不得更改**：

| 诊法 | 耗费 | 揭示的轴 | 特性 |
|---|---|---|---|
| **望** Observe | 1 行动 | 表里、**阴阳表层极** | 稳定；对"表证 / 神色"最灵 |
| **闻** Listen/Smell | 1 行动 | 寒热 | 稳定；气息、声音类病机必用 |
| **问** Ask | 1 行动 + 1 资源 | 寒热、虚实 | **90% 准确**——病人可能答错（见 4.7 / §5） |
| **切** Palpate | 1 行动 → **0 行动（被动）** | 虚实、**阴阳深层极** | 需「气感」属性；无气感者**不可执行**（不返回深层阴阳，**非假值**） |

- **切诊被动**：队伍中有**苏晚棠或陆九针**在场 → 切诊耗 0 行动（辨证是中医角色的核心职能）。望 / 闻 / 问 仍耗 1 行动。
- **阴阳两层**：望得表层极（**线索，不进"已知"态**，出牌按 M=0.7、不触发悖证）；切得深层极（**进"已知"态**，参与 M 与悖证）。详见 §3.2.1 / §3.2.2。**其余三轴单层**，揭示即真值。
- 每揭示一个轴，该轴进入「已知 Known」态；牌结算按**已知真实值**判定（`combat-system.md` §3.5）。
- **未揭示轴**：出牌时该方向视为「未证 Unverified」→ `M = 0.7`，**不伤正气**。
- **悖证**：某轴**已揭示**而牌方向与之**相悖** → `M = 0.0` 且伤正（`combat-system.md` §4.3 / §4.3b）。**确定性，不含随机。**（阴阳的"已揭示"仅指深层极已由切诊揭示。）

### 3.5 八法 × 证候轴 对应表 Eight Methods × Axes

治法牌对应中医**八法**（`combat-system.md` §3.6）。每张牌标注**主靶轴**（决定匹配系数 M 的唯一轴）与**次靶轴**（可贡献悖证，不贡献 M 加成）。M 口径严格沿用 `combat-system.md` §4.3：**对证 1.5 / 相关 1.0 / 无关 0.5 / 未证 0.7 / 悖证 0.0（伤正）**。

| 法 | 主靶轴:极 | M=1.5 条件（对证） | 相关轴（M=1.0） | 悖证条件（M=0.0 且伤正） |
|---|---|---|---|---|
| **汗** | 表里:表 | 病位确为"表" | 阴阳:阳（表属阳） | 已揭示"里"却用汗法（表里相悖） |
| **吐** | 表里:里 + 上焦 | 里实、病位偏上 | 虚实:实 | 已揭示"虚"却用吐法（虚人误吐，伤正重） |
| **下** | 表里:里 | 里实、病位偏下 | 虚实:实 | 已揭示"虚"却用下法 |
| **和** | 阴阳:失和 | 阴阳偏、寒热错杂 | 表里:半表半里 | —（和为调和，一般不致悖证） |
| **温** | 寒热:寒 | 病性确为"寒" | 阴阳:阴；虚实:虚（温可扶阳） | 已揭示"热"却用温法（以热助热） |
| **清** | 寒热:热 | 病性确为"热" | 阴阳:阳；虚实:实 | 已揭示"寒"却用清法（`combat §4.8` 教学例） |
| **消** | 虚实:实 | 实邪积聚（缓攻） | 表里:里；寒热:寒（消痰需温） | 已揭示"虚"却用消法 |
| **补** | 虚实:虚 | 正气确为"虚" | 阴阳:阴 | 已揭示"实"却用补法（闭门留寇） |

**★ R1（牌轴声明 · 与 `combat-system.md` §3.6 R1 同一规则）**：每张牌**必须**声明 `mainAxis`（**唯一**决定 `M` 的轴）与 `subAxes`（**只**贡献悖证 / 伤正，**不加成 `M`**）。本表「主靶轴:极」列即 `mainAxis`，「相关轴」列与「悖证条件」列共同给出 `subAxes` 的候选。

**多轴牌的 M 聚合规则**：`M = M(mainAxis)`；**`subAxes` 只在"已揭示且相悖"时触发悖证伤害（`ΔV_wrong`），不加成 `M`**。此规则保证 `combat-system.md` §4.2 的**单一 M** 口径成立，兼容既有伤害公式。

> **示例**：陆九针出「温」法牌。主靶轴 = 寒热。若已揭示寒热=寒 → M=1.5（对证）。若已揭示寒热=热 → 悖证 M=0.0（伤正）。若寒热未揭示 → M=0.7（未证）。三种输入的输出**完全确定**，玩家可预判。

### 3.6 证候状态 Status（词条）

**证候状态**是"证被读出后的可见后果"，挂载于**病机**（放大病势）或**病人**（损耗 / 束缚）。每一条含：所属轴、效果、叠加规则、时长。

状态分两族：**病邪侧**（挂病机，多为病势的**强化**）与**正气侧**（挂病人，多为病人的**削弱**）。

#### 3.6.1 病邪侧状态（挂于病机）

| ID | 名称 | 所属轴 | 效果 | 叠加规则 | 时长 |
|---|---|---|---|---|---|
| `st_cold_coag` | **寒凝** | 寒热:寒 | 病人 Speed −15%（CTB 变慢） | 可叠至 2 层，每层 −10% | 3 回合（可刷新） |

### 3.8 单镜型病机的数据形态 Single-lens Pathomechanisms

对应 `combat-system.md` §4.10.4。单镜型病机**本身**只有一种认识论够得着；它们的证候数据有特殊形态：

| 类型 | 数据形态 | 四诊表现 | 谁能处理 |
|---|---|---|---|
| **无症状带菌者** | `axes` 全轴 `strength = 1` 且标记 `subclinical = true`；`tags ⊇ {d_carrier}` | 望/闻/问/切一律返回「**无显著证候**」（不授予任何轴"已知"态） | 仅**检验**（还原）可识别；识别后病邪条才"显形"、才可被还原牌削减 |
| **心因性疾病** | 前三轴 `strength = 1`，但 `yinyang.innate` 显著（如 `D_innate = −0.9`）；`tags ⊇ {d_emotion}` | 四诊返回"证候**似有似无、随情志波动**"（提示该病"不在形质") | 仅**心身**（整体）可触；还原牌对病邪条效力 ≈ 0 |

- **建模要点**：单镜型不靠"免疫标志位"实现，而靠**两条数据路径**——带菌者是"证候真的不存在"（`subclinical`），心因是"证候存在但只在独立阴阳轴上"。
- **反向反馈**：错误阵容遭遇时，系统给出**行为级反馈**（反复"无显著证候" / 病邪对某类牌显示"打在了空气里"），并允许**立即转诊**换阵容重试——**不做强制失败**（`combat-system.md` §4.10.6）。

### 3.9 标签按剧情引入（技能即剧情）

> 原则（用户已定）：由**合适的人、在合适的时候**获得能力与认识。标签同理——**不得一次抛全**。

- §3.7 表中每条标签标注「首次出现卷次」；在该卷之前，对应病机的 `tags` 不得使用该标签（配置校验）。
- 玩家观感上：**新病种 = 新谜题**，新证候标签 = 新的连线可能（喂入 `progression-system.md` 3.7 的解锁表）。
- 与**双用软墙梯度**（`progression-system.md` 3.7：卷四软→卷五强→卷六硬）协同：卷四首次引入 `d_heart`/`d_gynecology` 等**跨两树**的病种标签，正是"第一次必须连线的教学战"的数据基础。

## 4. 公式 Formulas

### 4.1 证候向量编码 Syndrome Encoding

每轴编码为：`axis = { sign: ±1, strength: 1..3 }`，其中 sign 由极映射（表/热/实/阳 = +1；里/寒/虚/阴 = −1）。

### 4.2 阴阳两读式 Yin-Yang Two-Read Synthesis

```
D_derived_raw = sign(表里)·strength(表里)/3 + sign(寒热)·strength(寒热)/3 + sign(虚实)·strength(虚实)/3   ∈ [−3, 3]
D_derived     = clamp(D_derived_raw, −1, 1)      ← 先归一，后合成

S_surface     = 0.6 × D_derived                          // 表层（望可见，对 M 无效）
S_deep        = clamp(0.6 × D_derived + 0.4 × D_innate, −1, 1)   // 深层（切可得，决定 M 与悖证）

表层极 = 阳 if S_surface>0 ; 阴 if S_surface<0 ; 阴 if S_surface=0（兜底）
深层极 = 阳 if S_deep>0    ; 阴 if S_deep<0    ; 阴 if S_deep=0（兜底）
强度   = clamp( round( |S| × 3 ), 1, 3 )                // 表层、深层各算一次
极性矛盾 ⟺ 表层极 ≠ 深层极 ⟺ |D_derived| < 0.667 × |D_innate|
```

> **口径注 1（先归一）**：`D_derived` **先截断到 [−1,1] 再与 `D_innate` 合成**——这样"固有阴阳"才能在器质性三轴极强时**不被淹没**。若只在末尾对 `S` 截断，`D_innate` 的权重被压制，单镜型心因病机无法成立。
> **口径注 2（两读的意义）**：`S_surface` / `S_deep` 分离后，**望**给表层（一条线索），**切**给深层（真正的证）。**前 3 轴单层、不分离**——望闻问切揭示的即是真值。详见 §3.2.1 / §3.2.2。

**示例 A（器质性、纯派生；两读一致）**：表里=里(3)，寒热=寒(2)，虚实=虚(1)，`D_innate=0`。
`D_derived_raw = −2.0 → clamp −1.0`；`S_surface = 0.6×(−1.0) = −0.6`；`S_deep = −0.6 + 0 = −0.6`。
两读均为 **阴(2)**（`clamp(round(1.8),1,3)=2`）→ 望与切一致，无破绽。

**示例 B（心身病机、三轴同向饱和 → 强度型破绽）**：前三轴里、寒、虚（`D_derived = −1.0`），`D_innate = +0.9`。
`S_surface = −0.6` → 表层 **阴(2)**；`S_deep = −0.6 + 0.36 = −0.24` → 深层 **阴(1)**。
两读同极、**深层强度明显弱于表层** → 极性没翻转，但强度露出破绽（隐蔽信号，留给高手）。

**示例 C（心身病机、三轴错杂 → 极性型破绽）**：前三轴 表(1)/热(2)/虚(2)（`D_derived_raw = 0.333+0.667−0.667 = 0.333`），`D_innate = −0.9`。
`S_surface = 0.6×0.333 = +0.2` → 表层 **阳(1)**；`S_deep = 0.2 − 0.36 = −0.16` → 深层 **阴(1)**。
检验矛盾条件：`|0.333| < 0.667×0.9 = 0.6` ✓ → **表层显示"阳"、切诊实为"阴"**——玩家若只看望诊，会打出助阳的牌（深层悖证），这正是心身病的侦探钩子。

**预期输出范围**：`S ∈ [−1, 1]`；表层/深层强度各 ∈ {1,2,3}。

### 4.3 匹配系数 MatchCoefficient（引用 `combat-system.md` §4.3）

> **rev g 同步（2026-09-12 · 关闭 D7）**：本条旧版为**单列 5 行**表述，把「相关 1.0」写成**依赖揭示**——与 `combat-system.md` §4.3 的**二维表**冲突。**二维表是 M 判定的唯一真源**；本条改为等价的**二维引用**，不再自行演绎。

| 牌轴与致病轴的**客观关系** | 该轴**未揭示** | 该轴**已揭示** |
|---|---|---|
| **同轴 · 方向相符** | **0.7**（未证，不伤正） | **1.5**（对证，不伤正） |
| **同轴 · 方向相反** | **0.7**（未证，不伤正） | **0.0**（悖证，**伤正**，见 combat §4.3b） |
| **相关轴**（轴不同，但逻辑相邻、成立） | **1.0** | **1.0** |
| **无关轴** | **0.5** | **0.5** |

- **`M` 只取主靶轴**：`M = M(主靶轴)`；**次靶轴不加成 `M`**（§3.5 聚合规则）。
- **只有「同轴」这一列受揭示影响**：未揭示一律 **0.7**；已揭示才分 1.5 / 0.0。
- **相关轴 1.0 / 无关轴 0.5 不依赖揭示**——它们是**客观轴关系**，不是"已知信息"的判定对象。**哪些轴算相关轴**见 §3.5「相关轴（M=1.0）」列。
- **★ R2（轴不同 = 相关轴的必要条件）**：若一张牌的**全部轴**（`mainAxis` ∪ `subAxes`）都落在病机致病轴集合内，则该牌与致病轴**同轴**，**不得**判为相关轴。
- **★ 伤正（`ΔV_wrong`）与 `M` 是**独立**判定**（combat §4.3c）：
  ```
  触发 ΔV_wrong  ⟺  (同轴 · 已揭示 · 方向相反)      // 主靶轴相悖 → M = 0.0 且伤正
                  ∨  (任一次靶轴 已揭示 且 相悖)      // 次靶轴相悖 → M 不受影响，但伤正
  ```

**示例**：`combat-system.md` §4.2 的「清」法牌对"寒热=热"（已揭示）→ 同轴方向相符 → `M = 1.5` → `ΔE = 40×1.5 = 60`，与本文件口径一致。同上例但"寒热**未**揭示"→ `M = 0.7`。
**「补液·支持」示例（承 D6 / D9 裁决）**：主靶轴 `虚实:虚`，致病轴含 `虚实:虚` → **同轴**（**非**相关轴，R2）；未揭示 → `M = 0.7`；已揭示 `revealed(虚实)=虚` → `M = 1.5`。

### 4.4 传变触发与重组 Shift Trigger

**确定性触发**（不含随机）：

```
传变触发 = ( roundsElapsed ≥ stageThreshold[stageIndex] )
         OR ( evilBar.current ≤ 0.30 × evilBar.max  且 statuses 含 st_heat_deep/st_toxin )

传变执行：
  stageIndex += 1
  syndrome.axes = stages[stageIndex]        // 切换到预设的下一证候形态
  syndrome.revealed = ∅                     // 已揭示轴全部重置为未证
  清除"随传变"状态（st_cold_coag/st_heat_deep 等限时状态）
  按新 stage 的 tags 重新施加"证现则状出"状态
```

| 变量 | 类型 | 范围 | 说明 |
|---|---|---|---|
| stageThreshold | int | 3–8 回合 | 每次传变的回合阈值（随卷次配置） |
| stageIndex | int | 0..N−1 | 当前形态；末形态不再传变 |

- **传变是"病情演变"的机制化**：如"表证入里""寒化热"。玩家须**重新辨证**——不是一次性谜题（`combat-system.md` §5）。
- **确定性**：每个病机的传变序列在配置中**写死**，玩家可通过观察（`st_*` 状态、回合数）**预判**，符合全篇"可归因"原则。

#### 4.4.1 "病势燎原"——amp 越界的自动传变

病机 `ampPerTurn` 持续把病邪条推高，**一旦 `evilBar.current` 越过 `max × 1.5`**，不引入新机制，而是**复用本节的 stages**：`stageIndex` 强制前进到一段预置的**"病势燎原"形态**：

```
触发： evilBar.current ≥ evilBar.max × 1.5
执行： 复用"传变执行"流程（重置 revealed、清随传变状态）
      新 stage 的 behavior 由 加剧病邪 → 切换为 损耗正气
      新 stage 的 ampPerTurn ≤ 0（病邪不再自增）
```

- **为什么这样设计**：把"拖过上限"的惩罚**从数字溢出变成可见的病情恶化**——病邪不再涨，但病人开始快速掉正气。玩家看到的是"病人危急"，而不是"病邪条 150/100"这种抽象越界。
- **与持守型/防守局的关系**：末段"自限"stage 亦复用本机制：`ampPerTurn ≤ 0`、病机停手，配合关卡层的"撑到 N 回合"胜利条件（见 `combat-system.md` §4.10.3）。
- **配置校验**：`stages` 序列的**最后一段**必须是**终末形态**（不再传变）；若 `ampPerTurn` 允许越界，则 `stages` 必须至少含一段"燎原"形态，否则配置非法。

### 4.5 状态叠加与时长结算 Status Stacking & Duration

```
叠加： 乘法类效果  →  生效系数 = ∏ (1 − rate_i)      i = 1..层数（上限见 §7）
       加法类效果  →  生效值   = Σ delta_i
       层数        →  layers = min( layers + 1, layerCap )

时长： 每回合结束末尾  remaining −= 1
       remaining ≤ 0 → 移除该状态
       被"化解"（对证牌命中）→ 立即移除 1 层，remaining 重置（若仍有层数）
```

**示例**：`st_cold_coag` 2 层 → 病人 Speed 系数 `(1−0.15)×(1−0.10) = 0.765` → 速度降 23.5%。

### 4.6 状态对病邪 / 正气 / CTB / 资源的修正

| 目标 | 修正形式 | 接入点 |
|---|---|---|
| 病邪条 | 病机 `ampPerTurn` × (1 + Σ 病邪侧增幅) | 病机行动结算 |
| 病人正气 | 每回合 `vitalQi += Σ(−drain_i)` | 回合结算 |
| CTB | Speed × 系数 或 ActionGauge 增长 × 系数 | `combat-system.md` §4.1 |
| 双资源 | 回复效率 × 系数（`st_qi_def` / `st_yin_def`） | `combat-system.md` §3.2 |
| 匹配系数 | M ± 0.3~0.5（`st_phlegm` / `st_liver_dep` / `st_disharmony`） | 本文件 §4.3，出牌结算前 |

**示例**：病机带 `st_toxin`（增幅 +25%）与 `st_interior_excess`（+15%）→ `ampPerTurn = 8 × 1.40 = 11.2 → 11`（向下取整，见 §5 取整规则）。

### 4.7 四诊揭示准确性 Accuracy

```
望 / 闻 / 切：准确率 = 100%（凡"揭示"即给真实极与强度）
问：          accuracy = 0.90（默认）；叠加 st_spirit_dis 后 accuracy = 0.50
             命中准确 → 给真实值
             未命中   → 给"错报"（相邻极或降 1 级强度），玩家无法直接分辨真伪
```

- **问诊的 90%** 是全系统**唯一的随机源**，且其"错"是**角色化的**（"记不清了 / 怕冷吧……"），符合"病人可能答错"的医学真实（`combat-system.md` §3.5）。
- 玩家可**交叉验证**：用 闻（覆盖寒热）/ 切（覆盖虚实）这些 100% 准确的诊法去覆盖问诊的错报，从而"识破"——这是高级玩法。**注意阴阳是例外**：望/切 各给一层（表层/深层），须两层都读到、比对后才算识破（见 §3.2.2）。
- **预期输出范围**：问诊准确率 ∈ {0.50, 0.90, 1.00}（受状态影响）。

### 4.8 标签匹配与连线可行性（喂入成长系统）

```
LabelMatch(node_A, node_B) = |tags(node_A) ∩ tags(node_B)| ≥ 1
其中 tags 取 病种标签 ∪ 证候标签
```

- `LabelMatch` 为真，是 `progression-system.md` §3.4「通」的**必要条件之一**（另需"跨树"与"支付顿悟点"）。
- 本系统只提供 `LabelMatch` 判定函数，**不决定**连线、不由本系统扣 IP。

## 5. 边界情况 Edge Cases

| 场景 | 会发生什么 | 理由 |
|---|---|---|
| **多病机共存**（同一病人多个病邪条） | 各自独立证候向量与状态；对病机 A 的牌不影响 B；部分状态（如 `st_pestilence`）为**全场级** | 复现真实"复合病"（`combat-system.md` §5） |
| **证候传变** | 已揭示轴**全部重置为未证**；玩家须重新四诊 | 辨证是动态的（`combat-system.md` §5） |
| **矛盾证候**（如同时"实"与"虚"高强） | 允许存在（复合病机）；玩家须选**主证**优先处理，或靠"和"法调和；连线时若两节点给出矛盾治法 → 生成「未决」态（`progression-system.md` §5） | 认识论冲突的机制化 |
| **无症状（带菌者）** | 四诊返回"无显著证候"，不授予"已知"态；仅检验可识别 | `combat-system.md` §4.10.4 |
| **状态叠加达上限** | 该状态**层数不再增加**，仅**刷新时长**（不浪费、不溢出） | 防数值失控 |
| **状态 + 传变交互** | 传变清除"限时 / 随 stage"状态；跨 stage 的**持续性状态**（如 `st_toxin`）保留并按新 stage 重新叠加 | 病势演化的一贯性 |
| **病机 `tags` 为空（未登记病种）** | **配置校验拒绝**该病机上线；测试环境回退为 `d_cough` 并打印告警 | 标签是连线前提，不得缺失 |
| **单镜型 + 错误阵容** | 四诊返回"无显著证候"或病邪免疫反馈（效力 ≈ 0）；玩家可**立即转诊**换阵容，**不判负** | `combat-system.md` §4.10.6 |
| **阴阳 S=0（派生平）** | **表层值与深层值各自**兜底判为**阴(1)**，并在配置中标注 `tie_break: yin` | 保证两层都必有极与强度，消除除零 / 未定义态 |
| **阴阳两层分叉（表层极 ≠ 深层极）** | **合法**——这是心身 / 志怪病机的侦探线索。触发条件 `\|D_derived\| < 0.667×\|D_innate\|`；望显示表层、切显示深层，**不报错**；悖证只按深层判定 | §3.2.1 / §4.2 设计意图 |
| **只看望诊（表层）就打出阴阳相关牌** | 阴阳轴在切诊前按**未证**算（M=0.7），**不会**因表层极判悖证——玩家不会"望了一眼就被罚" | §3.2.2；守护"可预判"承诺 |
| **纯还原阵容始终切不到深层阴阳** | 心身病机对其**永久不可见**（无气感 → 切诊不可用）；这是**单镜型的机制来源**，非 bug | §3.2.2 / §3.8 |
| **病邪条 `current` 越过 `max × 1.5`** | **不数值溢出**：自动前进到一段预置"病势燎原"stage（复用传变），`behavior` 转**损耗正气**、`ampPerTurn ≤ 0` | §4.4.1；把越界变成可见的病情恶化 |
| **`ampPerTurn` 配置过高** | 关卡校验：**有效压力 = `amp × (病机Speed/医者均速)` 不得超过 15**，否则拒绝上线 | 保护"辨证必须划算"（§3.3） |
| **标签被标记 `deprecated`** | 既有存档仍可解析（ID 保留）；新病机配置**不得**再引用 | 冻结策略（§3.7.3） |
| **在标签首次出现卷次之前误用** | 配置校验拒绝（§3.9） | "技能即剧情"的硬保证 |
| **问诊错报 + 玩家据此打出悖证牌** | 错报使"已知"态失真，玩家据错报出牌**可能**撞悖证——但悖证判定仍基于**真实值**；玩家可用 100% 诊法交叉验证以自保 | 唯一随机源，且**可被玩家主动消除** |
| **状态层数取整** | 乘法类保留浮点，最终对 CTB / 资源取整**向下**（floor）；对病邪 / 正气取整**四舍五入** | 统一取整规则，避免"1 点之差"的复议 |
| **病机 `behavior=损耗正气` 且 `drainPerTurn` 过高** | 关卡配置校验：单回合 `drainPerTurn ≤ 0.35 × 病人正气上限`（防"未及出手即死"的死局） | 保证每关有可玩窗口 |
| **病邪条被 `st_stasis` 锁定且玩家无化瘀手段** | 削减上限 30% / 回合仍生效（非 0），玩家可"磨"过去或转诊；关卡校验保证至少一条化解路径存在 | 不留死锁 |
| **同一轴被多次揭示（望+切 均含阴阳）** | 幂等：重复揭示不重复施加状态、不刷新时长 | 一致性 |

## 8. 验收标准 Acceptance Criteria

- [ ] 每个病机含 4 轴证候向量，各轴有合法极与强度 1–3；`tags` 至少含 1 个病种标签——**配置校验可拒绝非法病机**（含空 `tags`）。
- [ ] 阴阳两读式符合 4.2（先 `clamp(D_derived_raw, −1, 1)`，再算表层 `S_surface` 与深层 `S_deep`）：示例 A（里3/寒2/虚1, 独立0）两层均 **阴(2)**；示例 B（同前三轴, 独立+0.9）表层 **阴(2)** / 深层 **阴(1)**（强度型破绽）；示例 C（表1/热2/虚2, 独立−0.9）表层 **阳(1)** / 深层 **阴(1)**（极性型破绽），误差 0。
- [ ] **极性矛盾条件可校验**：`\|D_derived\| < 0.667×\|D_innate\|` ⟺ 表层极 ≠ 深层极；不满足时两层必同极（仅强度可不同）。
- [ ] `S_surface = 0` 或 `S_deep = 0` 时**各自**兜底判为「阴(1)」，不产生未定义 / 崩溃。
- [ ] **未切诊前，阴阳轴按"未证"（M=0.7）结算**；仅望得表层极**不触发** M=1.5、**不触发**悖证——"看了望诊就被罚"的路径不存在（守卫检查）。
- [ ] **悖证只按深层极判定**；表层极永不触发悖证。
- [ ] **无「气感」的队伍切诊不可用** → 阴阳深层极读不到 → 心身病机对其不可见；此路径**无需特判**、由规则自然涌现（守卫检查）。
- [ ] 四诊 → 轴映射与 `combat-system.md` §3.5 **逐字一致**（望→表里+阴阳表层；闻→寒热；问→寒热+虚实；切→虚实+阴阳深层）。
- [ ] 切诊在队伍含苏晚棠或陆九针时耗费 **0 行动**；不含时耗费 1（守卫检查）。
- [ ] 匹配系数与 `combat-system.md` §4.3 **二维表**一致：同轴·未揭示 0.7 / 同轴·已揭示·相符 1.5 / 同轴·已揭示·相反 0.0 / 相关轴 1.0（**不看揭示**）/ 无关轴 0.5（**不看揭示**）——**逐格可测**，且示例（清法对热·已揭示 → M=1.5 → ΔE=60；同例未揭示 → M=0.7）复现。
- [ ] **★ R1 / 多轴牌的 M 只取 `mainAxis`**；`subAxes` 仅在"已揭示且相悖"时触发悖证伤害（`ΔV_wrong`），且**不加成 M**（守卫检查）。
- [ ] **★ 相关轴不看揭示**：`M = 1.0` 的相关轴路径在**未揭示**两侧取值一致（回归守卫——旧版把相关写成"依赖揭示"是 D7 根因）。
- [ ] 未揭示轴出牌 M=0.7 且**不伤正气**；已揭示轴相悖 → **确定性**触发悖证（连测 100 次一致，无随机）。
