## 1. 概述 Overview

《杏林江湖》的教学**已经写完了**——它由**七项手段**实现，散落在宿主系统各处：A-2 的战斗旁观遭遇（`combat-system.md` §3.10）、门槛阻塞提示（`level-system.md` §4.2）、悖证失败反馈（`combat-system.md` §4.8）、呈现层不显数值（`combat-system.md` §7 旋钮）、自由探索窗口（`level-system.md` §3.4）、转归独白（`vol-01.md` §3.5.1 / §3.6）、二级 / 三级递进（`vol-01.md` §1.3）。每一处都做得对。

**问题是：没有人写下过"它们为什么对"。** 支撑这七项手段的**六条口径规则**（§3.2）此刻各活在某一处散文里，**互相不知道自己存在**——于是任何一处单独修改时，看不见自己正在拆掉另一处的地基。这就是本系统存在的唯一理由。

| | 本系统**交付** | 本系统**不交付** |
|---|---|---|
| 交付物 | 六条口径规则（§3.2，**唯一真源**）· 七项教学手段登记表（§3.3）· 确定性边界（§3.4）· 十条守卫检查（§8） | 不造机制（§3.1 硬边界）· 不改数值（§4：本系统无运行时数值）· 不写文案（文案归各内容层） |

**一句话**：本系统是**教学的宪法，不是教学的实现**。

## 2. 玩家幻想 Player Fantasy

本系统的"玩家幻想"是**间接的**——它不是玩家直接体验到的系统，而是**玩家体验不到的那一层**。

> 玩家从不觉得自己"被教学过"。他只觉得自己**看懂了一个医者怎么想**。

**验收是肯定式的，但反例是否定式的**：若玩家在通关后能说出"这里的教学做得好"，本系统**成功**；若玩家说出"**这是教程吧**"——本系统**失败**。这不是措辞差别：前者说明他以为自己悟到的，后者说明他知道自己被喂了。

**这与"呈现层不显数值"是同一个赌注**（§3.3 手段 4）。不显数值、不给原理、不弹纠偏——三者共同押注同一件事：**玩家会自己把两件事连起来**。押错了，玩家会卡住；押对了，那一刻的"我懂了"没有任何系统能替代。本作的核心幻想（"外行即内行"）**只能由此产生**，不能由提示产生。

**节奏目标是内容层的，不是本系统的**（见 §3.3 末与 §7）：本系统只保证**不打架**，不规定**何时教什么**。

### 3.4 教学信号的确定性边界

> 承核心承诺「**失误是选择的结果，不是运气的结果**」（`combat-system.md` §4.3）。全系统唯一随机源 = 问诊 90%（`status-syndrome.md` §4.7），且**卷一不使用**。

**规则（本系统为真源）**：教学信号的**生成**不得读取任何随机结果。

**关键区分**——不能写成"教学段内不出现随机机制"：

| | 表述 | 判定 |
|---|---|---|
| ❌ 错 | 教学段**内不得出现**随机机制 | 过严——问诊是**就诊法**、是常规机制，教学段照样可以有 |
| ✅ 对 | 教学信号的**生成不得依赖**随机结果 | 精确——问诊可以出现，但**它不能是教学信号赖以成立的唯一来源** |

**可测形式**：**替换全系统随机种子，全部教学信号逐字不变**。举凡提示文本、缺口指向、独白分支、门槛可满足性——皆须**只**依赖于确定性状态（`flagSet` / `eventSeen` / `heardWall` / 节点进度 / 非问诊途径的 `revealed`）。

**与关卡层的关系**：本系统是这条原则的**真源**；`level-system.md` §4.2「**补全路径必须是确定性的**」（禁唯一 `问`）是它在关卡层的**实现**，由**配置期校验**强制。二者是"宪法"与"执行"的关系，不是两套规则。

**卷一的强形态**：卷一未习得四诊牌（`vol-01.md` §3.2）→ 除问诊外无随机源，且卷一不使用问诊的随机支 → **卷一的教学段根本没有随机源**，本条无需额外校验。**卷二起**四诊解锁（`progression-system.md` §3.7），本条才开始有实义。

## 4. 公式 Formulas

**本系统不引入任何公式与数值。**

**理由**：教学是**定性**的，不是**定量**的。任何形如"教学强度 = f(…)"的数值化都会立刻诱发一个坏动机——**为凑进度而教学**（在玩家已懂的地方仍塞提示，只因"该关的教学配额还没用完"）。这与 `combat-system.md` §4.10.1 砍掉阵容分类器**同因**：一个覆盖不了实际用例的量化构件，其危害不止于无用，还在于它会**反向塑造设计**去喂它。

**本节与 §8 的分工**：本系统确实有**可测**的东西——但它们是**守卫谓词（布尔）**，住在 §8 验收标准里，**不是运行时数值**。二者不可混淆：

| | 形式 | 归属 |
|---|---|---|
| ❌ 运行时数值 | "教学完成度 0.62" | **本系统不设**——不可测、且诱发凑数 |
| ✅ 守卫谓词 | "提示文本不含 `尚未辨明`"（真/假） | **§8 AC**——可测、无副作用 |

**若有人提议给本系统加数值**：那说明该需求错位了——回到宿主系统（`combat-system.md` §7 旋钮 / `level-system.md` §7 旋钮）登记，见 §3.1 硬边界。

## 5. 边界情况 Edge Cases

| 情境 | 会发生什么 | 本系统的立场 |
|---|---|---|
| **玩家跳过 A-2**（`spectated` 不点亮，`watched_diagnosis` 仍点亮） | 推进链**不断**（A-3 门槛照常满足，`vol-01.md` §2.4 ⑤）；代价是**参照系变弱**——一级教学弧只剩下"他问了两句"，没看到"他真打了一场、三味药人当场松快" | **不是教学失败**，是**教学强度降级**。系统**不做补偿**（不补弹提示、不补回忆闪回）——补偿会把"跳过"这个选择变成没有代价的选择。代价**如实**记录在 `spectated` 缺席上，供卷二自我评价消费（`vol-01.md` §4.1） |
| **重玩玩家**（已知答案） | `skipAllowed` 默认 `true`（`level-system.md` §7）→ 他可整段跳过 A-2 | **有意设计**。教学信号是给**未知者**的；对已知者强制播放，只会制造"被按住"的烦躁（同旋钮表所述代价）。跳过**不损害**任何东西——因为教学的好处已在他身上，不需要再教一遍 |
| **玩家在探索窗口什么都不探** | 治段慢、被 `drain` 拖、评级吃单核 −0.20 —— 即 `vol-01.md` §3.5 的 **甲a / 甲b** | **不是失败——这就是二级教学弧本身**（"有眼睛，看不见"／"我赢了，可我不知道我为什么赢"）。吃"拖 + 评级"的钝刀**正是设计意图**；一级教学弧（A-2）已经给过他参照系。**不干预** |
| **玩家全程跳过所有可选教学、只推主线** | 落到 **甲a（未探）** = **二级弧**。**三级弧（乙：已探仍打反）不可达**——它的全部前提就是"探过" | ⚠️ **不是缺口，是互斥分支的必然**。二级（甲）与三级（乙）由玩家的**探 / 不探**分岔，**不可能同时达成**（§3.3 手段 7 已登记）。若把它读成"教学保证失效"，就会去加一条不可能的守卫——**这正是本文件 rev a 初稿犯过的错**（曾写"三级须在二级之后"）。**验收口径**：二级与三级**各自可达**即可，**不要求**任何玩家同时经历两者 |

## 8. 验收标准 Acceptance Criteria

> 六条口径规则 + 零随机 + 数据驱动，逐条落成**可测守卫**。全部为**布尔谓词**（§4），无运行时数值。

- [ ] **规则一（只用临床语言）**：教学段文本**不出现**机制词汇（`M` / 牌力 / 对证 / 轴名 / `ΔE` / 数值 / "补液补的是虚" / "探虚实"）。（守卫检查：词表扫描）——反面例见 §3.2 表。
- [ ] **规则二（只给现象不给原理）**：教学段**不出现**"因为……所以……"式的机理因果。（守卫检查：A-2 自白只答"为什么下这一味"，不答"我怎么知道该先问那两句"；`vol-01.md` §2.4 边界二）
- [ ] **规则三（只给方向不给路径）**：教学段只给方向词（"该散，不该清"），**不给**执行路径。（守卫检查：`vol-01.md` §2.4 判词口径）
- [ ] **规则四（缺口必须具体）**：每个教学缺口**具体指向**某个未获取的信息。**对测法**：这缺口**能补吗**？**补法明确吗**？两问皆"是"方通过（泛化为"我看不见证候"即不通过）。
- [ ] **规则五（门槛提示只说动作）**：提示文本**不含**辨证结论字样（`尚未辨明` / `须先辨明` / `证候未明`）。（与 `level-system.md` §8 rev k+1 **三条** AC 同源：提示口径 · 教学期无 `revealed(轴)` 门槛 · `revealed(a)` 补全路径不含唯一 `问`）
- [ ] **规则六（纠偏在收束不在回合内）**：回合内**无**纠偏文本；纠偏**只**出现在收束独白。（守卫检查：§3.2 规则六下注）
- [ ] **零随机（§3.4）**：**替换全系统随机种子，全部教学信号逐字不变**。（回归用例：教学段文本 / 缺口指向 / 独白分支 / 门槛可满足性四类，换种子后逐字比对）
- [ ] **数据驱动**：教学触发条件来自**外部配置**，无硬编码。（守卫检查：关卡表 / 节拍表 / 遭遇表；同 `.claude/docs/coding-standards.md`）
- [ ] **手段 1 验收（战斗旁观）**：A-2 类遭遇**玩家零输入**（不编成 / 不出牌 / 回合推进不受玩家影响）· **数值不上屏** · 每回合有**推进信号**（`act` + `narration`）。（用例，`combat-system.md` §3.10）
- [ ] **手段 6 验收（转归独白）**：每条转归独白**通过规则四对测**——缺口具体、可补、补法明确。（用例，`vol-01.md` §3.6 甲a / 甲b / 乙 / 丙 四条）
