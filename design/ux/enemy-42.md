## 1. Overview

玩家在**世界空间**里看见敌人:一具身体(六态可读)+ 头顶一条**黄铜读数条**(V-10)。
本 spec 定义「玩家读到什么、按什么顺序读、什么时候出现与消失」——
**触发与状态归 27**(`EncounterStarted` / `EncounterEnded` + 六态机),
**值与语义经既有 `VitalsDto`**,42 只画材质与位置(`enemy-ai.md` 规则二十二)。

---

## 2. Player Fantasy / 玩家感受

**「我不需要血条,我读得懂他」** —— 敌人的状态**写在他的身体上**:
他在巡游 / 停下了 / 朝你来 / 贴身出手 / 退了 / 不动了。
黄铜读数条是**仪器**(全作唯一允许的贴屏数值反馈,`art-bible.md:587`),
挂在他身上,**不是** HUD。

**设计反命题**(为何不能做成传统血条):
- 传统血条 = 把「他还有多少血」变成**可以计算的资源** ⇒ 玩家开始**刷数值**,而不是**观察人**。
- 敌人读数条的形态 = **錾刻弧 + 指针**(机械表式),读数像**看表**,不像**看进度**。
- **禁**数字角标 / 进度填充 / 红点 / `X/N` 计数(`art-bible.md §7.8` 现代 UI 手法全禁)。

## 4. Interaction Flow

| 输入 | 行为 |
|---|---|
| 鼠标左键 / 手柄 A | **出手**(经 25 的 `CombatDriver` → `EnemyInjuryOnset`) |
| 指针悬停 | **无任何悬停态**(禁悬停交互提示;可取材微光也不是悬停态) |
| 点击读数条 | **不可交互**(它是仪器,不是按钮) |

**焦点导航**:**不适用** —— 本件无焦点、无 `tabIndex`、不进模态栈。
手柄焦点走既有的世界交互选择器(4 的目标选择),不经过本件。

## 6. Visual Direction(承 `art-bible.md`)

| 项 | 口径 |
|---|---|
| 墨铜分轨 | 兵痞 = 墨(褴褛衣料)+ 铜(缴获劣质器械);野狗 = 墨(皮毛 / 肌肉)+ 铜(牙 / 爪 / 甲) |

## 7. States & Variants

### 7.1 六态(呈现层必须让玩家读到的)

| 态 | 身体 | 读数条 |
|---|---|---|
| `Patrol` | 沿导航格巡游,不朝你 | **不显示**(未接战) |
| `Alert` | 面向你,不动 | 浮出 |
| `Chase` | 直线追击,**格间插值** | 显示 |
| `Flank` | 侧向路径 | 显示 |
| `Engage` | 出手动作 | 显示 |
| `Disengage` | 背对你走开 | 显示,随后淡出 |
| **`Down`(非态)** | 躺倒 + **呼吸层仍在** | **压暗但仍可见**(归零 ≠ 已清除) |

> **态不得只靠颜色传达** —— 每态都有姿态 / 动作差异(上表)。
> **`Down` 不做任何主动表现**:无转向 · 无寻找目标 · 无动作 —— 决策完全停止;
> 若有 idle 动画,选**最静止的那一档**(`enemy-ai.md §Visual 二③`)。

### 7.2 倒地可取材微光(2026-11-14 裁定)

| 项 | 值 |
|---|---|
| **触发** | `is_down ∧ down_class = Salvageable` —— P0 仅**野狗**;兵痞(`Healable`)只躺倒 + 呼吸 |
| **形态** | 外围一圈极淡**墨色**轮廓(倒置外壳),低频**呼吸**(2.2 Hz,与身体呼吸同频) |
| **禁** | 颜色单独承载信息 · 数字角标 · 进度填充 · 悬停交互提示 |
| **不改变** | 归零 = 「不动了」而非「死了」:死亡动画 / 尸体淡出 / 实体销毁 / 血液升级仍然**禁**;呼吸层仍然**必须**在 |

### 7.3 半格盲区(呈现纪律)

敌人朝旧格移动时,**照实播** —— 插值只发生在**逻辑格之间**,
**不**发生在「逻辑格与实际位置之间」(`enemy-ai.md §Visual 二②`)。
**禁**让敌人「平滑跟随」玩家的真实连续位置 —— 那会让玩家看到一个追踪精度远超 sim 的敌人。

## 8. Edge Cases

| 场景 | 行为 |
|---|---|
| 遭遇开始前 | 无身体、无读数条(**不存在** = 还没进遭遇) |
| 敌人倒地后遭遇结束 | **收场 ≠ 实体消失**(GDD 规则二十二)—— 视觉仍在场、保持倒地;销毁只在 teardown(`DestroyAll`)。**不是**「尸体淡出」 |
| 多敌人同遭遇 | 每具身体各一条读数条;各自独立六态(遇难内共享读量见 27 规则) |
| 相机遮挡 | **不做遮挡淡出**(与「照实播」同源;玩家看到什么就是什么) |
| 占位材质缺失 | **构造期抛**(不留品红、不静默降级) |
| 敌人与玩家重叠 | 允许(无 Collider;视觉可能穿插 —— 占位阶段的已知代价) |
