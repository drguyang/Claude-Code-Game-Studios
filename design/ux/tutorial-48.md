## 1. 类型声明与所有权边界

本 spec 是 `AC-42-F1` 七员闭集**第五员**「**⑤ 教学界面(48,纸堆翻页走查)**」的 per-screen UX spec;
模态身份 = `ModalId.Tutorial`(`adr-013:356`)。

| 方 | 拥有 | 不拥有 |
|---|---|---|
| **48** | 六步调度语义(`steps[]` 闭集 `{observe, judge, treat, close, archive, manage}`)· 媒体条目与引用完整性 · Anchor/Completion 判据 | 任何渲染(自陈零 UI) |
| **42** | 字幕呈现(E-12b)· one-shot clip 请求接口 · 本屏渲染与焦点 | 游戏进度状态(§9 C3)· 「引导是否完成」的对外查询面(`AC-48-17` 反射断言禁) |
| **44** | 口述声源 cue、字幕语义(`AC-44-15`) | 字幕的文字渲染(归 42) |
| **本 spec** | 调度壳的**最小具形**(§5,形态已由用户裁定成立 —— OQ-TUT-1 = 甲,2026-09-21)· 走查路径 | 任何步进度渲染(§6 禁令)· 「纸堆浏览」的功能发明(乙案作废) |

- **本屏与 ⑦ 的关系 = 并存不合并**(`adr-013:390`):⑦ 是世界内单张教学纸的近景;本屏是**调度媒体
  (口述/示范)的呈现壳**。两员语义互不吞并。
- **48 零设门的呈现侧对偶**:本屏**不得渲染任何「引导进度 / 已完成步数 / 下一步提示」**——
  48 的 API 面被 `AC-48-17` 断言禁止暴露进度查询;若本屏画步列表,等于用 UI 绕过该断言
  (渲染数据源 = 同一被禁查询)。**这是本 spec 从既有权威推导出的强约束,非新立规则。**
- **零档位耦合**:开合本屏**不发相机意图**(39 仍是全案唯一档位请求方);世界意图在模态开时冻结
  (规则十四 `IModalState` 消费方拒收),**不落流边沿**。

## 2. Purpose & Player Need

48 的幻想是「**师父不教,师父带你进门**」(规则五:零惩罚、零提示、可丢下、可回头)。
本屏的存在理由因此极窄、也极硬:

- 「走近再说」是 48 **唯一明载的可重放义务** —— 玩家错过的口述要能再听,而**再听的落点**
  在全部权威件中**没有位置**(声 = 44 有;字幕文字 = 义务在 42、形态无人写)。本屏先接住这一个落点。
- 示范(13 实体世界内做)错过即过 —— 本屏**不**承诺重播示范(重播 = 二次世界事件,归 48/13 另判);
- 走查义务(`AC-42-F1` / `AC-3-F1a` ① / `AC-48-05`):手柄单机必须**能走完本员的走查面** ——
  前提恰是本员有可操作形态,这是 §0 空洞的直接后果(空洞 ⇒ 走查无从执行 ⇒ 闭集全链 NOT-RUN)。

**什么会变糟**:把本屏做成「教学关卡菜单 / 教程图鉴」⇒ 同时破 48 规则一(重看不存在)、
规则五(引导变可管理的对象)与 `AC-48-17` 的精神;往屏幕上加任何按键提示 ⇒ 直撞联合 BLOCKING 条。

## 3. Player Context on Arrival

- **入口(本 spec 的最小具形;OQ-TUT-1 已裁 = 甲,本形态成立)**:玩家**走近某 Anchor 熄灭过的步的锚点物**
  (第一幕场地内:师父常到处所 / 病例案几 / 存档册道具位 —— 6 侧摆点)→ 对锚点物 Submit →
  开本屏,**可重听该处口述 + 读其字幕**。理据:「走近再说」原文即含「走近」,锚点物 = 其既载宿主;
  本 spec 只补「再说 = 摊开一页壳来听」这一呈现决定。
- ⚠️ 该入口**不新增动作资产**(复用 4 的世界 `Interact` 宽容半径判定路由)—— 但「锚点物 Submit →
  开 `ModalId.Tutorial`」的路由登记在 3/4 侧**零字**,列为 **R-涟漪 OQ-TUT-2**。
- **情绪**:好奇回访;零时间压力(48 无任何计时义务)。
- **出口**:同一 toggle 关闭;焦点回锚点物载体(P-02)。

## 4. Navigation Position

```
World(自由态)
  └─ 走近锚点物 + Interact ──▶ ModalId.Tutorial(本屏 · 世界意图冻结 · 档位不变)
  │                             ├─ 口述重听(播放/停)· 字幕滚动回读
  │                             ├─ 纸条目 → Submit ──▶ ModalId.PaperCloseup48(⑦ · 互斥切换,非嵌套)
  │                             └─ toggle ──────────▶ World
  └─ 走近教学纸(世界道具)──▶ ModalId.PaperCloseup48(⑦,独立员,其 spec = paper-closeup-48.md)
```

- **⑤↔⑦ = 栈内互斥切换,不是嵌套**:单值 `Modal` 非集合(规则十四)⇒ 从本屏进 ⑦ 是
  **关一开一**;退出 ⑦ 回世界(不回本屏 —— 无栈语义,禁「返回上一层」)。
- **零嵌套模态**、**零层内确认框**(叠模态须另判,不预留)。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **字幕行带**(口述文字的纸面承载) | 「走近再说」义务的可读落点 |
| 2 | **该处纸条目一览**(纸名/图题,来自 `papers[]`)| 仅**已在本幕出现过**的纸;是 ⑦ 的入口目录,非内容复制 |
| 3 | **口述重听控件**(单枚:听 / 停)| 唯一可操作媒体件 |
| 4(环境) | 所站锚点处世界(案几 / 师父位)| 「我在师父常到处翻他的纸」;零数据 |

**层级原则**:本屏是**壳**,不是书 —— 它把「声 + 字 + 通往纸的门」聚在一页上;**不复制任何纸的图、
不转录任何示范**,内容各归其权威(48 数据 / ⑦ 件 / 13·10 clip)。

### 5.2 Layout Zones

裁定:**师父案头单页摊** —— 等比纸本族(⑦ 的册形制同族,`paper-closeup-48.md` §1 用户裁定的口径),
**水墨侧**;本屏零黄铜件(无档位读数义务)。

1. **页上半 = 字幕带**:已播口述的**末 ≤3 条**按 `order` 排列(墨字,题签 = 讲者「师父」);
   重听时逐条高亮(墨框,非颜色)。⚠️ 字幕 = 口述的**平行文字承载**,明载「**字幕 ≠ 按键提示**」
   (`tutorial-and-onboarding.md:96-98`)—— 禁任何键位字形 / 操作动词混入字幕带。
2. **页下半 = 纸条目行**:每行 = 纸名 + 图题(≤2 行约束承 ⑦ 件 §12);行 Submit = 互斥切 ⑦
   (摆点走近路径仍在,本行是**快捷方式**,与键鼠=快捷方式纪律同构)。
3. **页角一枚铜钮 = 听 / 停**:重听当前页口述序列;播放中钮呈「振铃」微态(几何,非动画循环 —— 减动效钩子)。
4. **端点形态**:该锚点无口述可重听(Anchor 从未发火过)⇒ 本屏**不该被打开**(世界内 Submit 无事
   发生 = 纸面轻顿,拒绝反馈同族);不存在「空屏」。

**不具形清单**(刻意留空,非疏漏):翻页 —— 单页即完备(P0 种子 `narration[]` 全量仅 4 条,逐字引
内容债口径:「P0 种子 = 六步 + 4 口述 + 6 示范 + 1 纸 = **17 条**」,`tutorial-and-onboarding.md`
内容债段 ⇒ 每锚点 `narration[].order` 上界 ≤ 4 是**全量推论**非逐锚配额);进度 —— 禁(§1);示范重播 —— 无义务(§2)。
