## 杏林江湖/ — 《杏林江湖》(The Apothecary's Journey)

- **废弃日期**:2026-09-13
- **废弃原因**:用户决定推翻重来(「玩法巨大差异」→ 换整个游戏类型)
- **它曾是**:仙侠医道 · 队伍制回合制 RPG。病机/证候为敌,辨证施治为战斗,
  医道图谱为成长;十卷线性剧情,1905–1929 民国传奇。
- **它包含**:8 份系统 GDD(战斗/状态证候/队伍/对话/进度/任务/关卡/引导)、
  卷一内容层与对话、系统索引。
- **为什么死在半路**:主题(钱学森「新医学」/ 中西医汇通 / 外行→内行)是真的,
  但两次选的壳——多人在线平台、仙侠回合制 RPG——都撑不住单人第一作。
  这不是主题失败,是**壳**的失败。

### 可复用(已裁定「只复用世界与史实」)

- 断代与**史实时间线**(已完成核查:1910 东北鼠疫 / 1918 大流感 /
  1929 废止中医案 / 协和 1915–1921 / 张锡纯 1918 首刊)
- 时代事件骨架
- **「还原 × 整体」的双认识论核心洞察**
- **「外行 → 内行」**的主题

### 不可复用

- 人物(沈砚之/陆九针/柳希白/苏晚棠/陈九章/清和/霍崇光)
- 十卷线性剧情
- 回合制战斗与辨证施治数值系统(证候向量、Rating、医道图谱 IP 经济)
- 关卡/对话/任务的具体层级与门槛词汇
