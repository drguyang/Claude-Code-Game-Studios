# 结案页(`ModalId.CaseClose`)—— 系统 37 的结案形态

## 1. 目的与玩家需求

玩家手里有一例**已经处置过**的病例。他要做一个**不可撤销**的决定:宣布这一例结束。
现在的缺口:这个动作在 P0 里**没有载体** —— `AC-37-04`(BLOCKING)要求「玩家勾选『已处置』」
这个自述动作存在且可判,而 39 的 §7 动作表从来没有结案行。

**玩家到达时想的事**:「这一例我看完了,收了吧。」

## 2. 到达时的上下文

玩家站在病人旁(或刚离开不久),按了 `C`。他不知道这一按会不会立刻生效 —— 所以本屏的
第一职责是**把决定交回给他**:勾、还是不勾;结、还是合上。

## 3. 导航位置与出入口

| 项 | 值 |
|---|---|
| 层级 | 模态(`ModalId.CaseClose`,第十员) |
| 入口 | `C`(键盘)/ `leftShoulder`(手柄)→ `CaseClosePresenter.TryOpen(最近在场病人)` |
| 入口前提 | 该病人**有开着的病例**;没有 ⇒ **不开空页**(不开屏,不弹任何东西) |
| 出口 | 结案成功 ⇒ 自动合页;取消(`Escape` 经 `ModalInputDriver`)⇒ 合页、零写入 |
| 模态语义 | 摊开即挡世界意图(规则七);**叠栈**:若从暂停壳上层打开,取消后回暂停壳 |

## 4. 布局

```
┌──────────────────────────────┐
│           结  案             │   ← 标题(纸上墨字)
├──────────────────────────────┤
│  □ 已处置                    │   ← 墨勾行(焦点默认落这里)
├──────────────────────────────┤
│  结  案                      │   ← 提交行
└──────────────────────────────┘
  (被拒时:页面下方一行淡墨字,如「病未处置」)
```

- 页 = `.paper-page`(页框只在页级容器);两行 = `.ruled`(与脉案行同一声明块 ⇒ 44px 下限);
- **零现代控件**:墨勾是**纸面墨迹**(空 / 「✓」两种字形),不是复选框 ——
  39 §5.3 的禁「复选框」在**结构上**成立(没有复选框元素,只有字);
- **零数量类信息**、**零进度条**、**零角标**(承 42 禁词表与 37「系统沉默」纪律);
- **不显示病种 / 病名**(`disease_id` 禁入呈现层,AC-37-15)。

## 5. 状态

| 态 | 触发 | 呈现 |
|---|---|---|
| 未勾(默认) | 开屏 | 墨勾位空;提交行可聚焦 |
| 已勾 | 墨勾行 Submit | 墨勾位出现「✓」;再落一次 = 擦除 |
| 被拒 | 提交行 Submit 且写者拒 | 页面下方**一行淡墨字**说明拒因;页**不关** |
| 成功 | 写者返 `Closed` | 合页回世界 |

**淡墨行文案(装配层给,屏只显示)**:

| 结果码 | 文案 |
|---|---|
| `RejectNoTreatment` | 病未处置 |
| `RejectNotChecked` | 未勾「已处置」 |
| `RejectAlreadyClosed` | 此案已结 |
| `RejectNotOpen` | 此案已合 |

⚠️ 文案**只说「为何没生效」**,不透露病种、不提示该去做什么(教玩家归 48)。

## 6. 交互表

| 动作 | 键盘 | 手柄 | 即时反馈 | 路由 |
|---|---|---|---|---|
| 移焦 | 上下键(焦点两行) | 方向键 | 焦点墨框 | —— |
| 墨勾 / 擦除 | `Submit`(Enter) | `A`/`×` | 墨勾字形切换 | **无流事件**(纯呈现) |
| 提交结案 | `Submit` | `A`/`×` | 成功 ⇒ 合页;失败 ⇒ 淡墨行 | **37**(`CaseClosed`) |
| 取消 | `Escape` | `B`/`○` | 合页 | 无(纯呈现) |

**零按键提示**:本屏不解释任何按键(教按键归 48)。

## 7. 数据需求

| 元素 | 来源 | 归属 | 更新时机 |
|---|---|---|---|
| 是否需要开屏 | `CaseStreamQuery.OpenCaseOf` | 37 | 按键时 |
| 结案能否成立 | `CaseCloseWriter.TryClose` 的四条前置 | 37 | 提交时 |
| 淡墨行文字 | `CaseClosePresenter.ReasonOf(结果码)` | 装配层 | 提交返回时 |

**42 只渲染**:本屏不持有任何游戏状态(ADR-013 §9 C3);墨勾态是**屏内呈现态**,不进流、不存档。

## 8. 事件

| 玩家动作 | 产生的事件 |
|---|---|
| 墨勾 / 擦除 | **无** |
| 提交(成功) | `CaseClosed`(病例流,37 写者) |
| 提交(被拒) | **无** |
| 取消 | **无** |

## 9. 无障碍与本地化

- 焦点序 = 墨勾行 → 提交行(两行,手柄可达);
- 拒绝信息**不只靠颜色**(淡墨 = 字形 + 位置,不是红/绿);
- 纸面墨勾为字形,不依赖图元资源;
- 文案长度上限:标题 ≤ 4 字;行文字 ≤ 6 字;淡墨行 ≤ 8 字。
