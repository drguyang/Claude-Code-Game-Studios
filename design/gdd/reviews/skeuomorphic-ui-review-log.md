## Review — 2026-09-17 — Verdict: MAJOR REVISION NEEDED → **用户裁定 [A] 本轮修订;17 项阻断 + 14 项推荐修当日全部落盘**(~~待二轮评审~~ → **同日用户裁定免二轮,已 Approved,见上方结案条目**)
Scope signal: **L**
Specialists: unity-ui-specialist · ux-designer · accessibility-specialist · art-director · qa-lead · systems-designer(×6 报告,haiku 并行)· creative-director(opus 串行综合)
Blocking items: 17(去重后 **11 条 BLOCKER 级**)| Recommended: 14
Summary: 首轮 `/design-review`(`full`)。**CD 终裁:42 的架构姿态正确** —— 两栈边界(UI Toolkit 主 +
UGUI 补 world-space)· 焦点桥归引擎 · 只渲染不持有状态(承 ADR-013 §9 C3)三条主承重面
**未发现需推翻之处**;17 项阻断**全部是规格空洞、判据错挂与自相矛盾**,不是设计错误 ⇒
按清单一次性补齐,无重架构。CD 同时把五项跨域口径**交用户拍板**(读数条 owner · 刻度条禁令范围 ·
焦点门原子性 · 读数条值的通道 · 是否本轮修订)。

**🔴 五项用户裁定(2026-09-17,均照准)**:
① **[A] 现在就修订**;② 敌人读数条 owner = **27 敌人 AI**(原写 25)—— **态 / 时机归 27,画归 42,
值走 9 的既有 `VitalsDto`(不新增通道)**;③ 「任何刻度条」禁令**收窄为「墨侧禁刻度条」** ——
黄铜侧的錾刻刻度**本身合法**(旧稿同一份 GDD 里「库内零刻度条」与「敌人读数条有錾刻刻度」直接矛盾);
④ 焦点门「原子」取 **systems 版** —— **「原子」= 对外永不可观测到「两门皆开」**,
两门皆关窗口 `0 ≤ W_trans ≤ 1 frame`,**原 `E-3` 删除**;⑤ 读数条的**值**走 **9 的 DTO**。

**🔴 六路专家收敛的三条结构性根因**:
- **`F4` 的前提是假的(最具后果的一项)** —— 旧稿把两栈 z 序写成跨域全序 `S_UITK = φ(S_UGUI)`
  并**在装载期断言 `φ` 严格单调 + 单射**。但 UI Toolkit **Overlay 面板在全部相机之后合成**,
  UGUI World Space canvas 是**相机内几何** ⇒ **两个数分属两个合成域,不可比**,
  那条断言**是在断言一个不存在的对象**。更糟的是它会诱导实现走「调 `φ` 控制谁压谁」这条
  **注定失败的路**(引擎根本不让世界几何盖住 Overlay),得到「调了没用」再误判为 spike 失败。
  **修**:F4 重写为**三层口径**(L1 相机内 / L2 跨域**结构性二值** / L3 覆盖层内),`φ` **删除**,
  断言改锚为**两份域内序表各自无重复**;规则二 / `E-4` / `AC-42-F4` / 算例 / ADR-013 §一
  同批订正。
- **`AC-42-F1` 的主语是空集** —— 旧稿写「**已有** `design/ux/[screen].md` 的界面」,而该目录
  **不存在** ⇒ 判据在空集上**平凡变绿**(本仓反复出现的假通过形态)。**修**:改为**闭集点名六个 P0 屏**
  (① 脉案页 39 ② 存档位 7b ③ 库存容器 20 ④ 设置壳 42 ⑤ 教学 48 **⑥ 医馆面板 24** ——
  第六项是首轮补入:义务在 `AC-42-F5` 而主语不在)+ **`NOT-RUN` 纪律**(任一无 UX 规格者记 `NOT-RUN`
  并阻塞签核)。
- **`AC-42-B4` 与 ADR-013 的降级路径互斥** —— 旧文字断「焦点移动**不可由 42 自行计算**」,
  而降级 = **42 自实现焦点算法**(那时必然要算邻居)⇒ 降级一启用 `B4` 立刻变红。
  **这不是笔误,是把「对外契约」写成了「内部实现禁令」。修**:收窄为**只约束导出面**
  (邻居枚举 / 方向投影 / 几何查询不得出现在 42 的对外类型面上),内部实现不受约束,
  且**降级代码装配位置 = 42 自己的程序集**(否则 `AC-42-A4` 的反向白名单会被破掉 ——
  两道门原来二选一)。

**首轮补齐的其余阻断(逐项已落盘)**:
- **`AC-42-D4` 同时不可判且与渲染路径冲突** —— 「不读 DTO 的数值字段」无作用域(实现可把乘子
  说成「不是数值」),且 `AC-42-F5` **必须**读值。**修**:改**正面白名单**(枚举 / bool / 计数)+
  **限定在调试视图内**。
- **`V-11` 的「运行期只允许降级为续页」零 AC** —— 最易做、最像没问题的违规(`text-overflow`
  省略号,一行代码)**无门可抓**,而它恰是拟物铁律的反面(半截脉案画不在纸上)。
  **修**:新增 **`AC-42-F6`**(降级白名单**逐条枚举** + 开发期显式冲突路径 + 切分策略归内容拥有者)。
- **P0 承诺零 AC 真空(六条)** —— 规则五(元件库唯一出口)· 规则八(设置壳不缓存他系统状态)·
  对比度的「**全档均须满足**」义务 · 动效缩放挂点 · 载体欠账表会漂移 · 幻想的「我的笔迹 / 墨还没干」
  数据路径。**承诺写在正文里、零判据 = 没写。修**:新增 **G 组 6 条**
  (`G1`–`G6`,全 BLOCKING)。
- **`E-1`/`E-2` 的静默死锁与门语义** —— 取「不可观测双开」版后,`E-3`(窗口内吞键)描述的是
  **允许态**,写成 edge case 会把合法态固化成异常、诱导实现做「真原子切换」或「窗口内补发」。
- **`F1` / `F2` / `F5` / `F6` / `F7` 五式口径修正** —— 含循环定义(①`W_min = SL+SR+C_min`
  ②断言 `SL+SR+C_min ≤ W_min` 代入得恒真)、量纲不齐(断言断**面积**而公式给**计数**)、
  空集主语等。
- **`AC-42-C3` 的第二个载体漏登记**(构建期命名 job)· **`D3` 载体登记留白** —— 一并补入 §七。
