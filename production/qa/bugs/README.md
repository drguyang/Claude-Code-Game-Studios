# Bug Tracker

**Project**: 《大医精诚:破晓之剂》
**Status**: Operational (2026-10-02)

---

## Bug ID Format

`BUG-[NNNN]` (e.g., `BUG-0001`)

## Severity Levels

| Level | Description | Response Time |
|-------|-------------|---------------|
| **S1** | Crash / data loss / security | Immediate |
| **S2** | Feature broken / wrong behavior | Within sprint |
| **S3** | Minor issue / polish | Next sprint |
| **S4** | Cosmetic / nice-to-have | Backlog |

## Triage Cadence

- **S1/S2**: Daily triage
- **S3**: Weekly triage
- **S4**: Sprint planning
