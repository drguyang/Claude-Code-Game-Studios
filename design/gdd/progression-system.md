> **Author**: game-designer（本轮草案）

> **Layer**: Core · **Priority**: MVP（卷 1–3 竖直切片必需） · **Key deps**: 战斗系统、对话/论战系统、关卡系统、存档系统

## 1. 概述 Overview

成长系统是"新医学 = 把不同眼光拼成一副眼镜"的机制化身。玩家的成长不是数值膨胀，而是**图谱的连通度**：每位队员拥有一棵学科树，而全体共享一张《杏林汇通录》。图谱由三种成分构成——**还原树 Reductionist Tree**（往下钻：人→器官→组织→细胞→分子，越深越精确）、**整体树 Holistic Tree**（往上望：形→气→神，越高越宏观）、以及二者之间的**汇通图 Convergence Graph**。《杏林汇通录》的价值**只在跨树连线**：把一个还原节点与一个整体节点连起来，才生成一条「通」——一条新医学的合方技。**堆同类节点不给分，只有连"不同"才有。** 技能与认识**由剧情解锁**：由合适的人、在合适的时候交给玩家（技能即剧情）。

---

## 2. 玩家幻想 Player Fantasy

**"我在亲手缝一张网。"**

玩家要体验的，是一个人在两套互相敌视的知识之间**发现桥梁**的顿悟快感。当他第一次把"显微镜下看到的细菌"与"经方里说的伏邪"连成一条线，屏幕上一条新的「通」亮起——那不是学到一个技能，那是**养出了一双新眼睛**。

**玩家的动作只有一种：连线。** 个人树（还原树、整体树）的节点由剧情自动点亮——队伍走到哪里、遇见谁、想通了什么事，节点就长到哪里（技能即剧情）。玩家**不做数值分配、不管理 12 棵树**；他每卷唯一要做的决策只有一个：**"把哪两个已经亮起的、跨树的节点连起来？"** 这不是数值管理，这是**跨学科的联想**——正是"新医学"这道题本身。

成长的目标感来自**图谱越来越连**：开局只有半棵树（还原树）、孤零零的几个点；终局是一张纵横交错、横跨两棵树的网。而**失去**同样被机制承载——苏晚棠离队时，她的节点灰化、连线断开，图谱上留下一块刺目的空白，玩家亲手感受到"队伍的残缺"。

**情绪目标**：顿悟的快感（连线亮起）+ 协作的满足（共享图谱）+ 失去的重量（空白留白）。

## 3. 详细规则 Detailed Rules

### 3.1 图谱的三层结构

| 成分 | 归属 | 增长方向 | 视觉隐喻 | 数据宿主 |
|---|---|---|---|---|
| **还原树** | 个人（每位队员一棵） | 往下钻，越深越精确 | 根系 / 显微镜 | 队员属性 |
| **整体树** | 个人（每位队员一棵） | 往上望，越高越宏观 | 树冠 / 望气 | 队员属性 |
| **汇通图《杏林汇通录》** | **全体共享（单张）** | 横向连线，跨树 | 网 / 桥 | 队伍全局存档 |

> **关键规则**：还原树与整体树是**个人**成长（决定该队员的单方牌与被动），其节点**由剧情自动解锁**（技能即剧情，玩家不手动分配）；汇通图是**共享**成长（决定队伍可用的合方技），**是玩家唯一花费顿悟点（IP）的地方**。玩家的决策始终只有"连哪两个跨树节点"，不是"给谁加点"。

### 3.2 还原树（往下钻）

层级（由浅入深，共 5 层）：

| 层 | 名称 | 节点主题示例 | 解锁内容 |
|---|---|---|---|
| L1 | 人 Person | 整体观、体格 | 基础诊断 |
| L2 | 器官 Organ | 心 / 肺 / 肝 / 肾 / 脾 | 靶向单方、器官定位 |
| L3 | 组织 Tissue | 炎症、坏死、增生 | 局部干预、手术类牌 |
| L4 | 细胞 Cell | 细胞病变、免疫 | 高精度靶向 |
| L5 | 分子 Molecule | 微生物、化学、血清 | 特效药、疫苗类牌 |

- 节点来源：**由剧情 / 点拨自动解锁**（战斗中的"检验"行动、剧情中顾慎行等西医前辈、柳希白的点拨）——玩家不可见、不可花费 IP；节点的点亮与"技能即剧情"同步。

### 3.3 整体树（往上望）

层级（由低到高，共 3 层）：

| 层 | 名称 | 节点主题示例 | 解锁内容 |
|---|---|---|---|
| H1 | 形 Form | 望闻问切、四诊合参 | 诊断类牌、证候揭示 |
| H2 | 气 Qi | 阴阳、五行、气机升降 | 八法单方（汗吐下和温清消补） |
| H3 | 神 Spirit | 情志、心身、入静 | 心身类牌、心神纾解 |

- 节点来源：**由剧情 / 点拨自动解锁**（陆九针、清和、苏晚棠的点拨；四诊与内观的修习）——玩家不可见、不可花费 IP。

### 3.4 汇通图与「通」（连线规则）

- 汇通图的节点 = 队员们树上已点亮的节点（**聚合视图**）。
- **一条「通」= 一条跨树连线**，成立条件（**全部满足**）：
  1. 连线两端分属**还原树**与**整体树**（同类相连 → 无效，不生成「通」）；
  2. 两端节点共享至少一个**病种 / 证候标签**（如"热病""虚劳""疫"）；
  3. 玩家支付一次**顿悟事件**（剧情触发或主动消耗顿悟点，见 3.6）。
- **个人树节点自动就位**（见 3.1），因此**玩家唯一花费顿悟点（IP）的地方就是此处**：把两个已点亮的跨树节点连成一条「通」。
- 每条「通」生成一张**合方 / 合击牌**，可在战斗中使用，并享受汇通连线加成（见 `combat-system.md` 4.6）。
- **汇通率 ConvergenceRate** = 已生成「通」数 / 当前可达最大「通」数——是队伍成长的核心进度指标。

### 3.5 各队员在双树上的位置（职业框架）

> **归属为叙事层描述，不进机制**（本轮修订）：下表标注每位队员的**双树位置**，用于人物弧与剧情编排。**战斗层不再据此刻画战斗型**——单核 / 双核改由**牌池实际内容涌现判定**（见 `combat-system.md` §4.10.1），以免"为凑战斗型而硬派归属"。

| 队员 | 起点 | 双树位置 | 成长目标 |
|---|---|---|---|
| 沈砚之（主角） | 纯还原树 | 还原树深、整体树空 | 学会"望"上去；卷六获得**桥**能力 |
| 柳希白 | 还原树 | 还原树主脉（公卫 / 细菌） | 深钻 L5；习得"个体关怀"（向整体侧伸枝） |
| 陈九章 | 两树之间 | **桥（放大器）**——数理 / 系统 | 连接两树；"系统之眼" |
| 陆九针 | 整体树 | 整体树主脉（经方 / 气） | 习得"防疫 / 镜检"（向还原侧伸枝） |
| 清和 | 整体树最高处 | 整体树 H3（心身 / 神） | "入世即修行" |
| 苏晚棠 | **天生是桥** | 两树之间（家学即汇通派） | 全篇唯一开局即可连线的角色 |

> **两种"桥"须区分**（本轮修订，见 `combat-system.md` §4.10.1）：
> - **苏晚棠 = 临床桥**——她**针药皆通**，牌池内**同时**含还原牌与整体牌，是名副其实的"两侧供给源"。
> - **陈九章 = 催化桥（放大器）**——他通的是**数理 / 系统**这门**翻译语言**，而**非临床两侧**；他**不单独提供**还原或整体牌，只在**双核已成形**时放大合方 / 操控 CTB。故**他一人不能把队伍从单核变双核**。
> - **为何这样分**：`术数 / 数理` 是本作双认识论之间的**桥接语言**，不是与中西医并列的**第三棵树**（用户已裁定）。陈九章的墙也因此**不是**"中医式的说不清"，而是桥接者特有的"**以图为真**"（信模型甚于信眼前的人，见 `story-bible.md` §6）。
> - **主角沈砚之**卷六获得"桥"能力后归属随之变化——**归属须按卷次数据化，不得写死**（这也是战斗层改用牌池涌现判定的动机之一）。

### 3.6 顿悟点（图谱货币）与顿悟事件

- **顿悟点 Insight Points（IP）**：**生成「通」（跨树连线）的货币**——个人树节点自动解锁，不消耗 IP（见 3.1 / 4.1）。
- **获取途径**：战斗评级（见 combat 4.7）、论战胜利（卷八）、剧情顿悟、完成病例。
- **顿悟事件**：剧情中"想通一件事"的时刻——可**免费**生成一条「通」（若玩家已备好两端节点）；无剧情顿悟时，玩家可**主动**消耗 IP 连线（更贵，见 4.2）。
- **IP 的唯一去处**：连线。玩家不会在"给哪位队员加点"上花 IP——那是剧情的事。

### 3.7 技能 / 认识按剧情解锁表（技能即剧情）

> 原则：由合适的人、在合适的时候获得。前期允许单一流派通关（教学），中后期由剧情 + 敌人设计**渐进地**迫使双用（见下表"双用节奏"与 §3.9）。
> **双用节奏（渐进软墙，非突袭硬墙）**：卷四引入**强制性教学战**（单树只能削一半病邪，玩家在"赢"里第一次合方）→ 卷五**加强**（更多需跨树高效处理的证候）→ 卷六**彻底硬墙**（剧情 + 敌人设计迫使双核并用）。此前（序–卷三）为**教学期**，单一流派可通关。

| 卷 | 加入 / 事件 | 解锁的树或系统 | 解锁内容 |
|---|---|---|---|
| 序 · 卷一 | 沈砚之独自归国 | **仅还原树** | 检验、靶向、剂量（教学期：玩家亲身体验"只有一套眼睛"的局限） |
| 卷二 | **陆九针加入** | **整体树开放** | 经方、针灸、四诊、气机 |
| 卷三 | **柳希白加入** | 还原树深化 | 公卫 / 隔离 / 群体防治（战斗目标从"一个病人"扩到"一群人"） |
| 卷四 | **苏晚棠加入** | **汇通图开放** | 合方 / 汇通首次可用——第一个跨树连线技（她天生是桥）；**设强制性教学战**：病人同时有器质性病灶（需还原）与气机紊乱（需整体），单树只能削一半病邪 |
| 卷五 | **陈九章加入** | 两树之间 | 推演 / 布局（预判病邪走势、操控行动条 CTB）；**双用要求加强**：更多需跨树高效处理的证候 |
| 卷六 | **清和加入 + 主角"看见气"** | 整体树最高处 + 主角获得"桥" | 心身 / 神；**主角个人获得跨树能力**；**双核强制互用自此开始**（剧情 + 敌人设计迫使两套并用） |
| 卷七 | 苏晚棠归来 | 合方进阶 | 战地大规模救援的合方技 |
| 卷八 | 废止案 | 论战系统 | 「说服」线与图谱互通（说服 = 另一种"通"） |
| 卷九 | 大疫总攻 | 全系统综合 | 霍崇光"纯还原"终局战（须以"个体化、不可量化"的医道破其"数据节奏"） |
| 卷十 | 种子 | 图谱封笔 | 传薪：将最珍视的「通」标注为"传给后人" |

### 3.8 图谱封笔（卷十收束）

- 终局提供一次**传薪**：玩家回看整张图谱，将若干「通」标记为"传给后人"。
- 被标记的「通」进入"遗志节点"（永久、不可再成长），构成本作对"种子"主题的机制收束。

### 3.9 竖直切片示例：卷 1–3 的图谱如何成形

竖直切片（卷 1–3）要证明的是"从半棵树长出一张网"的第一步：

| 阶段 | 图谱状态 | 玩家体验 |
|---|---|---|
| 卷一开局 | 只有沈砚之的**还原树** L1–L2 数点，整体树全空，汇通图**零连线** | "我只会一套眼睛" |
| 卷二（陆九针加入） | 整体树开放：H1 形、H2 气 若干点；**首次出现可连的跨树节点对**（如"肺 Organ"×"气 Qi"，共享标签"咳喘"） | 第一次意识到"两边能连起来" |
| 卷二末（剧情顿悟） | 生成**第 1 条「通」**——免费，剧情触发（陆九针那句"证不是病"） | 连线亮起的顿悟快感 |
| 卷三（柳希白加入） | 还原树深化 L3–L4（组织/细胞，公卫标签）；整体树 H2 扩展 | 两条树同时变密，可连对数上升 |
| 卷三末 | 汇通率目标 **≥ 0.3**；至少 2–3 条「通」可供战斗 | 玩家第一次用**合方牌**打通一场"多人防疫"遭遇 |

> 若卷 1–3 结束玩家仍只练一棵树 → 卷三的"群体病患"遭遇会明显吃力（**最早的一道软墙**）。此后梯度递进：**卷四**设强制性教学战（单树只能削一半病邪，玩家在"赢"里学会合方）→ **卷五**加强 → **卷六**彻底硬墙。这验证了"教学期允许单一流派、中后期**渐进**强制双用"的节奏，而非在卷六突袭玩家。

## 4. 公式 Formulas

### 4.1 节点解锁节奏权重 NodeUnlockWeight（游戏内部；**玩家不可见、不可花费**）

个人树（还原树、整体树）节点**由剧情自动解锁**，不消耗玩家 IP（技能即剧情，见 3.1）。下式是**游戏内部**用于排布"剧情推进到某一步时，自动点亮哪个节点"的**节奏权重**——权重越高的节点，排在剧本中越靠后的解锁位：

```
NodeUnlockWeight = BaseWeight × DepthFactor × DistanceFactor
还原树： DepthFactor = 1.15 ^ depth      (depth = 1..5)
整体树： DepthFactor = 1.20 ^ height     (height = 1..3)
```

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| BaseWeight | float | 1–3 | 节点数据 | 基础解锁权重（越高 → 越靠后点亮） |
| depth / height | int | 1–5 / 1–3 | 节点层级 | 树深（越深/越高越晚） |
| DistanceFactor | float | 1.0–1.5 | 跨学科判定 | 同学科 1.0；跨学科 1.5 |

**示例**：还原树 L4（depth=4）一个跨学科节点，BaseWeight=2：`NodeUnlockWeight = 2 × 1.15⁴ × 1.5 = 2 × 1.749 × 1.5 ≈ 5.25`。
**预期输出范围**：1–12。
> **注意**：此值**不是价格**。玩家在任何界面都看不到它，也无法用它"买"节点——它只决定剧情自动解锁的先后节奏。玩家唯一花费 IP 的地方是 §4.2 的连线。

### 4.2 「通」的生成成本 LinkCost

```
剧情顿悟： LinkCost = 0（免费生成一条）
主动连线： LinkCost = (NodePower_A + NodePower_B) / Affinity
```

| 变量 | 范围 | 说明 |
|---|---|---|
| NodePower | 1–5 | 节点效力（层次 / 强度） |
| Affinity 亲缘系数 | 0.5–1.5 | 两学科语义亲缘度；越不相干越贵 |

**示例**：还原 L5（Power=5）与整体 H2（Power=4）主动相连，Affinity=0.8（跨得远）：`LinkCost = (5+4)/0.8 = 11.25 → 12 IP`。若是剧情顿悟则免费。
**预期输出范围**：主动连线 2–20 IP。

### 4.3 连线加成 LinkBonus（合方威力）

```
LinkBonus = (NodePower_A + NodePower_B) × Affinity × Teamwork
```

| 变量 | 范围 | 说明 |
|---|---|---|
| Affinity | 0.5–1.5 | 同上 |
| Teamwork 协作系数 | 0.8–1.2 | 两端队员同队时长 / 羁绊（聚散影响） |

**示例**：Power=5,4、Affinity=1.2（语义近）、Teamwork=1.1 → `LinkBonus = 9 × 1.2 × 1.1 ≈ 11.9`。此值喂入 combat 4.6 的 S_link。

### 4.4 汇通率 ConvergenceRate

```
ConvergenceRate = LinkCount_生成 / LinkCount_可达最大
```

| 变量 | 说明 |
|---|---|
| LinkCount_生成 | 已生成的「通」数 |
| LinkCount_可达最大 | 当前已点亮节点能构成的、满足标签匹配的跨树连线总数 |

**示例**：已生成 9 条「通」，当前节点结构最多可达 20 条 → `ConvergenceRate = 0.45`。
**预期输出范围**：[0, 1]；竖直切片目标 ≥ 0.3。

### 4.5 顿悟点奖励（战斗 / 论战产出）

```
IP_gain = IP_base × Rating × (1 + 首次通关加成)
```

| 变量 | 范围 | 说明 |
|---|---|---|
| IP_base | 2–8 | 遭遇基础值（随关卡难度） |
| Rating | 0–1 | 战斗评级（见 combat 4.7） |
| 首次通关加成 | 0 或 0.5 | 首通 +50% |

**示例**：IP_base=5，Rating=0.8，首通 → `IP_gain = 5 × 0.8 × 1.5 = 6 IP`。

### 4.6 顿悟点经济表（全篇产出 vs 消耗）

回答一个 §4.5 未回答的问题：**十卷总计，玩家预期获得多少 IP？又要花掉多少？** 目标——**每卷末保留少量结余（约 0.5–1.5 条连线未点，留给下卷初），既无大量盈余、也无赤字**。

> **前提**：汇通图**卷四**才开放（见 3.7），故卷一–三**不产出 IP**（机制尚未开放，避免无效囤积）。平均 `IP_gain ≈ 6`（=IP_base 5 × Rating 0.8 × 首通 1.5，与 4.5 一致）；`LinkCost` 随节点 Power 增长而逐卷抬升。

| 卷 | 遭遇数（战斗/论战/病例） | 平均IP_gain | 该卷产出 | 新增「通」数 | 平均LinkCost | 该卷消耗 | 期末结余 |
|---|---|---|---|---|---|---|---|
| 一 | — | — | 0 | — | — | 0 | 0（机制未开放） |
| 二 | — | — | 0 | — | — | 0 | 0（机制未开放） |
| 三 | — | — | 0 | — | — | 0 | 0（机制未开放） |
| 四 | 4 | 6 | 24 | 3 | 6 | 18 | **6** |
| 五 | 5 | 6 | 30 | 4 | 7 | 28 | **8** |
| 六 | 6 | 6 | 36 | 4 | 8 | 32 | **12** |
| 七 | 6 | 6 | 36 | 4 | 9 | 36 | **12** |
| 八 | 4 | 6 | 24 | 3 | 10 | 30 | **6** |
| 九 | 7 | 6 | 42 | 4 | 11 | 44 | **4** |

| **合计** | **34** | — | **204** | **23** | — | **198** | 净 +6 |

**校验**：总产出 204 ≈ 总消耗 198，净结余 +6 IP（约 0.6 条连线）——图谱在终局**几乎被连满**，却始终留有"还想再连一条"的余味，与"种子/留白"的主题一致。全篇约生成 **23 条「通」**，即 23 张合方牌。

**为何卷一–三不产出**：教学期（卷 1–3）汇通图未开放，玩家无处花 IP；若此时发放会造成无效囤积、稀释卷四"第一次连线"的分量。IP 从"玩家第一次能连线的那一刻"开始有意义。

> 全部数值位于**外部配置**，随纸面/数字原型测试调整；上表为初版预算，供关卡与战斗配平参照。

### 4.7 离队 / 归队 / 殉职三态（节点效能）

与 `combat-system.md` §5"依赖她的合方牌与连线**全部灰化不可用**"对齐，三态统一定义如下：

```
离队期间（卷六→七）：EffectivePower = 0
                     （节点完全灰化；依赖她的连线全部断开、合方牌不可用）
归队过渡期（卷七起）：EffectivePower = NodePower × K_reunion(t)
                     K_reunion(t) = min(1.0, 0.5 + 0.1 × t)   （t = 归队后经历的事件/战斗数，0..5）
殉职（卷九）：       EffectivePower = NodePower
                     （节点凝固为"遗志"，Power 冻结、永久不可再成长，但可作合方的一端）
```

| 变量 | 类型 | 范围 | 说明 |
|---|---|---|---|
| NodePower | int | 1–5 | 节点本征效力 |
| K_reunion(t) | float | 0.5 → 1.0 | 归队磨合系数：归队即有半力，之后每经历一个事件 +0.1，第 5 个事件起满力 |

**示例**：苏晚棠离队（卷六）→ 其节点 `EffectivePower = 0`、连线断开、合方牌不可用；卷七归队首战 `K_reunion(0)=0.5`，第 5 个事件后回到 `1.0`（"归来需要重新磨合"）；卷九殉职 → 节点凝固为"遗志"，`EffectivePower = NodePower`，仍可作合方的一端，但不再提供新成长。

## 5. 边界情况 Edge Cases

| 场景 | 会发生什么 | 理由 |
|---|---|---|
| 只练一棵树（如只走还原） | 卷 1–3 可通关；**卷四强制教学战**（单树只能削一半病邪）→ 卷五加强 → **卷六起彻底硬墙**（含心身/无形病机），单树无法通关 | 用**渐进**机制复现"只有一套眼睛看不好病"，避免突袭式挫败 |
| 苏晚棠**离队**（卷六→七） | 其节点**完全灰化，EffectivePower = 0**、连线**断开**、合方牌**不可用**；共享图谱出现空白 | "失去"的机制具象化（与 combat §5 一致） |
| 苏晚棠**归队**（卷七起） | 节点从 `K_reunion(0)=0.5` 起步，每经历一个事件 +0.1，第 5 个事件起回到 1.0（重新磨合） | "归来需要时间"；也给玩家缓冲 |
| 苏晚棠**殉职**（卷九） | 节点凝固为"遗志"，Power **冻结**、不可再成长，但**可作合方一端** | 死亡的不可逆 |
| 队友离队但节点支撑着唯一「通」 | 该「通」**失效**，合方牌不可用；若玩家无备份则战力骤降 | 强制队伍完整性 |
| 两节点对同一证候给出**矛盾**治法 | 连线**失败**，生成「未决 Undecided」态；须用论战系统或剧情顿悟化解 | 认识论冲突的真实写照 |
| 顿悟点不足 | 无法解锁 / 连线；玩家只能靠剧情顿悟免费连线 | 保证剧情推进不被卡死 |
| 主动连线选了两个"同类"节点 | 系统**拒绝**生成「通」；提示"同类不连，须跨树" | 核心规则不可绕过 |
| 连线后队员离队削弱了节点 | 已生成「通」的效力按**当前节点 Power** 重算（可能下降），不删除 | 关系是动态的 |
| 剧情顿悟时两端节点尚未备齐 | 顿悟事件**挂起**，待节点备齐后自动生成该「通」 | 不浪费剧情机会 |
| 卷十"传薪"标记后想反悔 | 不可撤销；标记前有**二次确认** | 收束的仪式感 |
| 存档点在连线动画中途 | 连线在**结算后**才落盘；中途退出视为未连线 | 状态一致性 |
| IP 数值溢出 / 负数 | 下限截断为 0；上限校验（配置 > 9999 拒绝） | 数值安全 |

| 对话 / 论战系统 | 双向 | 论战是 IP 来源与「说服型通」；本系统提供论战可用的认识论节点 |
| 关卡系统 | **它依赖本系统** | 关卡按解锁表门控可用技能；卷六硬墙依赖图谱结构 |
| 状态 / 证候系统 | 双向 | 节点标签与证候标签**共享同一标签体系**，是连线匹配的前提 |

## 7. 调参旋钮 Tuning Knobs

| 旋钮 | 当前值 | 安全范围 | 增大影响 | 减小影响 |
|---|---|---|---|---|
| 节点解锁权重 BaseWeight（**内部，玩家不可见**） | 1–3 | 1–5 | 自动解锁节奏变慢、节点靠后点亮 | 解锁节奏加快、图谱早熟 |
| 还原树深度系数 | 1.15 | 1.05–1.30 | 深层更贵、鼓励广度 | 深层易得、专精流可玩 |
| 整体树高度系数 | 1.20 | 1.10–1.35 | H3 极难 | H3 易得、"神"来得太早 |
| 跨学科系数 DistanceFactor | 1.5 | 1.1–2.0 | 逼玩家权衡、跨科更贵 | 跨科廉价、连线泛滥 |
| 亲缘系数 Affinity 区间 | 0.5–1.5 | 0.3–2.0 | 语义远的连线更贵 | 连线更自由 |
| 协作系数 Teamwork 区间 | 0.8–1.2 | 0.6–1.5 | 羁绊影响战力更重 | 羁绊影响变轻 |
| 汇通连线加成（/线） | 0.15 | 0.10–0.20 | 合方牌支配性↑ | 合方牌趋普通 |
| IP_base（遭遇） | 2–8 | 1–12 | 成长加速 | 成长放缓、更依赖剧情顿悟 |
| IP 首通加成 | 0.5 | 0–1.0 | 鼓励重玩 / 首通 | 无首通激励 |
| 离队 / 归队节点效能 | 离队=0；归队 0.5→1.0 | 离队 0–0.3；归队起点 0.3–0.7 | 失去更致残、磨合更久 | 失去更无感、归来更快 |
| 竖直切片汇通率目标 | ≥0.3 | 0.2–0.5 | 要求玩家更早连线 | 门槛更低 |
| 双用软墙梯度 | 卷四软→卷五强→卷六硬 | 更缓（卷五起才软）–更陡（卷三即强） | 教学强度大、更逼双用 | 更宽容、可能绕过双用（违背设计意图） |

**必须数据驱动**：以上全部值位于外部配置，不得硬编码。

## 8. 验收标准 Acceptance Criteria

- [ ] 还原树节点只能与整体树节点生成「通」；**同类相连被拒绝并给出提示**——可测试。
- [ ] **个人树节点全部由剧情自动解锁；玩家 UI 中不存在"消耗 IP 解锁个人节点"的入口**——可测试。
- [ ] 节点解锁权重符合 4.1（**内部值、玩家不可见**；示例：BaseWeight=2, depth=4, 跨科 → 5.25）。
- [ ] 剧情顿悟连线免费；主动连线按 4.2 公式扣 IP（示例 (5+4)/0.8→12 IP）。
- [ ] 合方牌加成 S_link 落在 [1.0, 1.6]，且随 LinkCount、Affinity 单调递增。
- [ ] 汇通率 = 已生成 / 可达最大，取值 [0,1]。
- [ ] 战斗评级喂入 IP：IP_gain = IP_base × Rating × (1+首通)，示例 (5, 0.8, 首通) → 6 IP。
- [ ] **顿悟点经济自洽**：按 4.6 预算，每卷末结余落在 0.5–1.5 条连线区间，全篇净结余不超 +16 IP——逐卷可核算。
- [ ] 卷一仅还原树可用；卷二开放整体树；卷四开放汇通图；卷六主角获得"桥"——按解锁表逐卷验证。
- [ ] **双用软墙梯度存在**：卷四强制教学战"单树只能削一半病邪"可复现；卷五更吃力；**卷六起单树存档无法通关**（逐卷回归测试）。
- [ ] 苏晚棠离队时其节点**完全灰化（EffectivePower = 0）**、相关「通」失效、合方牌不可用；归队后按 `K_reunion` 从 0.5 逐步恢复；殉职后凝固为遗志（可作一端、不可成长）——三态逐一可测试。
- [ ] 矛盾节点的连线失败生成「未决」态，且存在化解路径（论战 / 剧情顿悟）。
- [ ] 顿悟点不足时**不会卡死**：剧情顿悟仍可推进。
- [ ] 连线后的节点被削弱时，「通」效力按当前 Power 重算而非删除。
- [ ] 卷十传薪标记有二次确认，标记后不可撤销。
- [ ] 图谱结构、IP、遗志节点可完整存档 / 读档（往返一致）。
- [ ] 所有数值来自外部配置，实现中无硬编码。
- [ ] 性能：打开图谱 UI（≤ 200 节点）在 **16ms** 内完成布局与渲染（60fps 帧预算内）。
