## 4. 为什么到不了 `CaseOpened`(根因,代码面)

`unity/Assets/Gameplay.Presentation/Interaction/ModalGate.cs:84-92`:

```csharp
public bool Accept(in InteractIntent intent)
{
    if (_armed.IsArmed) return false;   // 方向①:10 的 Armed 期 ⇒ 压制
    if (_modal.IsOpen) return false;    // 方向②:42 的任一模态摊开 ⇒ 拒收
    return true;
}
```

**方向①** 解释了 `E` 无效:病人一进急危,`EmergencyChannel` 就 `Armed`,`E` 全被拒(这是 F-4.2「模态期按下的交互 = 没发生」的设计,不是 bug)。
**方向②** 未验证(本次无法判定当时是否有 42 的模态摊开)。

**「跳过」为何无反应 = 未定位**,三种可能都未被排除:
① 列表未获焦(`Return` 走的是 UI Toolkit 的 Submit,焦点不在行上就不触发);
② 回调已接线但 `EmergencyChannel.SkipAction` 在当前态返回 false(`EmergencyCandidateList._onSkipSubmit` 的接线在组合根,本次未验证);
③ 跳过成功了但病人仍处急危 ⇒ **立刻重新 Armed**(屏重新出现,肉眼与「没反应」同形)。

⇒ 这一条**只能记「真包里观察不到跳过生效」**,不能记「跳过是坏的」。
