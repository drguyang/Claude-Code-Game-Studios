## HUD Philosophy

**拟物纸面，信息极简。** HUD 不是浮在屏幕上的数字仪表盘——它是角色随身携带的纸面/器物的数字化投射。所有信息以「纸上墨迹」「铜器刻度」「卷轴展开」的视觉形态呈现，与游戏世界的物理质感一致（承 Art Bible 水墨 × 黄铜方向）。

核心原则：**HUD 不报状态，只留痕迹。** 玩家可以通过纸面上的痕迹推断自己的状态，但 HUD 本身不显示「生命值条」「耐力条」等传统 HUD 元素。

## Information Architecture

### Full Information Inventory

| 信息 | 载体 | 呈现形式 | 更新频率 |
|------|------|----------|----------|
| 当前疾病 / 目标 | 脉案（Casebook） | 纸页展开，病名墨迹（AI 材质层 + UXML `<Label>` 叠字） | 进入诊断时 |
| 体征读数（脉象 / 舌象 / 呼吸） | 诊脉台 / 听诊器 HUD | 铜器刻度盘 + 指针 / 波形纸带 | 实时 |
| 药材库存 | 出诊箱 | 抽屉式格子，实物图标 | 变化时 |
| 已用针数 / 手法次数 | 针囊 / 手法计数器 | 铜筹计数 / 墨点标记 | 动作完成后 |
| 当前地图 / 目标位置 | 纸质地图 | 卷轴展开，墨点标记 | 进入世界时 |
| 时间 / 天气 | 怀表 / 窗景 | 铜怀表指针 / 纸窗透光 | 持续 |
| 存档位 | 存档档 | 卷轴封条 | 进入存档界面 |
| 教程提示 | 教学纸近景（PaperCloseup48） | 纸页放大，手写批注 | 首次触发 |

### Categorization

- **诊断态 HUD**（脉案 + 体征读数）：最高优先级，占屏幕中央偏上
- **世界态 HUD**（地图 + 时间）：低干扰，右下角最小化
- **库存 HUD**（出诊箱）：按需展开，不常驻
- **模态 HUD**（存档 / 教学）：**近乎独占全屏的浮层**（世界不再可见 / 输入冻结），无其他 HUD 元素
  > ⚠️ **2026-10-03 订正**:原文作「独占全屏」。教学纸近景经用户裁定 = **占屏 60%**(见本件 §6),
  > **非全屏** —— 故「独占全屏」对本行**不成立**。但本行撒的是**整类**(存档 + 教学**界面** + 教学**纸近景**),
  > 该整类的共同点确为「世界不可见 + 无其他 HUD」⇒ 改为「近乎独占全屏的浮层」。**逐件占比归各 spec**,
  > 分类行**不承载具体尺寸**(否则即第二真源)。存档/教学界面侧未见 60% 类数字,如需收紧另行登记。

## HUD Elements

### 1. 脉案（Casebook）— 诊断态核心

- **形态**: 线装书展开，左页「四诊摘要」，右页「辨证记录」
- **交互**: 翻页（鼠标滚轮 / 手柄 LT/RT），书签跳转
- **信息**: 当前病名、四诊要点、已识模式、鉴别诊断清单
- **焦点导航**: 书签位 = 焦点导航停靠点（ADR-013 焦点单栈门）

### 2. 诊脉台 / 听诊器读数

- **脉象**: 铜器刻度盘（三指对应寸/关/尺），指针偏转 = 浮/中/沉
- **呼吸**: 波形纸带滚动（两纹：通带 + 噪声底，F-44.7 同构）
- **舌象**: 色卡比对（纸面色块，非数字）
- **视觉风格**: 黄铜质感 + 宣纸背景，无发光、无 HDR 高亮

### 3. 出诊箱（库存）

- **形态**: 抽屉式展开，每格 = 一种药材/工具
- **图标**: 实物线描（金银花、针具、绷带…），非抽象符号
- **数量**: 铜筹计数（小铜柱堆叠，数量 = 筹数）
- **焦点导航**: 四向格子移动，A 确认选用

### 4. 纸质地图

- **形态**: 卷轴展开，墨点标记当前位置与目标
- **交互**: 滚轮缩放，拖拽平移
- **信息**: 生态区边界（墨线）、POI 标记（印章式）、路径（虚线）

### 5. 怀表 / 时间

- **形态**: 铜怀表悬浮（左上），指针 = 当前时辰
- **天气**: 窗景效果（右上角半透明纸窗，透光 = 晴/阴/雨）

### 6. 教学纸近景（PaperCloseup48）

- **形态**: **纸页浮层放大,占屏 60%**，墨迹文字 + 水墨插图（AI 材质层 + UXML `<Label>` 叠字）
  > ✅ **2026-10-03 已裁(用户)**:教学纸近景 = **60% 浮层**(世界仍可见),**非**独占全屏。
  > 本行与 `paper-closeup.md:13/19/53` 口径一致,保留 60%;`:39` 分类行已同批改为「近乎独占全屏的浮层」。
- **交互**: 任意键 / A 键翻页，B 键跳过
- **触发**: 首次接触新机制时自动展开

## Dynamic Behaviors

| 行为 | 触发条件 | 动画 |
|------|----------|------|
| 脉案展开 | 进入诊断态 | 书页翻开展开（0.3s ease-out） |
| 脉案收起 | 退出诊断态 / 切换档位 | 合书（0.2s ease-in） |
| 出诊箱展开 | 打开库存键 | 抽屉滑出（0.25s） |
| 体征异常提示 | 读数超出正常范围 | 铜器边缘泛红（0.5s 脉冲，非闪烁） |
| 教学纸展开 | 首次触发 | 纸页从屏幕边缘滑入 + 放大（0.4s） |
| 地图展开 | 打开地图键 | 卷轴横向展开（0.3s） |

## Platform & Input Variants

| 输入 | 导航方式 | 备注 |
|------|----------|------|
| Keyboard/Mouse | 鼠标直接点选 + 滚轮翻页 | 主输入 |
| Gamepad | 焦点导航（L1/R1 切换 HUD 层，方向键移动焦点，A 确认） | 无指针，全焦点 |

## Accessibility

- **文字对比度**: 墨字 × 宣纸底 **≥ 7:1**(~~WCAG AA 4.5:1~~)
  > ⚠️ **2026-10-03 订正**:原文写 `≥4.5:1(WCAG AA)`。**AB-4 已于 2026-09-21 提档至 ≥7:1**
  > (`art-bible.md §4.5` 底线 / `accessibility-requirements.md:87,186` / 5 份 per-screen spec 均已是 7:1)。
  > 本行是**全库最后一处**残留 4.5:1 的现行条款;照原文实现 ⇒ 低视力 / 色觉档下**不达标**(7:1 ≈ WCAG AAA 正文)。
  > 同理:**纸纹是纹理不是纯色**,实测须按**纹理最亮像素**取对比(承 accessibility 该件口径)
- **色觉安全**: 体征异常 = 红 + 边框加粗（不依赖颜色区分）
- **焦点指示器**: 黄铜边框高亮（当前焦点元素 2px 黄铜色边框）
- **简化模式**: 可关闭纸面纹理（纯色底 + 无水墨装饰），降低视觉噪声
