### 1.2 卷一推进链（仙剑式：剧情段 → 战斗 → 剧情段）★ 前置条件全表

本卷是**一条单向链**：每一段的前置条件是**上一段已完成**，玩家不能跳段、不能倒序。推动力来自"剧情逼你出手"——与《仙剑奇侠传》"一段剧情、一场战斗、再一段剧情"同构。

**层级**：每段有两类前置——**章层**（`quest-system.md` §3.8：`chapterDone`）与**节拍/场景层**（`level-system.md` §4.2：`revealed` / `flagSet` / `heardWall` / `eventSeen` / `poolHas`）。**两层的条件词汇都不得含 `bondGE`**（羁绊阈值唯一真源在 `dialogue-system.md` §3.7）。

**钉死口径**：

1. **章 A 全程无战斗** —— 它是 story-bible 定义的"叙事引入，无可失败"；但其**章末仍有前置条件**（A-7 必须经 A-5 拿到遗稿），保证伏笔 #1 在卷一**必然埋下**（`level-system.md` §5"依赖已埋伏笔"的反向保证）。
2. **章 B 的入场前置 = 章 A 完成 ∧ 年末节点** —— 这是"章末关卡的前置条件"在**章层**的落点；玩家在卷一末**必须**已经历序章全部七段剧情，才谈得上"母亲的病"这场下马威。
3. **A-6 的门槛挂在"找到遗稿"上，不是挂在"探索"上** —— 遗稿是**主线场景**（不是探索节点），故不可错过；母语茶、巷口看诊等其余内容是**探索节点**（可选，见 §2.5）。
4. **链上无一个 `bondGE`** —— 卷一无同伴，羁绊系统此时尚未有对象；"信任"只以 `TrustDelta` 数值喂 #7，不作为推进门槛。
5. **A-2 是"旁观遭遇"，不是一场普通场景** —— 它按 `level-system.md` §3.2.1 的 `Encounter { kind: 旁观 }` 配置，行为规则见 `combat-system.md` §3.10：**玩家零输入、不结算评级与 IP、不累积耐药 / 紊乱、UI 不显示任何条与数值**。它**不进入 CTB**，故**不计入 `Progress`**；也因此**不改变"章 A 全程无战斗"**这一条——**该论证在 §2.3 收束段**（"A-2 的旁观遭遇不改变这一条"），遭遇的逐节拍配置见 **§2.4**。

### 1.3 教学弧："看不见"的三级递进

| 级 | 玩家处境 | 机制表现 | 情感落点 |
|---|---|---|---|
| **一级：没有可问的问题** | 序章 A-2 **旁观遭遇**：看老郎中给镇上妇人**走完一整遍"问 → 判 → 治"**（玩家零输入；**不给机制解释、不弹数值、不显示任何条**） | 玩家只"看见"中医问的是"怕冷还是怕热"，以及**三味药下去，人当场就松快了**——却**说不出为什么好** | 埋下模糊参照系："**原来要这样问**"＋"**原来这样就能治**"——**只给现象，不给原理**（见 §2.4） |
| **二级：有眼睛，看不见** | 章 B 治段——无四诊牌，`虚实` 轴未证 → 「补液·支持」落 `M=0.7`（若探到 `ex_v1_m_4` 则 `M=1.5`）；`寒热` 未证时「退热剂」亦落 `M=0.7` | 打得慢、被 `drain` 拖、Rating 吃 **单核 −0.20** | "我赢了，可我不知道我为什么赢" |
| **三级：看不见，却已经伤了她** | 章 B 治段——**若玩家先在探索节点拿到「寒」线索**，再打退热剂 | `revealed(寒热)` → 悖证 `M = 0.0`、错治 `−12` 正气、即时角色独白 | **"我知道她是寒，我还是打反了。"**（见 §6 D1） |

> **为什么把"悖证"放在三级**：本作核心承诺是**"失误是选择的结果，不是运气的结果"**（`combat-system.md` §4.3），而 `§4.3` 明文规定**悖证只在轴已揭示时发生**。故卷一的教训**不是**"猜错了被罚"，而是"**已知信息摆在眼前，你仍按旧习惯出手**"——这是**选择**，可归因、可预判。**未探玩家**不吃悖证，改吃"拖 + 评级"的钝刀。两条路都疼，疼法不同（见 §3.5 三分支）。

### 3.5.1 治段内心独白（叙事层，不影响机制）

> **设计意图**：卷一治段机制上**刻意单调**（1 人、2 张牌、3–4 回合），但**叙事层不能也单调**——否则玩家感到的不是"缺了一只眼睛"的憋屈，而是"这游戏好无聊"。故用**沈砚之的内心独白**给每一回合注入情感重量：**不新增任何机制**，不改 `M` / `ΔE` / `Rating` / 牌池 / 节拍链 / flag。

**触发规则**：

- 每次**出牌后**触发对应独白（退热剂按 **分支**；**补液·支持按使用次数** 首 / 二 / 三，其独白不随分支变）。
- 病机**每次出手**（第 3 回合起，每回合 `−10`）触发"病机出手独白"。
- **收束时**按分支触发对应独白。
- 独白为**纯文本**：不弹数值、不影响评级、不产 flag。
- **玩家可在设置中关闭**（默认开启）；关闭后战斗流程**不变**。

**文风约束**（承 `story-bible.md` §10.2 沈砚之初期腔调）：

- **短**：每段不超过 3 句。
- **碎**：是念头，不是分析；允许省略号、允许自问自答。
- **裂**：逻辑感还在，但开始出现"不对""为什么""我说不清"。
- **人称**：独白**一律第一人称**（"我"），**不得**混入第二人称"你"。须与**叙述层**区分——本卷的**叙述**（场景旁白）对玩家说话，用第二人称"你"（如"你推开门……"）；**独白**是沈砚之的心声，用"我"。二者**不得在同一段里混用**。
  > **★ 本轮修订（2026-09-12 复核）**：原 §3.5.1 ③ 与 `design/dialogue/vol-01-mother.md` §4.3 / §4.4 曾把"你听见 / 你盯着"混进独白；已统一为"我"（见 ③）。
- **中医术语**：独白**不用整体论的诊断词**。**三处豁免**（均以"他从探索节点拿到的**物证**"为据，非习得的**理论**）：① **乙 / 丙分支**的「**寒**」（两分支的 `revealed(寒热) = 寒` 来自**同一批节点物证** `ex_v1_m_1` / `ex_v1_m_3`）；② **丙分支收束**的「**温**」（他已持寒的物证，"缺一味温的药"是自然延伸）；③ 甲分支的「**虚**」为**口语义**（"人更虚了" = 虚弱），**不算**八纲术语。
