## Summary

53 是**世界对医者判断的回响**。它订阅病例流,结算一次诊疗的**后果**:
疫区被压住还是扩散、病人活下来还是走了、在场的人如何反应。

**边界已裁(2026-09-14,`systems-index.md` §2 注)**:53 = **水龙头**(单病例的**即时**后果);
31 声誉 = **蓄水池**(跨病例的**累积**声望)。**P0 的 53 自足** —— 它发后果事件,
**P0 没有订阅者时,后果由在场的人当场反应兑现**;P1a 起 31 接上,开始累加。

**53 是唯一判定「处置对不对」的系统。** 37 **只记账,不判对错**(AC-37-31);
**正确性只存在于 53 的输入侧**。这是本作「判断为骨」的兑现点:
世界不会当场告诉你错了 —— 它**延迟地、不可归因地**回应你。

> **⚠️ 2026-09-19 核心修订(用户裁定 [A] 双轴拆开,OQ-53-4)**:53 **不判生死**。
> 病人活 / 走 = **9 病程的结算**(53 只读,永不上裁决面);53 的裁量**只有回响轴**
> —— 判断误差的**物质痕迹**(后遗 / 复现 / 试药史)。「误诊自愈」= **无物质痕迹 ⇒ 不回响**
> (误诊判 BAD 而病人无恙 = **世界撒谎**;自愈判 GOOD = **系统撒谎** —— 双轴是唯一诚实解)。

> **⚠️ 53 的两条硬约束来自 37 的接口义务**(AC-37-25 / AC-37-28),
> 本节**必须承接** —— 否则支柱四的措辞订正(「37 沉默 ≠ 世界沉默」)失去落点。

## Overview

53 是**世界的回声系统**。它的存在回答一个本作最核心的问题:
**如果我判断错了,会发生什么?** 答案**不是「扣分」**,而是**世界变了**。

**53 的三层职责**:

1. **结算**(消费病例流 + 判断记录 + 处置记录)⇒ 一个**后果判定**;
2. **落为世界变化**(疫区状态 / 在场的人反应);
3. **发出后果事件**(`ConsequenceResolved` 等)—— **P0 零订阅者不算失败**(承 ADR-019 §七「水龙头」模型)。

**53 的 P0 范围 = 病人本人**(`systems-index.md:369`):
家属 / 村落的实体是 **36 NPC(P1a)** —— **P0 不为 53 提前 36**(`:154` / `:489`)。

**53 是「后果先在病人身上可见,再谈聚合」的兑现**(`:565`)——
**后果必须先在病人身上可见,再谈聚合**。这是本节的**第一原则**。

## Player Fantasy

**「世界没有打分,但它记得。」**

- **延迟的回响** —— 你结案时**什么都没有发生**。回响在**几步之后**到来:
  一个病人没再出现、一条街上的人看你的眼神变了、疫区的火被压住或烧得更旺。
  **你无法把它归因到某一次判断**(AC-37-25)。**这正是幻想的核心** ——
  医生**永远无法确定**自己做对了没有,只能从世界的脸色里猜。
- **不可归因 ≠ 不可关联** —— 53 **绝不**说「因为你在 3 号病例上误诊,所以……」。
  没有因果提示、没有高亮、没有「影响」浮层。**但世界必须留证据** ——
  **「可复盘缝」**:治好又回来的病人带着后遗症再遇(你记得自己的脉案,系统不必指)。
  **系统永不确认,但世界可被「误读为可归因」**(2026-09-19 修订,承 OQ-53-4 双轴)。
- **后果是人,不是数** —— 幻想要求在病人与在场者身上**看见**后果,
  **不是**在面板上看见一个信任值。**若处理成「后果只是一个数字」,核心承诺就退化**(`:565`)。

> **⚠️ 本 GDD 是「判断层好不好玩」的兑现点之一。** 51 遥测的 `AC-51-B3` 明说
> 「回答判断层到底好不好玩」;53 提供的正是**那个可被观测的东西**。

## Detailed Rules

### 规则一:水龙头 —— P0 自足,不等 31

| | 53 医疗后果(P0) | 31 声誉(P1a) |
| --- | --- | --- |
| **模型** | **水龙头** —— 单病例的即时后果 | **蓄水池** —— 跨病例累积 |
| **时域** | 一次诊疗的结算 | 长期声望 |
| **P0 状态** | **自足**(在场的人当场反应) | 未写 |
| **接口** | 53 **发**后果事件 | 31 **订阅** 53 |

> **53 不需要知道 31 存在**(承 `systems-index.md:150`)。**P0 的后果由在场的人当场反应兑现**
> —— 若无 36(村落实体),则表现为**在场病人 / 已有 NPC 的反应**。
> **53 不是 31 的前置;31 是 53 的下游。**

### 规则二:53 是唯一判「对错」的系统(AC-37-31 的 53 侧)

**37 只写记录,不产生 correctness 判定值。** 正确性**只**存在于 53 的输入侧:

| 材料 | 来源 | 53 用它做什么 |
| --- | --- | --- |
| `CaseClosed` / `PatternRecognized` | 病例流 | **触发**一次后果结算 |
| **判断记录**(病名 / 置信度) | 37 | 判断的**内容** |
| **处置记录**(哪些处置动作发生) | 病史流 | 判断的**执行** |
| **改写史** | 37(呈现态) | ⚠️ **53 绝不消费**(见规则五) |

> **⚠️ 53 与 8 的 S-8.3 性质 2 一致**:改写是**玩家的思考过程**,不是**错误次数**。
> `AC-37-20`(BLOCKING)明文:`改写次数`**绝不**出现在 53 的任何输入契约里。

> **🛡️ 支柱二锚点(2026-09-19 修订,gd#8 闭合)**:病人「走了」**永远呈现为世界的无慈悲
> (瘟疫杀人),不是玩家杀** —— 53 不产出「玩家致死」。致死只走 **9 的对因手柄门**;
> 与「见死不救杀不掉人」(仅约束敌人)的口径对齐。**53 的裁量只有回响轴,不碰生死**。

> **⚠️ 2026-09-19 修订(用户裁定 [A] 双轴拆开)**:触发集**不含死亡** —— 死亡由 **9 病程**
> 结算(`:383` 表)。**「病人死亡但病例仍开」不触发 53**;53 的回响键 = **判断误差的物质痕迹**
> (后遗 / 复现 / 试药史),死亡本身是 9 的结算结果。

### 规则三:后果结算 = 确定性函数(掷骰可重构)

**后果不是随机的,也不是脚本的** —— 它是**确定性函数**:

```
Consequence(case) = Resolve( 判断记录, 处置记录, 病程投影@Tick(结案), U )
U = SplitMix64( WorldSeed, "case-salt", salted_key )     // 承 ADR-008 §五
```

| 输入 | 来源 | 可重构? |
| --- | --- | --- |
| 判断记录 | 37(病例流) | ✅ 事件流 |
| 处置记录 | 病史流 | ✅ 事件流 |
| 病程投影 | 9(截至结案 tick) | ✅ 事件流重算 |
| `U` | `SplitMix64(WorldSeed, "case-salt", salted_key)` | ✅ 盐派生自 `WorldSeed`(ADR-008 §五) |

> **为什么 53 必须重算 `case-salt` 而不是读 37 的结果**:37 侧的类型面**无 correctness 字段**
> (AC-37-31),53 **自己**以 `salted_key`(承 37 二轮修订:`PatternRecognizedPayload` **含** `salted_key`
> **不含**裸 `disease_id`)匹配。**这是 53 为唯一裁量者的实现后果。**

> **⚠️ 2026-09-19 修订(用户裁定 [A] 双轴 + OQ-53-9 [A] 形状本轮定)**:
> **Judge() 的真值源登记** —— `P` = 判断记录(病名 / 置信度)· `C` = 处置适切性
> (哪些处置动作发生)· `D` = 9 病程投影(`treatable_by` 命中)。**真值不是 correctness
> 字段**(承 AC-37-31,37 无此字段);**误诊自愈示例** = `P` 不命中 `treatable_by` 而 `D`
> 痊愈 ⇒ **无物质痕迹 ⇒ 不回响**(世界不撒谎)。**试药史判据(用户裁定 [A])**:
> 试药序 = **同一 patient 的连续 `DrugTreatmentApplied` 序列、无 `JudgmentRecorded` 支撑**;
> 数值归平衡轮。

### 规则四:按 `Tick` 聚合,不按到达序(AC-37-28 的 53 侧 —— **前向悬垂引用**)

> **⚠️ 这是 37 交给 53 的硬接口义务**(`case-system.md:720-725`)。
> `PatternRecognized` 的**锚事件**可能**先于**其证据(`CaseClosed`)**到达流中**
> —— 因为跨流全序键是 `(Tick, StreamPriority, Patient, Seq)`,世界级事件用哨兵 `Patient = -1`,
> **它排列在病人事件之前**。

**裁定**:53 **必须按 `Tick` 而非流内到达序**取事件。

```
Aggregate(stream) = fold over events sorted by (Tick, StreamPriority, Patient, Seq)
                    // 不是按 arrival order
```

> **若 53 按流顺序流式消费,会出现未定义行为**(`case-system.md:721`)——
> 读到「图样已触发」时,触发它的 `CaseClosed` 还没出现。
> **53 的 GDD 承接此条 = AC-37-28 的载体**,由 **AC-53-04** 守。

### 规则五:53 绝不消费改写次数(AC-37-20 的 53 侧)

**53 的入向契约是闭集,改写次数不在其中。**

```
53.Inputs = { CaseClosed, PatternRecognized, JudgmentRecorded, CareApplied, 病程投影 }
53.Inputs ∌ 改写次数          // 绝不
```

> **实现判据**:53 的全部入向 DTO / 订阅载荷经**递归**反射扫描,**无任何**
> `rewrite_count` / `revision_count` / `edit_history_size` 类字段(AC-37-20 + AC-53-05)。
> **改写 = 思考**;**用思考次数扣分 = 惩罚玩家的谨慎 = 反支柱一**。

### 规则六:回响必须延迟且不可归因(AC-37-25 的 53 侧)

**53 落为世界变化时,两条硬约束**(`case-system.md:307-309`):

1. **不在结案瞬间同一 tick 发生** —— 后果**延迟**。
   (具体等待量归 53 的 GDD —— **见 OQ-53-2**;37 只登记这条义务。)
2. **不指向那三份脉案** —— 高亮病例 / 给地点提示 / 指名 **一律禁止**。

> **为什么**:37 的「守口如瓶」是**类型层**的(`disease_id` 不进 DTO);
> 但**感知层**上世界**确实沉默不了**(`case-system.md:305`「不沉默,且这是设计的」)。
> **唯一的收口方式 = 让回响延迟且不可归因** —— 玩家**看得见世界变了**,
> 但**永远无法把变化钉在某一次判断上**。
> **这既是支柱四的兑现,也是三案链「拼图样」的保护**(若可归因,拼图就变成系统替玩家拼好了)。

### 规则七:后果先在病人身上可见(第一原则)

**P0 的后果必须先在病人本人身上可见,再谈聚合**(`:565`)。

| 后果层 | P0 | 载体 |
| --- | --- | --- |
| **病人本人的结局** | ✅ **P0** | 9(存活 / 走了 / `DeathCandidate`) |
| **当场在场者的反应** | ✅ **P0** | 已有 NPC + 13 病人 AI 的表现(**P0 内容保证 ≥1 在场者**,2026-09-19 修订) |
| **家属 / 村落的反应** | ❌ P1a | 36 NPC 与村落 |
| **长期声誉** | ❌ P1a | 31 |
| **病人本人结局(生死)** | ✅ **P0** | **9 结算,53 只读** —— 双轴之结局轴(2026-09-19 修订) |

> **⚠️ 这是「后果不是数字」的机制化保证** —— 若 P0 就上「村落信任值」,
> 后果会退化为一个数字(`:565` 的警告)。**P0 宁可窄,不可退化。**
> **🔴 2026-09-19 修订(CD 部分驳回 gd#4)**:病人层**永远有载体**(9);
> 可为空的**只有在场者层** —— **AC-53-09 已加「P0 内容保证 ≥1 在场者」前置**。

## Formulas

> **本节公式在整数 / Q16.16 定点域**(承 ADR-005 / ADR-006)。
> **数值(权重 / 阈值 / 延迟量)归用户调** —— 本节只给**形状 + 变量表 + 调参旋钮**。

### F-53.1 · 后果判定(确定性纯函数)

```
Outcome(case) = Judge( P, C, D, U )
  P = 判断记录投影@结案       // Pattern / DiseaseId(经 salted_key)
  C = 处置记录投影@结案       // 病史流
  D = 病程投影@Tick(结案)     // 9 重算
  U = SplitMix64( WorldSeed, "case-salt", salted_key )
```

| 变量 | 类型 | 来源 | 说明 |
| --- | --- | --- | --- |
| `salted_key` | u64 | 病例流 `PatternRecognizedPayload` | **含 `salted_key` 不含裸 `disease_id`**(37 二轮订正) |
| `U` | `Fix` ∈ `[0,1)` | 派生 | 盐 = `WorldSeed` 派生(ADR-008 §五) |
| `Outcome(case)` | 枚举 | — | **取值归本节**(见下),P0 **不聚合** |

> **⚠️ 2026-09-19 修订(用户裁定 [A] 双轴)**:`Outcome` 是**枚举,不是分值**(P0):
>
> ```
> # 结局轴 —— 呈在病人身上(9 结算,53 只读)
> PatientLives / PatientLoses
> # 回响轴 —— 呈在世界状态上(53 裁量)
> Residual(后遗) / Recurrence(复现) / TrialHistory(试药史)
> ```
>
> **两轴语义**:结局轴 = 生死(由 9 病程结算,53 不上裁决面);
> 回响轴 = **判断误差的物质痕迹**(后遗 / 复现 / 试药史)。**误诊自愈示例**:
> `P` 不命中 `treatable_by` 而 `D` 痊愈 ⇒ **无物质痕迹 ⇒ 不回响** —— 世界不撒谎。
> **P0 刻意不给 `Outcome` 一个连续分值** —— 分值 = 数字 = 违反「后果是人不是数」(规则七)。
> **枚举 → 世界变化的映射**是 53 的**语义**;具体世界变化的实现归呈现层。
>
> **Judge() 真值源登记(全关键)**:`P` = 判断记录(病名 / 置信度)·
> `C` = **处置适切性**(哪些处置动作发生)· `D` = 9 病程投影(`treatable_by` 命中)。
> **真值不是 correctness 字段**(承 AC-37-31,37 无此字段)。判据:
> **有物质痕迹(后遗 / 复现 / 试药史) ⇒ 回响;无痕迹 ⇒ 不回响**。

### F-53.2 · 延迟量(回响的时间偏移)

```
DelayTicks(outcome) = DelayTable[outcome]     // ⚠️ 未定,见 OQ-53-2
EmitTick(outcome) = Tick( CaseClosed ) + DelayTicks(outcome)
```

| 变量 | 归属 | 状态 |
| --- | --- | --- |
| `DelayTable[]` | 本节 | ⚠️ **未裁** —— 用户调参轮 |
| `EmitTick` | — | 后果事件的发出 tick(**严格 > 结案 tick**,AC-37-25 ①) |

> **`DelayTicks > 0` 是硬约束**(AC-37-25 ①)—— `= 0` 会让后果与结案同 tick,可被归因。

### F-53.3 · 世界级后果(⚠️ **P1a** —— 2026-09-19 修订,归 OQ-53-3 / 复评门)

```
RegionOutcome(region, t) = F( 该 region 的已结案件投影, V )
V = SplitMix64( WorldSeed, "consequence", region_id, t_bucket )   // 形状
```

> **⚠️ P1a**,不在 P0 关键路径 —— P0 只落病人本人(规则七)。
> `RegionOutcome` **不是** per-case `Outcome` 的取值(2026-09-19 修订:枚举混层已消解,
> `RegionHeld` / `RegionSpreads` 移出 P0 枚举)。`t_bucket` 定义归 **OQ-53-3**(实现期 / P1a)。
> **「三案链全结案但玩家未认出」→ 禁止玩家通过「不归纳」免疫世界级后果**(2026-09-19 修订):
> 疫区扩散**不只**在 `PatternRecognized` 触发后结算 —— 归 P1a 时另立判据,
> **53 逐例结算的后果事件集是 RegionOutcome 的唯一输入**,`PatternRecognized` 是**加速器不是开关**。
