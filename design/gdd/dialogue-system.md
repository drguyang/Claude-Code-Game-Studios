## 1. 概述 Overview

对话系统把"**外行问内行**"做成可玩的动作（`story-bible.md` §12.3）。它的形态是**双声内心**：在场的同伴对眼前情境**随时插话**，以"**心声**"的形式在主角心里浮现——玩家**选择听谁**，就等于选择用谁的学科去看这家人、这个病。本作与《极乐迪斯科》式"技能之音"的根本不同在于：**这些声音的主人身体就在你身边**——同一句"这个证是寒的"，既是陆九针**说出口的话**，也是沈砚之**心里响起的解读**。一句话，两个声道。

系统最重要的三条主张：其一，**听谁 = 学谁的眼睛**——入心某条学科心声，就产出一枚该学科的"点拨碎片"，喂给医道图谱，让成长沿着你选择的视角生长；其二，**你能不能听到，取决于两把门**——**知识门**（在场者得**看得见**：有没有这门学科的视野）与**关系门**（在场者得**肯说**：羁绊够不够深），两门皆**确定性、零随机**；其三，**深层解读随队伍构成自然变深**——人间层恒在、临床层因主角常驻而恒在（合起来正是"**大众 + 医学生**"这对**双主**受众），而**论道层**只有带上"**多一门学科的人**"才会开。于是"**缺了眼，就永远听不见**"——单镜型在对话层的自然复现，**无需任何特判**。

> **快速索引** — 心声槽位 = min(可发声同伴数, 3) · 每节拍入心 1 条 · 知识门（同伴视野）→ 关系门（羁绊 50 / 75，表层 0）· **叙述层**（人间恒 + 临床恒 + 论道需异门视野）⊥ **同伴心声门**（临床回声/证候/心身/推演）· 对话**零随机** · 说服基元 手段×听众 → 喂论战。

## 2. 玩家幻想 Player Fantasy

**"我身边有人，我心里也有他们。"**

玩家要体验的，是一个医者**不再独自面对一个病人**的踏实，与随之而来的**选择的重量**。当周慧兰捂着胸口咳嗽，屏幕右侧浮起几条**同伴**的心声：陆九针说"证在里、在寒"，柳希白冷冷补一句"退热没用，得看是不是传给了孩子"。**这些声音都不属于主角**——他只是那个**听见**的人；他自己"先退热、别问那么多"的念头，是从他**自己的叙述**里冒出来的（他留洋西医的那一面），**不在这些声音之列**。**你只能深入听一条同伴的心声。** 你选谁，这一节拍就由谁的眼睛讲下去——而这一节拍产出的那枚碎片，会让你的图谱朝那个方向长一寸。

这份踏实还有另一面：**听不到的东西，是真实的缺席**。队伍里若没有一个"能看见气"的人，那么无论病人心里藏了多深的执念，**那些心声永远不会响**——不是被锁住、不是显示成灰色，而是**根本不存在于你的世界**。玩家第一次意识到这件事，往往是在一场"药都下对了、人却不见好"的病例之后：他翻遍对话记录，找不到任何一句话指向"她心里有事"，因为**他从来没带过那只能听见心事的人**。这正是本作的核心命题——**每个人在自己的专科之外都是外行**——最安静的形态。

而"关系门"给了这份缺席一个**可以努力的方向**：有些话，队友**欲言又止**。你在屏幕上看见他张了张嘴，话说了一半——"我父亲当年，也是……"然后没了。你**知道那里有东西**，但**你要先成为他信得过的人**。到羁绊攒够、他真正把心结说出来的那一次，响起的不是一条普通心声，而是一个人的**墙**被推倒的声音。

**情绪目标**：被同伴包住的踏实（有人在）· 择听的专注（听谁即学谁）· 沉默的恐慌（缺眼即不可见）· 破墙的震动（他终于肯说）。

## 3. 详细规则 Detailed Rules

### 3.1 系统定位与数据边界

| 上游 / 下游系统 | 从本系统取用 | 本系统不负责 |
|---|---|---|
| 队伍系统 `party-system.md` | 在场同伴名单（`roster`）、识证能力（气感/检验/心身）、羁绊矩阵、聚散状态 | 能力数值本身、羁绊的**存储**与 `Teamwork` 折算 |
| 证候系统 `status-syndrome.md` | 病机/病种的**标签**（供"学科视野"与点拨碎片打标） | 医学判定、证候向量、四诊准确性 |
| 成长系统 `progression-system.md` | 图谱节点解锁接口、顿悟事件接口 | 图谱结构、连线成本、「通」的生成 |
| 关卡 / 遭遇系统 | 当前情境（在场者、对象、可用话题） | 遭遇编排、胜负条件 |
| 论战系统（#8，待建） | **说服基元**（手段 × 听众 → 匹配系数） | 完整论战的胜负、会众模型 |
| 存档系统 | 已听心声、已产碎片、对话 flag | 序列化实现 |

> **边界声明（沿用 `party-system.md` §3.1）**：本系统**不做医学判定**。某人"说不说得出正确的证"不取决于对话系统，而取决于 `status-syndrome.md` 的诊法规则；对话系统只声明"**这个情境需要哪门视野**"，再交给证候系统去 gate。**解读是别人的事，本系统只负责把解读送到玩家耳边。**

### 3.2 双声道模型：心声 vs 发问

一名在场同伴对每个情境有**两个声道**，二者是不同的东西：

| 声道 | 定义 | 观众 | 玩家动作 | 主要产物 |
|---|---|---|---|---|
| **心声 Chorus** | 该同伴**用他的学科**对情境的**即时解读**（他心里响起的、也是主角听见的） | 主角内心（一人） | **听**（择一"入心"） | 点拨碎片（该学科） |
| **发问 Ask** | 玩家**主动**向该同伴提问，对方**说出口**作答（"外行问内行"） | 全队（其他同伴可接话） | **问** | 更深点拨 / 撬开"关系门" |

> **为何同伴身体在场，却仍叫"心声"**：本作把《极乐迪斯科》"技能之音"的**内在性**与仙剑式**队伍在场**的**关系性**缝在一起——同一个人的话，**既是他说出口的，也是主角心里响起的**。这一"双声道"正是主题的机制化身：**理解别人，靠的既是他愿意说，也是你愿意用他的眼睛看。** 因此：**心声无需对方"同意"即可浮现**（只要他有那门视野），而**发问必须先有羁绊**（他得愿意答）。

### 3.3 对话结构：场景 → 节拍 → 心声

- **对话场景 Scene**：一段对话的最小完整单元（一次看诊、一次夜谈、一场会面）。由若干**节拍 Beat** 串成。
- **节拍 Beat**：一次"情境更新"（新证候、新对白、新对象）后，系统**重新计算并浮现**可供入心的心声。**一节拍内只能入心 1 条心声**（见 §3.4）。
- **入心 Focus**：玩家选定一条心声深入 → 该心声展开（给出其学科视角的完整解读）+ 产出其产物 → 本节拍结束，进入下一节拍（情境可能随之更新：新症状被说出、新 flag 被点亮）。

**情境的输入**（决定这一节拍有哪些心声可能出现）：在场的对象与病机标签、当前剧情 flag、已揭示事实、各同伴的视野与羁绊。**这些输入全部是确定性的**——同样的队伍、同样的 flag、同样的节拍，**永远浮现同样的心声**（见 §4.4）。

### 3.4 心声带宽 Chorus Bandwidth

- **同时浮现的心声槽位 `ChorusSlots = min(可发声同伴数, 3)`**，其中 `可发声同伴数` 为**除主角本人外**、`roster ∈ {在队, 归队}`、且**至少携带一门学科视野**的在场同伴数（**与 `formation` 无关**，见下）；**本节拍真正有可浮现心声者才占槽**（§4.1 / §4.4）。
- **每节拍仅 1 条可"入心"**（`FocusPerBeat = 1`）。未入心的心声以**旁注**呈现——玩家能看见"他们还说别的"，但那句话**不展开、不产出**（一次呼吸的张力，不是可刷的资源）。**"旁注"是本节拍未入心声（含对立对的未选项）的统一存续态**，可在后续节拍再浮现（§3.6 / §5）。
- **为何设带宽 3**：竖直切片仅 4 人（含主角），槽位恒够；**后卷在场 6 人时（卷七起）**，主角最多同时"听见"3 条——复现"注意力有限"。既非限制可选人数（心声仍属全队），也非固定 4（那不是"耳边低语"的体感）。
- **心声以 `roster` 为准，与 `formation` 无关**：**人还在队里，他的心声就该在耳边**，哪怕这一关没把他编入出战。编成（`formation`）是**战斗**的事，不该决定主角**心里还有没有这个人**。
  > 与 `combat-system.md` / `party-system.md` 的**边界说明**：战斗的合方牌要求 `formation=出战`（`party-system.md` §3.6 / §4.7），但**对话不要求**。二者不冲突——一个管"牌要有人发"，一个管"人走了心里才空"。

### 3.5 两套镜头：叙述三层 ⊥ 同伴心声门

"能看见多深"由**两套互不占槽**的东西决定。此前把二者混进一张表，会引出"人间/临床到底谁提供"的自相矛盾（**本轮修订**）：**叙述层**决定**主角讲得多深**，**心声门**决定**同伴说得出什么**。

**表 A —— 叙述三层（主角的叙述深度，不占心声槽、不产同伴心声）**

| 叙述层 | 面向 | 开启条件 | 说明 |
|---|---|---|---|
| **人间层** (Common) | 大众 | **恒开** | 用故事、隐喻、人情理解。主角"普通人"的那一面。**永不缺席**。 |
| **临床层** (Clinical) | 医学生 | **恒开** | 真实症状、鉴别、思路。主角"留洋西医"的那一面。**永不缺席**。 |
| **论道层** (Dao) | 资深者 | **开启的「异门」同伴视野 ≥ 1**（异门定义见 §4.2；**不含**与主角同门的"临床回声"） | 学派分歧与哲学。**"带上另一种眼睛"才开**。 |

**表 B —— 同伴心声门（决定哪门"心声"可浮现）**

| 视野 Lens | 学科 | 开启条件（在场同伴 `roster ∈ {在队,归队}` 满足其一） | 竖直切片中谁提供 |
|---|---|---|---|
| **临床回声** (Clinical) | 还原论 | `sense.screen > 0` | 柳希白（3，卷三起）/ 陆九针（1，卷三镜检后）/ 陈九章（1，卷五起） |
| **证候** (Qi) | 整体论 | `sense.qi > 0` | 陆九针（卷二起）/ 苏晚棠（卷四起） |
| **心身** (Psyche) | 禅医 | `sense.psyche > 0` | 陆九针（`psyche=1`，卷二起）/ 清和（卷六起）/ 苏晚棠（卷七起） |
| **推演** (System) | 术数 / 数理 | 陈九章在场（`pc_chen`，专属） | 陈九章（卷五起） |

> **口径**：视野的 gate **完全依赖 `party-system.md` §3.3 / §3.5 的 `sense` 三值**，本系统不新增任何属性、不改任何数值。**"视野"是既有能力在对话层的投影**——`sense.screen>0` 在战斗里让你认出带菌者，在对话里让你**听得见"数据"的话**。同一把钥匙，两扇门。
> **为何主角的临床是"叙述"而非"临床回声"心声**：主角沈砚之自己 `screen=2`，若给他也开一条"临床心声"，等于把《极乐迪斯科》的"技能之音"原样搬来（**主角的学科替玩家出声**），本作"身体在场的同伴"这一立身之本（§3.2）就被抽掉了。他的临床视野**照样在**——只是以**他自己的叙述口吻**出现，而非以"另一个声音"出现。**主角不出声，是本系统与"技能之音"的分界线。**

**三条后果（与单镜型同构，无需特判）**：

1. **缺某门视野 → 该学科的心声永不浮现**（不是灰化、不是锁住，而是**不存在**）。例：纯还原队伍（无陆/苏/清）→ **证候 / 心身心声全沉默** → 心身类病机的"心事"线索**永远读不到**。
2. **心声相左须两门同伴视野俱在**——陆九针"证在寒"与柳希白"先隔离"的对立，只有**同时**有证候与临床回声视野时才成立（见 §3.6）。**只带一套眼睛的队伍，连"争论"都不会发生**。
3. **推演视野只揭示确定数据**：陈九章的心声给出病机**传变阈值 / 病机速度**（配置写死值，见 `status-syndrome.md` §4.4），**不含随机**、不预测未来（只陈述已知常量）。

### 3.6 心声相左 Contrasting Chorus

- 当两条可浮现的心声**学科立场相悖**（由配置标注 `opposes` 对）时，系统**成对呈现**，以"——"连接，视觉上并置。
- **对立是"可操作"的，不只是张力**：玩家**择一入心** → 被选中者成为本节拍的**主解读**（产其学科碎片、推进其视角）；**未被选中的一条**不消失，而转为**旁注（并列对的延续态）**留在界面角落；若后续节拍情境变化（新事实被说出、flag 翻转），旁注可**被重新浮现**。
- **对立心声不改变客观真相**：两条解读可能一"对"一"错"，但**系统如实呈现两个人的真心**——如 `story-bible.md` §10.2 所定，**霍崇光"说的话几乎全是对的"，这才是他可怕的地方**。对错由后续病例与剧情揭示，**不由对话系统当场裁决**。
- **对立对由两名同伴构成**（主角不出声，见 §3.5）：竖直切片示例对——陆九针「证候」心声（"这是寒证，当温"）× 柳希白「临床回声」心声（"寒热未明，先测体温再说，别急着温"）；柳希白「临床回声·公卫」心声（"先隔离，别传给家里人"）× 苏晚棠「证候」心声（"先问清他心里怕什么"）。

### 3.7 关系门：羁绊阈值 Bond Gate

知识门决定"**看不看得见**"，关系门决定"**肯不肯说**"。阈值**对齐 `party-system.md` §3.8 的名分档**，但**只取 50 / 75 两道分界**（**不使用 25**）；**表层心声的门槛 = 0**（知识门即够）。不新增数值：

> **与 `party-system.md` §3.8 四档（25 / 50 / 75）的关系（口径钉死）**：party 的名分档是**四档**（陌路 < 25 / 同袍 25–49 / 知己 50–74 / 生死之交 75+），本系统**只借用其中的 50 / 75 两刀**。**25 这一刀在对话层不充当任何门槛**——故 **陌路与同袍在对话层完全等价**（都只能听到 `surface`，均须 Bond ≥ 50 才及 `mid`）。这不是另立一套阈值，而是**同一套档位的一个子集**；实现时只需读 `Bond` 与 {50, 75} 比较，**无需判 25**。

| 羁绊档 | Bond | 该同伴可入心的心声层级 | 内容语义 |
|---|---|---|---|
| **陌路 / 同袍** | < 50 | **表层** `surface` | 他对**处境**的直接看法（学科解读、就事论事） |
| **知己** | ≥ 50 | **中层** `mid` | 他的**挣扎与自我怀疑**（开始暴露立场背后的东西） |
| **生死之交** | ≥ 75 | **心结** `wall` | 他的**局限之墙**的根（撬开即触发破墙剧情节点，见 `story-bible.md` §6 人物卡） |

- **判定顺序：先知识门，后关系门。**
  1. **先判知识门**（结构性）：情境是否**有人看得见**？**无人有对应视野 → 该层心声根本不生成**（沉默、不报错、不提示）。
  2. **再判关系门**（可变性）：有视野后，该同伴是否**肯说**？**未达阈值 → 心声以「欲言又止」态浮现**——玩家**看得见"他有话"**，但**不可入心**；系统只给一句关系提示（如"（陆九针看了你一眼，没再往下说。）"），**不消耗节拍、可日后重来**。达阈值 → 可入心。
- **为何先知识后关系**：知识门是**结构性的、剧情解锁的、不可刷的**；关系门是**可变的、可经营的**。先判结构性——因为**知识门不开时，关系再高也读不到**（没有那门眼睛，就没有那句解读可听）。这条顺序守住了"缺眼"主题：**羁绊不能替代视野**。
- **发问（Ask）与关系门**：当一条心声处于「欲言又止」态，玩家可对该同伴**发问**——**若 Bond ≥ 该层阈值**，对方**说出口**（心声解锁为可入心，消耗本节拍名额）；**若 Bond 不足**，发问得到一句婉拒（"……以后再说吧。"），**不消耗节拍**。**发问是"亲手撬关系门"的动作**，但它撬不动知识门——**没有视野，发问也问不出那条解读**（问题会被答成别的东西）。

### 3.8 三层解读 × 队伍构成 Depth by Composition

`story-bible.md` §10.5 的**三层解读**即 §3.5 **表 A 的叙述三层**——由队伍构成决定**主角讲多深**（与 `party-system.md`"带对的人"同构）：

| 层 | 面向 | 开启条件 | 说明 |
|---|---|---|---|
| **人间层** (Common) | 大众 | **恒开** | 用故事、隐喻、人情理解。**永不缺席**。 |
| **临床层** (Clinical) | 医学生 | **恒开**（主角沈砚之常驻，临床视野恒开） | 给真实症状、鉴别、思路。 |
| **论道层** (Dao) | 资深者 | **异门同伴视野 ≥1**（异门 = {证候, 心身, 推演}，唯一符号定义见 §4.2）；**任一带"桥"角色在场即开**（苏晚棠→证候、陈九章→推演、陆九针→证候/心身） | 点出学派分歧与哲学。 |

> **为何人间与临床"恒开"**：主角是**留洋西医**（临床）也是**这场故事的普通人**（人间）——他一个人就同时带来了**双主并重**的两位受众所站的位置。**双主恒被服务**，是设计上的保证；**论道层**才是"**带上对的人**才开"的那一层，与"资深者的乐趣需要经营"一致（`story-bible.md` §2.5）。
> **"桥"角色的口径**：苏晚棠 = 临床桥（携带证候视野）、陈九章 = 催化桥（携带推演视野）——**他们各自携带一门「异门」视野，故任一带上即开论道层**。注意这是**对话层**的判定，与"陈九章一人不能把单核编成变双核"（**战斗层**，`party-system.md` §3.9 / `combat-system.md` §4.10.1）**不冲突**：一个管"能不能聊到论道的深度"，一个管"牌池是不是两侧俱在"。

- **竖直切片的演进**：卷一（沈独行）→ **仅人间 + 临床**（"我只会一套眼睛"）；卷二（+陆九针）→ **+证候 +心身 → 论道层开**（第一次听见"证不是病"）；卷三（+柳希白）→ 临床·公卫深挖；卷四（+苏晚棠）→ 证候深化 + 临床桥。

### 3.9 说服基元 Persuasion Primitive（喂论战系统 #8）

对话系统提供一套**确定性的"说服基元"**，供后卷**论战系统**（独立 GDD，#8，Vertical Slice）在其上放大。**完整论战不在本轮范围。**

- **四手段 × 四听众**（取自 `story-bible.md` 卷五）：手段 = **证据 / 逻辑 / 案例 / 人心**；听众 = **学者 / 官员 / 病人 / 民众**。
- **匹配表**（与 `combat-system.md` §4.3 的 `M` **同值族、同「悖」位精神**，取值同族 `{1.5, 1.0, 0.7, 0.5, 0.0}`；**非结构同构**——`M` 的 0.0 由"轴已揭示"决定，本表的 0.0 由**听众类型**决定）：

| 手段 ＼ 听众 | 学者 | 官员 | 病人 | 民众 |
|---|---|---|---|---|
| **证据** Evidence | **1.5** | 1.0 | 0.7 | 0.5 |
| **逻辑** Logic | **1.5** | 1.0 | 0.5 | **0.0** |
| **案例** Case | 0.5 | 0.7 | **1.5** | 1.0 |
| **人心** Heart | 0.5 | 0.5 | 1.0 | **1.5** |

- **语义与 `M` 一一对应**：**1.5 对证**（正中此听众的心）、**1.0 相关**、**0.7 未证**（听众将信将疑）、**0.5 无关**（听不进去）、**0.0 悖**（**反效果：激怒 / 失言**，见下）。
- **0.0 是"悖"位，不是"无效"位**：全表**仅一处 0.0**——**「逻辑」对「民众」**。这把 `story-bible.md` 卷五"**赢了道理、输了人心**"写成了一条**数据**：用逻辑碾压学者（1.5）时若也对民众如法炮制，**民众会翻脸**（0.0）。玩家会**亲眼看见**自己最漂亮的一击换来的是一次离席。
- **0.0 有"主动负向落点"，比 `M` 的"被动伤正"更贴"悖"字**：`M=0.0`（悖证）在战斗里表现为**主动伤正气**（`combat-system.md` §4.3b）；对应的对话落点是**主动扣 Reception**——命中 0.0 的一次发言**不计入 Σ 说服力**，并触发 `Reception(a) −= P_penalty`（默认 0.3，见 §4.6）。两条都把"最漂亮的一击"兑成**可见的负收益**。**注意**：这是"同值族、同「悖」位**精神**"，**不是**结构同构——判据来源不同（见上）。
- **本基元不掷骰、不判胜负**：它只输出每个"（手段, 听众）"的**确定性匹配系数**；汇聚成"听众反应"（§4.6）。**谁被听见**（卷八的胜负）由论战系统在其上定义。

### 3.11 与"问诊"的关系（守住唯一随机源）

- **对话系统零随机**。本作**唯一**的随机源是**问诊的 90% 准确率**（`status-syndrome.md` §4.7），且它只发生在**战斗 / 病例关**的四诊流程里。

## 4. 公式 Formulas

### 4.1 心声槽位 ChorusSlots

```
可发声同伴数 = |{ c : c.roster ∈ {在队,归队} ∧ c ≠ pc_shen ∧ c 携带 ≥1 门学科视野 }|
           其中"携带≥1 门学科视野" = ( qi>0 ∨ psyche>0 ∨ screen>0 ∨ id=pc_chen )
ChorusSlots  = min(可发声同伴数, 3)                    // 带宽上限 Bandwidth = 3
实际浮现条数  = min( |Surfaced(beat)| , ChorusSlots )   // 无声可发者不占槽；槽位分配见 §4.4
FocusPerBeat = 1                                       // 每节拍仅 1 条可入心
```

| 变量 | 范围 | 说明 |
|---|---|---|
| 可发声同伴数 | 0–5 | 除主角外、**携带至少一门学科视野**的在场同伴；**与 `formation` 无关** |
| Bandwidth | 3（配置常量） | 同时浮现槽位上限 |
| 实际浮现条数 | 0–3 | 仅计入本节拍**真正有可浮现心声**的同伴（避免"无声可发者占槽"）；**可入心者优先占槽，§4.4** |

**示例**：卷一（沈独行）→ 可发声 0 → 无心声（主角"心里还没有别人"，与 §3.9 竖直切片一致）；卷三（沈/陆/柳）→ 可发声 2（陆 `qi=3`、柳 `screen=3`）→ `ChorusSlots = 2`；卷四（沈/陆/柳/苏）→ 可发声 3 → `ChorusSlots = 3`；卷七（沈/陆/柳/陈/清 + 苏归队）→ 可发声 5 → `ChorusSlots = min(5,3) = 3`（需择 3 人听）。
**预期输出范围**：0–3。

### 4.2 叙述层与同伴心声门开闭 LensOpen

```
异门视野 ALTERNATE = { 证候, 心身, 推演 }              // 唯一符号定义：异门 = 与主角"不同门"的学科
                                                       //   临床回声与主角同门，不算分歧，故不在其内
叙述层 NarrativeTier(beat):
    人间 = true ; 临床 = true                          // 主角的两面，恒开
    论道 = ( |{ L ∈ ALTERNATE : LensOpen(L) }| ≥ 1 )    // 开启任一「异门」同伴视野即开
同伴心声门 LensOpen(L) = ∃ c : c.roster ∈ {在队,归队} ∧ Provides(c, L)
Provides(c, 临床回声) = (c.stats.sense.screen > 0)
Provides(c, 证候)     = (c.stats.sense.qi     > 0)
Provides(c, 心身)     = (c.stats.sense.psyche > 0)
Provides(c, 推演)     = (c.id = pc_chen)
// 主角沈砚之 不参与 Provides 的心声判定——他不出声（见 §3.5）
```

| 变量 | 类型 | 说明 |
|---|---|---|
| Provides(c, L) | bool | 该同伴是否携带视野 L（完全由 `party-system.md` §3.3 `sense` 三值决定） |
| 叙述层 人间 / 临床 | — | 恒开（主角的叙述，**不占心声槽**） |
| 同伴心声门 | — | 仅由**除主角外**的在场同伴提供 |

**示例**：卷一仅沈砚之 → 叙述层 {人间, 临床}，**同伴心声视野 0**（无心声）；卷二 +陆九针（`qi=3, psyche=1`）→ 同伴心声视野 {证候, 心身} → **异门视野 ≥1 → 论道层开**；若只加柳希白（仅"临床回声"，与主角同门）→ **论道层不开**。
**预期输出范围**：叙述层 2–3；同伴心声视野数 0–4。

### 4.3 入心判定 Focus Resolution

```
可入心(心声 x) ⟺ LensOpen(x.lens) ∧ Bond(主角, x.speaker) ≥ Threshold(x.tier)
Threshold: surface = 0   （知识门即够）
           mid     = 50
           wall    = 75
```

| 变量 | 范围 | 说明 |
|---|---|---|
| tier | surface / mid / wall | 心声层级（见 §3.7） |
| 未达阈值 | — | 心声以「欲言又止」浮现，**可日后重来、不消耗节拍** |

**示例**：陆九针 `mid` 层心声（Bond=40 < 50）→ 欲言又止；Bond 升到 50 后同一情境可入心。

### 4.4 心声浮现的确定性 Deterministic Chorus

```
浮现集 Surfaced(beat) = 每位在场同伴至多一条 —— 取其在 Lines(beat) 中
                        「LensOpen(x.lens) 成立」且「层级 x.tier 最高」的一条
                        （层级最高使"他心里有事"优先暴露；无声可发者不入集）
可入心集 Focusable(beat) = { x ∈ Surfaced : x.tier = surface ∨ Bond(主角, x.speaker) ≥ Threshold(x.tier) }
欲言又止集 Held(beat)    = { x ∈ Surfaced : x.tier ≠ surface ∧ Bond(主角, x.speaker) < Threshold(x.tier) }
槽位分配（确定序）：先取 Focusable（按 speaker.joinVolume 升序）前 min(|Focusable|, ChorusSlots) 条；
                   不足 ChorusSlots 时，再用 Held（按 joinVolume 升序）补足剩余槽位。
FocusPerBeat = 1
```

- **占槽优先级：可入心者优先**（`Focusable` 先占槽，`Held` 只补余额）。这条防的是"全员羁绊不足时，3 条「欲言又止」把本该可入心的心声挤出屏幕"——**玩家永远能看见"谁真的能听"**，欲言又止不会喧宾夺主。

- **三集互斥且完备**：`Surfaced = Focusable ⊎ Held`。`Focusable` **可入心**；`Held` **可见但不可入心**（呈现为「欲言又止」，§3.7）。**关系门只决定 `Focusable / Held` 的归属，不决定是否 `Surfaced`**——这正是"看得见他有话、却还听不进去"的机制。
- **同输入必同输出**：给定（在场名单, 羁绊值, 已揭示事实, flag），浮现的心声集合与顺序**完全确定**——无种子、无抖动（对比 `status-syndrome.md` §4.7 的问诊，那是**唯一**允许含随机的地方）。
- **示例**：Bond(沈,陆)=40，陆的 `mid` 层心声在本节拍存在 → 入 `Surfaced` 与 `Held` → **「欲言又止」**；Bond 升至 50 → 同一情境该条移入 `Focusable`（与 §8 验收一致）。

### 4.5 说服基元系数 PrimitiveCoefficient

```
P(手段 m, 听众 a) = Table[m][a]        // 见 §3.9 的 4×4 表；取值 ∈ {0.0, 0.5, 0.7, 1.0, 1.5}
```

**示例**：`P(逻辑, 学者) = 1.5`（对证）；`P(逻辑, 民众) = 0.0`（**悖，反效果**）；`P(案例, 病人) = 1.5`。

### 4.6 听众反应 Reception（喂论战 #8 · 临时接口）

> **归属声明**：本节是**喂给论战系统（#8）的临时接口**，不是本系统的完整玩法。本系统只**冻结**两样：§3.9 的 4×4 匹配表，与下面这条聚合式。**最终聚合语义**（听众模型、多轮累积、饱和的最终口径）**由 #8 定义并拥有**；#8 落地时可覆盖本节。

```
说服力(i, a) = S_base × P(m_i, a) × (1 + Σs) × T_fatigue(i)
T_fatigue(i) = 1 / (1 + F_i × k_fatigue)      // 与 combat §4.5 同式；F_i 的计数维度见下表

逐条贡献（先逐条裁剪，再求和）：
    contrib_i = min( 单条上限 , 说服力(i,a) / (N_a × S_threshold) )   // 仅对 P(m_i,a) ≠ 0 的发言计算
    命中 P = 0.0 的发言：不产生 contrib，另计其条数为 z
Reception(a) = clamp( Σ_i contrib_i − P_penalty × z , 0 , 1 )
   边界：N_a = 0 ∧ z ≥ 1 → Reception = clamp(−P_penalty × z, 0, 1) = 0    // 无有效发言、只有悖位
         N_a = 0 ∧ z = 0 → Reception = 0                                // 本回合无任何发言
```

> **口径（消除歧义，本轮修订）**：① **先逐条裁、后求和**——每条 `contrib_i` 各自受"单条上限"约束，再累加，**不是**先求和对总和裁；② `P_penalty × z` 在 **`clamp` 之内**参与计算，`clamp` 下界为 **0**，故悖位只能把 `Reception` 压到 0、**不会为负**；③ `N_a` **只数 P≠0 的有效发言**，悖位命中不计入分母（否则会因分母虚高而"稀释"反而抬高 `Reception`）。

| 变量 | 范围 | 默认 | 说明 |
|---|---|---|---|
| S_base | 10–30 | 20 | 单条发言基元效力 |
| Σs | 0–1.5 | 0 | 加成和（学科语境、羁绊、场合） |
| T_fatigue(i) | 0.25–1.0 | 1.0 | 同手段连用的边际递减；与 `combat-system.md` §4.5 **同式**（计数维度不同，见 `F_i`） |
| F_i | 0–12 | — | 截至本条、对**同一听众**用**同一手段**的**累计**次数（combat 按牌族一维计数，本表按 **手段 × 听众** 二维计数） |
| k_fatigue | 0.15–0.35 | 0.25 | 疲劳**斜率**（同 combat `k_R`；**不是** T_fatigue 本身） |
| P_penalty | 0–0.5 | 0.3 | 命中 0.0 位时对 `Reception(a)` 的扣减 |
| N_a | 0–99 | — | 针对听众 a 的**有效**发言条数（P≠0；**不含** 0.0 命中） |
| z | 0–99 | 0 | 命中 P=0.0 位的发言条数（悖位负向项） |
| S_threshold | 20–40 | 30 | 听众"被说服"的基准线 |
| 单条贡献上限 | 0–1 | 0.5 | 单条 `contrib_i` 对 `Reception` 的贡献天花板 |

**示例（"赢了道理、输了人心"）**：某回合对**学者**与**民众**各发一次「逻辑」，`S_base=20, Σs=0.2, F=0 → T_fatigue=1`：
- **学者**（`P=1.5`，有效）：`说服力 = 20 × 1.5 × 1.2 = 36`；`N_学者 = 1` → `contrib = min(0.5, 36/(1×30)) = min(0.5, 1.2) = 0.5`；`z=0` → `Reception(学者) = clamp(0.5 − 0, 0, 1) = 0.5`（**赢，但未饱和——还需积累**）。
- **民众**（`P=0.0`，悖位）：不产生 `contrib`，`N_民众 = 0`、`z = 1` → `Reception(民众) = clamp(0 − 0.3×1, 0, 1) = 0`（**扣至下限，翻脸离席**）。
→ 系统如实显示"学者点头、民众转身"——**道理赢了，人心输了**，无需任何旁白解释。

**预期输出范围**：`Reception ∈ [0,1]`。

### 4.7 对话的羁绊增量 DialogueBondDelta

```
ΔBond = Σ 入心事件值 + Σ 发问事件值
入心（同场一次对话内首次入心某同伴）→ +5
发问成功（撬开 mid / wall 层）           → +10
关键顿悟节拍（共同经历）                 → +15
上限：单场对话 ΔBond ≤ +15   （落在 party §3.8 的"剧情事件值 +5..+15"区间内）
```

- **"关键顿悟节拍"的界定**：指剧情在 `beat` 上标注 `epiphany=true` 的节拍，**每场对话至多一次**；它**同时**产出 `EpiphanyEvent`（§3.10，免费生成一条「通」）。故其 +15 属**共同经历**类，**不是**逐条入心的累加项——这样才不会与上面的 +5 重复计。
- **三项可叠加但受单场上限约束**：入心 +5、发问 +10、顿悟 +15 各自触发，但**合计不超过 +15**。

**示例**：一场夜谈，玩家入心陆九针一次（+5）、成功发问其 `mid` 层（+10）→ `ΔBond(沈,陆) = +15`（单场上限）。
**预期输出范围**：单场 +5 .. +15；**不新增任何羁绊出口**（机械意义仍全经 `Teamwork`，`party-system.md` §3.8）。

| 场景 | 会发生什么 | 理由 |
|---|---|---|
| 队伍孤身一人（卷一沈独行） | **无任何心声浮现**（`ChorusSlots=0`）；对话退化为叙事段 + 人间/临床两层自白 | 主角"心里还没有别人"；教学期 |
| 无人具备某门视野 | 该门心声**根本不生成**（不灰化、不提示"缺少能力"、不报错） | 缺眼即不可见（§3.5）；单镜型同构 |
| 心声「欲言又止」（关系门未达） | 可见但**不可入心**；给一句关系提示；**不消耗节拍**；日后 Bond 达标即可重入 | 关系可经营、不惩罚（§3.7） |
| 发问但 Bond 不足 | 得到婉拒台词，**不消耗节拍**、不产生碎片 | 撬不动关系门也不惩罚 |
| 发问但无人有该视野 | 问题被**答成别的东西**（走人间/临床），**不报错** | 缺眼队伍问不出那门解读（§3.7） |
| 一节拍想入心 2 条 | **拒绝**：`FocusPerBeat=1`；未入心者转"旁注"存续，后续节拍**可再浮现** | 注意力有限；防"刷全" |
| 两条心声学科相悖 | **成对呈现**，择一为主解读，另一转"旁注"；**不当场裁对错** | 张力可操作，真相由后续揭示（§3.6） |
| 同场对话反复刷羁绊 | 单场 `ΔBond ≤ +15`；且入心"首次"才计 +5（同场重复入心不累加） | 防刷（对齐 `party-system.md` §5 防刷口径） |
| 同伴**离队**（`roster=离队`） | 其心声**不再浮现**（不再"在队"）；其"旁注"亦清空 | 人走了，心里那声音也停（聚散皆成长） |
| 同伴**归队**（`roster=归队`） | 心声**恢复**浮现（与 `formation` 无关）；但**羁绊不重置**（冻结值原样恢复） | `party-system.md` §3.8 归队口径 |
| 同伴**殉职** | 其心声**永久停止**；仅在卷十"传薪"节点可**回响一次**（一次性、不产碎片） | 死亡的不可逆 + 传薪的仪式（`story-bible.md` §8.1） |
| 陈九章「推演」心声 | 只给**确定数据**（传变阈值、病机速度，配置写死值）；**不预测、不掷骰** | 守"唯一随机源"；`status-syndrome.md` §4.4 |
| 霍崇光出现在心声列表 | **不出现**：`nonParty=true`，永不进入心声池 | `party-system.md` §3.9 |
| 玩家想在对话里用 IP 买节点 | **无此入口**；对话只产"点拨碎片"，解锁由成长系统按剧情执行 | `progression-system.md` §3.1（技能即剧情） |
| 主角自己"先退热"的念头 | 走**叙述层**（§3.5 表 A），**不进心声池、不占槽、不计入同伴视野** | 主角不出声——本系统与"技能之音"的分界 |
| 单句"完美"发言想直接说服 | 单条对 `Reception` 的贡献**上限 0.5**，不能一发定局；需累积 | 给论战 #8 留积累空间（§4.6） |
| 说服基元命中 0.0 位 | 该发言**不计入 Σ**，且 `Reception(a) −= P_penalty`（默认 0.3）；并给**角色口吻的即时反馈**（同 `combat-system.md` §4.3a 悖证反馈精神） | 悖位有**主动负向落点**（§3.9）；解释因果，非"惩罚" |
| 存档点在对话中途 | 对话产出（碎片/ flag / BondDelta）在**节拍结算后**落盘；中途退出视为未结算 | 状态一致性 |
| 同一情境重复进入 | 已产出的碎片/ flag **不重复发放**（按 `beatId` 去重）；BondDelta 同场上限约束 | 防刷 |

## 7. 调参旋钮 Tuning Knobs

| 旋钮 | 当前值 | 安全范围 | 增大影响 | 减小影响 |
|---|---|---|---|---|
| **心声带宽 Bandwidth** | 3 | 2–5 | 同时"听见"更多、注意力更散 | 更聚焦、后卷更压抑 |
| 每节拍入心名额 FocusPerBeat | 1 | 1–2 | 一次可深入多条、节奏快 | 一次只能听一条、更凝练 |
| 关系门阈值（mid / wall） | 50 / 75 | 30–90 | 深层心声更难、羁绊分量重 | 更易听到心结、破墙更快 |
| 入心 BondDelta | +5 | +1 – +8 | 对话即刷羁绊 | 羁绊更靠共同战斗 |
| 发问成功 BondDelta | +10 | +5 – +15 | 撬门回报高 | 撬门回报低 |
| 单场对话 ΔBond 上限 | +15 | +10 – +30 | 对话对羁绊影响重 | 对话对羁绊影响轻 |
| 说服基元 S_base | 20 | 10–30 | 单次发言更重 | 需多回合积累 |
| 听众基准线 S_threshold | 30 | 20–40 | 更难说服、论战更长 | 更易说服、论战更短 |
| 疲劳**斜率** k_fatigue | 0.25 | 0.15–0.35 | 连用同手段惩罚重 | 可反复用同一手段 |
| 悖位扣减 P_penalty | 0.3 | 0–0.5 | 命中 0.0 的代价更重 | 悖位近乎无代价 |
| 单条贡献上限 | 0.5 | 0–1 | 单句更接近一发定局 | 更依赖多轮累积 |
| 论道层开启要求 | 异门同伴视野 ≥1 | 更严（≥2）– 更松（恒开） | 论道更晚出现、经营感强 | 论道恒开、资深层无门槛 |
| 竖切片心声语料量 | 卷 1–3 全量 | — | （内容量旋钮，非数值） | — |

**必须数据驱动**：以上全部值位于**外部配置**（心声语料表、视野表、说服匹配表、羁绊阈值），不得硬编码（见 `.claude/docs/coding-standards.md`）。

## 8. 验收标准 Acceptance Criteria

- [ ] **对话零随机**：给定（在场名单, 羁绊值, 已揭示事实, flag, beatId），两次运行的**心声集合与顺序完全一致**（回归测试：重复 100 次，输出逐字节相同）。
- [ ] **唯一随机源不外泄**：对话系统中**不存在**任何掷骰 / 概率 / 随机吐露的调用点；问诊的 90% 仅在证候系统四诊流程内出现（守卫检查）。
- [ ] **心声带宽**（4.1）：卷一（沈独行）→ `ChorusSlots = 0`（无心声）；卷三（沈/陆/柳）→ 2；卷四 → 3；卷七（可发声 5）→ `min(5,3) = 3`（逐卷可测）。
- [ ] **入心名额**：一节拍尝试入心第 2 条被拒绝；未入心者转为"旁注"且可在后续节拍再浮现（守卫检查）。
- [ ] **知识门**（4.2）：队伍无 `sense.qi>0` 者时，**证候视野心声一条都不生成**（非灰化、非报错）；加入陆九针后同一情境开始浮现（两侧可测）。
- [ ] **心身视野**：无 `sense.psyche>0` 者时，**心身层心声不生成**；含清和（`psyche=3`）时浮现。
- [ ] **推演视野**：陈九章在场才浮现「推演」心声，且其内容仅为**确定性数据**（传变阈值 / 病机速度），**不含任何随机或"预测"**（守卫检查）。
- [ ] **关系门**（4.3 / 4.4）：Bond=40 时 `mid` 层心声仍**浮现**（进 `Surfaced`）但落 `Held`（「欲言又止」、不可入心、不消耗节拍）；Bond 升至 50 后同一情境移入 `Focusable` 可入心——逐档可测。
- [ ] **三集互斥且完备**（4.4）：任意 beat 下 `Surfaced = Focusable ⊎ Held`；`Held` 可见任意条但可入心 0 条（守卫检查）。
- [ ] **主角不出声**（3.5 / 4.2）：心声池、`Surfaced`、发问对象**均不含 `pc_shen`**；主角"临床/人间"仅出现在**叙述层**（守卫检查）。
- [ ] **判定顺序 = 先知识后关系**：无人有该视野时，即便 Bond=100 也不浮现（知识门先判）；有人有视野但 Bond 不足时浮现为「欲言又止」（守卫检查）。
- [ ] **声音以 roster 为准、忽略 formation**：某同伴 `formation=后备` 时其心声**照常浮现**；`roster=离队` 时其心声**停止浮现**（两侧可测）。
- [ ] **三层随构成变深**（3.8）：卷一仅人间+临床；卷二加入陆九针后**论道层开**——逐卷可测。
- [ ] **不含霍崇光**：心声池、发问对象、编成候选**均不含 `boss_huo`**（守卫检查）。
- [ ] **心声相左**：同时具备证候与临床回声同伴视野时，配置为 `opposes` 的成对心声**并置呈现**，择一后另一条转"旁注"且可再浮现（守卫检查）。
- [ ] **说服基元**（4.5）：`P(逻辑,学者)=1.5`、`P(逻辑,民众)=0.0`、`P(案例,病人)=1.5`——匹配表逐格可测；**全表 0.0 仅一处**（守卫检查）。
- [ ] **听众反应**（4.6）：示例（逻辑→学者）→ 逐条裁后 `contrib=0.5`、`Reception(学者)=0.5`（**未饱和**）；逻辑→民众 `P=0.0` → 不产生 contrib，`z=1` → `Reception(民众)=clamp(0−0.3,0,1)=0`；**"赢了道理输了人心"可复现**。
- [ ] **聚合顺序无歧义**（4.6）：**先逐条裁 `contrib_i` 再求和**；`P_penalty×z` 在 `clamp` 内且 `clamp` 下界 0（悖位不产生负值）；`N_a` 只数 P≠0 有效发言，**悖位不计入分母**；`N_a=0 ∧ z≥1` → `Reception=0`（守卫检查 + 边界用例）。
- [ ] **悖位主动负向落点**（3.9 / 4.6）：命中 0.0 的发言**不产生 contrib** 且计入 `z` 扣 `P_penalty`；匹配表全表 0.0 仅一处（守卫检查）。
- [ ] **单条不秒杀**（4.6）：任意单条发言的 `contrib_i ≤ 0.5`（先裁后和，守卫检查）。
- [ ] **可入心者优先占槽**（4.4）：一节拍内 `|Focusable| ≤ ChorusSlots` 时，所有 `Focusable` 心声**必全部占槽**；`Held` 只补剩余槽位，**永不超过**（守卫检查 + 用例：3 人全羁绊不足时，仍有可入心者不被挤掉）。
- [ ] **说服基元不判胜负**：本系统只输出系数与 `Reception`；**无任何"论战胜利"判定**（守卫检查，留给 #8）。
- [ ] **产物接口**（3.10）：入心产出 `InsightFragment`、关键节拍产出 `EpiphanyEvent`、对话产出 `BondDelta ∈ [+5,+15]`——结构齐备且**单向输出**。
- [ ] **不得花 IP 买节点**：对话 UI 中**不存在**"消耗顿悟点解锁节点"的入口（守卫检查）。
- [ ] **不新增羁绊出口**：对话只产 `BondDelta`；羁绊的机械意义仍**全部**经 `Teamwork`（`party-system.md` §3.8 一致）。
- [ ] **单场 ΔBond 上限**：同场对话多次入心/发问，`ΔBond ≤ +15`（守卫检查）。
- [ ] **防重复发放**：同一 `beatId` 重复进入不重复发放碎片/ flag（守卫检查）。
- [ ] **对白规范**：心声/对白文本**不含** `story-bible.md` §10.3 禁用词（病毒 / 抗生素 / 青霉素 / 输液 / CT / B 超）（内容审查）。
- [ ] **存档往返**：已听心声、已产碎片、对话 flag、`beatId` 去重表可**完整存档 / 读档**（往返一致）。
- [ ] **性能**：单节拍（≤3 槽位、≤200 条候选心声）的心声计算 + 渲染在 **16ms** 内完成（60fps 帧预算内）。
- [ ] 所有数值与语料来自外部配置，实现中**无硬编码**。

> **本轮已定（2026-09-11 · rev b 修订）**：
> 1. **形态 = 双声内心**：同伴身体在场 → **心声（他心里响起的解读）** × **发问（说出口的交流）** 两个声道；听谁 = 用谁的眼睛。**主角不出声**——他的"临床/人间"走**叙述层**，不走心声。
> 2. **两把门**：**知识门**（在场**同伴**有没有那门视野，由 `sense` 三值决定）→ **关系门**（羁绊 **50 / 75**；表层门槛 = **0**）。**判定顺序：先知识、后关系**；两门皆**确定性、零随机**。
> 3. **带宽**：`ChorusSlots = min(可发声同伴数, 3)`，每节拍**入心 1 条**；心声以 **`roster`** 为准、**忽略 `formation`**；**无声可发者不占槽**。
> 4. **叙述三层 ⊥ 同伴心声门**：叙述层（人间 + 临床**恒开**、论道需同伴视野 ≥1）决定**主角讲多深**；同伴心声门（临床回声 / 证候 / 心身 / 推演）决定**同伴说什么**——二者互不占槽（本轮拆分，消除"谁提供人间"的自相矛盾）。
> 5. **说服基元**：手段(4) × 听众(4) 匹配表，与 combat `M` **同值族、同「悖」位精神**（非结构同构）；**唯一 0.0 位 = 逻辑→民众**，且有**主动负向落点**（不计入 Σ + 扣 `P_penalty`）；本系统**只出系数与 `Reception`（临时接口），不判胜负**。
> 6. **对话零随机**：唯一随机源（问诊 90%）仍只在证候系统的四诊内；对话层的"失"只源于**带错人**或**不够信他**。
