per-screen UX spec;模态身份 = `ModalId.InventoryContainer`(`adr-013:354`)。

**四方分权**(权威 = 20 GDD `UI-20.1` + `skeuomorphic-ui.md:1224` 容器契约 —— ⚠️ 原引 `:356` 为**行号漂移**,该处实为 States and Transitions 标题,2026-09-22 /ux-review 轮订正,同族于 systems-index `:575`→`:616`):

| **21a** | 每件器物的形态 / 质地(`quality_character[]`)· 堆叠基数 | 摆放与翻页 |

  瓷瓶 / 盒不进箱 ⇒ **P0 不存在「点开容器看子件」的二层界面**。任何本屏内再开收纳面 = 破裁定。

- **档位零耦合**:开/关箱**不发相机意图** —— 39 是全案唯一档位请求方(用户裁定 2026-09-19);
  本屏开合不改 `ICameraRig` 模式。

## 2. Purpose & Player Need

药箱是**医者的身体延长**:打开它不是「清格子」,是**看一眼自己的家当与负担**。
它兑现 42 规则五的反幻想承诺 —— 器物有重量、箱有满溢、**放不下就是放不下**。

**这个屏存在的理由**:
- 载重是 52 的强度轴(`CarryLoad / CARRY_CAP`),但玩家**没有数字 HUD** —— 箱的满溢是唯一读数;
- 采集(17)/ 炮制(18)/ 处方(11)的产出全在此汇合 —— 「有没有这味药」的物面回答;
- 手柄遍历义务(`AC-20-20` / `AC-3-F1a` ② 的「20 容器界面走查」)必须有确定的焦点形态。

**什么会变糟**(若本屏形态不对):
- 做成背包格 / 加排序按钮 ⇒ 直撞 `AC-20-12`(反幻想,42 规则五);
- 四档做成进度条 ⇒ UI-20.3 明禁(「数字的变体」);
- 分档函数若随实现随意回头 ⇒ 破 BL-27 单调契约(「满档 ⇔ 装不进」就是余量读数本身)。

## 3. Player Context on Arrival

- **入口**:`OpenInventory` 动作(宿主 = 3,`input-system.md:147` —— ⚠️ 原引 `:144` 行号漂移,2026-09-22 /ux-review 轮订正)· 世界内自由态;
  联机下 = 本机箱(库存按 `player_id` 分轴,承 20 的分册同构)。
- **进入前一刻**:背着箱子(可能正沉 —— 满档态在开**之前**已由抬箱动画 / 步履体现,归 1/44,不在本屏)。
- **情绪**:事务性、短停;开箱不打断世界 tick(主机 `Step` 不停,承全局)。
- **出口**:同一 action toggle 关闭;焦点回进入前载体(P-02)。

## 5. Layout Specification

### 5.1 Information Hierarchy

| 序 | 信息 | 说明 |
|----|------|------|
| 1(首要) | **箱内实物阵列**(id 升序) | 存在与数量 = 器物本身;无清单、无格子 |
| 2 | **盖沿与满溢态** | 载重的唯一读数 —— 箱壳几何本身(§5.2 之 3) |
| 3 | **药签**(品级质地 + 措辞,21a 供)| 每件器物的「它是谁」;不占独立层 |
| 4(环境) | 箱外一圈(案面 / 地面)| 「蹲下来摊开箱子」;零数据 |

**层级原则**:读数 = 器物与箱的**物理关系**,不是器物之外的任何仪表 —— 删掉任何「像 UI 的东西」后信息仍完备,是本屏版面的验收直觉。

### 5.2 Layout Zones

裁定:**俯开药箱变体**(等比纸本族的**非纸侧** —— 本屏材质主语 = 木 / 皮 / 铜 + 器物本身;
水墨侧元件仅在药签上出现。规则五材质分界的**器具侧实例**;⚠️ 措辞订正(2026-09-22 /ux-review 轮):
原稿「登记为对 42 元件库的**引用**而非新语法」与本件 OQ-IC-4「元件库规则五现无器具侧先例、本屏是
**首个**混材屏」自相矛盾(若纯引用则 OQ-IC-4 无存在理由)。现口径(**OQ-IC-4 已裁 2026-09-22 = 甲**):
**版式组织 = 引用既有双材质分界纪律(纸/铜分界不新立);木 / 皮 / 铜器具材质档本身 = 已裁的
「器具」第三材质档**(`skeuomorphic-ui.md` §二 ⭑ 2026-09-22 注块之 ③ —— 库由双材质语言扩为三档)):

1. **箱体摊开**(画面中心,盖向后翻开):内部为**隔层**(20 GDD `:682`:「箱中的隔层,不是网格」)——
   隔层 = 视觉分区,**不承载机制**(无「哪一层装哪类」的机制规则;若有 = 破 §1 分权)。
2. **摆放函数**(顺序语义权威 = 20 规则十;布局参数 = 本 spec 行使 42 侧授权裁定):
   - 器物按 **`instance_id` 升序**自**左前 → 右后**蛇形落位:`slot(i) → (row, col)`,
     `col = i mod COLUMNS`,`row = i / COLUMNS`;
   - **本 spec 裁:P0 初值 `COLUMNS = 4` · `ROWS_PER_PAGE = 3`**(一屏 ≤12 件;两值 = 布局参数,
     归数值轮之外的 ux-design 域,可随时重调 —— **不触机制**);
   - **换页条件 = `row ≥ ROWS_PER_PAGE`**(20 规则十 ② 的原式);
   - 落位带**手摆的参差**(旋转 ±θ、微位移):确定性 = `instance_id` 的整数哈希副产物
     (**呈现层本地确定性函数,不进流、不存档**)—— 同 id 必同位,「随机感」不是随机。
3. **盖沿满溢带**(箱口上缘 + 合盖路径):载重四档的物理承载(§6);满档时**盖合到一半被顶住**
   —— 开箱态即见「压不住」的半盖,**载重读数先于任何交互**。
4. **页缘铜扣**(左右):`PagePrev/PageNext` 的焦点落点;第 1 页 / 末页时铜扣**卸为平整铜片**
   (与 `settings-shell-42.md` §6「单项失效卸形」同族通道,非置灰、非隐藏)。

## 6. States & Variants

**载重四档**(用户裁定 2026-09-18「拟物器具 —— 药箱的满溢感」的具名兑现;
**分档函数 = `slack = CARRY_CAP − CarryLoad` 的单调不增函数**,BL-27 契约;
`slack` 只由 `CarryRatioDto = {carry_load, cap}` 整数对导出 —— 本屏零第二容量真值):

| 档 | 判据(整数式,无浮点;阈值 = 本 spec 裁定,可调)| 呈现 |
|---|---|---|
| **空** | `CarryLoad = 0` | 箱底可见,器物零落 |
| **半满** | `2×CarryLoad ≤ cap` | 器物铺开,仍有空隙 |
| **近满** | `10×CarryLoad > 5×cap ∧ carry_load ≤ cap − W_MIN` | 堆高至沿口,取放需拨开(动作姿态)|
| **满** | `carry_load > cap − W_MIN`(**即 `AC-20-18` 的具名谓词**,非比值阈值)| 高出沿口,**合盖受阻**(半盖顶住);新增一律放不进 |

> ⚠️ **判据序 = 自上而下首个命中**(档优先级):`CarryLoad = 0` 同时满足「空」与 `2×0 ≤ cap` 的「半满」式,
> 若不声明序则两档双真,函数非良定(2026-09-22 /ux-review 轮补)。
> ⚠️ **满档边界不再是本 spec 的自由阈值**(2026-09-22 /ux-review 轮 BLOCKING 订正):`AC-20-18`
> (`inventory-and-items.md:819`,20 侧权威)把「新增一律放不进」定义为
> **`carry_load > cap − W_MIN`**(`W_MIN` = 烘焙期可算常量 `min{ItemDef[k].weight} ≥ 1`),并**明令
> 「禁简化成 `carry_load == cap`」** —— 本表原稿把「满」档裁成 `10×CarryLoad > 9×cap`,在
> `W_MIN > cap/10` 的物集下会出现「机制已拒收、呈现仍近满」的错位,恰是该 AC 二轮重写(BL-26)
> 要防的失败模式。**现口径**:「满」档直接取 20 的谓词(一侧一界);原 `9/10 cap` 比值式**不再作
> 档位边界**(近满 = `5/10 < CL ≤ cap − W_MIN` 的连续带,外溢画法的渐进度归美术轮)。
> 20 出谓词、42 出分档,两侧不各自判载重(`AC-20-18` 末句)。
> **禁**:四档做成 HUD 四格进度条(数字的变体);四档做成**颜色梯度**(非颜色铁律 —— 全走几何堆高)。

| 屏级状态 | 触发 | 呈现 |
|---|---|---|
| 未绑定 | `InventoryOf` 投影未到达 | 空箱全显(箱 = 形状先于内容,**族内约定** —— 与 ② 册 / ⑥ 面板同措辞;近亲既载条 = 42 §二 5「有格线无字」,但该条自标「**脉案专有**」⇒ 推广到本屏是族内约定而非全案规则,归 42 元件轮升格(承 G-4 同型的「三份各自为政、无归并权威」登记);不崩、无弹窗。⚠️ 原引「42『元件先于数据』」为**幽灵引据**:全仓 grep 该短语仅命中三份姊妹 spec 自身,`skeuomorphic-ui.md:339` 实为「消费方引用而非复制闭集」行,2026-09-22 /ux-review 轮订正,同修见 casebook-39 / save-slots-7b) |
| 空箱 | `CarryLoad = 0` | 同「空」档;页缘铜扣卸形(单页也无翻)|
| 不可取(超容)| `CanCarry == false`(抬起时判定)| 器物**放不回去**:抬 → 阻力 → 落回原位的物理动画;零文字报错、零弹窗(拒绝 = G-4 纸面同族,本屏为器物同族)|
| 翻页端点 | 首页 / 末页 | 对应铜扣卸为平整铜片 |
| 平台变体 | 平面 P0 | 全部如上;VR 不做(P1a 重议)|

## 7. Interaction Map

| 动作 | 输入(键鼠) | 输入(手柄) | 即时反馈 | 路由 |
|---|---|---|---|---|
| 开 / 关箱 | `OpenInventory` | 同一 action 资产 | 摊盖 / 合盖 ≤200ms(减动效:直接切;半盖顶住态仍显 —— **态不是动效**)| 无流事件 |
| 移焦 | 指针 hover = 快捷方式 | 官方桥 `NavigationMoveEvent` + `FocusController`(P-01,禁自实现;几何相邻由 §5.2 落位函数保证)| 焦点铜环压器物旁 | —— |
| 取用 / 提出 | 焦点器物 + Submit / 拖出 | 同一 Submit | 抬 / 落物理 | **20 意图事件 → 主机结算**(屏幕零 `Append`;结算 = 世界流 `DropClaimed` / `DropDespawned` 既有 Kind,**本屏不新增 Kind**) |
| 放入 | 从世界拾取路径(4 的宽容半径判定,ADR-009 §七)或箱内转移 | 同 | 落位(带参差哈希位)| 同上 |
| 翻页 | 点铜扣 / 滚轮于箱区 | 肩键 `PagePrev/PageNext`(3 消费者表补 20 = **R8 涟漪,本屏为验收主语**)| 移箱提页 | 纯呈现(页码不落任何持久 —— 箱无分册态;**OQ-IC-3**)|
| 读说明 | 悬停器物 | 焦点器物 + Select | 页侧注 ≤2 行 | 纯呈现 |

**焦点序铁律**:`instance_id` 升序 = 摆放序 = 遍历序 = **`AC-20-20` 的「同内容同方向键 ⇒ 同焦点目标」判据**;
任何按品名 / 类型 / 最近使用的重排 = 破 20 规则十 + `AC-20-12`(排序禁令)。

**零按键提示**(第一铁律):全屏零浮层;箱的用法由 48 教(`UI-20.4` 原口径)。

## 9. Transitions & Animations

| 转场 | 规格 | 减动效钩子 |
|---|---|---|
| 摊盖 / 合盖 | ≤200ms | 直接切(半盖顶住**态**不受钩子影响 —— 钩子砍动画不砍信息)|
| 抬 / 落器物 | 物理感(重量 = 抬速,21a 形态参数)| 直接显隐 |
| 放不回(阻力落回)| 一抬一顿一落 | 缩短为一顿(**拒绝反馈不可被钩子删除**)|
| 翻页 | 提箱换位 | 直接到位移终态 |

**禁入**:遮罩 / 滤镜(P-02);「背包整理」类一键归位动效(= 自动整理,`AC-20-12`);
