### 1.4 这些数字是**先算后跑**的

抽取是 `SplitMix64(WorldSeed, win, tier, ordinal)` 上的加权 CDF walk ⇒ 可以离线复算。
夹具写好后、跑第一次之前,我用 Python 独立实现 `Avalanche/Fold/Hash(a,b,c,d)` 与 CDF walk
算了一遍,结果与 Unity 实跑**逐项一致**(含第三个测试的 `2002 → 2003` 序)。

```python
M=(1<<64)-1; M1=0xBF58476D1CE4E5B9; M2=0x94D049BB133111EB
def A(z):
    z=((z^(z>>30))*M1)&M; z=((z^(z>>27))*M2)&M; return (z^(z>>31))&M
def Fold(s,w): return A((s+w)&M)
def H4(a,b,c,d): return A(Fold(Fold(Fold(a&M,b&M),c&M),d&M))
def pick(seed,win,tier,ordinal,keys=(2001,2002,2003,2004),w=100):
    r=H4(seed,win,tier,ordinal)%(len(keys)*w)
    for k in keys:
        if r<w: return k
        r-=w
# 0xA11CE → 2001, 2004, ...   0x5EED → 2002, 2003, ...
```

> 离线复算的用途**不是**「让测试好过」,而是让「期望值」有一个独立于被测实现的出处
> (承 `feedback_verify_assertions_offline_first`:错了会把正确实现判成红)。

## 2. 三条实测结论(其中一条推翻了此前写进代码注释的判断)

### 2.1 「三条 Event 源规则今日都不会触发」——**不成立**(已就地订正两处注释)

`TechniqueUnlockRules.Default` 的 remarks 与 `BootRoot` 4.4b 的注释都写着这条,依据是
`TD-randomevents-05`(上下文门硬编码 false)与 ADR-039 §R3(生产候选池为空)。

两处注释已就地订正(原文不删,加 🔁 段)。

### 2.2 「首抽被投放门拒 ⇒ 整日零产出」是一个**真实可达**的日型

机制:`EventRolled` 只在掷骰后落流(ADR-039 §D3 防孤儿行),而 `Ordinal` = 当日**已掷**数
(从流重构)。被拒的那一眼**不写任何事件** ⇒ 序号不前进 ⇒ 同一天里每一眼都落在同一个
`(win, tier, ordinal)` 上 ⇒ **抽到同一个 key、同样被拒**。跨日无此问题(`win = dayStart` 变)。

生产形态下这个日型被**钩子通道**吸收一次(每章 1 例,见 2.3),配额用完后照旧。
本批**只如实登记,未改任何口径** —— 是否算缺陷、要不要改「被拒也推进序号」,请你裁。

### 2.3 钩子配额是这条链「死日 ↔ 活日」的唯一开关(同一种子对照)

`0x5EED` 同一天:配额**关** ⇒ 6 眼全 `PatientSpawnUnavailable`、零病人;
配额**开** ⇒ 两个病人 + 学会金鸡纳(12)。这是 hook 规则 1「每章 1–3 例」在流层第一次可观测。

## 6. 如实登记的边界(禁借绿)

1. **夹具的 `isDiseaseAdmissible` 是自组装的**(见 1.2)。`CompositionRoot` 里是内联 λ ——
   这也是 `EventPoolPatientSpawner` 头注批评过的形态。本件没有把生产那段抽出来
   (那会动 `CompositionRoot`,超出本批范围),故这处**组装**仍是夹具一侧的复制。
   ✅ 但**判据本体**在生产件里(`PatientDrawEligibility`),本件只是把它接起来。
2. **`hookAllowed` 是常量,不是真配额**。真正的配额计数在 `HookCaseLedger`,
   本件用「开 / 关」表达「配额还在 / 已用完」。第三测因此只覆盖**章内第一例**。
3. **本件不覆盖**:多日连跑、跨日边界(`win` 变化)、`PatientAppearanceCap` 触顶、
   骨折 / 送医等收场路径。
4. **种子是夹具输入**:换种子 ⇒ 1.3 的数字全部要重算(每条的 `Assert` 旁都写了为什么)。
5. **2.2 的「死日」只登记,未定性**。它可能该改(被拒也推进序号),也可能该保留
   (配额本就是稀缺资源)—— 本批不替你做这个裁。
