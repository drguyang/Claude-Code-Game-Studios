# 音频系统 (Audio System) — 44

> **Status**: In Design
> **Author**: dr_guyang + audio-director / sound-designer / unity-specialist
> **Last Updated**: 2026-09-15
> **Implements Pillar**: 支柱一「判断为骨,手感为肉」
> **Authority**: `docs/architecture/adr-018-audio-architecture.md`(✅ Accepted 2026-09-15)

## Overview

**44 音频系统是表现层的一条「语义 cue → 声音」通道,与 42 拟物 UI 同构 ——
只触发 / 只渲染,永不持有游戏状态(ADR-018,✅ Accepted,本 GDD 的权威件)。**

它的技术面:**上游系统在表现层发出语义 cue**(13 的咳嗽呻吟 · 37 的结案纸页 ·
52 的预告线索 · 8 的听诊层 / 9 的呼吸语义),44 只把 cue 变成声音 ——
经由 **`AudioCueDto`**(无 `disease_id`,整数语义,受 `PresentationDtoGuard` 递归扫描)。
音频事件表走 **ADR-014 烘焙管线**(玩家构建零 JSON 解析器);混音拓扑为
`Master / Music / Ambience / Voice / SFX / Stethoscope / UICue` 七条总线 + 行为驱动的快照清单。

它的玩家侧:**你是**先听见后看见**的那个人**。玩家可以在隔壁房间听见病人呼吸变坏、
听诊器里听见细湿啰音(吸气象、断续、撕 velcro 那种)——**而系统永不叮一声告诉你「他转危了」**。
「无提示音」铁律由白名单断言机械化(AC-44-09 BLOCKING),让「判断为骨」在听觉侧成立:
**听见变化是你的本事,不是系统的通知。**

> **职责边界(一句话)**:44 不订阅 sim 真值、不写三流、不进 sim 程序集;
> 它消费的是**表现层语义 cue**,不是**游戏状态**。任何「我需要知道病种才能选素材」的需求,
> 语义解析都在上游完成,44 只收结果 cue id。

## Player Fantasy

**「门后的人还在喘气。」** —— 玩家可以在**看不到病人**的情况下,仅凭声音判断他是否转危。
这是无血条设计(支柱一「判断为骨,手感为肉」)在**听觉侧**的兑现:
`diagnosis-system.md:171` 转引的 9 的幻想「世界不为你暂停」,唯一不依赖 UI 的外显方式就是声音。

**玩家应该是那个「听见了什么」的人,不是那个「收到了通知」的人。**

- **听诊器里的世界**:低技能 ≠ 把啰音静音 —— 低技能 = 更高的接触噪声底、
  更窄的通带、更少的频段细节(摩擦声、衣料声、病人自己的呼吸声混进来)。这正是真实的实习医生体验
  (`diagnosis-system.md:1588-1591`)。**你的耳朵不会说谎,但你的耳朵也提醒你:「你没练过听」。**
- **变体库混合的病人语声**:病人是**人**,不是音效机 —— 男 / 女 × 强 / 中 / 弱 × 数种句尾,
  按 (病种语义, 精度档, 强度) 选变体并交叉淡化。**禁**把已录语声做五项参数调制
  (音高 / 气声 / 语速 / 断句 / 共鸣)—— 那是「变声器」,不是「病人说话」。
- **世界声是线索,不是警报**:狗吠 / 马蹄 / 锣声 / 鸟群惊飞(52 预告线索)是**可以听出来的前兆**,
  不是「红色感叹号的声音版」。玩家学到的不是「叮 = 危险」,而是「今晚的鸟在乱飞」。

**参考锚**:英灵神殿的**风声 / 门吱呀**—— 世界有声音,但从不替你说话;
《双城》式的拟物声(笔尖走路、翻纸)让「翻开脉案」本身有触感。
**要避免**:任何「成就达成」式 stinger、任何「转危报警」式 ducking、任何「玩家做对了就播对音」的素材切换。

## Detailed Design

### Core Rules

**规则一 · 44 与 42 同构 —— 只触发 / 只渲染,永不持有游戏状态(ADR-018 §一)。**
44 不读 sim 真值、不写三流、不进 sim 程序集(门 A 不受影响)。
数据入口只有 `AudioCueDto` + `VitalsDto`;输出只有 `AudioMixer`。

**规则二 · 音频触发源必须来自「行为反馈白名单」,不得来自「状态播报」(ADR-018 §六)。**

| 类别 | 例 | 归属 |
|------|-----|------|
| 玩家自身动作 | 笔尖走路 / 落笔 / 翻纸 / 器物放置 / 脚步 | 42 / 44 |
| 玩家主动的检查动作 | 听诊器接触声 / 摩擦声 / 衣料声 | 44(听诊层) |
| 玩家可感知的世界声 | 狗吠 / 马蹄 / 锣声 / 鸟群惊飞 / 哭喊 / 钟声 | 52 → 44 |
| 持续生理声(非状态播报) | 呼吸层的**连续**变化(平稳→急促→停顿) | 9 语义 → 13 触发 → 44 |

黑名单(禁止 —— 状态播报):任何 sting / jingle / 提示音宣告状态变化;
用 ducking 报状态;用素材切换报状态;用音频表达本来该由玩家读数得出的结论。
机械化 = **AC-44-09(BLOCKING)**:EditMode 断言音频事件表的每个 CueId ∈ 白名单类别,
且不存在「CueId → 状态变化枚举」的直接映射。

**规则三 · 快照由行为驱动,绝不用来播报状态(ADR-018 §三)。**
`StethoscopeFocus` 是玩家**自己**拿起听诊器触发的;`Paused` 是暂停。
快照切换**不**用于「病人转危 ⇒ 压低环境以突出心跳」。

**规则四 · 呼吸分两层渲染,精度档 = 通带与噪声底,不是静音开关(ADR-018 §四 需求①)。**
基础气流层 + 附加音层(细湿啰音等)。**低技能 ≠ 静音,低技能 = 更吵的接触噪声、更窄的通带。**
**AC-44-01(BLOCKING)**:三档下附加音层**始终非零**;断言无「档位 ⇒ 静音」路径。
**AC-44-08**:附加音层**不得**实现为连续水声(细湿啰音 = 吸气末、断续、细密的爆裂音,咳嗽后不消失)。

**规则五 · 语声走「变体库混合」,不是「参数调制」(ADR-018 §四 需求②)。**
男 / 女 × 强 / 中 / 弱 × 数种句尾;按 (病种语义, 精度档, 强度) 选变体并交叉淡化。
**禁**对已录语声做音高 / 气声 / 语速 / 断句 / 共鸣五项独立调制。

**规则六 · 接触噪声 / 信噪比是暴露参数(ADR-018 §四 需求③)。**
`Stethoscope` 总线暴露接触噪声底与信噪比,由精度档驱动。
`READ_FLOOR_MIN > 0` 在音频侧有对应实现:背景噪声永不为零,但也不毁掉信号。

**规则七 · 联机下听诊音精度统一取「主机技能」(ADR-018 §五)。**
单 `AudioListener` 每设备只有一条混音总线(结构性约束)。
**边界**:脉案仍每人一本、各按自己技能显字;分叉的**只有音**。
远端玩家空间化复用 ADR-001 第二 QoS 位置的**表现态位置**,44 **不自建位置通道、不新增 QoS 通道、不做语音通道**。

**规则八 · 44 不拥有音频素材的语义选择权。**
若「需要病种才能选素材」—— 那是上游(8 / 13)的责任,上游解析成 cue id,44 只收结果。
`AudioCueDto` 无 `disease_id`,`PresentationDtoGuard` 递归扫描覆盖。

**规则九 · 关键音频必须有视觉替代(无障碍,ADR-018 §八)。**
9 的呼吸是「唯一不看也能听出来的通道」—— 但**信息不得仅存在于音频**。提供 mono 选项。

### States and Transitions

**44 是表现层,状态是「混音 / 播放」状态,不是游戏状态。** 分两层:

**① 总线与快照层(ADR-018 §三):**

| Snapshot | 用途 | 触发(必须由行为驱动) | 回退 |
|----------|------|----------------------|------|
| `Default` | 常规游玩 | 默认 | — |
| `StethoscopeFocus` | 听诊聚焦(压 Ambience / Music,抬 Stethoscope) | **玩家主动**进入听诊动作 | 玩家离开听诊动作 |
| `DialogueFocus` | 语声优先(压 Ambience / Music) | 病人语声播放 | 语声结束 |
| `Paused` | 全总线衰减 | 暂停 | 恢复 |
| `VRComfort` | VR 模式(见 ADR-018 §七) | P1a | — |

**② 播放句柄层(循环 cue):**

```
BeginLoop(cue) → [Looping] ── EndLoop(handle) → (释放)
```

- 循环 cue(呼吸层 / 环境)由**唯一持有者(上游)**负责收尾;44 不自行决定何时结束。
- 一次性 cue(咳嗽 / 翻页 / 狗吠)即发即弃,无状态。

**禁**:任何「播放状态」被解读为「游戏状态」—— 44 的状态机只描述**声音正在发生什么**,
不描述**病人正在发生什么**。

## Formulas

> **44 的「数学」几乎全是映射,不是计算。** 三处硬约束(§Formulas 全部满足):
> ① `Intensity` 与 `Tier` 是 `byte`(0–255 / 0–2),在**呈现层**是渲染参数,**不回写 sim**,
> 不受 ADR-006 的禁 float 约束(它们在定点域之外);但取整数是为了与上游整数语义一致。
> ② **44 不拥有数值** —— 精度档曲线 / 阈值 / 通带参数全部是**8 的 F-8.x 或旋钮的映射输入**,
> 44 只做形状映射。
> ③ 任何「档位 ⇒ 静音」路径 = **AC-44-01 断言失败**(BLOCKING)。

### F-44.1 精度档 → 通带与噪声底(听诊层)

The tier-to-filter mapping formula is defined as:

`filter_params = TierMap[Tier]`(表驱动,无运算)

**Variables:**

| Variable | Symbol | Type | Range | Description |
|----------|--------|------|-------|-------------|
| Tier | T | byte | 0 低 / 1 中 / 2 高 | 来自 `AudioCueDto.Tier`;单机 = 本地技能档,联机 = 主机技能档(ADR-018 §五) |
| TierMap | — | table | — | 每档一行的 { 通带中心 / 通带宽 / 噪声底 gain / 频段细节数 };数值**待调**(用户调,见 §Tuning Knobs) |

**Output Range:** 每档一组 { 通带范围, 噪声底 dB, 频段细节 }。**约束:三档的附加音层始终非零**
(AC-44-01);差异必须**可辨**且**非静音型**(AC-44-02)。
**Example:** 低档 = 窄通带 + 高噪声底 + 少频段细节(摩擦声 / 衣料声混进来);高档 = 宽通带 + 低噪声底 + 全细节。

> **设计来源**:`diagnosis-system.md:1588-1591` ——「低技能 ≠ 把啰音静音;低技能 = 更高的接触噪声底、
> 更窄的通带、更少的频段细节。这正是真实的实习医生体验。」

### F-44.2 接触噪声底 / 信噪比(暴露参数)

`snr = SIGNAL_GAIN / (NOISE_FLOOR + CONTACT_NOISE_floor)` —— 以 `Stethoscope` 总线增益实现

**Variables:**

| Variable | Symbol | Type | Range | Description |
|----------|--------|------|-------|-------------|
| 信号增益 | SIGNAL_GAIN | float(dB) | 待调 | 附加音层增益;由 TierMap 驱动 |
| 噪声底 | NOISE_FLOOR | float(dB) | 待调 | 背景噪声,永不为零 |
| 接触噪声底 | CONTACT_NOISE_floor | float(dB) | 待调 | 听诊器摩擦 / 衣料声;随 Tier 变化 |

**Output Range:** SNR 随精度档上升(高档信噪比更高)。**硬约束:`READ_FLOOR_MIN > 0` 在音频侧有对应实现**
(AC-44-06):背景噪声永不为零,但也不毁掉信号。
**Example:** 低档 SNR 接近 1:1(噪声几乎淹没信号);高档 SNR 明显 > 1(信号清晰可辨)。

### F-44.3 语声变体选择(变体库混合)

`variant = SelectVariant(PatientSemantics, Tier, Intensity)` —— 查表选变体,交叉淡化

**Variables:**

| Variable | Symbol | Type | Range | Description |
|----------|--------|------|-------|-------------|
| 病种语义 | PatientSemantics | enum | 病种语义 × 通道 | 上游(8 / 13)解析,44 只收 cue id,不读 `disease_id` |
| 精度档 | Tier | byte | 0–2 | 同上 |
| 强度 | Intensity | byte | 0–255 | 来自 `AudioCueDto.Intensity`(0–255 归一,整数) |
| 变体库 | VariantLib | table | 男/女 × 强/中/弱 × 数种句尾 | 素材侧;每组录多个变体 |

**Output Range:** 一个具体变体 clip + 交叉淡化参数。**硬约束**:禁五项独立调制
(音高 / 气声 / 语速 / 断句 / 共鸣)—— 那是「变声器」不是「病人说话」(AC-44-03 / 04)。

### F-44.4 空间化锚点(整数格 → float)

`worldPos = LatticeToWorld(Cell)` —— 表现层换算,禁反推

**Variables:**

| Variable | Symbol | Type | Range | Description |
|----------|--------|------|-------|-------------|
| 整数格 | Cell | WorldPos | 格坐标 | ADR-015 §三 的单一整数格 |
| 表现态位置 | worldPos | float3 | 世界坐标 | 视觉层 float(ADR-015 两层世界) |

**Output Range:** float 世界坐标,用于 AudioSource 3D 空间化。
**硬约束:** **禁从 float 反推逻辑格**(ADR-015 / ADR-018 §二)。
联机下远端玩家的 `worldPos` 来自 **ADR-001 第二 QoS 通道**的表现态位置,44 不自建通道。

### F-44.5 呼吸层档位 ≠ 音量(连续变化语义)

`breathLoop = Loop(cue, TierMap[Tier].breathLayer)` —— 循环层,档位改滤波不改音量

**Variables:**

| Variable | Symbol | Type | Range | Description |
|----------|--------|------|-------|-------------|
| 呼吸层 cue | cue | CueId | 平稳 / 急促 / 浅慢 / 停顿 | 9 的连续变化语义(状态量),经 13 表现映射触发 |
| 档位 | Tier | byte | 0–2 | 同上 |

**Output Range:** 循环呼吸层的**连续**变化;**无突变音效**(AC-44-10)。
**硬约束**:转危 = 玩家自己听出来,不得用「突变音效」标记阈值跨越
(`disease-simulation.md:1120-1121`);「停顿 vs 停止」必须可听辨,但**不许用音效硬报**
(`disease-simulation.md:1118`)。

## Edge Cases

> 每条 = 明确条件 + 明确结局。**格式**:`If [condition]: [exact outcome]. [rationale]`。

### 听诊与呼吸层

- **If 玩家低精度档(0)听诊而病人有细湿啰音**:附加音层**非零但更吵**(窄通带 + 高噪声底),啰音**淹没在噪声里但存在**。
  **绝不静音**(AC-44-01)—— 静音 = 玩家以为漏了素材 / 以为病人没病。
- **If 玩家低精度档听诊而病人**无**啰音**:信号 = 基础气流层 + 噪声,无附加音;**
  **不**因为听不出啰音就出现「空洞」—— 那是正常现象(规则四 / F-44.1)。
- **If 档位变化导致通带突变**:交叉淡化 / 平滑过渡,禁止「啪」一声切换(爆音 / 相位抵消,AC-44-04)。
- **If 呼吸层从「急促」过渡到「停顿」**(转危):呼吸循环**连续**变慢 / 变浅,**无突变音效**(AC-44-10)。
  **停顿(昏迷)vs 停止(死亡)**:两者必须**可听辨**—— 停顿有极轻微的背景气流尾,停止完全无声;
  **但绝不**用「叮」宣告是哪个(9 的 AC-21 / ADR-018 §六)。
- **If 呼吸 cue 的循环句柄被上游重复 BeginLoop**:44 检测到同源重复循环,**以最后一次为准**,释放旧句柄;
  不叠加两条呼吸层(防「两层呼吸」bug)。
- **If 上游 EndLoop 传了过期句柄**:44 忽略;循环由唯一持有者收尾,过期句柄不产生播放错误。

### 语声变体

- **If 变体库缺该 (病种语义 × 精度档) 组合**:回退到最近可用档的变体(高→低),**不静默**;
  编辑期烘焙门拒绝「无任何变体可回退」的 cue。
- **If 强度(Intensity)超出 0–255**:钳位到 0–255(byte 天然钳位);不产生音量突变。
- **If 语声与呼吸层同时播放**:两者走不同总线(Voice vs Stethoscope),**不互压**;
  语声优先仅由 `DialogueFocus` 快照体现,不额外 ducking 呼吸层(规则三)。

### 联机与空间化

- **If 联机下四名玩家技能不同**:听诊音层次**统一取主机技能**(AC-44-07);
  脉案字体量仍各自分叉(铁律⑤)——**分叉的只有音**。
- **If 远端玩家在音频触发瞬间断线**:44 使用最近一次第二 QoS 位置快照;
  断线后 cue 静默过期,不崩溃(表现层降级,非 sim 事件)。
- **If 同一 `WorldPos Cell` 同时有多个声源**:按优先级队列混合(关键 cue > 行为反馈 > 环境);
  不逐帧重排。

### 白名单与边界

- **If 某个 CueId 不在白名单类别中**:AC-44-09 断言失败(BLOCKING,EditMode + CI 门)。
  这是构建期拒收,不是运行期告警。
- **If 上游试图传 `disease_id` 进 `AudioCueDto`**:`PresentationDtoGuard` 递归扫描失败(AC-37-15 一致性)。
- **If 玩家暂停游戏**:切 `Paused` 快照(全总线衰减);暂停期间的循环 cue 挂起,恢复后续播。
- **If 玩家进入听诊动作后长时间无任何 cue 更新**:维持 `StethoscopeFocus` 快照(玩家行为驱动,非状态);
  **不设超时**、不自动退出(任何超时阈值若引入,须登记为调参旋钮,不得写死)。

### 素材与管线

- **If 音频素材未烘焙(开发期直接播原文件)**:开发构建允许,但**玩家构建零 JSON 解析器**
  (ADR-014 继承验证)—— 事件表必须走烘焙。
- **If 素材文件缺失**:编辑期烘焙门拒绝;运行期绝不静默播放「空 cue」(缺失 = 构建失败,不是运行期降级)。
- **If 音量 / 总线增益越界**:暴露参数钳位(音量 0–1,dB -80–0);不做「玩家把音量拉爆」的降级处理(那是玩家的选择)。

> **无「the system should feel good」条款** —— 全部边界可机械验证(AC-44-01…13 承接)。

## Tuning Knobs

> **44 的旋钮全部「待调」(数值用户自己调 —— `feedback-user-owns-balance-values`)。**
> 本 GDD 交付**变量表 + 调参旋钮**,不拍定值。每个旋钮:安全范围 / 调太高 / 调太低。

### 听诊层族(F-44.1 / F-44.2)

| 旋钮 | 含义 | 安全范围 | 调太高 | 调太低 |
|------|------|---------|--------|--------|
| `TierMap[0..2]` 的通带宽度 | 低/中/高三档的滤波带宽 | 各档差异**可辨**(AC-44-02) | 高档也像低档(白噪音感) | 三档听不出差别(玩家困惑) |
| `TierMap[0..2]` 的噪声底 | 接触噪声底 / 信噪比 | 噪声永不为零(AC-44-06) | 信号淹没在噪声里(玩不了) | 噪声近零(丢失「实习医生」体验) |
| `CONTACT_NOISE_floor` | 听诊器摩擦 / 衣料声 | 随 Tier 变化 | 变「爽声」/ 摩擦噪声失控 | 消失(丢失低档体验) |

### 语声变体族(F-44.3)

| 旋钮 | 含义 | 安全范围 | 调太高 | 调太低 |
|------|------|---------|--------|--------|
| 变体库粒度(男/女 × 强/中/弱 × 句尾数) | 变体数量 | 每组合 ≥2 个变体 | 素材量爆炸(重录灾难) | 变体太少(重复感 / 缺组合) |
| 交叉淡化时长 | 变体切换平滑度 | 无爆音 / 相位抵消(AC-44-04) | 切换拖沓(反应迟钝) | 爆音 / 相位抵消 |

### 快照族(ADR-018 §三)

| 旋钮 | 含义 | 安全范围 | 调太高 | 调太低 |
|------|------|---------|--------|--------|
| `StethoscopeFocus` 的 Ambience/Music 压低量 | 听诊聚焦强度 | 玩家主动动作驱动 | 听诊时世界消失(出戏) | 听诊无聚焦感 |
| 快照过渡时长 | 切换平滑度 | 行为驱动 | 切换拖沓 | 突变(爆音) |

### 全局

| 旋钮 | 含义 | 安全范围 | 调太高 | 调太低 |
|------|------|---------|--------|--------|
| 总线音量(Music / Ambience / Voice / SFX / Stethoscope / UICue) | 玩家可调(无障碍) | 0–1 / dB -80–0 | 玩家自担 | 玩家自担 |
| mono 选项 | 听力辅助(AC-44-13) | 开 / 关 | — | — |

> **跨旋钮约束**:`TierMap` 的通带与噪声底**必须同向变化**(高档 = 宽通带 + 低噪声底);
> 反向即破坏「档位 = 解析带宽」的语义(AC-44-01/02 会失败)。
> **归属**:全部 44 拥有(音频事件表 `assets/data/audio_events.json`,走 ADR-014 烘焙)。
> **与 8 的关系**:8 的 `READ_FLOOR_MIN > 0` 是**8 的旋钮**,44 的 `NOISE_FLOOR` 是它的**音频侧实现**,
> 两者各自调,但方向必须一致(都「永不为零」)—— 已在 AC-44-06 锁定。

## Visual/Audio Requirements

> **44 的 Visual 侧极小**:它**不新增任何视觉语言**(与 8 / 9 / 37 的负面声明体例一致)。
> 唯一视觉义务 = **无障碍的视觉替代**(规则九)。以下正面定义音频本体。

### 声学方向(承 42 拟物语汇,《双材》)

**44 的声音必须与《双材》视觉同源**:水墨写意的**留白 / 呼吸感** × 黄铜工业的**机械质感 / 精密反馈**。

| 层 | 声学方向 | 素材命名(承 `diagnosis-system.md:1627`) |
|----|---------|----------------------------------------|
| **Music** | 京戏 / 民国氛围;**留白优先,不铺满** | `music_*` |
| **Ambience** | 风 / 鸟 / 村落底噪;4 生态区各一套(ADR-015) | `amb_*` |
| **Voice** | 病人语声**变体库**(男/女 × 强/中/弱 × 句尾);**非参数调制** | `vo_patient_*` |
| **SFX** | 纸面 / 器物 / 脚步;拟物质感(黄铜件、纸页) | `sfx_*` |
| **Stethoscope** | 呼吸两层 + 接触噪声:**核心声道** | `sfx_breath_base_loop_small.wav` / `sfx_breath_adventitious_*.wav` / `sfx_steth_contact_*.wav` |
| **UICue** | 笔尖 / 翻纸(**仅行为反馈**,见规则二) | `ui_*` |

### 听觉信息优先级(ADR-018 §六 白名单的播放序)

多声源竞争时的次序(承 sound-bible 模板的 Audio Feedback Priority):

1. **玩家自身动作**(笔尖 / 落笔)—— 最高,直接反馈
2. **玩家主动检查声**(听诊器接触)—— 听诊中最高
3. **可感知的世界线索**(狗吠 / 锣声)—— 空间化,远近有别
4. **持续生理声**(呼吸层)—— 连续背景
5. **环境 / 氛围** —— 最低

> **⚠️ 本项目特有条目**:上表**没有**「危险警告」类(那是黑名单)。
> 玩家必须自己从第 2 / 3 / 4 项**推断**危险,而不是从一条「警告音」被告知。

### 硬约束(负面声明)

- **禁**:sting / jingle 宣告状态(「病人转危」「误诊」「结案」「成就达成」);
- **禁**:ducking **报**状态(可以玩家驱动地聚焦);
- **禁**:素材切换到**报**状态(「答对了 ⇒ 播正确音」);
- **禁**:连续水声冒充细湿啰音(AC-44-08,医学受众第一个出戏点);
- **禁**:突变音效标记阈值跨越(AC-44-10)。

### 无障碍(AC-44-12 / 13)

- **关键音频必须有视觉替代** —— 承 `templates/sound-bible.md:126`;
  **9 的呼吸是「唯一不看也能听出来的通道」,但信息不得仅存在于音频**。
- **mono 选项** —— 单声道设备 / 听力辅助。
- **各总线独立音量** —— 玩家可调。

> 运行 `/asset-spec system:audio-system` 生成逐素材的视觉描述与生成提示。

## Acceptance Criteria

> **27 条 / 九组。** 承 **ADR-018 §Validation** 的 AC-44-01…13 落在**组二 / 三 / 四 / 五 / 九**
> (逐条落原编号);**组一 / 六 / 七 / 八为本 GDD 新增**(呈现层边界 / 联机 / 空间化 / 管线)。
> 「(BLOCKING)」= 构建门 / 铁律级。

### 组一 · 呈现层边界(ADR-018 §一 —— 与 42 同构)

- **AC-44-B1**:**GIVEN** 44 的实现,**WHEN** 静态扫描其程序集,**THEN** 它**不引用 sim 程序集**、
  **无任何 `IEventSink.Append` 调用点**(grep 断言)。
- **AC-44-B2**:**GIVEN** `AudioCueDto`,**WHEN** `PresentationDtoGuard` **递归**扫描它,
  **THEN** **无 `disease_id` 字段**(AC-37-15 一致性)。
- **AC-44-B3**:**GIVEN** 44 的公开接口,**WHEN** 检查,**THEN** 只有 `IAudioCueSink`(只入不出),
  44 **无反向查询上游的接口**。
- **AC-44-B4**:**GIVEN** 44 的运行,**WHEN** 追踪,**THEN** 它**不持有任何游戏状态**
  (病人病情 / 病例状态 / 世界状态),只持有「声音正在发生什么」。

### 组二 · 无提示音铁律(ADR-018 §六 —— 支柱一的听觉保障)

- **AC-44-09(BLOCKING)**:**GIVEN** 音频事件表的每个 `CueId`,**WHEN** EditMode + CI 断言运行,
  **THEN** 每个 cue ∈ 行为反馈白名单类别,且**不存在**「CueId → 状态变化枚举」的直接映射;
  **故意加一条 sting cue 时断言必须失败**。
- **AC-44-10**:**GIVEN** 病人在呼吸层从「急促」过渡到「停顿」(转危),**WHEN** 播放,
  **THEN** 过渡是**连续**的,**无突变音效**标记阈值跨越。
- **AC-44-C1**:**GIVEN** 快照清单, **WHEN** 检查切换触发源,**THEN** 全部由**行为 / 场景状态**驱动,
  **无**任何快照由「状态变化」触发(§三 断言)。

### 组三 · 呼吸两层与精度档(ADR-018 §四 需求① —— V-8.7 债务清偿)

- **AC-44-01(BLOCKING)**:**GIVEN** 呼吸附加音层,**WHEN** 在低 / 中 / 高三档下播放,
  **THEN** 附加音层**始终非零**;**断言不存在任何「档位 ⇒ 该层静音」的实现路径**。
- **AC-44-02**:**GIVEN** 三档的呼吸音,**WHEN** 听测,**THEN** 差异**可辨**且**非静音型**
  (通带更窄 / 噪声底更高,而非更小音量)。
- **AC-44-08**:**GIVEN** 附加音层(细湿啰音),**WHEN** 实现,**THEN** 它是**吸气末、断续、细密的爆裂音**
  (搓头发 / 撕 velcro 那种),**咳嗽后不消失**;**不得**实现为连续水声(医学受众约束)。

### 组四 · 语声变体库(ADR-018 §四 需求②)

- **AC-44-03**:素材形态 = **变体库**(男/女 × 强/中/弱 × 数种句尾),运行时按
  **(病种语义, 精度档, 强度)** 选变体并**交叉淡化**;
  **禁**对已录语声做五项独立调制(音高 / 气声 / 语速 / 断句 / 共鸣)。
- **AC-44-04**:交叉淡化**无爆音(spike)、无相位抵消**。

### 组五 · 接触噪声 / 信噪比(ADR-018 §四 需求③)

- **AC-44-05**:`Stethoscope` 总线暴露**接触噪声底**与**信噪比**参数,由精度档驱动。
- **AC-44-06**:`READ_FLOOR_MIN > 0` 在音频侧有对应实现 —— **背景噪声永不为零**,但也不毁掉信号。

### 组六 · 联机(ADR-018 §五 需求④)

- **AC-44-07**:**GIVEN** 联机下同一听诊 cue 对 4 名玩家,**WHEN** 播放,**THEN** 听诊音层次**一致**
  (取主机技能档);**脉案的字体量仍各自分叉**(回归测试覆盖)。
- **AC-44-D1**:**GIVEN** 远端玩家的空间化,**WHEN** 检查位置来源,**THEN** 复用 **ADR-001 第二 QoS 通道**,
  44 **不自建位置通道 / 不新增 QoS 通道 / 不做语音通道**。

### 组七 · 空间化与坐标系(ADR-018 §二 · ADR-015)

- **AC-44-D2**:**GIVEN** `AudioCueDto.Cell`(整数格),**WHEN** 空间化,**THEN** 由表现层把整数格换算为 float;
  **禁从 float 反推逻辑格**。
- **AC-44-D3**:音频空间化**不写 sim**、**不回写三流**。

### 组八 · 管线与素材(ADR-018 §五 补注 · ADR-014)

- **AC-44-D4**:音频事件表走 **ADR-014 烘焙管线**;玩家构建**零 JSON 解析器**。
- **AC-44-D5**:素材本体 = `assets/audio/`(Addressables 流式),与 `data-core` 组区分。
- **AC-44-D6**:素材缺失 = **编辑期烘焙门拒绝**(构建失败,不是运行期静默降级)。

### 组九 · 无障碍 / VR / 性能

- **AC-44-11**(P1a):VR 空间化音频**无晕动症相关副作用**;头显挂**单 `AudioListener`**。
- **AC-44-12**:关键音频(承担信息者)必须有**视觉替代**。
- **AC-44-13**:提供 **mono 选项**。
- **AC-44-E1**:**GIVEN** P0 构建,**WHEN** 检查 VR 音频,**THEN** **不在 P0 范围**;
  P1a 交付切面(挂点 / 快照 / 延迟)已登记。
- **AC-44-E2**:**GIVEN** 音频 DSP 占用,**WHEN** 实测,**THEN** 不超帧预算
  (16.6 ms 平面 / 11.1 ms VR);**音频触发不在 `<50 ms` 急救延迟路径内**(急救判定本地即时,音频在其后)。
- **AC-44-E3**:**GIVEN** 混音拓扑,**WHEN** 检查,**THEN** 七条总线
  (Master / Music / Ambience / Voice / SFX / Stethoscope / UICue)**单一出处**,与 ADR-018 §三 一致。
