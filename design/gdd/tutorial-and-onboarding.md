## Summary

48 是**在零 UI 提示的前提下,把核心循环教给玩家**的那一层。

它的存在是一个**矛盾的正解**:本作**禁止一切按键提示浮层**(`AC-3-F1a`),
而一个玩家**必须知道怎么玩**。48 的答案 = **教的方式本身是世界的一部分** ——
**口述 · 示范 · 纸上的图**(`input-system.md:1004`),而不是浮层、箭头、任务列表。

**48 不持有游戏状态,不落盘,不阻塞任何东西。** 它的引导进度是**世界状态的纯函数**
(「这个玩家做过 X 没有」可从事件流读出)—— 与 51 的「回放即记录」、53 的「水龙头」
同一条纪律:**派生,不存储**。

## Player Fantasy

**「有人教过我,但没有人在旁边指挥我。」**

- **被带进门,而不是被推着走** —— 第一幕的引导是一段**关系**:
  某个人(师父 / 邻里 / 病人自己)告诉你「我们这儿是怎么看病的」。
  **它不像教程,像开场。**
- **学到的是「怎么想」,不是「按哪个键」** —— 48 教的最重要一课是
  **观察 → 判断 → 选手段**(支柱一)。教按键是**次要的副产品**,
  且**必须藏在世界动作里**(看别人怎么做一次)。
- **不被告知对错** —— 48 **绝不**在玩家做错时提示。
  承 8 铁律①(不给病名)与规律七(误诊不报错)。
  48 教的**只是动作与视角**,不教**答案**。

> **⚠️ 48 的幻想有硬边界:它不能变成「第一个任务」。**
> 无任务列表、无目标标记、无「去和 X 说话」的指引。
> **玩家可以完全不做 48 的引导而直接开始看病** —— 且**零惩罚**(规则五)。

## Detailed Rules

### 规则一:第一铁律 —— 零按键提示浮层(48 是第一责任人)

**48 绝不产出任何形式的操作提示 UI:**

| 禁止形态 | 为什么 |
| --- | --- |
| 「按 X 键」文字 / 图标浮层 | `AC-3-F1a` ① 明文禁止 |
| 高亮圈 / 箭头 / 世界内标记 | 同上一句话的推论:**任何「指这里」的东西** |
| QTE 提示条 | `AC-3-F1a` ① 明文禁止 |
| 持久 HUD 的操作提示 | 同 |
| 任务列表 / 目标追踪 | **反幻想一**(无待办;承 `case-system.md:947`) |
| 完成度 / 进度条(教学进度) | 承 UI-8.1 铁律②:那会把**理解**变成**打勾** |
| **教学期**的豁免 | **已否决**(`input-system.md:983`) |
| **教学口述零字幕** | **⭑ 2026-09-19 裁定新增** —— 人物语声统一配字幕(承 `AC-44-15`,与病人语声同类同规);**零字幕 = 与 AC-44-15 同场不一致** |

> **48 的回答只有三种媒体**(承 `:1004`):
> **① 口述**(世界内的人说)· **② 示范**(世界内的人做一次)· **③ 纸上的图**(世界内的一张纸)。
> **三者都是世界的一部分,不是叠在世界上的一层。**
>
> **⭑ 2026-09-19 裁定(承首轮评审 OQ-48-5 —— 用户裁定 [A] 复用字幕通道)**:口述**配有字幕**,
> 复用 42 / 44 已承诺的**人物语声字幕管线**(`AC-44-15`,2026-09-18)—— **字幕 ≠ 按键提示**,
> 不属 `AC-3-F1a` 禁例(它不「指哪按哪」,只承载说出来的话)。口述、示范、纸的**调度**不变,
> 只是口述多了**一条平行的文字承载**。**故「教学口述零字幕」本身被列为新禁项** ——
> 保持「病人语声 → 病人字幕 / 教学语声 → 教学字幕」同场一致(原 OQ-48-5 的「无任何文字承载」路作废)。

### 规则三:教的顺序 —— 观察 → 判断 → 选手段(不是操作顺序)+ **P0 内容清单**

48 的引导**按核心循环排**,不按「先说移动、再说交互」的**操作清单**排:

```
① 观察  —— 教「看」:怎么看一个人(承 8 的五通道)—— 总是内含在对病人「把脉+看气色」示范里(不单选)
② 判断  —— 教「本子」:怎么在一个病例上落笔(承 8 S-8.3 / 39)
③ 手段  —— 教「做点什么」:处置动作的存在(承 10 急救 / 11 处方用药)
④ 收尾  —— 教「结案」:一个病例如何了结(承 37)
⑤ 册子  —— 教「存档」:师父示范**翻开存档册**(媒体 = 示范)——《存档册教学入 LS 第⑤步》
⑥ 经营  —— 教「医馆」:建造 / 修缮的**存在**(承 24 医馆机器)—— P0 内容债清单末位,媒体以示范为主
```

**每条只教一次,且只教「有这件事」,不教「这么做就对了」** ——
承支柱一:玩家要**自己**发现判断的依据。

> **⚠️ 教「诊断」时不教病名。** 48 教的示例病例**不含任何「正确答案」**
> —— 示范者演示的是**动作**(把脉、翻本子、落笔),不是**结论**。

### 规则四:引导进度 = 世界状态的纯函数(**零持久化**)+ 两相语义(`Anchor` / `Completion`)

**48 不存任何「已教过」标记。** 引导是否触发,由**玩家的动作历史**推导。**⭑ 2026-09-19 修订
(承首轮评审 B1 —— 原 F-48.1 恒假的根因)**:触发必须拆成**两相** —— **完成判据**(`Completion_s`,
「已学会」,从动作历史读,单调)**与引发锚点**(`Anchor_s`,`Completion_s` 变为真的那一刻,边沿)。
原稿把「引发」与「完成」折叠进同一 `Taught` 符号 ⇒ `¬Taught ∧ Predicate ≡ ⊥`(见 F-48.1 勘误)。

```
完成(单调,读时计算):Completion_s(p) ⟺ Predicate_s(Proj(p))
引发(边沿,进程内闩锁):Anchor_s(p) @ t ⟺ Completion_s(p) 在 t 首次为真
                           (冷启动:从载入流播种,已满足谓词永不发火)
```

| 变量 | 说明 |
| --- | --- |
| `p` | 玩家(联机下**每人一份引导进度** —— 承 39 的分册同构;世界流 / 病史 / 病例流按 `author_player_id` 过滤) |
| `Completion_s` | **完成判据**(单调布尔):该步的**内容是否已被玩家做过**(逐条定义见 F-48.1 表) |
| `Anchor_s` | **引发判据**(边沿布尔):该步的**引导在该时刻首次触发一次**(进程内闩锁,非落盘) |
| `Proj(p)` | **边界层只读投影查询**(承 `AC-51-A2` 同型) —— 48 经边界程序集消费只读事件流投影;**不是**直接引 `SimEvent`(见规则七) |

> **⭑ 2026-09-19 裁定(承首轮评审 B3 —— `Proj` 无提供方)**:48 的 `Proj` 提供方 =
> **呈现层只读投影查询接口**(与 51 的「边界程序集只读引用 sim·零 Append」同构,ADR-019 §三)。
> 48 **可读**只读投影、**不可**引 sim 类型作交付物 —— `AC-48-04` 相应放宽为 **`AC-51-A2` 语义**
> (只读链),交付物仍限呈现 DTO(`assembly` 白名单)。

> **为什么必须派生**:① 落盘标记 = 第二真源(承 ADR-009 §一 Q1 判据);
> ② 它是**表现态**(只影响呈现),**进流会污染三流的有界性论证**;
> ③ 派生使「老玩家读档回到第一幕」也**不会重播教过的内容**(`Completion_s` 已成立,
> 闩锁从载入流播种)。
> **这是 51「回放即记录」与 53「水龙头」的第三次同构应用。**
>
> **⚠️ 无「可重看」**:`Anchor_s` 是**边沿**,`Completion_s` 已真的步**永不再发火** ——
> 「重看教学」不存在(规则一)。**「走近再说」** = 口述**重播**的呈现选项:同一 `Anchor` 已熄灭
> 的步,其口述内容**走近可再听**(呈现层本地回放,不产生流事件),**不违反一次触发** ——
> 「触发一次」的义务 = `Anchor` 不重复发火(玩家能不能再听,由呈现层决定,不改变 `Anchor` 状态)。

### 规则五:引导不阻塞、不做门

**48 绝不 gate 任何东西。**

- **玩家可以完全不理会引导** —— 不对话、不看图、不跟着做,**零惩罚、零提示**;
- **引导不锁动作、不锁系统** —— P0 无「先完成教学才能 X」(承 UI-8.2:「P0 没有不可用动作」);
- **引导可以中途丢下、事后回来** —— 判据是**动作历史**,不是**流程位置**。

> **不 gate 的机械化(2026-09-19 修订,承首轮评审 qa-#8)**:48 的 API 面**不得暴露**任何
> 「引导是否完成 / 某项功能是否解锁 / 是否处于引导期」的**查询接口** —— 由 **AC-48-17** 以反射 /
> 接口面断言守住(否则「零设门」退化为口头承诺)。

### 规则六:第一个病例 = 引导的载荷,不是特制关卡

**P0 的引导不新建内容** —— 它把**第一个病例**当作教学场:

- 37 提供「第一个病例」的**引导锚点**(`case-system.md:408`);
- 48 在这个锚点上**调度**口述 / 示范 / 纸上的图;
- **病例本身是真实病例**(走 9 / 37 的正常路径)—— 48 **不造假病例、不改病程**。

> **⚠️ 这是 48 与 37 的唯一接口,且是单向的:48 读 37,37 不知道 48 存在**(承 13 ↔ 37 的单向无环纪律)。

## Formulas

> **48 不产生任何数值。** 它是呈现系统 —— 公式只有**触发判据**与**顺序**两条,全布尔 / 枚举。

### F-48.1 引导步触发(两相:**引发** `Anchor` / **完成** `Completion`)

**⭑ 2026-09-19 修订(承首轮评审 B1 —— 原稿 `Taught(p,step) ⟺ Predicate_step` 代入
`FireAdvance = ¬Taught ∧ Predicate ≡ ⊥`,字面实现 = 教学永不触发;单调性 ≠ 边沿检测)。**

```
完成(单调,读时计算):Completion_s(p) ⟺ Predicate_s(Proj(p))
引发(边沿,进程内闩锁):FireAdvance_s(p)@t ⟺ Completion_s(p) 在 t 首次为真
                      (冷启动:闩锁从载入流播种 —— 已成立判据永不发火)
```

| 变量 | 类型 | 说明 |
| --- | --- | --- |
| `Proj(p)` | 投影 | 玩家 `p` 的**事件流只读投影**(边界层查询接口,承 `AC-51-A2` 同型;按 `author_player_id` 过滤) |
| `Predicate_s` | bool → bool | 该步的**完成判据**(逐条定义于下表;**单调**,即 `t` 处为真 ⇒ 永真) |
| `Completion_s` | bool | 该步的**内容是否已被玩家做过**(读时计算,零存储) |
| `FireAdvance` | bool | 该步的引导在 `Completion_s` **首次为真那一刻**触发一次(**边沿**,进程内闩锁) |

> **一次性的实现不需要存储**:`Completion_s` 单调 ⇒ `FireAdvance` 自然是个边沿(首真时刻),
> **由闩锁捕获,不是计数器、不是落盘标记**。**有界性**:每帧重投影 = O(|流|×4×4×帧);
> 单调闩锁使摊销 **O(1)**(已在边沿捕获,不再重扫)。存储态止于 ≤24 布尔。
> **冷启动播种**:读档瞬间 `Completion_s` 已真 ⇒ 闩锁直接置饱和,永不发火(AC-48-08)。

**`Predicate_s` 逐条定义(承首轮评审 B2 —— 原稿只有「如…」示意,不可实现)**:

| `s` | 步 | 定义(`∃` = 存在,作者 = `p`) | 源流 / Kind |
| --- | --- | --- | --- |
| `1` | **判断**(含 ① 观察,合并入 `Anchor_1`) | `∃` 首个 `CaseOpened(patient=p)` | 病例流(37:408) |
| `2` | **落笔** | `∃` `JudgmentRecorded(author=p)` | 病例流(39 分册轴) |
| `3` | **手段** | `∃` `EmergencyAttempt` / `DrugTreatmentApplied`(initiator=p) | 病史流(10 / 11) |
| `4` | **收尾** | `∃` `CaseClosed(patient=p)` | 病例流(37) |
| `5` | **册子** | `∃` `Checkpoint` 写入(7a) | 存档头 / 7a |
| `6` | **经营** | `∃` `StructurePlaced(23)`(承 22 / 24) | 世界流(23) |

> **单调性**:每条判据都是「某事件是否存在」 —— 存在性是单调的。**蕴含链**:⑥ 是内容债末位
> (可缺席);②–④ 若玩家直接做了 ③ ⇒ ② 与 ③ 的判据**同时成立**(事件彼此独立,见 F-48.2)。

### F-48.2 步序单调性

```
step ∈ {1, 2, 3, 4, 5, 6}      // 判断(→含观察)→ 落笔 → 手段 → 收尾 → 册子 → 经营
∀ p:  Completion_j(p) ⟹ Completion_k(p)   (j ≥ k 时无蕴含;判据彼此独立,如 ②、③)
```

> **⭑ 2026-09-19 修订(承首轮评审 B2 —— 原 F-48.2 断言「做③⇒①②同时成立」仅当谓词嵌套;原稿
> 恒假公式下该断言**不推导自任何公式**)。现口径:**判据彼此独立**(各自是事件集合上的存在性),
> 玩家可**任意跳步**;跳过的步的 `Completion_s` 可能**永远不成立**(内容未做)⇒ **不补播**(承规则五)。
> 「不补播」= **不因跳步而重播已完成内容**,由 `Completion` 单调性直接保证,不依赖任何蕴含链。
> 若玩家直接做了 ③ 处动作但从未落笔(②),② 的 `Completion_2` 不成立 ⇒ 02 的引导**稍后**仍可发火
> (玩家随时可以回来做) —— 与「可丢下、可回头」(规则五)一致。

## Visual/Audio Requirements

- **视觉 = 世界内的纸与人**:
  - **口述**:NPC 面向玩家说话(承 13 的行为表现);**无对话框气泡**(那是浮层)。
    ⭑ **2026-09-19(承 OQ-48-5 裁定)**:口述**配字幕**(复用 `AC-44-15` 管线,归 42 呈现、
    44 供语义)—— **字幕 ≠ 按键提示**,不属 `AC-3-F1a` 禁例。**听力障碍玩家经字幕获得全部口述内容**。
  - **示范**:NPC 执行一次动作(动画归表现层,承 25 的「倒下 = 水墨」同源口径:动作优先于 UI);
    示范 clip 由 **13 经 42 的 one-shot clip 请求接口**开姿态槽位(呈现层一次性)。
  - **纸上的图**:一件**静态、不可拾**的世界道具(6 布置),**走近 → 42 近景模态**阅读,
    承 42 的纸纹 / 墨迹元件库(⭑ 2026-09-19,见规则二)。
- **音频**(承 ADR-018 §六):口述 ∈ 世界内空间化声源;**禁**任何「教学 jingle / 叮一声 / 高亮音」
  —— 那是**状态播报**(「你学到了 X」),属无提示音铁律的黑名单侧,**由 AC-44-09 断言**。
- **一律无 HUD** —— 本节**不产出任何 HUD 规格**(规则一)。

> **本节只给边界与语义** —— 具体道具 / 材质 / 声源规格归 `/art-bible`、42 的元件库与 44 的 sound-bible。
