## 0. 本文件的口径与边界（**先读**）

**① 本卷没有人声槽（`ChorusSlots = 0`）**
卷一只有沈砚之 1 人（`vol-01.md` §3.8：论道层**关闭**）。按 `dialogue-system.md` §3.4 / §4.1，**可发声同伴数 = 0** → 本卷**不浮现任何同伴心声**，UI **不得**渲染心声槽位。

> 故本文件的文本只有**三类**：**叙述**（**第二人称**，对玩家说话，如"你扶了扶西装的下摆"）· **NPC 对白**（母亲 / 老郎中 / 老周 / 镇人 / 妇 / 脚夫）· **沈砚之内心独白**（**第一人称**"我"）。**叙述层与独白层的人称不得混用**（承 `vol-01.md` §3.5.1 文风约束"人称"条）。**没有"入心 / 旁注"机制**（无对象可入）。

**② 本文件是 `vol-01.md` §2 的全文落地**
场景链、节拍序、前置条件、产出 flag 以 `vol-01.md` §2.2 / §2.4 / §2.5 为**唯一真源**；本文件只做**文本实现**。二者冲突时**以 `vol-01.md` 为准**。

**③ 叙述两恒开、论道层关闭**
人间层 + 临床层**恒开**（`dialogue-system.md` §3.5 表 A）；**论道层关闭**（开启条件是"异门同伴视野 ≥ 1"，卷一 `ChorusSlots = 0`）。本文件**不出现**学派分歧的深论——那是卷二陆九针加入后的事。

**④ ★ 术语口径：章 A 与章 B 不同（勿套用）**
- **章 B** 的 D1 / Q1 / S1 文本**不出现任何中医术语**（`vol-01.md` §3.8，人间层禁令）。
- **章 A** 的 **A-2 战斗旁观遭遇**里，**老郎中故意说术语而不解释**——"寒邪束在表头。该散，不该清。"（`vol-01.md` §2.4 ①；**判词标点钉死为句号**）。这是**刻意的**：玩家**看见**这套话，**听不懂**它，正是"只给现象、不给原理"（§1.3 一级教学弧）。**注意边界**：他的**自白**（"她缩着肩——是怕冷""这味是给她止咳的""药不在多，在对着哪儿使"）用**白话讲依据**，**不是**把上面的术语翻译成机制——**术语说出口但不解释，白话只讲行为与理由**（`vol-01.md` §2.7 临床层边界）。
- **★ 边界二：缺口约束（2026-09-12 补，承 `vol-01.md` §2.7）**：老人的**自白答的是「用药之理」**（为什么下这一味）；**「辨证之法」仍然不给**——他**凭什么**先问"怕冷还是怕热""夜里咳还是天明咳"、怎么从这两个回答走到"该散不该清"，**全程不说**。**故自白不得出现**"我一看就知道是表证""这是风寒束表，所以用麻黄"式的**辨证机理**。这一缺口正是 §1.3 一级教学弧的落点（玩家"**说不出他凭什么先问那两句**"），也是章 B 的痛。
- **唯一的不变量**：**沈砚之自己的独白**不用整体论的诊断词（他不信、也不会用）——他的独白是纯还原论视角。

**⑤ 零随机**
本卷对白**全部确定性**（`dialogue-system.md` §3.11 / `vol-01.md` §7 AC）。本卷玩家**无四诊牌**，故**不存在**"问诊 90%"随机源。

**⑥ 伏笔埋设点（本文件负责的文本面）**
- **#3 随身病理学笔记** → S-A1（`vol-01.md` §2.3 S1 / §4.2）
- **#2 药茶** → S-A4 + S-A7（台词面）
- **#1 祖父遗稿「陆九针」三字** → S-A5

## 2. S-A1 码头·登岸（`sc_v1_dock` · A-1）

**情境**：游戏开场。汽笛长鸣，火轮靠岸。沈砚之**独自**回家——不是衣锦还乡，是**回来"告别"**。

**节拍 A1-1｜叙述 · 登岸**

> 汽笛长鸣。火轮慢慢靠上码头。
> 你扶了扶西装的下摆。这身在舷梯上显得很挺括，踩上青石板，就有点陌生了。
> 怀里的手稿硌着胸口——一沓病理学笔记，你在船上又誊了一遍。**（#3 埋）**

**节拍 A1-2｜对白 · 脚夫**

> （脚夫）"先生，箱子搁哪儿？"
>
> （沈砚之）"沈氏医庐。青石巷里头。"
>
> （脚夫）"哟——沈家的少爷回来了。老郎中……可惜了。"
>
> 你顿了顿。
>
> （沈砚之）"……嗯。"

**节拍 A1-3｜★ 独白 · 归舟的立场**

> 我回来，是来告别的。
> 把老宅处置了，接娘去上海。

## 3. S-A2 巷口·看老郎中治病（`spect_v1_old_doctor` · A-2）★ 章层战斗旁观遭遇

**情境**：沈砚之**独自**在巷口撞见老郎中给镇上妇人治病。**周慧兰不在场**（`vol-01.md` §2.4 ⑥）。
**结构**：`ctb = true` —— 本遭遇**真跑 3 个 CTB 回合**（`R1 / R2 / R3`），**每回合老人出一味药**，并把他的**判断依据与用药依据**用**自白**说出口。

> **呈现口径（硬约束，承 `vol-01.md` §2.4 / `combat-system.md` §3.10）**
> ① **玩家零输入**；唯一可用交互是**注视点**（§3.4）。
> ② **数值一律不上屏**：全程**不显示**病邪条 / 正气条 / 行动条 / 证候向量 / `M` / `ΔE` / 牌名 / 任何资源数值——**即便 CTB 在内部真跑**（呈现层与结算层分离，`combat-system.md` §3.10）。
> ③ **不给机制解释**；本遭遇**真跑 CTB**（老人出牌、`ΔE` 内部照算），但**玩家侧不可见**，且**不结算 `Rating` / `IP`**、**不计入 `Progress`**、**恒不可失败**。
> ④ **可跳过**（`skipAllowed = true`）——语义见本节末。
> ⑤ 下列 `R1…R3` = `vol-01.md` §2.4 `script` 的三个 **CTB 回合**（术语已由 `B1…B3` 更名——**旧"三节拍"即今"三回合"**）。`combat-system.md` §3.9 的"诊 / 辨 / 治"三段是**每回合内的叙事框架**，**不是**回合的计数单位。

### 3.1 回合 R1｜诊 · 辨 · 第一味（麻黄）

> 药铺在巷口。门脸旧，招牌上的漆掉了半边。
> 你在门口停住。里头围着几个人。
> 一个老先生正给镇上一位妇人看病。你没见过她——三十来岁，一直捂着嘴咳。
>
> 老先生先看她的舌，再看她的气色。
>
> （老郎中）"怕冷，还是怕热？"
>
> （镇上妇人）"怕冷。身上总是凉飕飕的。"
>
> （老郎中）"夜里咳得凶，还是天明咳得凶？"
>
> （镇上妇人）"夜里。一到后半夜就咳得睡不着。"
>
> 老先生点点头，闭上眼，三指搭上她的腕。
> 半晌，没出声。
>
> 他睁开眼。
>
> （老郎中）"寒邪束在表头。**该散，不该清。**"
>
> ……我没听懂。
> 按我的法子，这时候该量体温、该听肺、该取痰。
> 可我什么也做不了。我只能站着。
>
> 老先生像是在跟自己说话——
>
> （老郎中）"她缩着肩——是怕冷。这病在**皮面上**，得**往外赶**，不能**往里压**。"
> 他拉开一格抽屉，取出一味。
>
> （老郎中）"第一味。发汗的。"
>
> 妇人咳了一阵，咳嗽的**间隔**松了些。

> **口径（勿踩）**：
> - 判词"寒邪束在表头。该散，不该清。"**逐字保留**（`vol-01.md` §2.4 / §2.3；**标点钉死为句号**）：老郎中**只说方向、不点破机理**。
> - **自白用白话**（`vol-01.md` §2.7 临床层边界）：他说"皮面上 / 往外赶 / 往里压"——这是**他判词的日常话重述**，**不是**把术语翻译成机制。**不得**出现"表证就是……""寒邪会……"式的解释。
> - **自白**只讲**用药之理**（为何下这一味），**不讲辨证之法**（他凭什么先问那两句）——见 §0 ④ **边界二**。
> - **沈砚之的独白用纯还原论语言**——他不知道"散"是什么、也不知道"清"是什么，这正是教学落点。
> - **机制侧（勿写进游戏文本）**：本手 `主靶轴 = 表里:表`、`M = 0.7`（**未揭示列 · 同轴**——`revealed = ∅`，**呈现层演了四诊 ≠ 结算层写入证候**，故永远进不了"已揭示"列）、`ΔE = 35 × 0.7 = 24.5 → 25`、病邪 `60 → 35`——**全部不上屏**（`vol-01.md` §2.4）。

### 3.2 回合 R2｜第二味（杏仁）

> 老先生再看她一眼，听她咳。
>
> （老郎中·自白）"凉赶出去一半了。她还咳——夜里咳得最凶。光赶凉不够，这味是**给她止咳的**。"
> 他又拉开一格抽屉。
>
> （老郎中）"第二味。让她这口气顺下来。"
>
> 妇人喘了口气，肩膀塌下来。

> **口径**：自白承载**用药依据**——"为什么加这一味"（对应"夜里咳得凶"这个**问出来的事实**）。**仍不给机理**：不说"肺气不降"，只说"止咳"。

### 3.3 回合 R3｜第三味（甘草）· 收手

> 老先生不再搭腕，收手。
>
> （老郎中·自白）"甘草，甜的。**这味不冲病去，是护着她的。**……**够了——药不在多，在对着哪儿使。**"
> 第三味药，分三手取完。
>
> 妇人当场把药汁喝了。
> 她喘了口气，肩膀松下来。
>
> （镇上妇人）"……好多了。先生，谢谢您。"
>
> 我想问一句"为什么"。凭什么三味药，就让她松快了。
> 话到嘴边，又咽了回去。

> **口径**：末句"**药不在多，在对着哪儿使**"是**老人给玩家的、唯一可带走的一句白话道理**——它讲的是**"对着哪儿使"**（靶向），**不是**"望闻问切"（诊断法），与卷一还原论的"靶"暗合（`story-bible.md` §12.4）。**但仍不给"怎么知道对着哪儿"**——那正是章 B 的痛。（对照 3.5 离场独白走"原来要这样**问**"，二句**不重复**。）

### 3.5 收束独白 · 离场（R3 之后；一级教学弧落点）

> 三味药。就三味。
> 我看过一千份解剖报告，却看不出一张方子里藏着什么。
> 我转身走了。心里有个念头，很小，我不肯细想——
>
> "……原来要这样问。"

> **口径（勿踩）**：
> - **不解释**他"说不出为什么"（`vol-01.md` §1.3 一级："只给现象，不给原理"）。此独白**必须停在"说不出"上**，不得让它变成"我明白了"。
> - 末句"**原来要这样问**"直接承接 `vol-01.md` §1.3 表一的模糊参照系，以及 §2.4 末段"玩家离场时心里带着一个模糊的参照系"。**注意**：它与 R3 的"药不在多，在对着哪儿使"**互补不重复**——前者指向**诊断法**，后者指向**靶向**；**两句都只有"方向"，没有"怎么做到"**（那留给章 B）。
> - 此独白**不产 flag**；`spectated` / `watched_diagnosis` 由遭遇本身的 `yields` 白名单产出（见下）。

## 10. 口径张力与待办（喂回上层）

> **本文件不改任何系统规则**（内容层无权重）；下列冲突**登记**，不就地"修好"。

**T1 · 「化验单」的年代性（待核）**
- **症状**：本文件**两处**用到"**化验单**"（**S-A1 独白** / **S-A5 叙述**）——**R1 沈砚之独白中并无此词**（其独白作"该量体温、该听肺、该取痰"，**不含**"化验单"）。该词出现在 `story-bible.md` §6.1 的**标志性台词**里（"中医连一张化验单都没有"），属**上游授权用词**；但 §10.3 的"避坑指南"**未**收录它，且"化验"作为机构化的检验报告，在 **1905 年的江南乡镇**是否已有稳定叫法，**未核实**。
- **两条出路**：**(甲)** 保留（承 story-bible 授权）；**(乙)** 换为更稳的说法（如"一张验单""一张检验的凭据"）。
- **本文件取 (甲)**，并**登记**——若裁决 (乙)，须**同时**改 `story-bible.md` §6.1 / §七 卷一 的两处标志性台词（**共四处同改**：本文件 2 + story-bible 2）；**本文件不单方面改**。

**T2 · A-2 是否允许沈砚之独白**
- `vol-01.md` §2.4 只规定"**玩家零输入**、不弹数值、不给机制解释"，**未禁**独白。本文件在 R1（诊·辨后）/ §3.5 离场各加了 1 段独白（**纯叙事、不产 flag**）。
- **风险**：独白若写成"他明白了"，会稀释 §1.3 一级教学弧的"**说不出为什么**"。**新增风险（rev b）**：老人自己的**自白**若越界成"讲机制"，会与沈砚之的"听不懂"打架——故自白**只讲行为与理由**（用白话），**不讲术语与因果**（`vol-01.md` §2.7 临床层边界）。**新增风险（rev c）**：自白若把"**辨证之法**"也答了（即说明他**凭什么**先问那两句、怎么从"怕冷 / 夜咳"走到"该散不该清"），则 §1.3 一级教学弧的落点（"**说不出他凭什么先问那两句**"）**直接消失**。
- **本文件的护栏**：沈砚之两段独白**都停在"听不懂 / 答不上来"上**，末句"原来要这样问"只是**模糊参照系**，不是领悟；老人自白**不含术语、不含机制**。**（rev c 补）**自白**只答用药之理、不答辨证之法**——见 §0 ④ **边界二**；**禁**"我一看就知道是表证"。请 narrative-director 终审确认。
