## 1. 概述 Overview

战斗系统是本作对"治病"这一行为的下游机制化：玩家面对的不是敌人，而是**一场病**。场上有两类实体——**病机 Pathomechanism**（携带「病邪 Qi-Evil」条）与**病人 Patient**（携带「正气 Vital Qi」条）。玩家指挥由队员组成的医疗队，在**行动条（CTB）**时间轴上依次出手，用取自各自**方剂牌组**的牌去削减病邪。**病邪清零 = 治愈（胜）；正气归零 = 病人死亡（败）**——玩家可能因为"用药过猛"而输掉一场已经"指标正常"的战斗。系统同时承载两套医学认识论（还原论与整体论），并以"只靠一套必败"的结构迫使玩家两者并用。

> **快速索引** — 双资源：剂量 Dosage（还原）/ 气机 Qiji（整体）· 双条：病邪 / 正气 · 核心张力：治得快 vs 治得住。

## 2. 玩家幻想 Player Fantasy

**"我同时拿着显微镜和脉枕。"**

玩家要体验的，是一个医者在病床前的**双重专注**：一边用化验与检查锁定病原的身份（"是哪种菌、坏在哪个器官"），一边用望闻问切读出这个人此刻整个的状态（"他此刻是寒是热、是虚是实"）。成功的战斗有一种**侦探破案式的豁然**——证候对上的那一刻，牌力骤增，"啪"地一声，病邪退去。

同时要有**如履薄冰的责任感**：你手里的牌是药，也是刀。打错一张，病人的正气就掉一截；为了速战而滥用峻剂，可能赢下指标、输掉病人。玩家在胜负之间体验到的不是"打赢了"，而是**"我把他救回来了"**或**"我把他治死了"**。

**情绪目标**：从容辨析（侦探式）+ 责任重量（不可轻率）+ 顿悟快感（对证时牌力爆发）。

## 3. 详细规则 Detailed Rules

### 3.1 战场实体与胜负条件

| 实体 | 携带条 | 归零后果 | 备注 |
|---|---|---|---|
| 病机 Pathomechanism | 病邪 Qi-Evil（0–100 基准值） | 治愈（胜） | 一"敌"可含多个病机（多病邪条） |
| 病人 Patient | 正气 Vital Qi（0–100 基准值） | 死亡（败，立即判定） | 一"友"方病人，可为多人 |
| 医者 Healer | 无血条；有资源 | 无 | 牌组使用者 |

**胜负判定顺序（不可颠倒）**：
1. 若任一病人**正气 ≤ 0** → **立即判负**（即使同一结算中病邪也已归零）。
2. 否则，若所有病机**病邪 ≤ 0** → **判胜**。
3. 否则继续。

> 判定顺序即本作的核心道德命题：**"指标正常了，人没了"依然是失败。**

### 3.2 双资源（两套认识论）

| 资源 | 归属认识论 | 生成 | 过用后果 |
|---|---|---|---|
| **剂量 Dosage** | 还原论（西医） | 每回合基础回复 + 部分牌生成 | **耐药 Resistance**↑ → 同族药效衰减 |
| **气机 Qiji** | 整体论（中医/心身） | 每回合基础回复 + 部分牌生成 | **气机紊乱 Disruption**↑ → 回复效率衰减 |

- 每张牌标明其**费用类型**：还原牌耗剂量，整体牌耗气机。玩家**不能**用一种资源支付另一种的牌——这是"两套语言"的硬边界。
- **资源按队员各自独立核算**：每位在场医者持有**自己的**剂量池与气机池，出牌由**发牌者本人**支付，**不共享、不跨人支付**（见 `party-system.md` §3.2 / §3.6）。
- 资源上限与初始值由队员属性与图谱决定（见第 4、7 节）。

### 3.3 行动条 CTB（出手顺序）

- 每个实体（医者、病机）在行动条上拥有「行动值 ActionGauge」。
- 每时间刻 Δt：`ActionGauge += 速度 Speed × Δt`。
- 当 `ActionGauge ≥ 阈值 Threshold`（默认 1000）→ 该实体行动；行动后 `ActionGauge -= Threshold`。
- 同一刻多方同时达标 → 按 **速度降序** 结算；速度相同 → 按 **队伍位次**（医者优先于病机，遵守"救人先手"的主题）。
- 影响行动条的牌：**先手**（自身行动值 +Δ，提早上场）、**迟滞**（目标行动值 −Δ，推迟病机发作）、**回气**（提前一轮行动）等。

### 3.4 证候向量（辨证）

- 每个病机拥有一组**隐藏的「证候向量」**，取自八纲的四个轴，每个轴为**双极**：

| 轴 | 两极 | 说明 |
|---|---|---|
| 表里 | 表 / 里 | 病位浅深 |
| 寒热 | 寒 / 热 | 病性 |
| 虚实 | 虚 / 实 | 正邪消长 |
| 阴阳 | 阴 / 阳 | **总纲**——唯一有"两层"的轴：表层极（望，仅线索）/ 深层极（切，真正的证），见 3.5 |

- 每个轴带**强度** ∈ {1, 2, 3}（弱 / 中 / 强）。
- 证候对玩家**默认完全隐藏**；玩家必须用四诊逐轴揭示。

### 3.5 四诊（揭示手段）

| 诊法 | 耗费 | 揭示的轴 | 特性 |
|---|---|---|---|
| **望** Observe | 1 行动 | 表里、**阴阳表层极** | 稳定；对"表证/神色"最灵 |
| **闻** Listen/Smell | 1 行动 | 寒热 | 稳定；对气息、声音类病机必用 |
| **问** Ask | 1 行动 + 1 资源 | 寒热、虚实 | **90% 准确**——病人可能答错（见 5.8） |
| **切** Palpate | 1 行动 → **0 行动（被动）** | 虚实、**阴阳深层极** | 需医者具「气感」属性；无气感者**不可执行**（不返回深层阴阳，**非假值**） |

- **阴阳两层（本作核心机制之一）**：阴阳是唯一分"表层 / 深层"的轴（详见 `status-syndrome.md` §3.2）。
  - **望**给的是**表层极**——一条**线索，不是证**。**在切诊之前，阴阳轴按"未证"结算（M = 0.7）**，望得的表层极**不触发** M=1.5、**不触发**悖证。
  - **切**给的是**深层极**（由完整阴阳值决定，含病机固有倾向）——此后的阴阳轴才进入「已知」态，才参与 M 与悖证判定。
  - 普通病机两层一致（无破绽）；**心身 / 志怪类**病机两层可分叉（表层"阳"、深层"阴"），是单镜型玩法的侦探钩子。**纯还原阵容没有气感 → 切诊不可用 → 深层阴阳读不到 → 心身病机对它永久不可见**（此"缺眼"效果无需特判，由规则涌现，见 4.10.4）。
- **切诊被动（角色职能）**：队伍中若有**苏晚棠或陆九针**在场，切诊**不耗费行动**——辨证是中医角色的核心职能，应由他们承担操作负担。望 / 闻 / 问 仍耗 1 行动。此被动使"带对的人"在辨证节奏上获得实质收益，强化"聚散皆成长"。**注意**：切诊被动是"看谁在队"，与"谁有气感"是两回事——**能免费切 ≠ 人人能切**；无气感者即便免费也读不到深层阴阳。
- 每揭示一个轴，该轴进入「已知」态，牌结算时按已知真实值判定。
- **未揭示轴**：玩家出牌时该方向视为"未证 Unverified"，匹配系数 **M = 0.7**，**不伤正气**。惩罚只针对"无视已揭示信息的鲁莽"（见下），不针对"信息不足时的合理猜测"。
- **悖证是可预判的确定性惩罚，不含随机**：若某轴**已揭示**，而玩家打出与该轴真实极**相悖**方向的牌 → 悖证（M = 0.0，伤正气，见 4.3）。玩家永远能事先知道一张牌会不会伤到病人——**失误是选择的结果，不是运气的结果**。**对阴阳而言**："已揭示"仅指**深层极**已由切诊揭示；只有表层极时不算已揭示，**永不触发悖证**（见上）。

### 3.6 治法牌（八法）与匹配

- 治法牌对应中医**八法**，每张牌标注其**法**与**方向**（作用于哪个轴的哪一极）。

| 法 | 主作用 | 典型方向 |
|---|---|---|
| 汗 | 解表 | 表 |
| 吐 | 涌吐上焦实邪 | 里·上焦·实 |
| 下 | 攻下里实 | 里·实 |
| 和 | 调和半表半里 / 阴阳 | 阴阳·失和 |
| 温 | 温里散寒 | 寒 |
| 清 | 清热 | 热 |
| 消 | 消积散结 | 里·实（缓） |
| 补 | 扶正补虚 | 虚 |

- 牌与证候的匹配关系决定效力与是否伤正（见 4.3）。

**★ R1（本轮新增）· 每张牌必须声明「主靶轴」与「次靶轴」**：

| 字段 | 作用 | 是否影响 `M` |
|---|---|---|
| **`mainAxis` 主靶轴**（单值，形如 `虚实:虚`） | **M 的唯一决定轴**（见 §4.3） | **是**——`M = M(mainAxis)` |
| **`subAxes` 次靶轴**（0–n 个） | **只贡献悖证**（该轴已揭示且相悖 → 触发 §4.3b 伤正） | **否**——**不加成 `M`** |

- **为什么必须显式声明**：`M` 的判定**只能有一个输入轴**（§4.2 的公式里 `M` 是标量）。多轴牌若不定主次，`M` 就无从取值——这正是 **D9** 的根因（详见 §4.3 D6 / D9 裁决）。
- **守卫**：`status-syndrome.md` §5 已要求"多轴牌的 `M` 只取主靶轴"；本条把该要求的**数据前提**（牌必须有主靶轴）钉进战斗侧。
- **★ R3 · 卷一教学牌「补液·支持」的轴声明**（原「强心剂」，2026-09-12 更名；**更名与本次轴声明均不改 `P` / 资源类型**）：

  | 字段 | 值 |
  |---|---|
  | 资源 | 剂量（还原） |
  | `P` | 35 |
  | **`mainAxis`** | **`虚实:虚`** |
  | `subAxes` | `[表里:里]` |
  | `no_resistance` | `true`（**本轮新增，见 §4.5**） |

  - **`mainAxis = 虚实:虚` 是 D9 的裁决结果**：卷一的 `虚实` **可由章 B 的探索节点 `ex_v1_m_4` 揭示**（见 `design/levels/vol-01.md` §3.4），故打出「补液·支持」**可能**进入 `M = 1.5` 对证档——这是**卷一唯一**能让玩家亲身体会"对证 → 牌力骤增"的通道（详见 §4.3 D9 裁决）。若改取 `mainAxis = 表里:里`，则卷一永不揭示 `表里`、`M` 恒为 `0.7`，**卷一将不存在任何 `M = 1.5` 时刻**——玩家体会不到对证的收益。

### 3.7 峻剂（风险回报）

- 部分牌为**峻剂 Drastic**（猛药）。打出时**主动**以病人正气换取更高病邪削减。
- 峻剂对病人正气造成固定损耗，换取约 **3:1** 的病邪收益（见 4.4）。
- 峻剂是**玩家主动选择**的风险，与"错治惩罚"（被动）并列为两条伤害正气的路径。

### 3.8 合方 / 合击（汇通连线技）

- 战斗中的最强牌来自成长系统的**《杏林汇通录》跨树连线**（见 `design/gdd/progression-system.md`）。
- 一条"通" = 一张**合方牌**：同时具备还原与整体两种方向，可一次性处理"病邪削减 + 正气维护"。
- **费用"双付"**：合方牌由**两端队员各付其对应侧资源的一半**（见 `party-system.md` §3.6）；若一端为"遗志"（殉职者）或不在场，则费用全由在场发起方承担。合方牌要求**两端队员均在本场出战**。
- 合方牌享受**汇通连线加成 S_link**（见 4.6），且**不受**单侧耐药/紊乱影响（因为它换用了新的认识论）。

### 3.9 回合流程

1. **诊段**：战斗开始，证候全隐藏；玩家可先手投入四诊行动。
2. **辨段**：玩家依据已揭示轴，决定以哪套认识论为主、出哪一法的牌。
3. **治段**：CTB 推进，交替出牌→病机行动（病机行动通常**加剧病邪**或**损耗病人正气**，视病机类型）。
4. **收束**：判定胜负；结算战斗评级（治愈/代价/是否留后遗症）。

**状态机（病机）**：

| 状态 | 进入条件 | 退出条件 | 行为 |
|---|---|---|---|
| 潜伏 Latent | 战斗开始、未揭示 | 任一轴被揭示 | 不行动或弱行动 |
| 发难 Active | 被揭示 / 回合数达标 | 病邪清零或传变 | 正常行动 |
| 传变 Shifting | 回合数达到传变点 | 传变完成（1–2 回合） | 重组证候向量（见 5.4） |
| 势穷 Spent | 病邪 ≤ 20% | — | 行动减弱（濒死反扑可选） |
| 已瘥 Resolved | 病邪 ≤ 0 | — | 移出战场 |

### 3.10 旁观遭遇 Spectator Encounter

一种**玩家零输入的演出**（`playerControl = none`）：完整的"诊 → 辨 → 治"由**固定脚本**驱动。用于教学铺垫（卷一 A-2：旁观老郎中治病，见 `design/levels/vol-01.md` §2.4）与剧情演出（如卷二"回看"陆九针救母）。

**两个表现模式（`ctb` 字段，2026-09-12 增）**：

| `ctb` | 名称 | 是否实例化战斗循环 | 用途 |
|---|---|---|---|
| `false` | **叙事旁观** | **否**——三段 = `§3.9` 的 诊段 / 辨段 / 治段，是**叙事节拍**，不是行动回合 | 纯演出（如卷二"回看"） |
| `true` | **战斗旁观** | **是**——真跑 CTB，逐回合出牌、逐回合结算 `ΔE`；玩家零输入 | 教学铺垫（**卷一 A-2**） |

> **为何要有"战斗旁观"**：教学承诺是"**仙剑式的'先看别人打，再自己打'**"——若旁观段**根本不跑战斗**，玩家看到的是"别人**问**了一遍"，**看不到"打"**。故 A-2 取 `ctb = true`：玩家逐回合看见"**看见 → 判断 → 出手 → 病人变化**"的**决策链**，这才是可被模仿的对象（`design/levels/vol-01.md` §2.4 设计意图）。

**两个模式共有的不变量（硬约束，勿踩）**：

- **玩家零输入**：`playerControl = none`；玩家尝试操作时**输入被忽略**（§5）。唯一可用交互是注视点（`FocusPoint`，纯叙事，不产 yield）。
- **不产出评级与 IP**：不结算 `Rating`（§4.7）、不发放 `IP_gain`（**真源 `level-system.md` §4.5**；**卷一–三不发放**见 `progression-system.md` §3.9）；不计入成就、战斗统计、连胜 / 连携数据。**`yields` 白名单只允许 flag**（`level-system.md` §3.2.1）。
- **UI 不显示机制数值**：**不显示**病邪条、正气条、行动条、证候向量、`M` 值、`ΔE`、牌名、资源消耗。只呈现"**动作 + 病人状态变化 + 角色自白 / 独白**"。理由：教学期"不给机制解释、不弹数值"（`design/levels/vol-01.md` §1.3）。**`ctb = true` 时数值在内部照算**（否则不是"真战斗"），但**不呈现给玩家**——见下"呈现层与结算层分离"。
- **恒不可失败**：`failMode = none`，脚本 / 病机配置保证演出必然走到"治愈"。"正气下限钳到 1"（`level-system.md` §3.6）在此**不触发**——脚本保证病机不会把人打死（卷一同例：`drainPerTurn = 0`）。
- **确定性**：脚本是固定序列，无随机源（`combat-system.md` §4.7 的"问诊 90%"随机源**不在此启用**）。同一脚本连演 100 次结果一致。
- **脚本中的病机数据仍须合法**：`syndrome` / `revealed` / `behavior` 等字段取值须**合法**——`behavior` 必须是 `status-syndrome.md` §3.3 的合法枚举（用 `ampPerTurn = 0` / `drainPerTurn = 0` 表达"不出手"，**不得发明新枚举值**；`amp` / `drain` 的**值域为非负整数**，`0` 合法 = 本回合不出手，见 `status-syndrome.md` §3.3 ★ 值域），`syndrome.yinyang` 必须是 §3.2 的**两层结构** `{ surface, deep, innate }`。**数据合法性不因"不结算评级"而豁免。**
- **可跳过**：`skipAllowed = true` 时玩家可整段跳过；跳过**不改变**用于**推进链**的 flag（链完整性优先），但**另产出一个"是否真看过"的 flag** 供下游叙事分支（`level-system.md` §3.2 `Encounter.yields`）。
- **中途跳过 / 断点存档（2026-09-12 补）**：`ctb = true` 时演出**可与"整段跳过"之外的中途操作共存**——① 玩家可在任一回合影后按"跳过整段"，语义等同"从头跳过"（**已执行的回合不产生任何持久副作用**，因本遭遇不写 `Progress` / `Rating` / IP / 耐药 / 紊乱，见下）；② **存档点不得落在遭遇中途**（`ctb = true` 的遭遇是**原子演出**：要么未开始、要么已演完；中途退出视为整段跳过）。理由：本遭遇零输入、零结算写入，中途存档无状态可存。
- **不留后遗症（2026-09-12 补）**：遭遇**不写入**病人 / 主角的任何持久状态——不产 `revealed`、不累加耐药或紊乱、不触发传变、不改患者 `vitalQi` 的存档值（脚本内的 `vitalQi` 变化是**演出局部量**，演出结束即弃）。**推论**：同一存档连看 100 次，结果与存档状态一字不变。

**`ctb = true`（战斗旁观）专有规则**：

- **`ΔE` 照算，但 `M` 只可能落在「未揭示」一列**：**观众侧"叙事层的四诊" ≠ "结算层对 `revealed` 的写入"**——老人在台上望闻问切，但**结算层不由观众写入任何证候状态**，故 §4.3 二维表的**已揭示**两格**在本模式下不可达**——`M` 恒为**未揭示**列（按轴关系分别取 **0.7 / 1.0 / 0.5**，其中**同轴 = 0.7**，`相关轴 = 1.0`，`无关轴 = 0.5`；**不是**"恒等于 0.7"）。**推论**：战斗旁观**永远不会出现 `M = 1.5` 的对证时刻**（教学铺垫**故意**不给"对证是什么样"，留给玩家自己打）。这条须在配置期校验（脚本内任何牌若声称对证 → 拒绝）。
  > **为何强调"四诊 ≠ 写入"**（2026-09-12 修正）：原口径写作"零输入 → 不能探、不能问出证候"，把**因果**归到了"玩家没输入"上——但老人**确实演了四诊**，正确的口径是**层面错位**：**呈现层**（老人怎么看）与**结算层**（谁写入 `revealed`）是两回事；观众**不拥有结算层的写权限**，与"他看了几眼"无关。同口径见 `design/levels/vol-01.md` §2.4 ③。
- **回合推进须有可读信号（`ctb = true` 专有，2026-09-12 增）**：因 UI **不上屏行动条**，**每一回合的推进必须由"老人的下一个动作 + 一句自白"显式承载**——脚本内每个 `ScriptedTurn` **必须自带** `act`（动作）与 `narration`（自白），缺一即配置校验**拒绝**；否则玩家无从判断"这已经是下一手了"。这是"不显数值"的**代价与补偿**：不能让玩家既看不到行动条、也看不出回合在走。
- **老人（旁观者）的出牌是固定脚本**，不是 AI：脚本逐回合钉死"出哪张牌、为什么"（为什么由**角色自白**承载）。**不实现决策系统**。
- **呈现层与结算层分离（★ 本模式的核心口径）**：结算层**真跑** CTB 与 `ΔE`（病邪条在内部实时下降）；呈现层**只给**：老人取药的动作、他说的判断依据、妇人身上的**可见变化**（咳嗽间隔、肩膀、脸色）。**病邪条 / 正气条 / 牌名 / 数字一律不上屏**。
  > **理由**：若把数值亮给玩家，则章 B 的"看不见"就不再是**发现**，而是**复习**——§1.3 一级教学弧（"只给现象，不给原理"）会塌掉。**故"真战斗"与"不显数值"不矛盾**：前者是结构（CTB 真跑），后者是呈现（玩家看不到）。**唯一例外**：若后续裁决要求亮数值，只改呈现层，**不动脚本与结算**——保留此条为**可独立翻转的旋钮**。
- **不进 `Progress`、不结算 `Rating` 仍成立**：真跑 CTB **不等于**它是一场"治段"——它不与 `MainBeat(治)` 绑定，不喂 §4.7 的 `Rating`。章 A 因此仍满足"**全程无战斗结算**"。

## 4. 公式 Formulas

### 4.1 行动序（CTB）

```
下一行动时刻 T_next = (Threshold − ActionGauge) / Speed
```

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| Threshold | int | 800–1200（默认 1000） | 全局配置 | 行动条阈值 |
| ActionGauge | int | 0 – Threshold | 运行时 | 当前行动值 |
| Speed | int | 40–150 | 单位属性 | 医者 80–140；急性病机 100–150；慢性病机 40–80 |

**示例**：病机 A 速度 120，医者 B 速度 100，ActionGauge 均为 0。
- T_A = 1000/120 ≈ **8.33 刻**；T_B = 1000/100 = **10 刻**。→ 病机先手。
- 若医者先出一张「先手」牌使自身 ActionGauge += 300，则 T_B = 700/100 = **7 刻** → 医者反先。

**预期输出范围**：单次行动间隔 6.7–25 刻。

### 4.2 病邪削减 Qi-Evil Reduction

```
ΔE = P × M × (1 + Σb) × T_drug × S_link
```

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| P | float | 10–60 | 牌面数据 | 基础效力 |
| M | float | 0.0–1.5 | 见 4.3 | 匹配系数 |
| Σb | float | 0.0–1.5 | 加成和（图谱、士气、连携） | 各项加成之和 |
| T_drug | float | 0.25–1.0 | 见 4.5 | 耐药/紊乱衰减 |
| S_link | float | 1.0–1.6 | 见 4.6 | 汇通连线加成（仅合方牌 ≠1） |

**示例**：P=40 的「清」法牌，对证（寒热轴=热，M=1.5），无加成（Σb=0），首用（T_drug=1.0），非合方（S_link=1.0）：
`ΔE = 40 × 1.5 × 1 × 1 × 1 = 60`。一次打掉 100 病邪条的 60%。

**预期输出范围**：单牌 ΔE ∈ [0, 约 200]（含合方与满加成上限）。

**★ R4（本轮新增）· `ΔE` 逐牌取整**：`ΔE` 的乘积**逐张牌四舍五入到整数**后，再从病邪条上扣除。理由：病邪条是**整数**资源，余量永远以整数结算；不取整会让"是否打得完"依赖浮点末位，玩家无法预判。

- **取整时点**：**每一张牌各自取整**（不是把整回合的多张牌求和后一次性取整）。
- **卷一即用到**：`35 × 0.7 = 24.5 → 25`；`35 × 1.5 = 52.5 → 53`（见 §4.8）。
- **★ 边界必须钉死**：`§4.8` 乙 a 恰好坐在临界上——`4 × 25 = 100`（第 5 回合清零、正气 58、`Rating 0.581`）对 `4 × 24.5 = 98`（第 6 回合清零、正气 48、`Rating 0.503`〔该支 `R_actual = 6 > R_ref = 5` → `Eff = 5/6`〕）。**取整方向不同，结论会跳到另一支**。本条锁定为**四舍五入**。

### 4.3 匹配系数 MatchCoefficient

**唯一真源声明**：下面的**二维表**是 M 判定的**唯一真源**，并由 **R1–R4**（§3.6 / §4.2 / 本条）补全机械判据。`status-syndrome.md` §4.3 的小标题写着"（引用 `combat-system.md` §4.3）"，但其现存 5 行旧式表述与本表**冲突**（它把"相关 1.0"写成**依赖揭示**）——**rev g 已把该文件纳入改动集并同步修订**（见 `status-syndrome.md` §3.5 / §4.3）。

| 牌轴与致病轴的**客观关系** | 该轴**未揭示** | 该轴**已揭示** |
|---|---|---|
| **同轴 · 方向相符** | **0.7**（未证，不伤正） | **1.5**（对证，不伤正） |
| **同轴 · 方向相反** | **0.7**（未证，不伤正） | **0.0**（悖证，**伤正**，见 §4.3b） |
| **相关轴**（轴不同，但逻辑相邻、成立） | **1.0** | **1.0** |
| **无关轴** | **0.5** | **0.5** |

- **两个维度**：**轴关系**（同轴 / 相关轴 / 无关轴——牌轴与病机致病轴的**客观**关系，是病机自身的**事实**，玩家未读也知道自己在打哪根轴）**× 揭示状态**（该轴可否由四诊读出）。
- **只有「同轴」这一列受揭示影响**：方向未明时（未揭示）一律 **0.7**；方向已明时（已揭示）才分 1.5 / 0.0。
- **相关轴 1.0 与无关轴 0.5 不依赖揭示**：它们是客观轴关系，不是"已知信息"的判定对象。
- **推论（核心承诺）**：**未揭示的牌永远落在 0.7 / 1.0 / 0.5 三档，绝不可能触发悖证 0.0**——0.0 的前置就是"已揭示"。故玩家**永远能事先知道牌会不会伤人**。

> **相关轴的真源**：哪些轴算"某致病轴的相关轴"，由 `status-syndrome.md` §3.5「八法 × 证候轴 对应表」的 **`相关轴（M=1.0）`** 列给出（如 汗→阴阳:阳；温→阴阳:阴 / 虚实:虚；清→阴阳:阳 / 虚实:实；消→表里:里 / 寒热:寒）。该表以**法**为键，故**法牌**（整体树）可直接查得；**还原牌**的轴关系须按牌轴与致病轴的客观邻接判断。

> **关键差异（第二轮修订）**：悖证**只在轴已揭示时**才可能发生——即玩家**明知**证候是"寒"却打出"清热"牌。未揭示轴出牌永远只是效力打折（M=0.7），**绝不随机伤人**。这一改动消除了"凭合理猜测却被概率惩罚"的挫败，把惩罚严格绑定到"无视已知信息的鲁莽"这一**可预判、可归因**的行为上。

> **阴阳特例（本轮修订）**：阴阳是唯一分层的轴。**"已揭示"仅指深层极已由切诊揭示**；只望得表层极不算"已揭示"，其出牌按 M=0.7 结算、**永不触发悖证**。原理见 §3.5 与 `status-syndrome.md` §3.2.2——守护"玩家永远能事先知道牌会不会伤人"的承诺。

> **★ R2（本轮新增，承本表表头）· 「相关轴」以「轴不同」为必要条件**：本表的表头把相关轴定义为"**轴不同**，但逻辑相邻、成立"。该条**机械化**后即为 R2：若一张牌的**全部轴**（`mainAxis` ∪ `subAxes`）**都落在病机的致病轴集合内**，则该牌与致病轴**同轴**，**不得**判为相关轴。**推论**：「补液·支持」（`虚实:虚` / `表里:里`）对病机「寒饮伏肺」（致病轴 `表里:里` + `虚实:虚`）**不构成相关轴**——它的两支都在致病轴集合里。

**4.3c 伤正（ΔV_wrong）的触发条件（本轮补全 · 原二维表无法表达）**

```
触发 ΔV_wrong  ⟺  (同轴 · 已揭示 · 方向相反)          // 主靶轴相悖 → M = 0.0 且伤正
                ∨  (任一次靶轴 已揭示 且 相悖)          // 2026-09-12 新增：次靶轴相悖 → M 不受影响，但伤正
```

- **新增第二条的理由**：`status-syndrome.md` §3.5 规定"次靶轴只在**已揭示且相悖**时触发悖证伤害，**不加成 M**"——但原二维表**只按主靶轴的轴关系定 `M` 与伤正**，表达的永远是"伤正 ⟺ `M = 0`"，与 §3.5 冲突。本条把 `status-syndrome.md` §3.5 已定的规则**落进战斗侧的真源**。

**4.3b 错治伤正**：

```
ΔV_wrong = C_base × (1 + Overdose) × (1 / 1 + B)
```

| 变量 | 类型 | 范围 | 说明 |
|---|---|---|---|
| C_base | float | 10–15（默认 12） | 基础错治损耗 |
| Overdose | float | 0 或 0.5 | 是否猛药；猛药错治更重 |
| B | float | 0–10 | 病人虚衰度（正气已低时更脆弱） |

**示例**：C_base=12，普通牌误投（Overdose=0），病人虚衰 B=0 → `ΔV_wrong = 12`。若为猛药（Overdose=0.5）→ 18。

### 4.4 峻剂换血（主动交易）

```
ΔE_drastic = P × M × K_drastic
ΔV_drastic = P × C_drastic

换血比 ExchangeRatio = ΔE_drastic / ΔV_drastic = (M × K_drastic) / C_drastic
```

| 变量 | 范围 | 默认 | 说明 |
|---|---|---|---|
| K_drastic | 2.0–3.0 | 2.5 | 峻剂病邪增益 |
| C_drastic | 0.6–1.0 | 0.8 | 峻剂正气损耗系数 |

**示例（对证峻剂）**：P=40，M=1.5 → ΔE = 40×1.5×2.5 = **150**；ΔV = 40×0.8 = **32**。换血比 ≈ **4.7:1**（对证时更划算）。
**示例（未证峻剂）**：M=0.7 → ΔE=70，ΔV=32 → 2.2:1。**教玩家：先辨证，再下猛药。**

### 4.5 耐药与紊乱（过用衰减）

```
还原牌： T_drug = 1 / (1 + R × k_R)
整体牌： T_drug = 1 / (1 + D × k_D)
```

| 变量 | 范围 | 默认 | 说明 |
|---|---|---|---|
| R 耐药 Resistance | 0–12 | — | 同一药族本场使用次数累加 +1 |
| D 紊乱 Disruption | 0–12 | — | 同一"法"在**非对证**下使用 +1 |
| k_R | 0.15–0.35 | 0.25 | 耐药斜率 |
| k_D | 0.10–0.30 | 0.20 | 紊乱斜率 |

**示例**：同族还原药连用 4 次 → T = 1/(1+4×0.25) = **0.5**；连用 8 次 → **0.33**。

**★ 豁免：`no_resistance: true`（本轮新增，承 D11）**

- 牌可声明 **`no_resistance: true`**，则该牌**永不累加 `R` / `D`**，恒取 `T_drug = 1.0`。
- **「补液·支持」即此类**：**生理盐水不产生药理耐受**——同一药族连用不会"越用越不灵"。这是**医学身份**判断（39 行的专家受众首战不能出戏），不是数值调参。
- **D11 的由来（已裁决）**：`§4.5` 规定同族还原药连用 4 次 → `T_drug = 0.5`，但此前 **`T_drug` 从未进入任何一次演算**——`§4.8` 与 `design/levels/vol-01.md` §3.5 都按 `T_drug = 1.0` 打出 4–5 张同类牌。若照 §4.5 严格执行，五张牌的实际总量只有 24.5+19.6+16.3+14.0+12.3 = **88.5 < 100**，丙 a / 乙 a **根本打不完**（需 8 回合、正气落到 40、`Rating ≈ 0.43`），"3–5 回合"的**教学节奏整体崩塌**。
- **裁决（2026-09-12，用户选）**：给「补液·支持」加 `no_resistance: true`——**六子支数值照 §4.8 原样成立**，教学节奏不动；其余还原药（洋地黄类、解热镇痛类等**确实会产生耐受**的药）**仍按 §4.5 累加**。
- **附注**：`§4.5` 的"连用 4 次 → 0.5"隐含 `R` 的**初值为 0**（首用 `T_drug = 1.0`，与 §4.2 示例一致）——此处**明写**，消除"连用 4 次是第 4 次还是第 5 次"的歧义。

### 4.7 战斗评级（结算）

```
Rating = w1 × (1 − 病邪残余率) + w2 × (正气保有率) + w3 × (回合效率 Eff) − 罚项
```

| 权重 | 默认 | 罚项示例 |
|---|---|---|
| w1 | 0.35 | 有"后遗症"（正气 < 30% 收场）→ −0.15 |
| w2 | 0.45 | 使用峻剂次数 × 0.02 |
| w3 | 0.20 | 错治次数 × 0.03 |
| — | — | **单核取胜**（本场未动用两侧资源出牌，走 §4.10 速攻型 / 持守型）→ **−0.20**（"缺一只眼睛"的代价，见 4.10.6） |

评级影响顿悟点奖励（见 progression GDD 4.5）。

**★ 回合效率 `Eff` 的定义（rev h · 关闭 D12 —— 本项此前**只有权重 `w3 = 0.20`、全库无公式**）**

`Eff` 是一个**只罚超时、不奖速杀**的**平台函数**：

```
Eff = clamp( R_ref / R_actual ,  Eff_min ,  1.0 )
```

| 符号 | 类型 | 范围 | 说明 |
|---|---|---|---|
| `R_ref` | int | 2–20（**配置项**；卷一教学关 = **5**） | **关卡基准回合数 = 该关"零探索基线路径"的回合数** |
| `R_actual` | int | 1 – `roundLimit`（默认 12） | 实际收束回合 |
| `Eff_min` | float | 0.30–0.60（默认 **0.40**） | 下限钳，防长卷的回合数把该项压死 |
| `Eff` | float | **[0.40, 1.00]** | **上钳 1.0 = 速杀无额外奖励**；有界、与回合尺度无关 |

- **上钳 `1.0`（为何不给速杀加分）**：本作的教学承诺是"**先辨证、再下药**"。若"打得快"另加分，会让**抢回合**压过**读证候**；更具体的害处是**放大 D13**——`虚实` 已知能省 2 个回合（§4.8），若速杀再吃一份效率分就是**双重计酬**。
- **为何不能是固定常数 0.5**：`status-syndrome.md` §3.3 的 **amp 型病机**（只增病邪、不 `drain` 正气）下，**拖延零代价** → 龟缩成最优解，`w3` 便形同虚设。
- **基准取"零探索基线"**：探索的收益已**一次性**体现在 `M`（牌力）与正气保有上；`R_ref` 取**不探任何节点**那条路径的回合数，可使探索**不被效率项二次计酬**。
- **算例**（`R_ref = 5`）：`R_actual` = 2 / 3 / 4 / 5 → `Eff` **全为 1.000**（**平台**）；= 8 → **0.625**；= 13 → 0.385 → **钳到 0.400**。
- **与卷一的关系**：六子支的 `R_actual` **全 ≤ 5**（2–5 回合）→ **`Eff ≡ 1.0`**，六支**同取满值**。故本裁决**不改变六子支的相对排序**，只把整表从"假定 0.5"改为"定义 1.0"，**六支各 +0.10**（见 §4.8）。
- **为何延迟起效**：卷次越长、病邪越厚，`R_actual` 才会超过 `R_ref`、`Eff` 才开始真正拉动评级——**教学期刻意不引入"抢速度"压力**。
- **持守型特别约定**：`§4.10.3` 持守型的胜法是"守满 `N` 回合"，其 `R_ref` **取 `N`**（守满即满效率）——否则该型在构造上必吃满额衰减。
- **未清局**：`R_actual` 已达 `roundLimit` 而病邪未清零时，**残余率与 `Eff` 两罚并存**（语义不同：**没做完** vs **做得慢**）。
- **边界**：`R_actual ≥ 1`，不出现除零；转诊退出 / 判负**不结算** `Rating`，故无 `R_actual = 0`；传变（§4.4）**不重置** `R_actual`。
- **★ 连带项（IP 尺度重校）**：本裁决使评级**整体上移**（卷一六支 +0.10），故 `level-system.md` §4.5 的 `IP_gain = IP_base × Rating × …` 与卷档案 Severity **须同批重校 `IP_base`**（该文件 rev g 已登记）。

### 4.9 特殊战斗设计：霍崇光终局战（卷九）

> 本场是全篇的**终极 Boss 战**，也是主题"两套认识论"的最后清算。它不是一场"打怪"，是一场**认识论的辩论被做成了战斗**。

**人设绑定**：霍崇光 = 还原论极端（"纯医学"、数据至上），见 `story-bible.md` 6.7。他不携带"病邪条"式的血肉，而是**将自己作为"一个绝对正确的体系"来运转**——玩家攻击的不是他的命，是他**信念的完整性**。

**"数据节奏"机制（他的行动）**：
- 他的行动模式**完全固定、可预测**：每回合重复同一套"标准化治疗"（固定顺序、固定数值），像一台从不失误的机器。
- 但他每回合会**免疫玩家上一回合使用过的牌类型**（"学习"）：若玩家连续两回合用同类型的牌（同"法"或同"认识论"），第二回合该类型对他**效力归零**。
- **设计意图**：逼迫玩家**每回合换策略**，不能用一套连招碾压——正如现实中"标准化方案"会迅速被耐药/演化瓦解。玩家必须不断换眼睛，才能不被他算死。

**破法（唯一绕过"学习免疫"的路）**：
- **只有合方牌（汇通连线技）能绕过他的"学习免疫"**。因为合方牌包含"人的因素"——其效果**随机浮动、不可被预测**。他的系统能学会"清热""攻下"这类**可命名、可归档**的牌，却学不会"沈砚之把陆九针的方和苏晚棠的针拼在一起"这种**没有标准名字的、个体化的**东西。
- **机制化的主题**：数据能学习"可量化"的一切；个体化、不可量化的医道，是它的盲区。

**胜负条件（不是打死他，是让他看见）**：

```
证伪触发： Σ Damage_convergence ≥ 0.6 × E_max
其中 Damage_convergence = 本场所有合方牌对霍崇光造成的伤害之和
```

- **E_max** = 霍崇光"信念完整性"条（基准 100，与病邪同尺度）。
- 当**累计合方伤害 ≥ 60% × E_max** → 霍崇光进入**「证伪 Falsified」状态**，战斗结束。
- 结束方式**不是打赢/打死他**，而是他**当众问出那句全篇最深的疑问**（见 `story-bible.md` 卷九）："我算过每一个变量。……我算过每一个人。可人，怎么可以不算进去？"——**他看见了自己的错，战斗即终结。** 这是一场以"敌人的自我怀疑"为胜利条件的战斗，也是本作对"科学主义"最克制、最不流血的批判。
- **失败条件**：病人（若场上有危重病人）正气归零，或**回合数超过上限仍未达证伪阈值**（表现上：玩家的"个体化"始终没能击中他，他被"证明"是对的）。

**示例计算**：E_max=100，证伪阈值 = 60。玩家本场合方牌累计造成 62 点伤害（如三条「通」各命中一次，S_link 加成后合计 62）→ `62 ≥ 60` → 触发证伪 → 战斗结束。

**与其它系统的关系**：本战的胜利路径**强依赖成长系统的汇通图**——若玩家到卷九仍未建起足够多的跨树连线，就**没有足够的合方牌**去击穿他的免疫，这正是"只练一棵树"在主线上的终局代价。

### 4.10 特殊战斗设计：单认识论遭遇（单核 / 双核由牌池涌现）

> 前面所有战斗都默认"两套眼睛并用"。但玩家完全可能**只带一套眼睛**上场——尤其是剧情早期（卷一只有沈砚之），或队伍因聚散而缺员时。本节定义：**当牌池只有一侧资源时，这场仗怎么打。**
>
> **核心原则——不做强制失败**：单核牌池永远留一条**"惨胜"之路**（病邪清零且病人存活），但它赢得极窄：容错极低、评级极低、常常损正气。系统用**明确的敌人行为与反馈**提示"你缺一只眼睛"，而**不用硬性锁死**拒绝玩家。全篇唯一的例外是 §4.9 霍崇光终局战（见本节末）。

#### 4.10.1 单核 / 双核 由牌池涌现判定（不给角色贴标签）

> **本轮修订（砍掉阵容分类器）**：早期版本给每名队员贴 R/H/B"主树归属"标签、再由在场阵容推导战斗型。**该分类器已删除**——理由是它**覆盖不了实际用例**：全篇（依 `story-bible.md` §8.1 聚散总图）**陆九针自卷二起全程在队**，故"只有整体"的持守型**实际零次发生**，而"只有还原"的速攻型**仅卷一一次（且是教学脚本）**。一个三态分类器覆盖两个实例、其中一个是脚本，属**过度设计**；更糟的是它会诱发"为凑战斗型而给角色硬派归属"的动机（见下）。

**改为按牌池实际内容涌现判定**——不引用任何角色标签：

```
本场可用牌池 P = 在场队员的单方牌 ∪ 已生成「通」的合方牌

has_R_pool = P 中存在消耗「剂量」资源的牌（还原侧）
has_H_pool = P 中存在消耗「气机」资源的牌（整体侧）

has_R_pool 且 has_H_pool → 双核型（常规，走 §3–§4 全部规则）
仅 has_R_pool            → 速攻型 Race
仅 has_H_pool            → 持守型 Sustain
两者皆无（空池）          → 非法，配置校验拒绝
```

- **好处**：①**纯涌现**——无需维护角色归属表，角色换流派/后期转树也不会失配；②顺带消掉"为让战斗型成立而硬凑归属"的设计动机；③归属描述**只留在叙事层**（`progression-system.md` §3.5 人物弧），不进机制。
- **叙事落点不变**：同伴来去仍**直接改变能打的仗**——苏晚棠（天生是桥，牌池含两侧）在队时队伍天然握有两套眼睛；她离队（卷六→七）后合方牌灰化，若其余在场者牌池只剩一侧，战斗型随之落回单核。这是"聚散皆成长"在战斗层的直接体现。

**注**：单镜型（下 4.10.4）**不是**由此判定出来的，而是**病机自身的属性**——它决定"哪些牌能处理这个病机"，与上面的单/双核判定正交。

#### 4.10.2 速攻型 Race —— 纯还原牌池（只有西医）

- **可胜路径**：还原牌（耗剂量）直接削减病邪；病邪清零且病人存活即"惨胜"。
- **代价**：队伍**无"托住正气"的手段**——没有整体牌去扶正、调衡。剂量毒性、峻剂、耐药持续侵蚀病人正气，且**没有任何牌能把正气抬回来**。
- **玩法本质**：**赛跑**——在附带损伤杀死病人之前清空病邪。节奏紧、容错低、几乎不容一回合浪费。
- **主题**：还原论**快、准、狠**，靠速度赢、不靠平衡。它是一把锋利的刀，刀没有问题，问题是刀不负责"养人"。
- 与 §4.8（卷一教学关：只有还原；病人正气从 100 掉到 **58–100**，六子支区间——最差乙a **58**、最好丙b **100**，见 §4.8 结论表）同源——那就是速攻型的极端样本。

#### 4.10.3 持守型 Sustain —— 纯整体牌池（只有中医 / 心身）

> **本轮修订（降级为关卡层）**：持守型**不进战斗规则**，而是**关卡胜利条件的一个变体**——由关卡系统接管（见 §6 关卡系统依赖）。理由是"撑到某回合"是**换目标**，不是新机制；把它塞进战斗结算层只会徒增状态机复杂度。

- **可胜路径**：整体牌（耗气机）护住病人（扶正、调衡、固本），并**缓慢"化"解**病邪。
- **代价（若临时出现）**：整体论缺"斩杀键"——对**暴发性 / 急性**病机，病邪削减速率追不上增幅 → 只能拖。**注意**：能修得暴发急症的情形在本作剧本中**极罕见**（陆九针全程在队），故此型主要为**框架完备性**与**单镜型遭遇**而保留。
- **主题**：机制化历史上那句真实而沉重的批评——"中医救不了急症"。不是中医无能，是**整体论要的是时间，而急症不给时间**。
- **胜法（关卡层实现，复用既有 stages，不加新机制）**：把该关的胜利条件从"削减病邪"改写为**"存活到第 N 回合"**：
  1. 末段 stage 设为**"自限"形态**（复用 `status-syndrome.md` §4.4/§4.4.1 的"病势燎原"同款机制）：`ampPerTurn ≤ 0`、病机停手——避免"病邪条还很高却判胜"的观感。
  2. 关卡校验 `N ≤ 0.8 × 正气上限 / 每轮净损耗`，保证 N 回合内病人不会先死（有余量、非侥幸）。
  3. **中段插入 1–2 次"诊断性转折"**（本轮修订，取代早期的"援军"）：病机**传变**，迫使玩家**重新四诊、重排治法**——让防守的空转段变成**谜题节拍**，且贴整体论气质（"援军"是还原式救援，不搭）。
  4. **转折必须带正收益**（否则纯成本、玩家觉得被课税）：传变后的新 stage **必须附带一个可化解的状态**（如 `st_toxin` → 对证牌化解后该 stage 的 `ampPerTurn` 再降 25%）。传变次数**限 1–2 次**，防疲劳。

#### 4.10.4 单镜型 Single-lens —— 只有一种认识论有效

有些病机**本身**只有一只眼睛看得见。此时**错误的牌池面对的是一个"查不出、打不动"的敌人**：

| 病机类型 | 只有谁能处理 | 其他牌池遭遇时 | 
|---|---|---|
| **无症状带菌者** | 只有「**检验**」（还原）能识别与处理 | 纯整体牌池**无法通过四诊发现病机**——望闻问切一律返回"无显著证候"；病邪条可见但对整体牌近乎免疫 |
| **心因性疾病**（情志、癔症等） | 只有「**心身**」（整体）能触到 | 纯还原牌池的检验 / 靶向**对病邪条无效或甚微**——查不出病灶，也打不动"病邪"。**且纯还原阵容无「气感」→ 切诊不可用 → 深层阴阳读不到**（见 3.5），此"缺眼"由规则涌现、无需特判 |

- **设计意图**：**反向巩固"两套都要"**——有些问题**确实**只需要一只眼睛；但反过来，**没有任何一种眼睛能包打全场**。单镜型遭遇让玩家体会到：不是"双用永远更强"，而是"带错眼睛，连病都看不见"。
- **提示方式（用行为说不，不用锁死不让你打）**：敌人行为 / 系统反馈明确示意"你缺一只眼睛"——例如对带菌者反复只给"无显著证候"的回报；或病邪对某类牌给出**"免疫"的视觉反馈**（"你的药，打在了空气里"）。玩家可**立刻转诊**（见 §5）换阵容重试，而非被判负。

#### 4.10.5 失败模式保留（主题不可丢）

两种"单镜之败"必须在数值上**真实存在**、可被玩家亲身踩到，它们是全篇主题的反面教材：

| 失败模式 | 表现 | 对应主题 |
|---|---|---|
| **霍崇光式失败**（纯还原） | 病邪清零了，病人却因正气耗尽而死 | "指标全正常，人没救回来"——卷九霍崇光体系的证伪 |
| **救不了急症式失败**（纯整体） | 病人被养得越来越舒服，暴发性病邪在平衡回来之前先杀死了他 | 历史上"中医救不了急症"的批评 |

二者都呼应 §5 边界中"病邪清零但正气也归零 → 判负"的用例——**判定顺序本身就在为这两种失败兜底**。

#### 4.10.6 "惨胜"的判定

单核牌池的胜利**不是**被禁止的，而是**代价可见**：

- **满足**常规胜利条件（病邪 ≤ 0 且所有病人正气 > 0）即判胜，**不额外锁死**。
- **但评级被显著压低**：`Rating` 计入**单核罚项**（见 4.7 与 §7 旋钮）——单核取胜的 `Rating` 显著低于双核解，因此顿悟点奖励更少（见 `progression-system.md` 4.5）。**赢是赢得起，但赢得不漂亮。**
  - **罚项的判定改为按资源使用结算**（本轮修订，取代"按阵容"）：`若本场未动用任一侧资源（剂量或气机）出牌 → 触发罚项`。语义不变（"你只用了半套眼睛"），定义更硬（以实际行为为准，不依赖阵容归属标签）。
- **常见次生代价**：病人以低正气收场（< 30%）→ 触发**后遗症 debuff** 带入后续关卡（沿用 §5 既有规则）。
- **设计承诺**：玩家**永远**有一条路走通每一场常规遭遇——哪怕只有一套眼睛。系统只负责把"你走得多艰难"如实算给他看。

#### 4.10.7 与 §4.9 的关系（全篇唯一的强制双核例外）

- **常规遭遇**（§4.10.2–4.10.6）：**不做强制失败**——单镜型永远留"惨胜"之路。
- **§4.9 霍崇光终局战**：**全篇唯一**允许"单核无法通关"的战斗。他的"学习免疫"使任何单一流派必被算死，**只有合方牌能击穿**——即**强制双核**。这是主题的终局清算，且经卷四→卷六的**渐进软墙**（见 `progression-system.md` 3.7）长期铺垫，玩家到卷九早已具备双核能力。
- 二者的关系是**程度之别、非矛盾**：常规遭遇用"惨胜的代价"逼你学会双用；终局战用"单核必败"逼你**兑现**双用。**主题从"建议"升格为"考核"。**

## 5. 边界情况 Edge Cases

| 场景 | 会发生什么 | 理由 |
|---|---|---|
| 同一结算中病邪归零、正气也归零 | **判负**（正气优先判定） | 核心命题："指标正常，人没了"= 失败 |
| 病邪清零但病人正气 < 30% | 判胜，但附加**后遗症 debuff** 带入后续关卡 | 治好了，但伤本 |
| 多病人关卡中一名病人死亡 | 若为**主要病人**（目标）→ 立即判负；若为**次要病人** → 判负但允许"转诊"重试 | 区分目标与背景患者 |
| 战斗中证候**传变**（轴重组） | 已揭示的轴**重置为未证**，病机进入「传变」态 1–2 回合后重组 | 辨证是动态的，不是一次性谜题 |
| 手牌全部不匹配 | 玩家只能出**无关牌（M=0.5）**或使用「换气/弃牌」行动重抽；不出悖证不会伤正 | 保证玩家永远有"劣解"，不会死锁 |
| 病人身上**同时多个病机** | 多病邪条并列；玩家须**选择优先削减**哪个；不对某病机的牌可能加剧另一病机（可选高阶规则） | 复现真实"复合病" |
| 前 3 回合就使用峻剂 | 允许；但对虚衰度 B 高的病人风险放大（ΔV_wrong/ΔV_drastic 乘 (1+B)） | 惩罚鲁莽，不禁止选择 |
| 猛药 + 错治叠加 | 同时触发 ΔV_wrong(Overdose) 与 ΔV_drastic，**两者相加** | 最坏情形显式定义 |
| 无症状带菌者（证候完全不可诊） | 四诊均返回"无显著证候"；只能靠**检验**（还原）识别，且检验需特定队员 | 还原论不可替代的场景 |
| 玩家中途退出/逃跑 | 视为**转诊**：判"未愈"，病人保留生命但关卡记为未完成，可重试 | 医疗语境的合理逃逸，非死亡惩罚 |
| 战斗中存档 | 快照仅存于**回合边界**；回合结算中途不可存（防作弊/状态不一致） | 实现可行性 |
| 队员在战斗中阵亡 | 队员**不会死亡**（无血条），但可被"击倒/离场"，其牌暂时不可用 | 保护叙事角色（苏晚棠之死由剧情决定，不由战斗随机决定） |
| 苏晚棠离队期（卷六→七） | 依赖她的**合方牌与连线**全部灰化不可用，队伍被迫用残缺图谱作战 | 剧情与机制绑定的"系统性留白" |
| 阈值为 0 或负数 | 配置校验拒绝启动；速度 ≤ 0 视为非法数据 | 防除零/负时间 |
| 单张牌 ΔE 超过病邪剩余 | 病邪截断至 0，**溢出伤害不转嫁**正气或他病机 | 避免"过量治疗"被误当收益 |
| **旁观遭遇**（§3.10）被跳过 | 演出整段跳过；**不结算任何评级 / IP / 耐药 / 紊乱**（本就为 0）；推进链 flag 由关卡层保证点亮 | 跳过改变的是"理解厚度"，不是"事实" |
| **旁观遭遇的配置数据非法** | 配置校验**拒绝**启动：`behavior` 须为 `status-syndrome.md` §3.3 合法枚举、`syndrome.yinyang` 须为**两层结构**——**不因"不结算"而豁免数据合法性** | 数据合法性（§3.10） |
| **旁观遭遇中玩家尝试操作** | 输入**被忽略**（`playerControl = none`）；不弹牌面、不弹行动条。**`ctb = true` 时 CTB 在内部照跑**（回合推进不受玩家影响），但玩家侧看不到行动条 / 牌面 | 演出态而非可玩态（§3.10） |
| **旁观遭遇脚本宣称"阴阳已证"但脚本内无切诊** | 配置校验**拒绝**：望只给表层极，**阴阳深层极须由切诊揭示**——脚本缺切诊即不得置阴阳轴为「已揭示」 | 守护"玩家永远能事先知道牌会不会伤人"（§3.5 / §4.3） |
| **`ctb = true` 的旁观脚本出现 `M = 1.5`（对证）** | 配置校验**拒绝**：战斗旁观**在结算层不由观众写入 `revealed`**（"呈现层四诊 ≠ 结算层写入"），`M` 恒落**未揭示**列（按轴关系取 0.7 / 1.0 / 0.5）。脚本任何牌若依赖"已揭示"取 `1.5` / `0.0`，**非法** | 守护"对证时刻留给自己打"（§3.10） |

## 8. 验收标准 Acceptance Criteria

- [ ] 战斗可在"病邪归零"时判胜、"正气归零"时判负；**同刻双归零判负**——测试用例可验证。
- [ ] CTB 行动序符合 `T_next = (Threshold − ActionGauge)/Speed`；给定速度可预测出手次序（误差 0）。
- [ ] 还原牌与整体牌分别只接受剂量 / 气机支付；跨资源支付被拒绝。
- [ ] 打出对证牌（M=1.5）时 ΔE 与公式一致（示例：P=40→ΔE=60，误差 < 1%）。
- [ ] 打出悖证牌触发 ΔV_wrong；数值 = 公式值（示例 C_base=12→−12 正气）。
- [ ] 峻剂牌 ΔE/ΔV 比值落入 2:1–5:1 区间，且对证峻剂比未证峻剂明显更优。
- [ ] 同族还原药第 4 次使用的 T_drug = 0.5（±0.01）；**声明 `no_resistance: true` 的牌（如「补液·支持」）连用任意次均恒为 T_drug = 1.0**（守卫检查，§4.5 / D11）。
- [ ] **`ΔE` 逐牌取整**（§4.2 R4）：单牌 `ΔE` 四舍五入到整数后才从病邪条扣除；`35 × 0.7 → 25`、`35 × 1.5 → 53`（边界值测试）。
- [ ] 未揭示轴出牌按 M=0.7 结算且**不伤正气**；已揭示轴打出相悖方向牌时**确定性地**触发悖证（M=0.0 + ΔV_wrong），可复现、无随机（连测 100 次结果一致）。

- [ ] 队伍含苏晚棠或陆九针时，切诊行动耗费为 0；不含时耗费为 1（守卫检查）。

- [ ] 手牌全不匹配时，玩家仍有"换气/弃牌"行动可用，不会死锁。
- [ ] 证候传变后，原已揭示轴重置为未证。
