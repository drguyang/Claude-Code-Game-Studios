## 1. 「教学」在本文件里的定义

**认知** = 玩家知道**该看什么、为什么这么判断、有哪些手段**。
**技能** = 玩家能在时间中**亲手做出来**(节奏 / 力道 / 顺序)。

**归属边界**(三路专家一致,本轮采纳):

| 层 | 归谁 | 交付什么 |
|---|---|---|
| 调度 | **48 教学** | 何时说 / 做什么示范 / 给哪张纸;零状态、零提示、零门 |
| 判定 | **10 急救** | 三扇门(幅度 / 节奏 / 稳度)→ 结果档 |
| 成长 | **30 熟练度** | 按新颖度加权(与质量无关,裁定 ① 保留) |
| 呈现 | **13 病人 AI + 44 音频** | 身体读数:胸廓起伏 / 口唇色 / 渗血 / 呼吸两层音 |

## 5. 明确不做 / 推 P1

**P0 不做**:
- 一键通过 / 自动完成(删掉支柱本身)
- 把体征变数字进度条(违零提示铁律 + 反幻想)
- 实时评价型字幕(「太快了」= 变相提示)
- 报状态的音画提示(ADR-018 §六)
- 手势 / 手部追踪 / 3D 空间标注 / 晕动开关(**假预留** —— P0 无第一人称位移与手部输入,留了无从验证)

**推 P1a**:质量进成长(裁定 ① 的「练得准练得深」)、病灶特异动作库、按压顺序判定、动作解锁门。

**推 P1b**:VR 急救动作(裁定 ② 要求把它写成 P1b 的验收条件)。

**真预留(P0 做,四条)**:媒体/锚点与承载解耦 · 字幕走语义 ID 而非坐标 · `ModalId.PaperCloseup48`(闭集第七员已在)· 44 的声源归属。
