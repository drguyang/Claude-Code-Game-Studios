## Overview

**持久化服务(7a)是全案唯一没有前置 GDD 的 Core 系统,同时也是全案唯一「不产生任何游戏事实」的系统。**
它做的事只有两件:把三条逻辑流(病史 / 病例 / 世界)连同存档头变成一串字节写到盘上;
再把那串字节读回来、还原成模拟态。它不决定谁痊愈、不决定建造是否合法、不决定掷骰结果 ——
那些事实在它开口之前**就已经被决定了**。7a 决定的是:**这些事实以什么形状被写下来,
以及它们能不能逐位不变地被读回。**

它在结构上是**确定性的最后一道闸门**。ADR-005 承诺「病史事件流是唯一真源、逐位可复现」,
ADR-008 / 009 把这条承诺扩到三条流;但只要有**一份存档**,这条承诺就必须能在一台具体的机器上
被验证 —— 同一份存档在编辑器 Mono 与 IL2CPP 玩家上产出**相同的字节**。这份字节流是
ADR-012 的跨平台确定性 CI 门**唯一可对拍的面**(ADR-010 §Enables 已明写 7a 是 R-5 的前置)。
没有 7a 的 codec 与黄金夹具,「确定性」全案只是一句纸面声明。

**关键立场:7a 是三流的载体,不是第二真源。** 真相**永远**在事件流里;定期快照只是
**加载加速**与表现态位置恢复的优化(ADR-009 §六)。这条立场决定了 7a 的一条硬边界 ——
快照损坏、缺失、或跨版本不可读时,**世界流仍是唯一裁判**:丢掉快照只会让加载变慢、
让掉落物出现在「上次快照的位置」,不会改变任何一个游戏事实。

存档的物理形状:**头部 + 三逻辑流 + 快照段**,全二进制手写 codec(`Fix` 经 ADR-006 §五
自定义编码器,按字段名编码、禁位置),显式小端,校验和用 BCL `SHA256` 覆盖头部之后的全部字节。
损坏时自动回退到上一好档,**玩家无打断**;版本升级走逐版本迁移链,`WorldSeed` 与已发生事件
**原样保留**。玩家从不直接接触 7a —— 它唯一的露出面是 7b 存档位 UI 呈现的槽位列表
(格式归 7a,渲染归 42)。

> **Quick reference** — Layer: `Core` · Priority: `P0` · Key deps: 五份契约 ADR(005 / 006 / 007 / 008 / 009,已由 **ADR-010 §三** 收敛)· 下游 7b / 9 / 45 / 51

## Player Fantasy

**玩家永远感受不到 7a。他感受到的是「这个世界是一个地方,不是一次会话」。**

`game-concept.md:143` 写的是本作对失败的态度:**「救人失败 = 病患死亡,不可撤销。
但你的《脉案》会记下这一例,失败是叙事与学习的材料,不是读档点。」**
这句话不是文案,是一条**对存档系统的设计约束** —— 它要求 7a **不能提供廉价的后悔药**。

7a 兑现这条约束的方式不是加一个「禁用读档」的开关(那会被立刻绕过),而是
**从形状上不给后悔药留接口**:存档触发点是三个大类别 —— **checkpoint(事件触发为主 +
定时兜底)· 退出保存 · 7b 手动槽(规则十四契约)**。三个里面**没有一个是「随时回滚到
30 秒前」**;没有 quicksave / quickload,没有「进战斗前自动存一份」。
存档的**粒度是叙事事件,不是每 tick** —— **事件触发(2026-09-16 玩家裁定「两个都留」)**:
checkpoint 绑定**叙事事件**(脉案落笔 / 病例结案 / 出诊启动 —— 锚点白名单的产生者 =
**8 诊断 / 39 脉案(脉案落笔)· 37 病例(病例结案)· 52 随机事件(出诊启动)**,
7a 只出观察钩子形状),「落了笔的才算数」成为可感知的世界规则;**定时兜底**只在事件
长期缺席时触发(间隔 `CHECKPOINT_INTERVAL`,按出诊周期级)。玩家能回到的最近一点 =
最后一个叙事事件(或兜底定时器启动点),而非他刚犯下那个致命误诊之前的位置。

| 玩家感觉到的东西 | 7a 里对应的是什么 |
|---|---|
| 「这个世界是持续的」 | 三流 + `WorldSeed` 跨会话、跨版本原样保留 |
| 「我做过的事算数」 | 事件流是唯一真源;快照只是优化,**永不作数** |
| 「我搞砸了,那就搞砸了」 | 三个触发点里没有廉价回滚;粒度 = 叙事事件(「落了笔的才算数」)+ 定时兜底,回退点永远在叙事事件之后 |
| 「崩溃不该惩罚我」 | 原子写 + 校验和 + `bak` 自动回退,**玩家零打断** |

最后一行是本节的张力所在:**7a 既要保护「失败不可撤销」,又要保护「玩家不因技术故障受罚」。**
二者不矛盾 —— 区别在**撤销的是游戏事实还是硬件事故**。回退到上一 checkpoint 只丢失
**上一个叙事事件之后发生的事**(定时兜底只在事件长期缺席时触发),且这是崩溃的代价
不是设计的惩罚;而**已经在盘上的历史,任何东西都改不了它**。

## Detailed Design

### Core Rules

> **本节是 ADR-010 §三「义务汇总表」11 条的兑现**(7a 的单一出处)。每条规则标注其义务号
> (ADR-010 §三 表的 `#1-11`);**任何新委派只追加到 ADR-010 §三,不散落本节**。

**规则一 · 7a 是三流的载体,不是第二真源。**(义务 3/7/8)
真相**永远**在三逻辑流里(ADR-005 事件流唯一真源 · ADR-008 · ADR-009);7a 把三流写成字节、
读回并重放。**定期快照 = 优化非真相**(ADR-009 §六):快照用于加载加速与表现态位置恢复;
快照损坏 / 缺失 / 跨版本不可读时,世界流仍是唯一裁判 —— 丢掉快照只让加载变慢、
掉落物回到「上次快照的位置」,不改变任何游戏事实。

**规则二 · 全二进制手写 codec;`Fix` 经自定义编码器按字段名编码。**(义务 3/9/10)
禁 JSON / PlayerPrefs / BinaryFormatter / JsonUtility(ADR-006 §五:`Fix` 经内置序列化器**静默归零**)。
`Fix._raw` 的 `long` **显式小端**写出;三流每条事件按字段名 / tag 编码(`Tick` / `Patient` / `Seq` /
`Kind` / `Payload`,**proto 风格字段表**),**禁位置打包** —— 历次修正案字段序有变,位置化编码会让
两种抄本写出两种字节流。字节序显式声明小端并写**黄金字节夹具**钉死(编辑器 vs IL2CPP 产出相同字节,
ADR-012 R-5 的对拍面)。子实例闭包校验(容器 `children` 闭环,装配期断言,义务 10)。

**规则三 · SHA256 校验和,禁 `UnityEngine.Hash128`。**(义务 1/2)
校验和用 BCL `SHA256`(IL2CPP 可用,确定性;MB 级 1–5 ms)。覆盖范围 = checksum 字段之后的
**全部字节**(头部 + 三流 + 快照)。`Hash128` 文档不保证编辑器 vs IL2CPP 玩家逐位一致,弃用。
`WorldSeed`(u64,义务 1)与 `ConfigVersion`(u32,义务 2)进存档头;`ConfigVersion` 由
ADR-014 §五 派生(源文本内容哈希),7a 只消费。

**规则四 · 原子写 + 双档(bak)。**(ADR-010 §四)
写入流程:`final ← 存档路径(唯一)`,`bak ← final 的上一好档`。写 checkpoint:① 主线程序列化到
内存 buffer(Step 边界)② 后台线程写 tmp(`Flush(true)` + rename)③ tmp → final 原子替换
(final 存在则先 final → bak)。**「POSIX = `rename(2)` 原子」为训练数据推断,须首个 spike 实测**
(`File.Move(tmp, final, overwrite:true)` 三参重载在 Unity Mono/IL2CPP 的暴露面,与 ADR-012 F7 spike 同批);
**降级路径**:三参重载不可用 ⇒ 两参 `Move` + 显式删除(非原子,靠双档兜底),在 ADR-010 修订前
**不作为原子承诺**。**禁 `File.Replace`**(Mono 系 BCL 于 Unix 抛 `NotSupportedException`,须实测,倾向弃用)。
**断电不在承诺内**(`Flush(true)` 不 fsync 父目录目录项,BCL 无跨平台目录 fsync;承诺收窄为
「进程被杀」,掉电 = 已登记缺口,见 Edge Cases 故障类)。**禁写安装目录**(写
`Application.persistentDataPath`,**读于主线程启动期缓存一次**,后台线程禁调 Unity API);
杀软 / OneDrive 锁文件 ⇒ `IOException` 退避重试。

**规则五 · 主线程只序列化,写盘交后台线程。**(ADR-010 §六)
序列化在 Step 边界(主线程);写盘在 `Task.Run` / `ThreadPool`(IL2CPP 托管线程可用)。
sync 写 MB 级 SSD 仅几 ms,HDD / 杀软可上百 ms ⇒ **默认后台写**。**后台线程禁调 Unity API**。
**SHA256 校验和也在后台线程计算**(与写盘同批,回填校验和段;主线程零哈希 —— MB 级 1–5 ms
不吃 16.6 ms 帧预算;全文字节上限在实现期实测后锚定)。
**后台 worker 顶层全兜 `try/catch`**(未观察异常可终止 IL2CPP 进程 —— 与「玩家零打断」冲突)。
**GC 纪律**:大 `byte[]` 分配会触发主线程 GC 停顿 ⇒ **缓冲池复用**。
**退出保存同步**:挂 `Application.wantsToQuit`(稳定 API;`OnApplicationQuit` 在 Editor 停播亦触发,
作兜底不为主)时后台写未完成 ⇒ **限时 join**(默认 1s)。崩溃 / 强杀不触发退出钩子 ⇒ 由
下次启动的会话标志检测兜底(规则十三)。

**规则六 · 三个存档触发点类别;没有「随时回滚」。**(ADR-010 §六 · 2026-09-16 玩家裁定「两个都留」)
存档只发生在三处:**checkpoint(事件触发为主 + 定时兜底)· 退出保存 · 7b 手动槽(契约见规则十四)**。
没有 quicksave / quickload、没有「进战斗前自动存」。
- **事件触发(主要粒度)**:checkpoint 绑定**叙事事件** —— 脉案落笔 / 病例结案(37)· 出诊启动(52)
  的锚点白名单。**7a 只出观察钩子形状**(「一个值得锚点的叙事事件」的接口),不拥有具体事件列表;
  各系统在**生成该类事件时**同步触发 checkpoint。**「事件触发 = 调度策略,不是第四个存档入口」**
  (2026-09-16 裁定 —— 否则 AC-7a-08「恰三处」会把事件触发判为违例)。
- **定时兜底(备份触发)**:事件长期缺席时(初次启动无叙事事件 / 长时间探索期)由
  `CHECKPOINT_INTERVAL`(默认 5 分钟,安全区间 1–30 分钟,定值归用户)兜底触发 —— 保证
  「崩溃损失 ≤ 一个间隔」恒成立;防御性下限为**出诊周期级**(防跨不可逆单位,见 Edge Cases)。
- **粒度 = 叙事事件 / 兜底间隔,不是每 tick**。玩家能回到的最近一点 = 最后一个叙事事件
  (或兜底定时器启动点),永远**在最后一个不可逆裁决之后** —— game-concept:143「失败不是读档点」
  由此在形状上被守住,而非加一个可绕过的禁用开关。

**规则七 · 禁 quicksave / quickload(代码层 + 判据层双守)。**(2026-09-16 玩家裁定)
7a 的服务接口**不提供** quick 存档能力(`Checkpoint()` 只接 Step 边界调用参数,无「立即回滚点」参数);
判据层加**忘词令**(判据端断言符号表不含 `quicksave` / `quickload` / `save-now-slot` 类 API)。
**两守归一**:服务层无该能力 + 判据层符号扫描,后续若有人加 quicksave 会触警。
**忘词令的判据载体裁给 ADR-012 CI 门**(2026-09-16 用户裁定;ADR-012 尚未落盘,本 GDD 先立
**7a 自身可测的半守**:接口签名反射断言 —— `ISaveService` 公开可触发写入的方法参数集恰等于
`{SaveSlot}`(`Checkpoint(SaveSlot)` · `Load(SaveSlot)`;**`SaveOnExit()` 为空参退出钩子,不参与该断言**;
签名权威 = ADR-010 §Key Interfaces,2026-09-19 已由规则十四回填),多一参即 fail;该半守是 AC-7a-08/09 的判定面)。

**规则八 · 折叠谓词 `Folded(p)` 单一出处 = 7a。**(义务 4 · 9 的 AC-36 会签)
病史流终态折叠。三条件合并(一处,不散落各 AC / 各 ADR):
① **终态**(痊愈 / 死亡,9 的 AC-36)② **plateau / `relapse.*` 豁免**(AC-36)
③ **无未结案病例**(ADR-008 §六 —— 未结案病例被折叠删掉 ⇒ 病例回放缺环)。
> ⚠️ **2026-09-21 第二十七批登记(不代拍,归 `OQ-7a-9`)**:本谓词目前**按病人(p)整体折叠病史行**,
> 而病人 p 名下的 **`SkillGrown` 事件(29 的 F-29-4 掉级 fold 的输入、30 的成长真源)若一并被折掉**,
> `Level(s)@t` 的逐位重放即破(等级永不被死亡夺走 = 30 的机制承诺)。折叠行形状
> `(onset, 病种_id, patient_id, patient_seed, outcome, t_end)` **无成长载体** ⇒ 须裁:
> **折叠豁免扩一类 Kind** / **折叠行扩列携带成长摘要** / **改 fold 读侧**(29/51 从快照取基线)。
> 三案任选其一即闭合,**本批零机制改动**(29 的 AC-29-16 已改挂 `OQ-7a-9` 不记绿)。
折叠行 = `(onset, 病种_id, patient_id, patient_seed, outcome, t_end)`;**`patient_id` 必留**
(ADR-006 Amendment B:高水位可重构的前提 —— 折叠丢弃流位置、`patient_seed` 是
`hash(WorldSeed, patient_id)` 的**可重建派生值**(replay 参数,非不可重建通道;ADR-007
「掷骰输入须可从事件流重构」的不变量由该派生性坐实),不留 id 则高 id 病人折叠后
`max(patient_id)` 不可重构 ⇒ 撞号 = 两病人共写一份病程)。

**规则九 · `max(patient_id)` 重构扫三流并集。**(义务 5 · 高水位机制 A)
`next = max({ id | id ∈ 三流并集 ∧ id ≠ PatientId.None }) + 1`,由事件流**重构**,不作独立快照;
**空集 ≠ 未定义** —— 约定 `max(∅) = −1`(全空 / 仅含 `None` 两种情形结果相同),见 F-7a-3。
**计数器永不复位 0**(三条硬不变量,ADR-006 Amendment B)。
`ItemInstanceId.Next()` **同机制,扫描域一致**:`next(instance_id) = max({ instance_id ∈ 三流并集 ∧
非哨兵 }) + 1`(ADR-010 §五「由三流并集重构」;**不窄化到世界流 `Drop*` 事件** ——
`instance_id` 若亦现于病史流,窄扫描 ⇒ 高水位低估 ⇒ id 复用)。

> **2026-09-21 第二十七批补(兑现 ADR-006 注记残留③)**:玩家 id 计数器(`next_player_id`,
> registry 已具名登记)**共用本规则的扫描域与同一条重构路径** —— 扫描域 = 三流并集内全部
> 受伤实体 id **与**玩家 id 之并(ADR-006 注记:不引入第二 id 空间)。
> **7a 显式声明:不独立快照玩家 id 计数器**(高水位可由事件流重构 ⇒ 少一份可失步的状态,
> 承 ADR-006 Alternative 4 理据);存档头**无** `next_player_id` 字段位。

**规则十 · 迁移链逐版本脚本;`WorldSeed` 与已发生事件原样保留。**(义务 1/8 · ADR-010 §七)
`SaveVersion`(存档格式版本)决定迁移链入口;加载时逐版本升级(0 → 1 → … → N),每步一个
显式迁移脚本。**`WorldSeed` 与已发生事件在迁移中一律原样保留**(ADR-007 §二 硬约束:
`WorldSeed` 被改 ⇒ 全案病程与事件流同时作废)。`ConfigVersion` ≠ `SaveVersion`:前者决定
**后续窗口**用什么值(旧存档读入时,已发生事件不受影响),后者决定迁移链。

**规则十一 · 加载失败硬失败,绝不静默兜底。**(ADR-010 §四)
校验和失败 ⇒ 自动读 `bak`;成功则继续并提示「已回退到最近检查点」;两级都坏 ⇒ 提示损坏。
任何路径**不**静默新建空档 / 不 null 解引用。

**规则十二 · authority-agnostic(C6)。**(systems-index §8 C6)
9 的 tick 模型与 7a 的持久化从第一天起 authority-agnostic —— 同步点抽象、状态可序列化、
与 authority(单机 / 联机后主机)正交。**现在免费,P1b 重构是三个月级灾难**。

**规则十三 · 退出保存失败 = 限时重试 + 下次启动提示。**(2026-09-16 玩家裁定)
退出保存(`Application.wantsToQuit` 钩子,规则五)写盘失败 ⇒ 限时重试(默认 1s,
`SAVE_EXIT_RETRY_TIMEOUT` 旋钮),仍失败则**关盘后记日志**;下次启动检测到未完整保存会话 ⇒
**非阻塞提示**「上次会话未完整保存」。**不静默丢,不卡退**。

**规则十四 · 7b 手动槽契约:反 save-scum 的第三道守,契约立在这里。**
(**2026-09-16 玩家裁定「立契约」· 2026-09-19 承 7b 首轮评审补载入安全上下文门**)
7b 手动槽是反 save-scum 论证的软肋 —— 「恰好三个触发点」的计数防不了玩家趁自己**没犯错**时
手动存一份再作死(误诊前存一份恰是 scum 最优解)。7a **在这里立契约**,
7b 的 GDD 撰写时**只兑现呈现语义,不新增第四逻辑**:
- **槽位只进不退**:`Checkpoint(slot)` 只能写**按时间序递增**的槽位;覆盖已有槽位 = 覆盖
  **该槽位所辖叙事事件之后**的全部历史 ⇒ **违反「只进不退」,由 7a 拒绝**(写入层的护栏,
  `slot_seq` 单调递增校验,非 7b 的 UI 提示)。
- **读档即锁**:从某槽位载入后,该槽位在**同一会话内锁定 reads 侧**(禁止「先手动存,读档,
  再覆盖回去」的闭合回路 —— 该回路 = 事实上的 quicksave)。锁持续到下一次叙事事件触发 checkpoint。
  7b 呈现锁状态(灰置),禁载语义在 7a。
- **载入安全上下文门**(2026-09-19 用户裁定,承 7b 首轮评审 BL-1):读档**与写同钩** ——
  载入也须在「脉案落笔 / 病例结案 / 出诊启动」等**无未决医疗动作**的上下文(与手动存共用同一
  观察钩子)。**在未决动作进行中 / 出诊流程进行中请求载入 = 被 7a 拒绝**。堵:
  ①「带伤 / 带病 / 战斗中读档 = 逃生通道」(清除污名进度 = 事实上的逆转一次失败);
  ②「无未决动作窗口」恰好覆盖出诊前后 ⇒ 与存同约束,堵 7b 首轮评审 BL-1 的交替载入绕行。
  该门**不改变**锁的 per-slot 会话语义(两次载入的中间仍可再载入,只要在安全上下文内)。
  7b 的呈现后果:册子不可读时灰置页**与「写不可」同因** —— 均以「现在不是翻开册子之时」为册级门,
  单页灰 = 只进不退的「不能改写」,页级「读音 / 写因」双投影(见 7b F-7b.2)。
- **手动存须在无未决医疗动作的上下文**:槽位写入只允许在「脉案落笔 / 病例结案 / 出诊启动」等
  **叙事事件同步点**(与事件触发共用同一观察钩子);急救动作进行中 / 病人未处置的任意时刻
  手动存档 = **被 7a 拒绝**。7b 的 GDD 撰写时,该约束的**呈现**归它(灰置 / 文案),
  **语义**归 7a。
- **效果**:玩家能在**叙事事件之间**用手动槽「存档断点」,但**回不到任何一次判断之前** ——
  手动槽永远在**最后一个叙事事件之后**,恰与事件触发粒度同余。

### States and Transitions

7a 有**两个正交的状态机**:写入流程(存档服务)· 加载流程(读档服务)。两者由 Step 边界 / 启动事件驱动。

**写入状态机**(每份存档每次写盘走一遍;**in-flight 守卫见下**):

| 状态 | 进入条件 | 退出条件 | 行为 |
|------|---------|---------|------|
| `Idle` | 无待写数据 | 触发点在任一触发源(叙事事件 / 定时兜底(规则六)/ 退出 / 手动(规则十四))命中 | 无 IO;零成本 |
| `Dirty` | 任意触发源设脏 | 主线程进入 Step 边界 | 记录待写 buffer 的引用,不阻塞 Step |
| `Serializing` | Step 边界 | 序列化完成入缓冲池 | 主线程:头部 + 三流 + 快照 → 内存 buffer;**禁 Unity API 之外 IO**;SHA256 **不在此处**(后台,规则五) |
| `WritingAsync` | buffer 就绪 | 后台线程 `Flush(true)` 完成 | 后台线程:算 SHA256、回填头部、写 tmp;`IOException` ⇒ 退避重试(规则四);worker 顶层全兜 `try/catch`(规则五) |
| `Committing` | tmp 完整 | rename 成 final(或迁移 bak) | 原子替换;失败 ⇒ 回到 `Dirty` 下一触发点重写 |
| `Returning` | rename 完成 | 缓冲池回收 buffer | 释放引用;无持久失败状态 |

> **in-flight 守卫(2026-09-16 修订)**:同一时刻至多一份存档在 `WritingAsync` / `Committing`
> (one-writer 单飞队列) —— 上一份未 `rename` 完成时新触发 ⇒ 排队不并发,防两条
> `final→bak` + `tmp→final` rename 竞态把 `bak` 覆盖成半途产物。
> 退出保存:从 `WritingAsync` 起**限时 join**(默认 1s),未完成 ⇒ 规则十三(日志 + 下次启动提示)。

**加载状态机**(启动 / 7b 手动载入):

| 状态 | 进入条件 | 退出条件 | 行为 |
|------|---------|---------|------|
| `Unloaded` | 启动 | 选定槽位 | 无状态 |
| `Gating` | 7b 发起手动载入 | **在安全上下文 / 拒绝** | **2026-09-19 新增(承 7b 首轮评审 BL-1)**:载入安全上下文门 —— 无未决医疗动作才放行(C 语义);未决动作中载入 ⇒ 拒绝,返回「当前不可载入」 |
| `Verifying` | `Gating` 放行 | 校验通过 / 失败 | SHA256 校验,先 `final` 后 `bak` |
| `Migrating` | 校验通过且 `SaveVersion < 当前` | 逐版本升至当前 / 失败 | 每个版本跑显式迁移脚本(规则十);**`WorldSeed` 原样** |
| `Replaying` | 迁移完成 | 三流重放完 | 三流按全序重放重建模拟态;快照段用于表现态位置恢复(加载加速,非真相) |
| `Ready` | 重放完 | — | sim 就绪;后续写盘走写入状态机 |
| `Fallback` | `final` 校验失败,`bak` 通过 | 提示「已回退」后进 `Migrating` | 自动回退,玩家无打断(规则十一) |
| `Corrupt` | 两级都坏 | 提示损坏 | 显式报损坏;**不**静默新建空档 |

## Formulas

> **7a 的数学刻意少。** 本节只收入**真正写进判据、可以被独立验证的两条公式**:
> F-7a-3(高水位重构)与 F-7a-4(折叠谓词)。体积上界论证(ADR-009 §六 / ADR-008 §六 的有界性)、
> SHA256 覆盖范围、缓冲池旋钮等 **不立编号** —— 它们要么是定义(覆盖范围)、要么是恒等式论证
> (上界)、要么是实现纪律(缓冲池),机械证据由规则 + AC 提供,不需要公式层。

### F-7a-3 高水位重构(义务 5 · ADR-006 Amendment B)

**`next(id) = max({ id | id ∈ 三流并集 ∧ id ≠ PatientId.None }) + 1`**

**变量:**

| 变量 | 符号 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| 计数器的下一值 | `next(id)` | int64 | `≥ 0`({…} 非空时恒) | 新 authority 的 `IIdAuthority.Next()` 基线 |
| 三流并集中的 id 集合 | `{ id ∈ 三流 }` | int64 | `{…} = ∅` 时 `max(∅) = −1` | 由事件流**重构**,不作独立快照 |
| 哨兵排除 | `PatientId.None` | int64 | `= −1` | ADR-007 §四;不污染高水位 |

**空集约定与输出范围:** 排除 `None` 后集合可能为 `∅`(**全空** 与 **仅含 `None`** 两种情形
结果相同)。`max(∅)` 数学无定义 ⇒ **钉成约定 `max(∅) = −1`**,于是:
- `{…} 非空 (max ≥ 0)` ⇒ `next = max + 1 ≥ 1`;
- `{…} = ∅ (max = −1)` ⇒ `next = 0`,计数器从 0 起,不冲突。
(**2026-09-16 修订**:原「`max ≥ 0` 恒成立」与「`max = −1`」自相矛盾 —— 现口径:
`max ≥ 0` 仅对**非空集合**成立,空集由约定 `max(∅) = −1` 覆盖。)

**例:** 病史流 id 至 `{0,…,1023}`,病例流 `{4,512}`,世界流 `{1001}` ⇒ `max = 1023` ⇒ `next = 1024`。
三条硬不变量(ADR-006 Amendment B):① 计数器永不复位 0;② 任意权威变更后由三流并集重构;
③ 终态折叠行须保留 `patient_id`(规则八)。

**`ItemInstanceId.Next()` 同机制(义务 6 · ADR-010 §五):**
`next(instance_id) = max({ instance_id ∈ 三流并集 ∧ 非哨兵 }) + 1`
—— **扫描域 = 三流并集**(与 `PatientId` 完全一致;**不窄化到世界流 `Drop*` 事件**;`instance_id`
若亦现于病史流,窄扫描 ⇒ 高水位低估 ⇒ id 复用)。`Drop*` 事件**必须保留 `instance_id`**
(ADR-009 §五),否则掉落清单无从重构。

### F-7a-4 折叠谓词(义务 4 · 三条件单一出处)

**`Folded(p) = 终态(p) ∧ ¬豁免(p) ∧ ¬未结案(p)`**

| 条件 | 来源 | 内容 |
|------|------|------|
| `终态(p)` | 9 的 AC-36 | 痊愈 / 死亡 |
| `¬豁免(p)` | 9 的 AC-36 · **2026-09-16 口径对齐**:豁免 = **豁免类**(`lethal = false ∧ plateau`,R3.6)**或携带 `relapse.*` 块**。全 `plateau` 免豁会把 `plateau ∧ lethal` 型(可达终态、可折叠)误豁免,故豁免类必须带 `lethal = false`;`relapse.*` 病种回放需完整病程,不折叠(AC-36) | 
| `¬未结案(p)` | ADR-008 §六 | 该病人**无未结案病例**(37 的结案判定;`已结案` 由病例流 `CaseClosed` 事件可判 ⇒ 输入可从事件流重构) |

**输出:** 布尔。真 ⇒ 该病史行进折叠(折叠行保留 `patient_id`,规则八)。

**根本例 — `未结案` 可从流重构:** 查询病例流在该病人的 `CaseOpened` 事件及其后的 `CaseClosed`;
存在已开未闭 ⇒ `未结案 = true` ⇒ `Folded = false` ⇒ 不折叠(否则「该癌症的病例」回放缺环,
37 的改写史断)。该谓词的**全部输入 ∈ {事件流 + 烘焙数据}**,满足「可重建」不变量。

> **单一出处**:三条件**合并于本节一处**;9 的 AC-36 只定义 ①②,37 的结案判定只定义 ③,
> **7a 是唯一把三者合起来的地方**。任何新折叠条件只追加到这里。

## Edge Cases

> 三类各成一组:**故障类**(物理坏点,每个都要名字)· **快照 / 恢复类**(快照 = 优化非真相的边界)·
> **公式 / 边界类**(F-7a-3 / F-7a-4 的补强)。每条 = 「条件 → 精确结果」,无「处理得优雅」。

### 故障类(物理坏点)

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| **写盘中途崩溃 / 进程被杀(tmp 已写,final 未换)** | `final`(上一好档)完整,`tmp` 残留;加载只需 `final`,残留 `tmp` 下次启动清理。**玩家回到上一 checkpoint** | 原子写 tmp → rename 的配对保证。崩溃点永远在「要么旧档完整 / 要么新档完整」之间 |
| **rename 前后崩溃 / 进程被杀(新旧都可能存在)** | rename 原子 ⇒ 只有旧档或新档存在,不会被截断;加载不管哪个完整都进 `bak` 保护 | `File.Move` overwrite 原子性为**首个 spike 实测项**(规则四);掉电待实测后补档 |
| **`final` 与 `bak` 都坏** | 提示损坏,**不**静默新建空档、不 null 解引用 | 规则十一;静默重建 = 抹掉真相 |
| **`final` 坏但 `bak` 好** | 自动读 `bak`,提示「已回退到最近检查点」,进迁移链继续(玩家无打断) | 规则十一 / 状态机 `Fallback` |
| **篡改任一字节** | 校验和失败 ⇒ 走回退,不尝试「修复」 | SHA256 覆盖头部后全部字节;任何字节错位都逃不掉 |
| **杀软 / OneDrive / 双进程写同一份** | `IOException` 退避重试(带抖动),仍失败 ⇒ 保进下一触发点 | 规则四;`final` 唯一路径 + 双档 |

### 快照 / 恢复类(快照 = 优化非真相)

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| **快照损坏** | 三流仍完整重放;快照段**忽略**,表现态位置从世界流重建(缺失丢的是「上一次完整位置」) | 规则一;真相永远是世界流 |
| **快照缺失(0 字节 / 空段)** | 同上;加载变慢(要扫世界流找掉落位置),不失败 | 快照只是加载加速 |
| **快照跨版本不可读** | 迁移脚本更新三流时**顺带重建快照**(幂等);重建与重放结果一致 | 义务 8;迁移后快照是派生态,重新打出 |

### 公式 / 边界类(补强 F-7a-3 / F-7a-4)

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| **三流全空(仅 `None`)** | `max(∅) = −1`(**全空** 与 **仅含 `None`** 两种情形相同)⇒ `next = 0`,计数器从 0 起,不冲突 | F-7a-3 空集约定;`None = −1` 被显式排除 |
| **`WorldSeed` 边界(全 0 / 全 1)** | 合法;`WorldSeed = 0` 是合法种子(不是「未设置」) | ADR-007 §二:跨版本原样保留;0 没有特殊语义 |
| **高水位撞折叠**(高 id 病人全折叠) | 折叠行**保留 `patient_id`** ⇒ 高水位仍可重构;缺该字段 ⇒ 撞号 | 三条硬不变量 ③;规则八 |
| **崩溃回退跨一次致命误诊(规则六兜底防御)** | 定时兜底间隔的防御性下限 = **出诊周期级**(≥ 一个不可逆单位);崩溃回退的最近点绝不在「最后一个叙事事件之前」。**若某版本兜底间隔短于一个出诊周期:** 该版本崩溃回退 = 崩溃**发放**的后悔药,须**立即**修定为叙事事件粒度(见 `CHECKPOINT_INTERVAL` 旋钮) | `game-concept.md:143` —— 5 分钟 checkpoint 可横跨一次致命误诊(T+2 存、T+4 误诊、T+6 崩溃 ⇒ 读档把死人还给你);事件触发主粒度已消解此洞,兜底为防御下限 |
| **`ConfigVersion < 当前` 读档** | 已发生事件不受影响,后续窗口用新配置;存档头记 `ConfigVersion` 供排查回放不符 | ADR-010 §七:非致命,记录即可 |

## Acceptance Criteria

> **判据纪律(与 6 / 9 同型,吸取其首轮评审教训)**:全部 BLOCKING 判据**可判定** ——
> 「负存在断言」(「不应有 X」)不可反射证明,必须落成**可扫描 / 可反射的正面断言**;
> 不点名 AST,用 Unity 测试原语能执行的东西。
> **守 14 条规则 + 2 条公式各至少一条**;跨系统断言
> (黄金字节对拍 / 忘词令)标注其执行点。
> 每条主判据标注**所守规则 / 公式**:`AC-7a-NN(规则 N / F-7a-X)`。

### AC-7a-01(规则一 · 快照 = 优化非真相)

**GIVEN** 一份存档的快照段损坏 / 缺失 / 跨版本不可读,**WHEN** 加载该存档,**THEN** 三逻辑流
完整重放;**指定病人 outcome / 掉落清单 / id 高水位 == 直接重放世界流所得**(不因快照段
损坏而变);仅表现态位置回到「上次快照的位置」、加载变慢,**不失败、不提示存档损坏**(BLOCKING)。

### AC-7a-02(规则一 · 世界流是唯一裁判)

**GIVEN** 快照内容与三逻辑流不一致(快照是旧派生态、世界流才是最新事实),
**WHEN** 加载,**THEN** 各游戏事实以**世界流 / 事件流**为准 —— 断言**具体量**:指定病人 outcome /
掉落清单 / id 高水位 == 以世界流直接重放所得,快照只贡献加载加速与表现态位置(BLOCKING)。

### AC-7a-03(规则二 · 黄金字节对拍:编辑器 Mono vs IL2CPP 逐位一致)

**GIVEN** 同一份**具名存档夹具**(固定 WorldSeed + 固定三流输入;**夹具 id 与生成提交在本 GDD
之外的测试资产目录落为具名文件**,见 ADR-012 双级夹具),**WHEN** 在编辑器(Mono)与 IL2CPP 玩家
上各序列化一次,**THEN** 两条字节流**逐位一致**(字节哈希相等);这是 ADR-012 R-5 的对拍面,
由 CI 黄金夹具矩阵常驻执行,**重签须全体平台同时**(ADR-012 版本化刷新,禁单平台独签)
(BLOCKING · 执行点 = ADR-012)。

### AC-7a-04(规则二 · 全二进制 codec,禁位置化 / 禁 JSON)

**GIVEN** 一条三流事件(含 `Fix` 字段、`long` 字段),**WHEN** 写盘再读回,
**THEN** 字段值**逐位往返不变**;且三次序列化同一状态 ⇒ **三次字节流逐位一致**。
正向扫描判据:**点名扫描集** —— `design/gdd/persistence-service.md` 承约束的 sim 侧程序集
(门 A:`"noEngineReferences": true`)IL 扫描**零** `BinaryFormatter` / `JsonUtility` / `PlayerPrefs` 调用
(**可序列化类型集合由源码枚举,扫描对象 = 程序集产物目录**;注释 / 字符串字面量假阳性由
扫描工具置于白名单,不误伤)。
`Fix` 的 `long` 按**显式小端**写出,黄金夹具钉死字节序;小端编码**强制 `BinaryPrimitives`
显式小端**、**禁 `BitConverter`**(夹具结构上抓不到主机端序依赖) —— 该约束是新维度,**单独 IL
扫描断言**(BLOCKING)。

> **codec 隐式不确定面(2026-09-16 修订,与夹具互补的执行纪律)**:夹具能检出**跨平台字节差异**,
> 但抓不到**同类平台内的隐式不确定** —— ① **集合迭代序**:凡三流 / 高水位并集落盘前
> **按 key 规范排序**(禁 `foreach` 直写 `Dictionary` / `HashSet`,序随插入 / 重哈希变);
> ② **字符串字段**(`病种_id` / `item_key`):**UTF-8 无 BOM + 字节数长度前缀**(非字符数,
> 禁 culture 敏感格式化)。两者各加一条 IL / 行为断言,与夹具互补。

### AC-7a-05(规则三 · SHA256 校验,禁 Hash128)

**GIVEN** 一份已写盘的存档,**WHEN** 翻转文件中任一非校验和字节,**THEN** 校验和验证失败、
走回退路径;断言 **`final` 字节与 mtime 未变**(不尝试「修复」)。
判据端:IL 扫描断言校验和实现 = BCL `SHA256`(点名程序集),**零** `UnityEngine.Hash128` 引用
(BLOCKING)。
> **校验和覆盖口径(2026-09-16 修订)**:布局把 `Checksum` 放在头部**末**字段时,
> 「checksum 字段之后的全部字节」**不含头部** —— `WorldSeed` / `ConfigVersion`(ADR-007 硬约束)
> 将逃过校验。**修正:校验和段置于头部之**首**,覆盖其后的全部字节(含头部其余字段 + 三流 + 快照)**;
> 若保存在后,则口径改为「头部 + 三流 + 快照 全字节」。二选一,实现期以 AC-7a-05 为准。

### AC-7a-06(规则四 · 原子写 + 双档,进程被杀后 final 或 bak 必完整)

**GIVEN** 正在写盘,**WHEN** 在「tmp 已写 / rename 前后 / 已替换」任一断点**强制终止进程**,
**THEN** 重启后 `final` 或 `bak` 至少一份**通过校验和**;断言 `final` 哈希 ∈ {上一好档哈希,
新档哈希}(无「半写损坏的 final」,无第三哈希);残留 `tmp` 被清理(BLOCKING)。
> **执行点(2026-09-16 修订)**:崩溃注入**非 UTF 内可做** —— 须 **OS 级 kill**(POSIX `kill -9`
> / Win `TerminateProcess`)的**子进程 + 屏障钩子 harness**(测试进程开子进程跑 save,
> 屏障点让子进程自曝位置后 `kill`);该 harness 与 CI 跑格(哪几格跑 / 哪几格跳过)落
> ADR-012 的执行矩阵,qa-lead 评审判据、不评 harness 实现。

### AC-7a-07(规则五 · 后台线程写盘,禁 Unity API)

**GIVEN** 一个 checkpoint 触发,**WHEN** 写入发生,**THEN** 序列化在 Step 边界主线程完成,
**写盘 IO 与 SHA256 在非主线程**;`IOException`(杀软 / OneDrive 锁)按 `WRITE_RETRY_DELAY`
退避重试(BLOCKING)。
> **后台线程零 Unity API(2026-09-16 修订)**:运行时调用栈不可事后采集 ⇒ 改为**编译期断言** ——
> `WritingAsync` 状态被调集合(read only 数据的**被写集合**)做 IL 扫描,**零** `UnityEngine` 命名空间
> 被调;`Application.persistentDataPath` 的读取**主线程启动期缓存一次**(规则四),扫描证其
> 不在后台被调集内。

### AC-7a-08(规则六 · 存档触发点恰为三处,无第四入口)

**GIVEN** 已落盘的存档服务接口,**WHEN** 枚举全部可触发写盘的入口,**THEN** 恰好三个:
checkpoint(事件触发 + 定时兜底,2026-09-16 裁定「事件触发 = 调度策略,非第四入口」)/ 退出保存 /
7b 手动槽;**不存在**第四入口(无 quicksave、无「进战斗前自动存」)。
**判据 = 接口签名反射断言(`ISaveService` 公开可触发写入方法参数集恰等于 `{SaveSlot}` ——
`Checkpoint(SaveSlot)` · `Load(SaveSlot)`;`SaveOnExit()` 空参退出钩子不参与; ADR-010 §Key
Interfaces 2026-09-19 已回填)+ 接口级正面枚举 +
IL 正面断言(仅 `SaveService` 类可达 `FileStream.Write` / `File.Move`)三方守**(BLOCKING)。

### AC-7a-09(规则七 · 忘词令双守:q 系列 API 零符号)

**GIVEN** 全仓符号表,**WHEN** 判据端扫描 `quicksave` / `quickload` / `save-now-slot` 类标识符,
**THEN** 零命中(扫描集与假阳性白名单见 AC-7a-04);且 7a 服务接口中不存在「立即回滚点」参数
(判据 = **公开接口签名反射检查**:`ISaveService` 公开可触发写入方法参数集**恰等于** `{SaveSlot}`
—— 多一个「立即回滚点」类参数即 fail;该反射断言是 7a **自身可测的半守**,不依赖 ADR-012)。
**忘词令载体已裁(2026-09-16 用户裁定):符号扫描 / grep-IL 守卫脚本归 ADR-012 CI 门**,挂三格
常驻矩阵同流水线;qa-lead 只评审判据。`OQ-7a-2` 已闭合(BLOCKING)。

### AC-7a-10(规则八 · Folded(p) 三条件单一出处,未结案不折叠)

**GIVEN** 三种病人状态 —— (a) 痊愈且无未结案病例 (b) 痊愈但**有**未结案病例
(c)`plateau` / `relapse.*` 豁免型,**WHEN** 计算 `Folded(p)`(F-7a-4),
**THEN** (a) 真 ⇒ 折叠、(b) 假 ⇒ **不折叠**(否则病例回放缺环)、(c) 假 ⇒ 不折叠;
三条件合并**仅存在于 7a 一处**(9 的 AC-36 只有 ①②、37 的结案判定只有 ③)(BLOCKING)。

### AC-7a-11(规则八 · 折叠行保留 patient_id)

**GIVEN** 病史流发生终态折叠,**WHEN** 检查折叠行,**THEN** 折叠行以
`(onset, 病种_id, patient_id, patient_seed, outcome, t_end)` 落盘,**`patient_id` 必在**;
缺该字段 ⇒ 高水位不可重构、撞号(BLOCKING · ADR-006 Amendment B 三硬不变量 ③)。

### AC-7a-12(规则九 / F-7a-3 · 高水位扫三流并集)

**GIVEN** 三流中 patient_id 分布如:病史流 `{0,…,1023}`、病例流 `{4,512}`、世界流 `{1001}`,
**WHEN** 求 `next(patient_id)`(F-7a-3),**THEN** `max = 1023` ⇒ `next = 1024`;
`PatientId.None = −1` **不参与 max**;三流**全空**(以及**仅含 `None`**)时 `max(∅) = −1`
⇒ `next = 0`(计数器从 0 起,两种情形同结果)(BLOCKING)。

### AC-7a-13(规则九 · ItemInstanceId 同机制,无复用)

**GIVEN** `ItemInstanceId` 已发放至 `N` 且主线程序列化到存档,**WHEN** 迁移 / 重构计数器,
**THEN** `next(instance_id) = max({ instance_id ∈ 三流并集 ∧ 非哨兵 }) + 1`(**扫描域 = 三流并集**,
与 `PatientId` 一致;ADR-010 §五)—— `instance_id` 在病史流 / 病例流 / 世界流任一出现都计入;
**> 当前已用最大值,零复用**。`Drop\*` 事件保留 `instance_id`(否则掉落清单无从重构)(BLOCKING)。

### AC-7a-14(规则十 · 迁移链逐版本,WorldSeed 与已发生事件原样)

**GIVEN** 一份 `SaveVersion = k`(< 当前 N)的旧档,**WHEN** 加载,**THEN** 沿迁移链
`k → k+1 → … → N` 逐版本执行显式脚本;**`WorldSeed` 与已发生事件在迁移前后逐位不变**;
`ConfigVersion` 不匹配 → 已发生事件不受影响、仅记录并供排查(BLOCKING)。

### AC-7a-15(规则十一 · 加载失败硬失败:回退 / 报损,不静默兜底)

**GIVEN** (a) `final` 校验失败但 `bak` 通过,**WHEN** 加载,**THEN** 自动回退 `bak` 并提示
「已回退到最近检查点」,进迁移链继续;(b) `final` 与 `bak` 都坏,**THEN** 进入 `Corrupt` 态、
抛指定异常,**槽目录文件数不变**(不静默新建空档、不 null 解引用)(BLOCKING)。

### AC-7a-16(规则十二 · authority-agnostic:同步点与形状正交)

**GIVEN** 同一份三流输入,**WHEN** 分别在「单机权威」与「模拟的主机权威」两种 authority 布局下
序列化(**authority 布局 = 可注入测试替身,非全局单例**),**THEN** 产出字节流**逐位一致**
(同步点抽象与 authority 正交,9 的 tick 模型不需要为联机改形状)(BLOCKING)。

### AC-7a-17(规则十三 · 退出保存失败:限时重试 + 下次启动提示)

**GIVEN** 退出保存(`Application.wantsToQuit` 钩子,规则五)写盘失败,**WHEN** 按
`SAVE_EXIT_RETRY_TIMEOUT`(默认 1s)限时重试后仍失败,**THEN** 不阻塞退出、记日志;
下次启动检测到**会话未完整标志位(头字段 / 标志文件)** ⇒ **非阻塞提示**「上次会话未完整保存」
(提示承载归 42 / 7b,7a 只断言标志位置位)(BLOCKING)。

### AC-7a-18(全局 · 存档与事件流零 float)

**GIVEN** 三流载荷类型表与存档头字段表,**WHEN** IL 扫描**点名程序集**的全部可序列化类型
(扫描集 = 门 A sim 程序集 + 边界层承载 codec 的程序集<!-- ⚠️ 2026-09-20 ADR-025 回写加注:
「边界层承载 codec 的程序集」现名 = `Sim.Codec`(ADR-025 §①:`Fix` 自定义编码器住此,
`internal` + `InternalsVisibleTo("Sim.Contracts.Tests")` —— D-21-18 守卫的可执行形态) -->),**THEN**
**零** `float` / `double` 字段(ADR-006 拒浮点;`Fix._raw` 是 `long`);扫描正向断言
(可序列化类型的字段类型 ∈ 整数域白名单,白名单枚举于测试资产,非实现内联)(BLOCKING)。

### AC-7a-19(规则十四 · 7b 手动槽契约:只进不退 / 读档即锁 / 叙事事件上下文)

**GIVEN** 玩家主动手动存档,**WHEN** 三场景 ——
(a) 写**时序递增**槽位(上次叙事事件之后):允许;
(b) **覆盖既有槽位**(`slot_seq` 不增):被 7a 拒绝(`slot_seq` 单调校验,非 7b 提示);
(c) 在**无未决医疗动作的上下文之外**(急救动作进行中 / 病人未处置):被 7a 拒绝;
**AND** 从某槽位载入后,该槽位在同一会话内 **reads 侧锁定**(锁持续到下一次叙事事件触发
checkpoint),再次读该槽 = 被拒 —— 断言的闭合回路:「先手动存 → 读档 → 再覆盖回去」
任一环被 7a 拒绝(BLOCKING)。

### AC-7a-20(规则六 · 事件触发 checkpoint:叙事事件锚点白名单)

**GIVEN** 叙事事件白名单 `EVENT_CHECKPOINT_ANCHORS`(脉案落笔 / 病例结案 / 出诊启动,
只增不删,2026-09-16 玩家裁定),**WHEN** 任意白名单事件被提交,**THEN** 在**该事件的 Step 边界**
触发一次 checkpoint;**非**白名单事件(普通世界流事件)不触发;若叙事事件长期缺席(初次启动 /
纯探索期)由 `CHECKPOINT_INTERVAL` 定时兜底触发 —— **事件触发 = 调度策略,非第四存档入口**
(与 AC-7a-08 相容)(BLOCKING)。
